# M01「多房间连续体」v0.1 审查

结论：**视觉气氛通过，怪物原型不通过。保留为构图底图，不能作为最终设计定稿。**

## 已成立

- 千禧年前后沿海酒店客房走廊的材质、灯光和尺度可信；
- 画面能够被直接想象成第三人称游戏镜头，而不是概念海报；
- 同一件湿外套在多扇门出现，初步制造了“究竟有几个人”的不安；
- 镜子被放到视觉中心，玩家能自然用它验证现实；
- 没有依赖血浆、海洋外壳、长发女鬼或常规感染脸。

## 核心失败

### 1. 镜中只是一个横向伸展的人

镜中姿态仍可被理解为一个普通人弯腰伸手，甚至像舞蹈或失去平衡。它没有显示身体被多个房间深度反复折叠，因此最重要的空间恐怖缺失。

### 2. 现实局部与镜中全身没有严格对应

现实有近门的头肩和中门的手，镜中却没有让服装接缝、肩部转动、手的位置与这些局部形成一一对应。观众更容易理解成三个人或超自然复制，而不是一具身体。

### 3. 人体仍然太完整、太容易读

近门露出大半个上身，镜中又出现完整人形。怪物的真相过早退化为“这个人身体很长”，没有经历从正常背影到空间结构错误的二次识别。

### 4. 没有攻击可能性

画面阴森，但看不出身体如何借门重新分配、夹击或拖拽玩家。它仍像一个被观看的异象，不像主动猎手。

## v0.2 唯一修改目标

不增加新器官、不增加血浆、不增加海洋装饰。只强化一件事：

> 镜中全身必须像一张被房间深度折了三次的纸带；每一次折返都在一扇门框处发生，而现实中对应门框只露出那一折的局部。

具体视觉校验：

- 近门现实只保留后脑、半肩，不再出现大半个身体；
- 中门现实出现同一外套的肘部与手；
- 远门现实出现腰胯或一条承重腿；
- 镜中恰好只有一头、两臂、两腿，且衣服接缝连续；
- 镜中身体至少三次改变朝向，折点严格落在三扇门框上；
- 最近的手已经从观众视角后方的门伸入画面，明确产生包抄感。
