# H00-C 前台危机后 v0.1 审查

结论：**全景探索主机位通过；钥匙格异常的近景表达未通过。**

## 通过

- 与 H00-A 的机位、柜体、前台、CRT、总机、台灯和年代质感高度一致，能够形成记忆差分；
- 现实人物全部消失，电话听筒与椅子保留动作结果，失踪首先是生活层面的暴力；
- 左侧入口低雾从地面进入，没有形成整层雾平面；
- 右侧镜面保留婚宴，直接可见空间无人，构成次级时间矛盾；
- 四个异常格口集中在柜体中部，其余钥匙格保持正常，没有全屋异变；
- 暖灯仍亮、材质仍普通，避开熟悉的“切换到血肉／铁锈／蓝灰异世界”。

## 未通过

- 格口内的床、浴室、门和地毯虽然可辨，但在全景比例下仍像精致微缩模型；
- 缺少移动视角产生的视差，单帧无法证明它们是完整房间；
- 钥匙在边界两侧的重力变化没有形成；
- CRT 中的未来手部痕迹太小，当前帧无法读取；
- 画面尚未证明这些格口会威胁玩家，只证明了空间异常。

## 游戏内解决方式

不继续破坏这张全景。将它作为危机后主后景板，异常通过实时层与第二机位完成：

1. 玩家点击／靠近钥匙柜，固定镜头推进到柜体占画面 45% 以上；
2. 四个格口使用独立 SubViewport 或预渲染短循环，产生真实视差；
3. 两把钥匙牌使用实时骨骼／绳链模拟跨越重力边界；
4. CRT 使用独立可替换屏幕纹理，提前显示 M01 的手；
5. 三个格口按延迟播放同一次呼吸，第四格随后承受墙体闷撞；
6. M01 的局部只在玩家看完 CRT 后进入现实格口。

全景负责气氛与记忆差分；近景负责原理、威胁与互动。两者不能由一张图同时承担。
