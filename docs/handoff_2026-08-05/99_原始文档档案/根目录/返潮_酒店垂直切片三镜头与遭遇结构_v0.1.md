# 《返潮》酒店垂直切片：三镜头与遭遇结构 v0.1

> 目的：把“CRT 预现、器官全貌、可玩威胁”从一张过载概念图拆成三个连续、可实现、可验证的游戏镜头。

## H01A：电视先看见

### 画面

前景是一台放在前台侧柜上的老式 CRT，约占画面三分之一。屏幕显示同一大堂的固定闭路机位：酒店发育器官已经跨过红毯闭合，过滤扇正压在玩家即将经过的位置。

屏幕外的真实大堂仍然空着，只出现三个极早征兆：

- 左侧消防管冷凝水逆向爬升；
- 电梯钢缆在没有轿厢移动时短促绷紧；
- 雾被尚不存在的体积推出一个缓慢移动的凹面。

电视画面中不出现随机鬼脸和数字 glitch。未来器官清晰到足以让玩家理解危险区域，发生时间却不可判断。

### 声音

- CRT 行频轻微下滑；
- 屏幕里先传来过滤扇合拢的密集擦碰；
- 现实仍然安静；
- 当现实第一根钢缆绷紧，屏幕声音与现实之间的延迟开始缩短。

### 玩家行为

玩家可以继续穿过红毯、绕到前台后方，或靠近电视观察。没有强制看完动画，也没有倒计时提示。

## H01B：酒店开始发育

### 画面

使用 v0.6 的大堂全景机位，但重构实体：

- 三个清晰锚点分别来自地面、柱体和电梯；
- 中央没有完整躯干，只存在偏心关节与两个液压囊；
- 三束透明韧带承担主要受力；
- 支撑分支压住二层结构；
- 三组不共面的过滤叶阵列朝向回风口展开；
- 建筑负形清楚显示矿物支架来自酒店材料；
- CRT 在远景只保留亮度变化，不承担叙事阅读。

### 发生过程

玩家不观看“完整变身动画”。不同部件在玩家移动与声音间隙中逐步获得位置：

1. 液压囊先充盈；
2. 地面支撑板抬起；
3. 电梯配重下降，钢缆收紧；
4. 偏心关节离开地面；
5. 过滤阵列从雾中展开；
6. 红毯上方第一次形成闭合危险区。

## H01C：它使用酒店捕捉玩家

### 画面

机位降低到红毯附近。前景可见纤细过滤叶阵列正在从两侧不同角度合拢；中景是仍可通过的窄路线；背景前台电话、消防阀与电梯控制构成可干预物。

怪物不是直接追逐：

- 玩家踏上石材时，振动沿栏杆传至关节；
- 器官让电梯钢缆收缩，把过滤阵列转向玩家；
- 玩家踩回地毯，振动减弱，过滤阵列继续执行电视中已显示的旧姿态；
- 玩家制造新的结构声，CRT 蓝图重新构图，器官随后改变闭合方向。

### 一次完整玩法循环

1. 从 CRT 获得“红毯将被闭合”的不完整知识；
2. 观察现实消防管、电梯钢缆与雾压，判断发育已经开始；
3. 选择快速穿过红毯或绕入前台后方；
4. 用前台电话铃／行李车撞击／电梯召唤制造一次误导振动；
5. 过滤阵列朝错误方向闭合；
6. 玩家从支撑板留下的建筑负形进入客房连接段；
7. 电视画面更新为下一地点的身体配置，建立后续威胁。

## 资源边界

### 预渲染

- H00 正常营业大堂；
- H01A 真实空大堂底板；
- H01B 三个发育状态底板；
- H01C 低机位背景；
- CRT 的两段未来姿态视频；
- 建筑负形、雾遮挡和前景过滤叶遮罩。

### 实时器官

- 三块主锚板；
- 一个偏心关节；
- 两个液压囊 shape key；
- 三束主韧带；
- 两条分支；
- 三组过滤叶，每组使用实例化与统一相位控制；
- 三条电梯钢缆和一条消防压力输入；
- 三个动画状态：发育、采样、闭合。

### 实时声音

- CRT 预声与同步差；
- 消防压力波；
- 电梯配重与钢缆；
- 矿物支撑板起裂；
- 透明韧带受力；
- 三组过滤叶不同频段的擦碰；
- 雾被大体积排开的低频空气声。

## 视觉门顺序

1. 先做 H01A，验证“电视比现实先看见”能否一眼成立；
2. 再修 H01B，验证器官是否原创、功能明确且可拆 rig；
3. 最后做 H01C，验证它是否提供可玩的威胁而非静态奇观；
4. 三张都通过后才进入 Blender／Godot 正式重构。
