# 《返潮》异形方法与灭世生物恐怖原型 v0.1

> 本稿不复制《异形》的头部、黑色甲壳、肋骨、管线、卵与寄生生命周期。吸收的是其创作方法：生物形态、环境、繁殖方式和功能结构属于同一套生命逻辑；再与生态恐怖、宇宙生物恐怖、深时古生物和《返潮》的酒店／CRT／海雾结合。

## 1. 这次吸收什么，不吸收什么

### 从《异形》与 Giger 吸收的方法

Ridley Scott 回忆，他看到 Giger 的 `Necronom IV` 与 `V` 后，坚持让电影生物沿其形式发展，因为其中的恐怖与美感同时成立。Giger 的“biomechanics”并非简单把齿轮贴到肉上，而是机械与有机结构共同组成一个无法干净拆开的世界。

对《返潮》最有价值的不是某个著名轮廓，而是四个原则：

1. **环境与生物同源**：怪物进入的地方本来就已经使用它的形态语言；
2. **每个局部都有功能**：关节、外壳、孔、管、叶片和动作能够回答它如何呼吸、感知、捕食或发育；
3. **个体只是生命周期的一段**：玩家看到的形态不是“最终 Boss”，而是更大繁殖／发育过程的局部；
4. **美感与恐惧同时存在**：必须拥有精确、克制、可以凝视的结构，而不是纯粹堆脏与堆刺。

### 明确不使用

- 长而光滑的后脑壳；
- 黑色油亮外骨骼；
- 暴露的肋骨式胸腔；
- 金属软管铺满全身；
- 内外双口、酸液、抱脸寄生与卵舱；
- 女性生殖器、男性生殖器与强迫性性暴力意象；
- 太空船／巢穴使用与怪物完全相同的 Giger 纹样。

借这些元素只会得到低质量仿作；借“功能、生命周期、环境同源”才可能形成原创。

## 2. 用户提到的类型如何定位

没有一个唯一固定名称能完全概括“灭世的生物恐怖”。对《返潮》有用的是几个领域的交叉：

- **生态恐怖（ecohorror）**：恐怖来自人与环境关系失去既有秩序；传统形式常把自然当作外部敌人，更新的方向更强调人体、社会与环境原本就互相嵌套；
- **生态怪诞／eco-weird**：保留科学内部逻辑，同时拒绝让人类获得完整解释；
- **宇宙生物恐怖**：生命的尺度、时间和目的超出人的位置，人类不是被仇恨，而是失去作为观察中心的资格；
- **生物末日／生态末日**：真正的灭世不是巨兽踩平城市，而是支持人类生活的环境被另一套生命过程持续改造成别的用途；
- **生物机械恐怖**：机器、建筑和生物功能无法再分开，日常基础设施成为器官，而非怪物身上的装饰。

《返潮》的主方向确定为：

**具有宇宙尺度后果的生态—生物机械恐怖。**

怪物不是“海洋报复小镇”，也不是“远古动物复活”。返潮让一种发育逻辑获得材料，酒店只是它当前使用的一枚临时器官。

## 3. v0.5 为什么仍然失败

已归档的 v0.5 图有大尺度，却没有生物恐怖：

- 八个外板变成相似的圆环，像一串悬浮机关；
- 内侧叶片被画成统一牙齿，功能从滤食退化为通用攻击符号；
- 板间没有真正的组织关系，只是间隔排列；
- 外壳从墙里出来，却没有酒店系统参与它的生命活动；
- CRT 只是角落里的彩蛋，不是生物感知的一部分；
- 玩家只能想象它砸下来，无法想象它怎样生长、判断、繁殖或改变世界。

因此“大”不等于“灭世”，“古生物”也不等于“生物恐怖”。

## 4. 新核心：酒店不是外壳，而是发育器官

返潮中的古海矿物外板仍然保留，但只作为一种古老的**发育支架**。真正的新生命由现代酒店系统补齐早已消失的软组织功能：

| 酒店系统 | 被接管的生物功能 | 玩家可见的变化 |
|---|---|---|
| 消防与供水管网 | 液压运动与体液压力 | 管内水逆流，压力波令外板关节依次抬起 |
| 电梯钢缆与配重 | 肌腱与收缩储能 | 钢缆不被肉覆盖，而是被湿透明韧带包裹并跨接不同外板 |
| 空调风道与回风口 | 呼吸与过滤 | 风道内侧长出矿化滤叶，吸入海雾，呼出无水的冷空气 |
| 地毯、窗帘与合成纤维 | 暂时性软组织 | 纤维溶解成层状湿膜，只存在于活动关节附近 |
| 铜线、闭路线缆与 CRT | 本体位置感与发育模板 | 屏幕先显示器官下一姿态，现实随后按该姿态生长 |
| 客房与走廊 | 分节生长空间 | 每一间房只容纳同一器官的一段，关门会改变局部压力 |

这不是把管子做成血管的视觉比喻，而是明确规定：如果移除某套酒店设施，实体会失去一种能力。建筑系统成为可玩的生物学。

## 5. CRT 不是预言机，而是它的“身体蓝图”

老 CRT 预先显示恐怖事件的想法保留并升级。

屏幕显示的不是未来录像，而是这套生命过程正在尝试实现的**下一份身体配置**。图像先于物质出现，就像胚胎发育中先存在空间梯度，细胞随后才抵达位置。

游戏内永远不解释“形态发生场”之类术语，只让玩家观察一致证据：

- 电视中的外板已经弯曲，现实外板仍然平直；
- 电视显示一条尚不存在的湿韧带连接两层楼，随后电梯钢缆开始自行收紧；
- 电视中的怪物身后没有某扇门，现实数分钟后那扇门被新组织封闭；
- 玩家改变电梯、消防泵或回风系统后，电视画面先重新构图，实体随后改变发育方向；
- 完全断电不会消除蓝图，屏幕余辉仍会在黑暗中短暂保留下一姿态。

因此 CRT 同时是：

- 怪物的本体感觉器官；
- 玩家预测危险的工具；
- 返潮“未发生之物也能返回”的证据；
- 从酒店局部危机通向全镇灭世规模的传播节点。

## 6. 第一实体不再是一条完整前肢

玩家看到的是一个尚未决定最终形态的**发育器官**，当前借用了古海滤食附肢的局部方案。

### 总体轮廓

- 只有一条明确主轴，从电梯井下方伸向三层挑空，不再螺旋排列八个圆环；
- 近端是三块巨大的矿化支撑板，分别锚定地面、柱体和电梯结构；
- 中段由两条不对称关节链分叉，一条负责支撑，一条负责采样空气与湿度；
- 远端展开一面扇形过滤器，但扇面由长短不同的细密滤叶构成，能像深海生物的捕食附肢一样改变开合面积；
- 外壳板之间出现有限、功能明确的湿组织：透明韧带、液压囊和收缩纤维，而不是完全空白或全身肉化；
- 整体看上去正在学习如何在空气与建筑中活动，没有成熟动物的左右对称与完成感。

### 材料

- 古海矿化板：灰白、烟褐、局部半透明，有沉积层与应力裂纹；
- 新生韧带：近乎无色，只有水分、张力纹和细小气泡使其可见；
- 人造参与物：钢缆、玻璃纤维、织物纤维与铜丝保留来源，但被重新编排；
- 内部流体：不是血，是高盐、含矿物颗粒的近黑海水，在强光下出现层流；
- 不使用全身黑亮甲壳、工业软管美学与肉色组织。

### 动作

- 消防泵启动：液压囊充盈，近端三块支撑板错时抬起；
- 电梯配重下降：韧带被拉紧，整个器官完成一次储能；
- 回风系统吸气：过滤扇面朝雾中展开，所有细叶先后对齐；
- 捕捉到振动：器官不扑向玩家，而是让酒店系统把玩家所在路线折入它的闭合区；
- 动作完成以后，CRT 中的下一配置立即变化，证明当前形态只是连续发育的一帧。

## 7. 真正的“灭世”在哪里

它不靠一只酒店巨物毁灭世界。更恐怖的是：**它的后代不是卵、幼虫或孢子，而是一份能够在潮湿基础设施中自我实现的身体配置。**

传播链如下：

1. 酒店器官通过供水压力、闭路信号、电网噪声和雾中低频形成同一节律；
2. 镇内其他 CRT 首先出现不属于本地房间的器官蓝图；
3. 墙内管线开始按蓝图改变压力，矿物、金属与合成纤维逐步取得功能位置；
4. 不同地点不会复制同一怪物，而会根据当地设施发育成不同器官；
5. 当足够多的器官形成，它们共同建立一种适合古海生命逻辑、却不再适合人类居住的海岸生态；
6. 人类文明不是被杀光，而是住宅、道路、医院、酒店和通信逐渐不再以人的身体为尺度工作。

这使返潮具有灭世潜力，又不需要在 Demo 中展示巨浪、军队与全球新闻。

## 8. 全镇不同地点的器官差异

酒店只负责“姿态预现与关节发育”，不能把同一结构复制到全镇。

- **酒店**：CRT／闭路网络成为身体蓝图与本体感觉；电梯、消防、空调驱动关节和过滤器；
- **海洋馆**：观察玻璃、循环泵和巨型骨架形成深度感知与摄食器官；
- **广播／邮电设施**：模拟信号与线路延迟形成跨地点的神经传导；
- **卫生所**：冷藏、输液与人体记录形成错误的修复／免疫器官；
- **住宅**：家庭物件与潮湿墙体形成记忆和认领的局部组织，但规模保持私人化；
- **港区与旧厂**：吊机、取水、冷库和管网形成大尺度运动与代谢器官。

不同器官共享一套发育节律，却拥有不同恐惧主题。游戏因此可以容纳更多内容，而不是每关换一种海洋贴图。

## 9. 宇宙恐怖的边界

- 不出现远古神祇、教团、符文和召唤仪式；
- 不让居民早已知道完整宇宙真相；
- 不解释它来自外星、未来、古海还是某种未实现的进化分支；
- 不给玩家一份可以彻底阻止生命过程的“核心样本”；
- 不把灭世归咎于某个家庭、某个工人或某个传统犯错；
- 人的哀悼与送面习俗只改变了边界条件和认领方式，不创造这种生命；
- 恐怖来自人类生活暂时借用的一切材料，可能从来不只属于人类的历史。

## 10. 对下一版视觉图的要求

下一张图不再画悬浮壳环。它必须显示一个已经拥有生物功能、又尚未完成发育的酒店器官：

- 三块不相似矿化支撑板锚定地面、柱体与电梯井；
- 电梯钢缆被近透明湿韧带包裹，成为跨层收缩结构；
- 消防／供水压力推动一组液压囊，但没有红色血肉；
- 远端展开一面不对称密集过滤扇，滤叶具有真实功能；
- CRT 清晰显示它下一次闭合后的姿态；
- 酒店空无一人，海雾只负责显出运动与尺度；
- 缩略图首先读到一个具有姿态和方向的完整器官，而不是一堆圆环、骨头或管线。

只有这一版通过，才进入 Blender 结构设计。

- H.R. Giger 官方资料保存了 Ridley Scott 对 `Necronom IV/V`、恐怖与美感以及 Giger 参与《异形》设计的回顾：<https://www.hrgiger.com/alien4a.htm>

- Cambridge 对 SF 与 weird 的区分提醒我们：形态应有可相信的内部科学逻辑，但整体原因不必被解释完：<https://www.cambridge.org/core/books/abs/cambridge-companion-to-american-horror/sf-and-the-weird/AD1BBAD2238ECADF583262CFDD74AFB5>
- Cambridge 的 EcoGothic 研究强调恐怖可以从家庭现实跨越到行星尺度，适合《返潮》从酒店局部推向环境接管：<https://www.cambridge.org/core/books/abs/cambridge-companion-to-victorian-literature-and-the-environment/ecogothic/5AE6EE3EB1EB4D2EB7546378B481B311>
- Nature Communications 对滤食型 radiodont 的研究显示，真实过滤附肢依赖大量细长、密集、功能明确的刚毛／叶片，而不是统一粗刺：<https://www.nature.com/articles/s41467-018-06229-7>

这些来源只提供方法、生态尺度与功能形态依据；下一版不得复刻任何现成怪物轮廓。
