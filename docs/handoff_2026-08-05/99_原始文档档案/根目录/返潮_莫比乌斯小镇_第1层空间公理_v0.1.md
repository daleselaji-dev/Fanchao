# 《返潮》莫比乌斯小镇：第 1 层空间公理 v0.1

> 本层只回答：蚀湾怎样成为一张连续却只有一面的城镇表面。
>
> 本层不回答：成因、人物、怪物、玩法代价、剧情解释和具体美术风格。

## 1. 工作模型

蚀湾不是被卷成一个夸张的物理纸环。它仍使用正常重力、正常建筑尺度和可连续行走的局部地面。

莫比乌斯性质发生在**城镇方位框架**中。沿核心路线前进一整圈后：

- 行进方向仍连续；
- 重力仍向下；
- 同一地点仍能被认出；
- 但“海侧／陆侧”“建筑正面／背面”“路线内圈／外圈”中至少一组分类翻转。

简化表达：

```text
起点：route_parity = 0，海在道路左侧，市场面向陆地
连续走完一圈
终点：route_parity = 1，仍在同一市场，但海陆与建筑正背面的归属已经交换
再次走完一圈
回到：route_parity = 0
```

这使玩家第一次回到起点时处于“同一地点的另一面”，第二次才回到原始方位。

## 2. 七条空间公理

### 公理 A：局部欧氏，城镇非欧氏

玩家周围约 0—30 米保持可信：路宽、台阶、房间尺度、重力和碰撞都正常。异常主要在 30—500 米的路线、地标、天际线和回程关系中显形。

作用：防止项目再次退回门缝怪物、局部镜子或随意拉伸走廊。

### 公理 B：翻面必须连续

玩家不能指出“这里加载了异世界”。道路材料、步伐、天气或至少一个远处地标在整个过程里连续存在。黑场、传送门和强制昏迷不算通过。

### 公理 C：一圈翻面，两圈复原

任何核心环路都携带一个奇偶状态 `route_parity`：

- 走完奇数圈，至少一组海陆／内外／正背分类翻转；
- 走完偶数圈，分类才回到原状态；
- 同一地点在两个奇偶状态下共享大部分局部资产，但拥有不同的远景、朝向解释和可见连接。

### 公理 D：地标不消失，只背叛方位

广播塔、防波堤灯塔、冷库烟囱、海洋馆穹顶等大地标不能随机出现或消失。它们应在过长的路段中持续可见，却逐渐占据不可能的方位：本该在身后的灯塔缓慢移到前方，本该隔海相望的烟囱出现在山坡内侧。

地标因此不是导航奖励，而是玩家判断世界已经翻面的证人。

### 公理 E：海岸既是边界，也是接缝

蚀湾的海不是地图最外圈。沿不同路线向“内陆”前进，最终仍可能在正前方看见同一片海；从海边回望城镇，也可能看见自己刚才走过的道路位于海的另一侧。

海面负责显露城镇表面的连续折返，不负责充当怪物或能量源。

### 公理 F：天空、地平线和建筑共同翻面

全镇级异常不能只改一栋楼。每次主要视觉证据至少包含三者中的两者：

- 地平线的高度或弧度；
- 一个跨区域地标的方位；
- 中景街区的正背面／海陆关系。

天空不使用全屏扭曲。它通过云层消失点、雾层厚度、远山遮挡和海天线与地面几何共同证明错误。

### 公理 G：翻面留下状态，不是一次镜头戏法

玩家离开镜头后，奇偶状态仍保留。NPC 路线、远景方位、地图批注、窗外景观和返回入口都读取同一个 `route_parity`，不能各演各的超现实。

## 3. 后续构建必须使用的状态变量

| 变量 | 含义 | 美术用途 | 引擎用途 |
| --- | --- | --- | --- |
| `zone_id` | 当前现实区域 | 确定本地建筑、材料与社会功能 | 流送单元 |
| `fold_phase` | 当前路线从 0 到 1 的连续翻面进度 | 控制地标漂移、地平线、雾层和街区显露顺序 | 路线曲线参数／全局状态 |
| `route_parity` | 已完成翻面的奇偶数 | 决定同一地点处于哪一面 | 0/1 持久状态 |
| `coast_bearing` | 玩家此刻感知的海岸方位 | 组织海天线与声源 | 导航与远景旋转基准 |
| `landmark_set` | 当前视野必须保留的远处地标 | 防止远景随意换图 | 可见性与 LOD 集合 |
| `face_class` | 建筑被视作正面、背面、内侧或外侧 | 控制入口、窗、服务面和背街资产 | 连接规则与资产变体 |
| `return_signature` | 玩家以何种状态回到熟悉地点 | 为同地对照关键帧提供差异 | 检查点／存档证据 |

这些变量不是玩法 UI。它们是后续地图、美术、流送和可视化使用的共同语言。

## 4. 三条路线证明

### R1：环湾海堤——水平翻面（主路线）

**路线**：新市场停靠点 → 港池海堤 → 泵站 → 家属区高坡 → 冷库背街 → 新市场停靠点。

**连续证据**：灯塔和广播塔始终可见；路面由沥青、堤面水泥和家属区水磨石连续过渡；没有室内传送。

**翻面结果**：

- 出发时海在左侧，市场正门朝陆地；
- 行程中灯塔从身后缓慢移动到前方，但玩家没有掉头；
- 接近终点时，海同时出现在冷库背街尽头和市场正门方向；
- 返回同一停靠点时，站牌、时钟和店铺仍是原物，但市场正门被理解为临海一面，`route_parity` 从 0 变为 1。

**为什么选为首个视觉／技术原型**：它同时暴露海岸、街区、远景和回程，能够证明是全镇翻面，不会退化成一个房间的机关。

### R2：广播塔坡路——垂直翻面

**路线**：家属区晾衣场 → 旧村坡巷 → 学校挡土墙 → 广播塔平台 → 家属区晾衣场。

**连续证据**：玩家一直上坡，广播塔杆体始终在视野上方，重力和脚步正常。

**翻面结果**：到达平台后没有下坡，前方坡路却自然回到山脚；回望时，广播塔仍在“上方”，但塔基已经位于海天线以下。高处／低处不被简单颠倒，而成为同一坡面的两种归属。

**验证用途**：证明系统不只会做水平地图循环，也能处理海拔、天际线和遮挡层级。

### R3：县道末班车——边界翻面

**路线**：新市场 → 县道 → 盐田外缘 → 海雾路段 → 港区进镇口。

**连续证据**：车辆保持单向行驶，路灯编号和电线杆顺序连续，镇区灯光在后窗逐渐变远。

**翻面结果**：巴士没有掉头，却从本应位于海侧的港区入口重新驶入蚀湾。离开小镇的道路成为进入小镇的道路；前窗与后窗看到的天际线在中途短暂属于同一方向。

**验证用途**：定义世界边界，阻止后续用封路、空气墙或任意迷雾遮蔽“镇外不存在”的问题。

## 5. 第一组美术证据规格

第 1 层不先画怪物、人物剧情或局部室内，只画 R1 的四张同天气宽画幅关键帧：

1. **F0 起点**：市场、海堤、灯塔与广播塔建立正常方位；
2. **F1 漂移**：玩家未转身，灯塔已占据前侧方，海仍在左边；
3. **F2 双海岸**：冷库背街两端都被同一片海天线封住，中景街区仍可行走；
4. **F3 另一面起点**：回到同一市场机位，前景物件不变，整座街区的海陆与正背关系已经翻转。

四张图必须使用同一时段、天气、地标形状和人物密度。不能用换季、天色突变或空场差异冒充空间翻面。

## 6. 第 1 层通过门

必须同时满足：

- 一条路线可以被画成连续图，而不是靠“然后传送”连接；
- 走完一圈后存在清楚的奇偶翻转，两圈才能复原；
- 任一关键帧的主要异常占据至少中景和远景，不藏在局部道具；
- 去掉 NPC、字幕、声音和故事，空间仍然不可能；
- 地标、地平线和街区资产能明确拆给下一层使用；
- R1、R2、R3 分别覆盖水平、垂直和边界三种问题，不是同一走廊换皮。

## 7. 当前保留的开放问题

这些问题故意留到后续层级，不在第 1 层抢答：

- 蚀湾为什么具有这种拓扑；
- 居民是否意识到两种奇偶状态；
- 海雾、媒介和异变体如何读取 `fold_phase`；
- 玩家是否能主动改变路线奇偶；
- 最终使用 UE5、预渲染、实时 3D 或混合实现。

第 2 层只需先建立一个没有异常也成立的现实蚀湾底图，并把 R1 三十到五十分钟的现实步行距离压缩成可生产的游戏尺度。
