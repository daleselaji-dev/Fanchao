# 《返潮》阈限酒店危机前后修正 v0.2

> 本稿修正 `返潮_阈限酒店与首个实体原型_v0.1.md` 中两个错误：雾被设计成二层以上的水平实体界面；危机后的镜面仍然出现大量普通婚宴宾客。二者均不再采用。

## 1. 同一酒店必须存在两个明确状态

### 危机前

酒店正在营业。大堂有人入住、退房、等车、搬运行李，宴会厅婚宴正在进行，服务员和婚礼录像设备都在工作。海雾已经抵达一层入口，但可以被理解为正常天气：

- 门外灰白，进门人的衣服带着潮气；
- 一楼地面有极薄雾丝，被开门、脚步和空调吹散；
- 越向挑空上部，雾越浓，上层栏杆稍显模糊；
- 墙面存在尚可解释为施工或返潮的湿斑；
- 镜子、CRT 和真实人物基本一致，只出现一次可被否认的错位。

危机前不是长时间安全区。它的作用是让玩家记住同一机位中的人、声音和用途，使危机后的清空具有重量。

### 危机后

返潮越过临界点以后，酒店公共空间不再出现普通 NPC。玩家回到同一大堂时：

- 前台、行李、酒杯、香烟、登记簿和仍在转动的设备证明人群刚才确实存在；
- 婚礼录像可以保存过去的人，但现实空间、镜面实时反射与楼层回廊中只有空位和实体；
- 幸存者不会站在大厅等待对话；需要遇见他们时，应位于暂时封闭的安全房、广播另一端或后续独立区域；
- 视觉上能够活动的类人轮廓必须首先被玩家当作潜在怪物，而不能继续用群众填满危机场景。

这使危机拥有明确的断裂：不是滤镜变暗，而是正常社会突然从公共建筑中撤走，只留下仍在执行错误入住关系的东西。

## 2. 海雾不再是二层的硬切面

酒店中的海雾遵循“从一楼已经存在、随高度与建筑深度加重”的连续分布：

- 正门、旋转门缝、地面排水口和电梯井首先出现薄雾；
- 一楼仍可看清完整路线，但远端对比度被吃掉；
- 二层回廊形成中等雾幕，人物或房门只能读取轮廓；
- 三层以上雾密度急剧上升，栏杆、门与吊灯上部逐渐消失；
- 雾不是平整水面，也没有悬浮的物理边界；局部受空调、开门、热源和返潮压力影响，形成真实的层流、回卷和停滞区；
- 危机感来自整座挑空建筑被雾逐级吞没，而不是在某个高度放置一张白色平面。

雾可以在声音上保留垂直异常：上层声源听起来比一层更近，某些电话铃声从雾中垂直下降，但视觉仍保持自然扩散。

## 3. 危机后大堂的返潮强度

危机后不能只靠雾和湿地板。大堂必须同时出现三种不同尺度的返潮证据。

### 建筑尺度

- 挑空上部的墙面、吊顶与柱体出现数米范围的缓慢浮肿，隆起跨越结构接缝；
- 墙板仍保持原来的颜色、漆面和拼缝，证明它是被内部压力改变的建筑，不是换成肉墙；
- 某一条旧门框或拆除楼梯的轮廓在湿度差中显现，暗示酒店正在退回翻修前结构。

### 近景尺度

- 一楼柱脚与地毯边缘出现黑色返潮斑点，沿毛细路线向上生长；
- 黑点在少数高压褶线聚成密集潮孔，其中混有盐晶、闭合幼贝和细碎海生钙壳；
- 这些区域需要手电近照才能看到有规律的轻微开合，远景首先仍是建筑病害。

### 运动尺度

- 水膜沿柱体、电话线和吊灯链条向上移动；
- 雾被看不见的体积挤开，形成一个比当前可见人形更大的移动空腔；
- 镜面反射中的雾和现实雾流向不同，为贯穿房间的实体提供第一次证据。

## 4. 大堂中的怪物呈现

危机后第一张主镜头中只保留一个可确认的活动主体：远处住客层入口的背影。

- 现实中它保持人类尺度，站姿或缓慢动作尚可被误判；
- 大堂镜墙不再反射婚宴人群，而是反射空大堂与同一背影；
- 镜中背影的身体向相邻门廊延伸一段不可能的长度，肩与手臂的位置无法同时属于一个房间；
- 上层浓雾中可以出现被它挤开的巨大空腔，但不增加第二、第三只剪影怪物；
- CRT 可以继续播放危机前婚宴录像，形成“屏幕里有人、屏幕外只剩怪物”的明确边界。

## 5. Demo 中的状态切换

同一大堂使用一套基础几何、两套人群/异常层与连续声音完成断裂：

1. 玩家第一次穿过大堂：真实 NPC、婚宴漏音、行李轮声、前台电话、轻雾；
2. 公共断裂发生：泵压和空调声同时消失，所有电话提前响一声，画面不立刻切黑；
3. 玩家短暂失去方向或被迫进入侧厅；
4. 再次回到同一主机位：NPC 层完全撤除，物品状态保留，雾与返潮层加深，远处背影成为唯一活动主体；
5. 玩家通过镜面和 CRT 逐渐确认背影不是幸存者，随后进入住客层遭遇。

冲击力来自可比较的同一空间，而不是危机后突然加载一座从未见过的废墟。

## 6. 对 H01 的新要求

H01 此后专指危机后目标帧：

- 一楼已经有薄雾，向上逐层加重；
- 不存在水平硬雾面；
- 现实与镜面都没有普通 NPC；
- CRT 可以保留危机前婚宴影像；
- 大堂只有一个远处实体背影；
- 返潮必须同时具备建筑浮肿、密集微观潮孔与逆向运动证据。

危机前同机位另记为 H00，后续单独制作，不能与 H01 混成一张折中画面。
