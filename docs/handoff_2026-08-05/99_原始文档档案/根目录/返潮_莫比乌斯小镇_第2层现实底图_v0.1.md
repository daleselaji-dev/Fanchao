# 《返潮》莫比乌斯小镇：第 2 层现实底图 v0.1

> 本层只建立没有超自然内容也能成立的蚀湾。第 3 层只能扭曲本稿已经存在的海陆、道路、地标与视线关系，不能为异常临时拼景。

## 1. 地理尺度与坐标

- 现实镇区范围：东西约 2.4 公里，南北约 1.8 公里；
- 坐标原点：被填平的旧内湾中心，X 向东、Y 向北内陆、Z 为海拔；
- 海面位于南侧，旧村与广播塔位于西北坡地，县道从东北进入；
- 围填区平均海拔 2—18 米，家属区 14—36 米，广播塔平台约 105 米；
- `world_data/retide_town_base_map_v0.1.json` 使用米制，可直接转换到 UE5、Godot 或 Blender。

旧内湾只是一层真实地理事实：厂区、公用设施和部分家属区建在围填地上，泵排系统持续维持陆地。它不是隐藏房间、Boss 场或超自然能量中心。

## 3. 三套现实交通骨架

### 县道—生活骨架

`新市场 → 家属区 → 公共生活带`

这是外来者最容易理解的进入路线，7—13 分钟即可从公交站进入居民生活核心。它负责建立正常方向、普通商贸和镇区人口尺度。

### 单位—港区骨架

`家属区 → 公共生活带 → 冷库厂区 → 海洋馆港池`

这是旧单位换班与新旅游开发重叠的路线。建筑从住宅尺度逐步过渡到工业大体量，烟囱与蓝色穹顶在多段道路上交替出现。

### 坡地—海岸骨架

`旧村广播塔 → 泵站 → 防波堤 → 港池`

这是地形和排水最清楚的路线：高处住宅、围填低地、排水出口和海岸依次出现。它为后续垂直翻面提供真实海拔基准。

原则：地标在异常发生后不能随机消失。第 3 层要让它们持续存在并背叛正常方位。

## 5. R1「环湾海堤」现实基线

现实路线：

`新市场停靠点 → 海洋馆港池门 → 西泵站 → 家属区晾衣场 → 冷库背街 → 新市场停靠点`

- 全长约 4.35 公里；
- 正常步行约 56 分钟；
- 海拔从 14m 降到 3m，再升到 22m，最后回到 14m；
- 正常状态下海只应出现在路线南侧或被建筑遮挡；
- 正常走完一圈不会改变任何建筑正背面和海陆归属。

这条现实基线不是最终游戏时长。第 8 层会通过区块流送和路线压缩，把它变成 8—12 分钟连续可走段；第 2 层先保留真实城镇距离，避免地图像主题公园。

## 7. 第 2 层通过门

- 所有区域即使删除异常也有明确社会功能；
- 道路能够解释居民为什么来往，而不是专为玩家解谜；
- 海拔、排水、港区与围填地关系没有明显自相矛盾；
- 六个地标拥有固定位置和正常可见范围；
- R1 在现实状态下是一条合理环路，异常不会从地图漏洞里偷来；
- 地图数据已 结构化为区域、节点、边、地标和观察站，能被后续工具读取。
