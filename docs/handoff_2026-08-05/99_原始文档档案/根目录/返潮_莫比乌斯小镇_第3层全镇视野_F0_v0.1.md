# 《返潮》莫比乌斯小镇：第 3 层全镇视野 F0 v0.1

> 观察站：F0 新市场停靠点，向西南观看蚀湾。
>
> 本层只回答“整个视野如何连续翻面”。人物、怪物、谜题、代价、剧情解释继续锁定。

## 1. 为什么从 F0 开始

F0 同时看见四种尺度：

- 0—30 米：公交站、市场铺面、修理摊和湿沥青；
- 30—180 米：市场屋顶、家属区边缘、道路和电线；
- 180—900 米：广播塔、冷库烟囱、海洋馆穹顶和工业屋面；
- 900 米以外：海岸、海天线、远坡和天气层。

只要固定这个机位，就能判断异常是否真的覆盖全镇，而不是又缩回一扇门或一个道具。

## 2. 摄影与 PS3 画质合同

- 16:9，等效 35mm，水平视场角 55°；
- 机位高度 1.65m，位置误差不超过 1.2m；
- 主目标为高完成度 PS3 末期生存恐怖画面：1280×720 内部构图、真实材料、有限动态范围、清楚的中远景层次；
- 不使用景深、鱼眼、色差、镜头倾斜或现代 HDR 眩光；
- 时间固定为小雨后的阴天傍晚，能见度约 1.4km；
- 正常人群保持零散生活密度，不构成仪式队列或群众奇观。

## 3. 五阶段视野语法

### Phase 0：现实基线

画面必须首先像 2001 年真实存在的中国海镇。前景有市场和停靠点，中景能辨认居民区与工业带，远景从左到右依次是广播塔、冷库烟囱、海洋馆蓝色穹顶。

这一张不能主动阴森化。它的任务是让后续所有异常拥有不可替换的现实证据。

### Phase 0.25：方位迟滞

相机和前景完全不动，三个远处地标却分别发生方向不一致、需要 A/B 对照才能发现的缓慢漂移；海天线继续保持水平。

它不是透视错误或鱼眼。电线杆、屋檐、海天线和道路消失点保持正常，所以玩家能排除相机转动。地平线矛盾延后到 Phase 0.5，避免第一步同时堆叠两种异常。

### Phase 0.5：双海岸

同一片海以相同波纹、天色和船灯，分别封住画面左侧背街与右侧港区。两段海天线之间仍是连续、可步行的镇区。

冷库烟囱仍在中央，证明不是把两张风景图拼在一起；市场背街同时成为城市内部服务面和海岸边缘。

### Phase 0.75：城镇表面卷起

冷库烟囱成为稳定铰点，烟囱右侧的港区地表向画面右上方缓慢卷起：海面、海堤、道路、排水、屋顶和电线共同沿一条宽弧上升，建筑没有漂浮。

海洋馆穹顶随局部地面向左上方移动，最远端坡度约 24°；观众开始看见街区道路趋向“另一面”，但地标完整换序延后到 Phase 1，避免同一关键帧堆叠两种高潮。

### Phase 1：同一地点的另一面

画面重新平静，地平线再次接近水平。公交站、市场铺面、雨水痕迹和近处人物仍处于原位，但远景从左到右变为海洋馆穹顶、冷库烟囱、广播塔；海出现在原本的内陆侧。

这不是镜像图：文字、人物左右手、车辆方向和前景铺面均未翻转。只有小镇的海陆、正背面和跨区方位进入 `route_parity = 1`。

## 4. 全阶段不可漂移项

- 同一相机位置、焦段、俯仰和画幅；
- 同一公交站杆、前景铺面、修理摊和路面水迹；
- 同一时间、天气、太阳方向与人口密度；
- 同一广播塔、烟囱与蓝色穹顶造型；
- 30 米内贴图和局部几何不改变；
- 不用色调、噪点、雾量或亮度变化替代空间变化。

## 5. 明确退回

- 螺旋隧道、鱼眼、万花筒、镜像街道；
- 漂浮城市、折纸岛、建筑融化或迪士尼式奇观；
- 怪物、群众仪式、血污、门缝与边缘惊吓；
- 只把海贴到另一侧，却没有地标、道路和遮挡共同变化；
- 每个阶段换一个机位、天气或街道，让差异无法比较。

## 6. 当前制作顺序

1. 先生成并审查 Phase 0 正常母版；
2. Phase 0 通过后，只对母版做一次 Phase 0.25 编辑；
3. 每次只推进一个阶段，前一阶段未通过不得生成下一阶段；
4. Phase 1 完成后，将五张图做无标题盲测：测试者必须看出“同一地点翻到了另一面”，而不是“世界变魔幻了”。

结构化状态数据位于 `world_data/retide_sightfield_f0_v0.1.json`，后续美术和引擎不得各自重新解释 `fold_phase`。
