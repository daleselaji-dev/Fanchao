# 《返潮》莫比乌斯小镇：F0 首轮美术切片复审 v0.1

> 结论：**这是可运行的美术构建切片，不是美术候选，更不是 PS3 最终画面。** 它证明地域材质、屋顶、市场道具、渔棚、船、电杆和海岸可以在同一莫比乌斯路线场中工作；同时也明确暴露了距离《死魂曲》级完成度还缺什么。

## 1. 本轮从灰盒中真正替换了什么

- 六类运行时可平铺材质：湿沥青、盐析水泥、陶瓷墙面、灰瓦、锌皮、篷布；
- 低层建筑不再是单色盒：出现两层窗格、平屋顶压边和四坡屋顶两种轮廓；
- F0 固定近景加入市场瓷砖墙裙、门、雨棚、中文市场牌、修理摊顶棚与立柱、工作台、轮胎、排水沟、积水、货筐、塑料凳和一名普通居民；
- V2 加入稀疏低矮渔棚和分属两侧水面的作业船代理，避免“双海岸”退化为空测试场；
- V3 的镇面背侧不再使用纯黑底面，而与正面共享盐析、道路、屋面和水面细节；
- 阴影只由真实建筑和道具投射，自定义海面/镇面不再以错误的未变形深度污染近景。

### 新增：可导出的渔业家属楼英雄资产

本轮没有继续增加运行时方盒代理，而是在远端 Blender 5.2 实际导出了一个原创的 `F0_fisher_family_house` 资产包：`.blend`、`.glb`、构建脚本、1280×900 预览图与部件清单均已落盘。资产为 `12.55 × 14.98 × 10.75m`、`6,234` 三角面、`150` 个命名子件，包含 L 形三层主体、两层外梯平台和栏杆、五类凹窗、瓷砖墙裙、不等长阳台、晾晒、空调、PVC/排水立管、水箱和天线。它不复用第三方几何或贴图；每个部件保留为可独立绑定 `routeFoldSample` 的逻辑单元。

GLB 已接入 F0 运行时，且没有加载错误；同时机检查也暴露了一个必须正视的问题：资产在当前 F0 基线镜头的中景密度与灰度下被吸收，尚未成为清晰可读的英雄立面。因此它的状态是“已导入、已服从同一折叠场、未通过构图验收”，不能把存在于工程里等同于美术完成。

## 2. 修复的关键空间错误

闭合路线的海岸条带会与其他路线段在平面上重叠。旧海面高度为 `0.18m`，高于镇面和道路，因此 Phase 0/1 的海岸权重变化会把 F0 近景罩成不同颜色，等于几何意义上的“局部进水”。

现在深度合同固定为：

```text
coast -0.015m < town 0.025m < road 0.065m
```

镇面和道路以真实深度遮住回环海面，开放岸线外仍能看到水。Phase 0 与 Phase 1 的公交镜、黄线、市场、修理摊、居民和近景光照重新一致；变化只保留在海岸归属与远景地标。

该合同已移入 `sightfield_state.mjs` 并加入自动测试，不再只靠视觉记忆维护。

## 4. 负载证据

1280×720、Phase 0.75 当前为：

- `276 calls`；
- `33,316 triangles`；
- 场景更新加渲染工作时间 `p95=4.7ms`；
- `100%` 工作帧不超过 33.3ms。

这些数字只证明当前美术构建方式有余量。内嵌浏览器原始 RAF 仍受宿主调度影响，不能据此宣布端到端 30fps 已通过。

## 5. 仍然失败的美术项

第二轮已经用八条组合规则为路线住宅添加阳台板、矮栏、雨棚、水箱、空调机、通风筒与天线；所有附件都通过 `routeFoldSample` 变形，而不是固定在世界或画面上。F0 市场与修理摊分别加入暖色灯和冷色荧光灯；V2 渔棚不继承住宅附件，避免空调机悬浮在海面。

第三轮把若干关键代理换成有剖面的真实低模：住宅出现 L 形侧翼、六级实体外梯和排水立管；渔船使用收尖船艏、船舱、桅杆和网卷；双侧岸线使用低矮阶梯海堤，并由缆绳段连接泊船柱。首测中黑色斜坡楼梯和高密白色海堤被直接淘汰，当前版本使用踏步几何和更低、更少接缝的海堤。

### 现实基线还不够可信

- 建筑主体仍重复；L 形侧翼、外梯和管线打破了部分轮廓，但窗格、建筑进退与楼梯平台仍过于规整，缺少晾晒、栏杆细分和维修痕迹；
- 新的渔业家属楼已经提供了非规则楼梯、晾晒和生活管线的可复用样本，但它需要移入一个能让外梯/阳台形成剪影的街景构图，不能继续埋在同色中景体块里；
- 市场、修理摊、公交镜和居民仍由代理几何组成，没有达到角色可近看的资产密度；
- 道路太宽，摊位、门面和路缘的生活层不足；
- 光照只有基础方向光与软阴影，没有烘焙遮蔽、室内暗部和局部实用光；
- 材质只有颜色细节，尚无最终 normal、roughness、decal 与 LOD。

### V2 仍可能被读成普通海岛

收尖船体、桅杆、网卷、低阶海堤和缆绳补回了港口剖面，但仍缺船舷深度、松弛绳形、排水格栅和同一海面的波纹连续性。下一轮必须让两侧岸线拥有可追踪的同一编号与磨损序列，而不是只靠相似构件证明海。

### V3 仍有“顶棚”感

背面已经可读，不再纯黑；阳台、雨棚、水箱和通风筒增加了局部厚度，但真实背墙、排水管、电杆和街巷纵深仍不足，部分区域仍像纹理化大板。下一轮必须增加位于局部表面法线方向上的背面建筑构件，而不是继续加深颜色或雾。

## 6. 下一轮只做三件高收益资产

1. **市场—修理摊近景组合件**：把 F0 从代理几何提升到可近看的真实海镇基线；
2. **八种中景住宅轮廓套件**：阳台、外梯、水箱、灰瓦/锌皮屋顶和管线形成不重复的天际线，也让 V3 背面有真实厚度；
3. **海堤—排水—泊船连续链**：同时强化 V2“双海岸”和 V3“海水跟随镇面”，一套资产服务两个核心命题。

不新增玩法、酒店、门、钥匙、群众仪式、怪物图鉴或恐怖滤镜。完整资产接口与预算见 `world_data/retide_f0_art_slice_manifest_v0.1.json`。
