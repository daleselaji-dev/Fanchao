# 《返潮》干路沉降 MVP

一段 42 秒的实时力学灰盒：**没有裂缝、没有积水的柏油路，将一辆停驶班车完整吞入自身；轮胎和车身被看不见的深处压低，路面仍像平整的干路。**

它验证“深海误认海床”的第二种画面，不解释世界观，也不引入怪物、任务或收集。

## 当前结论

这个版本只证明了车辆与路面可以共享沉降动作，**没有通过美术审查**。程序化车体、建筑和路面没有达到目标帧的中国千禧生活密度，也不足以产生恐怖。后续若保留这个画面，只能以实拍基底、真实班车比例、乘客/站务行为和高保真材质重建；不得把本灰盒当作发布级方向。

从仓库根目录运行：

```bash
python3 -m http.server 4175 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4175/prototypes/pressure_road_mvp/?automation=1`。

审查重点：

- 观众必须先认出干燥的中国小镇班车和新铺柏油；
- 班车下沉时，路面不裂、不湿、不变成泥；
- 车轮、车顶、路标与地面碎屑必须共同服从“垂直沉降 + 单向拖曳”；
- 场景中不得出现海洋生物、发光色、水体或巨物剪影。
