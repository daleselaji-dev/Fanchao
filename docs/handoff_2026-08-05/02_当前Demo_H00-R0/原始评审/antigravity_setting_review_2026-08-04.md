# 《返潮》基础设定审查报告（2026-08-04）

## 1. “一句话世界”审查
* **视觉与冲击力评估：** 核心句（“2001 年，一座海边小镇把送无尸亲人归海的‘归面礼’做成了召回；潮水没有上岸，深度却来了，海用古老器官补全人们记错的亲人，把他们送回了家。”）极具画面感，成功制造了深海恐怖与预期违背的压迫感，能够在一眼内产生强烈的冲击。
* **像解释而不是故事的句子：**
    * “这里的‘深度’不是水位。”
    * “它是深海压力、沉积年代、声音延迟和材料受力一起进入干燥空间后的结果。”
    * “房屋仍然没有被海水淹没，但墙……”
    * **建议：** 这些句子带有明显的“说明书”感，打断了叙事沉浸。建议直接描述物理现象，如：“干燥的房间内，墙壁和玻璃突然发出不堪重负的吱嘎声，就像被拽入了八千米的海底。”

## 2. 编剧补全规则（不超过 5 条）
1. **缺失必有填补：** 死者生前未被记住或缺失的部分（如没见过的脸、没听过的声音），必定会被海洋用深海物质（矿化壳板、复眼、盐晶）强行填补。
2. **行为受限于记忆：** 归来者没有自由意志和新思考，其所有行为仅仅在重复家属记忆中最深刻、最执念的一段动作或生活轨迹。
3. **物理异常先于形体：** 归来者出现前，周围的干燥空间必先发生形变与声音异常——空气变得沉重、物品发出受压异响、出现回声延迟。
4. **强行索要社会关系：** 归来者会回到旧家庭位置，强迫活着的家人按其生前状态继续互动，一旦活人拒绝或偏离，就会引发致命危险。
5. **拒绝解释自我：** 归来者绝不会通过语言说明自己的状态，也不传达任何“深海的意志”；它们只是按错误记忆运行的愿望躯壳。

## 3. 核心机制检查
* **无正面父亲 (Faceless Father)：**
    * **视觉动作：** 沿回声倒退接近、从所有玻璃反光中睁开复眼。动作极其鲜明且独具恐怖辨识度。
    * **行为规则：** 保留生前拖脚半步的特征，不转身，只沿呼名和警报回声移动。逻辑严密。
    * **可实现边界：** 仅需一个背部人类模型与正面的甲壳复眼模型，利用镜头与反光机制呈现，技术实现成本极低且边界极度清晰。
* **警报测深 (Alarm Depth Sounding)：**
    * **视觉动作：** 玩家操作控制箱，环境受压（尘埃、布料、金属形变）。视觉呈现与听觉强绑定。
    * **行为规则：** 清晰回声代表安全（浅处），拖长降调回声代表危险（深处）；测深同时会暴露自身坐标吸引怪物，形成高风险高回报的博弈。
    * **可实现边界：** 依赖音频后处理（降调/延迟）与轻量级环境动画（细微形变/掉灰），无需复杂 UI 与透视扫描，实现边界非常明确。

## 4. 滩涂细节资产（1天内可制作）
1. **半干涸的“归面”残躯**
    * **近景材质重点：** 粗糙泥土干裂的纹理，混杂着尚未风化的灰白贝壳粉。表面局部附着干枯、结块的旧毛线或衣物纤维，突出被遗弃的手工人造物特征。
2. **受压形变的警报喇叭（掉落物/环境件）**
    * **近景材质重点：** 金属表面呈现非自然的向内凹陷与扭曲，边缘有严重剥落的旧漆面与析出的盐霜结晶。没有水渍，但要有曾承受极高水压的物理破坏质感。
3. **干结沉积物的遗落鞋子**
    * **近景材质重点：** 鞋面原本的布料或皮革质感被灰白色的海洋沉积物（如微小藤壶的石化痕迹或管虫壳）大面积覆盖。整体干燥且质地坚硬，表现“未触水却被深海侵蚀”的怪诞感。

## 5. 最终审查结论
**结论：需修改 (Needs Modification)**

**最高优先级的 3 个修改点：**
1. **重写“深度”的设定说明句：** 将第一节中“这里的深度不是水位…”等说明书式句子，改写为具象的环境变化描述，消除设定的解释感。
2. **细化“警报测深”的视觉反馈落点：** 目前对测深的描述偏重声音（回声降调），需要进一步明确“环境内缩”在游戏引擎内的低成本视觉表现，例如布料突然诡异地绷紧、或是金属门框发出肉眼可见的轻微挤压形变。
3. **补充无镜面环境下的“无正面父亲”压迫感：** 设定中强调怪物从反光中睁开复眼，需补充在室外滩涂等缺乏大面积镜面的环境中，玩家如何感知到它正面的恐怖（例如通过怪物在泥面投射的诡异阴影，或靠近时周围细小物体的受压反应）。
