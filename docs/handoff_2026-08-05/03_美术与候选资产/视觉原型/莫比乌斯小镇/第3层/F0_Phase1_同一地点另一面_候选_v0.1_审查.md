# F0 Phase 1 同一地点的另一面：审查 v0.1

> 结论：有条件通过。F0 五阶段的视觉论证已经闭合，但在进入第 4 层之前必须通过无标题盲测，证明观众读到的是“同一地点翻到了另一面”，而不是“换了一座镇”。

## 通过项

- 远景唯一地标从 Phase 0 的广播塔—烟囱—蓝色穹顶，变为蓝色穹顶—烟囱—广播塔；
- 海面只出现在左侧，原右侧港湾被连续屋顶、道路、电线与低矮内陆坡地替代；
- 冷库烟囱仍是中心铰点，三处地标没有复制；
- 地平线恢复接近水平，没有保留 Phase 0.75 的弯曲奇观；
- 前景公交镜、铺面、黄线、人物、修理棚与自行车维持原朝向，没有通过整图镜像作弊；
- 单独观看仍像一座可信的 2001 年海镇，恐怖只在与 Phase 0 的记忆冲突时成立。

## 有条件项

- 中远景建筑细节发生较大重绘，观众可能把它判断成“同机位的另一座镇”；盲测若出现此结论，必须增加跨 Phase 保持不变的中景屋顶组、道路节点和电线锚点；
- 左侧海面宽度与 Phase 0 右侧海面并非严格等量，引擎版必须由同一海岸状态和遮挡参数计算，不复制概念图像素；
- 生成式图像不能证明真实连续行走，也不能证明 PS3 目标平台性能；
- 当前通过只证明美术叙事和空间读法，不能替代后续锁机位引擎构建。
