# F0 Phase 0「新市场正常视野」候选 v0.1 审查

## 结论

**有条件通过，作为 Phase 0.25 的唯一母版；不是发布级最终图。**

它已经建立了足够具体的正常蚀湾：普通市场生活、由高到低的镇区层次、港池、工业体量和三个可记忆地标都在同一自然摄影逻辑中。后续不得重新生成另一座更“恐怖”的镇来代替它。

## 通过项

### 1. 地标顺序清楚

广播塔位于左侧山坡，冷库烟囱位于中央，蓝色穹顶位于右侧港池。三个轮廓差异大，能够承担后续方位漂移。

### 2. 前中远景均可锁定

- 前景：圆形停靠标、左侧雨棚、路面黄线、右侧修车棚和自行车；
- 中景：下坡市场、灰白屋顶、电线和零散行人；
- 远景：坡地、工业带、海洋馆与海面。

这些物件足以检查后续编辑是否偷换机位或街道。

### 3. 中国沿海生活成立

材料、铺面、雨后路面、摩托维修、塑料凳、低层建筑和普通居民比此前酒店走廊更接近项目需要的现实底材。画面没有靠群众队列、仪式或怪物制造意义。

### 4. 摄影克制

曝光、色彩和天气稳定，没有红光、青橙调色、VHS 噪点和电影海报式人物中心。

## 未完全通过

### 1. 海面略宽

正常规格要求海主要出现在右侧；当前海天线从烟囱后方延伸到右侧。Phase 0.25 编辑时不能继续扩大海面，Phase 0.5 的“双海岸”必须通过左侧新增的同一海面才产生明确差分。

### 2. 蓝色穹顶略大、略现代

它作为导航锚点有效，但后续引擎资产应缩小约 15%，并补入旧冷库基座、玻璃钢鲸尾或九十年代公共建筑细部，防止像现代体育馆。

### 3. 人物数量高于提示词

居民仍是散布状态，因此不构成群众秩序；后续编辑必须保持现有密度和姿态，不能再增加人群。

### 4. 这是美术目标，不是 PS3 实机证据

当前图的照片清晰度高于最终 720p 运行画面。后续不能靠简单降分辨率冒充 PS3 质感；必须在第 8 层重新证明低面数体块、有限材质分辨率、远景雾化与角色轮廓仍能保住同一构图和三座地标。

## Phase 0.25 编辑硬锁

- 不改变前景圆形停靠标、雨棚、黄线、修车棚、自行车和所有人物；
- 不改变时间、天气、曝光、镜头和画幅；
- 只让三座远景地标产生方向不一致的 3—7° 漂移；
- 海天线右端仅抬升约 2°，不新增第二片海；
- 不增加恐怖色调、雾、怪物或视觉噪声。
