# M01「父亲」真实人形基底建模交接单 v0.1

用途：交给真实人形 Base Mesh / 雕刻管线执行。此文件不是贴图说明，也不是最终资产确认。

## 目标

做一个能在三视图中先读成人的低模/灰盒：2001 年中国沿海基层工人，疲惫、略驼背，褪色蓝灰工装；左肩因长期扛网或重工具下沉，右脚落后并半拖。

## 正面结构

正面没有正常脸。人体前侧保留可辨认的骨骼支承关系，但从眉弓、喉部、胸骨到上腹被干燥海床矿化器官压入。该结构必须是人体前轮廓内的负体积，不得形成外壳或外挂面板。

矿化底床：贝灰、泥岩、壳基底的连续干燥结构；边缘沿人体压力线缓坡过渡，不能有 90 度包边。

复眼晶面：7–9 个大小、方向、间距不规则的浅平晶台或裂隙面，深度/宽度小于 0.15；由同一底床直接刮削，禁止单独建球、孔、圆环、镜片或蜂窝阵列。

## 交付顺序

1. 无材质人形 Base Mesh：背面与侧面通过。
2. 工装和姿态灰盒：背面先读普通父亲。
3. 前侧负体积雕刻：侧面不得超过原人体前轮廓。
4. 同质矿化底床和浅晶面：正面不得读面具、胸甲、孕腹或伤口。
5. 只有三镜头 Gate 全部通过后，才允许 UV、PBR、贴图和 UE 导入。

## Gate 镜头

- Gate 01 背面：普通工人身份、工装、塌肩、拖步。
- Gate 02 纯侧面：负向凹陷、无外凸、无外挂薄片。
- Gate 03 正面/警报箱反射：连续海床器官、同质浅晶面、无脸无眼球。
