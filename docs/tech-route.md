## 2. UE 5.8 主线（路径 A）

### 2.1 工程形态

- 独立轻量工程 `FanchaoH00UE`，**不**引用约 2.8 GB 的旧泥滩工程。
- 空间不依赖资产：运行时由 `H00DemoDirector` C++ 代码在空 `Entry` 地图上生成 A/B/C/D/E 五个功能区、归档台与实体航点（源码见 `demo/ue/H00_Source/H00DemoDirector.cpp`）。
- 不使用 World Partition 关卡做底座（历史教训：复制的 `Lvl_ThirdPerson` 离开原工程后触发引擎断言，且 Enhanced Input 资产缺失）。
- 输入：经典 Axis/Action 绑定（`DefaultInput.ini`），`WASD` 移动、`E` 交互、`R` 复位。
- 行为自动验证：命令行开关 `-H00BehaviorTest` 复用与玩家相同的距离门槛跑归档+复位回归。

### 2.2 行为合同的代码事实（Web 切片与之对齐）

| 合同项 | UE 实现 | 数值 |
| --- | --- | --- |
| 归档交互半径 | `TryArchive` 2D 距离门槛 | 240 UU（2.4 m） |
| 实体航点 | `SetRoute` 五点循环 D→B→C门外→E→D | 见 `H00DemoDirector.cpp` |
| 实体步速 | `H00Returner::Tick` 匀速位移 | 150 UU/s（1.5 m/s），恒定，不因玩家改变 |
| 工作点停留 | 到点后 `PauseRemaining` | 1.4 s |
| 玩家步速 | `MaxWalkSpeed` | 360 UU/s（3.6 m/s） |
| 全局复位 | `ResetDemo` 同步恢复玩家/录像带/航点 | R 键 |

### 2.3 当前阻塞与下一步（= 计划里程碑 M2）

Round 4 状态机 Gate 已于 2026-08-04 在原开发机 PASS（编译日志、航点日志、归档与复位日志）；但最后一次视觉 QA 在空 `Entry` 地图出现黑屏，补了显式玩家生成与中性工作灯后**尚未复验截图**。因此 UE 主线的下一步只有一件事：

1. 在装有 UE 5.8 的机器上打开工程，`-game` 启动 `Entry`；
2. 产出非黑屏 720p 截图 ≥3 张（A/B 入口、C 归档台、E/B 交界）；
3. 人工走完 60–90 秒节拍并录像。

在此之前不做任何资产、材质、灯光风格工作。

## 3. Web 行为灰盒并行切片（本仓库新增）

### 3.1 为什么存在

行为合同此前只存在于文字与一次无法在云端复跑的历史日志。Web 切片（`demo/web/`，纯 HTML/Canvas，零依赖）把 Round 2 合同变成任何人可打开、可操作、可截图的活文档，并作为跨端回归基线。

### 3.2 验证范围（白名单）

- A/B/C/D/E 空间闭环与门位拓扑（对齐 Round 3 灰盒俯视图）；
- 浅处服务线 / 低处器材线双路线与"低处只改声学与材料证据，不画线、不变色"；
- REC/PAUSE 归档任务（半径 2.4 m，对齐 UE 的 240 UU）；
- 实体 D→B→C门外→E→D 匀速回返、工作点停留、**让行不推回**；
- E/B 交界一次性短暂侧向证据（≤2 秒，不跳脸、无音刺）；
- 声音先于画面（实体不可见时仅有工作声；视线被墙遮挡则不渲染实体）；
- R 全局复位（RESET_REASON 日志对齐 UE 格式）。

### 3.3 明确不验证（黑名单）

时代底片、材质、灯光、镜头手感、正式声音设计、M01 造型——这些只属于 UE 主线对应 Gate。Web 切片的画面是示意灰盒，**不得**被当作美术参考提交审查。

### 3.4 一致性规则

Web 切片与 UE 出现行为分歧时，以 Round 2 合同为唯一裁判修正两端；合同本身的修改必须先过用户确认，再同步改两端。

## 5. 技术侧禁止事项

1. 禁止在旧泥滩工程上叠加任何生产。
2. 禁止把"安装了某工具"当作进度汇报。
3. 禁止用 World Partition 模板地图做 H00 底座。
4. 禁止在行为 Gate 未过时导入正式模型/贴图（含把候选 GLB 当正式资产）。
5. 禁止伪造运行证据：所有 PASS 必须附可复核的截图/日志/录像，并注明验证环境与时间。
6. 禁止用蓝色滤镜、可见水线、海洋装饰等"便宜恐怖"弥补技术画面的单薄。
