## D1 Demo 升级路径（`demo/web`，Demo 执行栈 ☁）

目标：让现有 3D Demo 从「质感验证」升格为「命题验证」——盲测者能复述「这里是干的，但已经在海底」。每步一个 PR，顺序不可换：

### D1-1 测深听感原型（机制门前哨）

- **做什么**：Web Audio 程序化合成两族回声（清晰短促 / 拖长降调 + 结构内缩杂音），独立 A/B 测试页（[02 §2.3](02_创新提升方案.md#23-声音先行的工程化测深先出声再出图)）。
- **怎么算过**：≥5 名盲测者听声辨深浅，答对率 ≥80%。**不过就换合成参数重试，过不了三轮升级为设计危机上报**——这是全项目最早该炸的雷。

### D1-2 测深实装 + 承压证据链

- **做什么**：B/C 配线龛测深点（对齐 [07 §2.1](../game-design/07_Demo垂直切片_玩法与叙事框架.md#21-空间不新增全部为宪法已批空间)）；按方向播两族回声；测深触发 M01 循声态（合同已实装，接线即可）。同步给场景加同一高度的承压证据：胶条挤出、桌腿短缩、门框密封条外挤——灰盒级几何即可，禁止贴图化妆。
- **怎么算过**：陌生测试者两次测深内读懂深浅与走向（P1 机制门原文）；测深后 M01 循声反应可复现；新增单测覆盖「测深即暴露」。

### D1-3 守仪式第一课：不回头

- **做什么**：实装 07 B8 拍——身后呼名声源 + 回头判定 + 归位演出（替代 R 复位成为玩家侧唯一「失败」）；R 降级为调试键。
- **怎么算过**：回头触发归位、不读档、世界状态延续；「想回头」的声音压力被至少一名盲测者主动描述。

### D1-4 玻璃对照位（命题一帧证明）

- **做什么**：实装 07 B7 拍——一段海洋馆走廊：缸内有水有气泡有水声（全 Demo 唯一合法水声），缸外干燥承压。
- **怎么算过**：盲测者看截图能说出「水在缸里是正常的，外面反而不对」；一帧一异常审查通过。

### D1-5 成片门盲测

- **做什么**：8–12 分钟完整录像（无解释文字），外部盲测。
- **怎么算过**：复述命中「这里是干的，但已经在海底」与「它是被记错的人」两个短语语义（[07 §1.3](../game-design/07_Demo垂直切片_玩法与叙事框架.md#13-验收) 原文）。命中一个为 CONDITIONAL，零命中退回 D1-2。
