# 《返潮》创新提升方案

> 日期：2026-08-25。地位：**提案**——每条通过后按 [05 审定文档](../game-design/05_设定审定_保留与删除.md)流程写入宪法，未通过的条目死在这里，不准以探索稿复活。
> 写作纪律：每个想法先给**一句主句**；主句必须自己站得住，补充只许三行。一句话说不清的想法不会出现在本文——它们已经被丢进 [§6 丢弃清单](#6-丢弃清单)。
> 所有提案共同的边界：不新增恐怖类型、不新增第五个动词、不碰叙事空洞（全作不回答的问题继续不回答）。

---

## 1. 剧情创新

### 1.1 无名护甲

> **主角唯一的护甲是没人记得他——而这份工作要求他到处留名。**

韩汛是外乡人，全镇没有一条关于他的记忆，所以海没有材料塑他——这就是他能在归来者之间穿行的全部原因，也是「外乡人」从叙事设定升格为机制资产的一步。而线务员的每张工单都要签名回执：不签，镇务不认工时、剧情通路不开；签了，就是给 M04 未面者递材料。**制度逼你签，规则劝你别签**——开场在镇务处的入职登记是玩家欠下的第一笔债，没得选，这很重要：清白从第一分钟就不存在。

### 1.2 结局反转判定

> **别的游戏结局看你收集了多少真相，这一作看你被收集了多少。**

三结局（送走/留住/切断）的判定变量不是玩家知道了什么，而是**镇子记住了他多少**：签名数、被呼名应答数、入镜数、认领值。玩到最后玩家自然会问「我还剩多少是我的」——这句话就是本作的主题句，由系统替玩家问出来，不用任何台词。实现上零新系统：认领状态机已在宪法里，只是把它从「威胁进度条」升格为「结局的秤」。

### 1.3 一个叫对名字的人

> **全镇都在改口叫你别人，只有一个人还叫对你的名字——保住这个称呼，就是保住你自己。**

阿澄（N01）是唯一从头到尾用正确称呼叫主角的人。她的称呼状态成为一条无 UI 的全局进度显示：她哪天也叫错了，玩家立刻知道自己剩多少。终局选择因此有了身体——「送走」结局的最后一个操作，是听见她在背后叫对你的名字而**不回头**：守了一整作的仪式，最后一次守在她身上。情感线与守仪式动词在同一个按键上合流，零新增系统。

## 2. 技术栈呈现

### 2.1 录像带栈

> **Demo 不必假装成品——把它做成一盘 2001 年的婚宴录像带，画质缺陷全部变成叙事资产。**

双栈裁决（06 §1）的遗留焦虑是「Three.js 画质与 UE 差距怎么交代」。答案：不交代，**入戏**。Demo 执行栈的输出定义为「一盘流出的婚宴录像带」：低内部分辨率、压缩伪影、色阶断层、片门微晃——`demo/web` 已实装的 PS3 后期链只需换一个名义就从「模仿」变成「文物」。附带收益：录像带开头可以合法地放日期字幕与家用机 OSD（▶ PLAY），这是零成本的年代锚；巧思 1「录像先于现实」直接获得容器。**UE 负责「现实」的画质，Web 负责「记录」的画质——双栈从预算妥协变成叙事分工。**

### 2.2 借视的合宪改造：线务听诊

> **不借它的眼睛，借电线的耳朵。**

现 Demo 的 Q 键借视（接入 M01 视角）违反宪法「不借用敌人视野」硬约束（[评估报告 C1](01_现状评估报告.md#3-不一致清单两套文档都自称现行的地方)）。改造：Q 键变为**接入全镇广播线路**——听到的不是它看到的，而是**它经过的地方**（哪个喇叭区有拖步声、餐具声，方向与远近由声像呈现）。已写好并通过单测的过载/冷却/回落合同原样平移：线路听久了会烧断信号。职业逻辑（线务员本来就干这个）、信息价值（定位威胁）、不安来源（贴耳听一条有东西在里面走的电线）全部保住，宪法一个字不用改。

### 2.3 声音先行的工程化：测深先出声，再出图

> **测深的第一个可交付物是一段音频，不是一个系统。**

用 Web Audio 程序化合成两族回声（清晰短促 vs 拖长降调 + 结构内缩杂音），先做成**十秒 A/B 听感测试页**：随机播一族，测试者答深浅。答对率 ≥80% 之前，不写一行测深的游戏逻辑——**听感不成立，机制就不存在，早死早超生**。这是把「声音成立 → 动作成立 → 画面成立」的宪法验收顺序第一次用在机制自己身上。

## 3. 核心玩法

### 3.1 声音是弹药

> **本作唯一的弹药是安静：每打出一发声响，世界就永远少一处安静。**

无战斗、无背包，但资源管理存在——**可发声物是有限且一次性的**：碗敲一次会裂（音色变哑，第二次不再有效）、卷帘拉一次卡死在半程、扩音器每次测试警报都在给归来者的地图添一笔。玩家自然学会数着声音过日子，而「舍不得出声」正是本作想要的身体状态。实现上是给每个声源加一个衰变状态，零新系统。

### 3.2 让行选位

> **给它让路的时候，别站在任何算「座位」的地方。**

让行合同（玩家占道，它原地等待）升级一层：让行时若站进「家庭位置」——椅子、床沿、工位、被登记的座位——等同入座，认领 +1。躲避从「找个角落」变成一瞬间的空间语义判断：门槛、楼梯中段、服务通道是安全的**无名位置**（与 M02 数人的母亲的应对规则同源，提前在 M01 身上教学）。恐怖点：你会开始害怕椅子。

### 3.3 帮它干活

> **帮它收场，就是帮它回家。**

09 §2.3 已埋下「玩家替 M01 摆桌可清空其航点」的设计，升格为正式机制并说破代价：每替它完成一桌，它在场时间缩短（短期收益），宴会厅离「他回来了」的场面近一步、B10 留位证据增多（长期喂养）。四动词之外零新增——它只是「改承压」的社会版本：**你改的不是力的路径，是关系的路径**。

## 4. 视觉设定

### 4.1 反光是另一个时态

> **镜子不反射现在——反射「应该」。**

把巧思 1（录像先于现实）、巧思 3（反光同帧睁眼）、B9（镜墙里持续返席）统一成一条渲染宪法：**所有反射面（镜、玻璃、CRT 熄屏、水面）渲染的是「被记忆要求的版本」**——婚宴永远开席、M01 有正面、缺席者在座。现实与反射的差异本身成为可读证据层，反光导航（B8）从技巧升格为世界规则。实现：UE 用 Scene Capture 渲染替代状态场景；Three.js 用 render target 换道具组——两栈都便宜，且天然服从「一帧一异常」（差异点就是异常点）。

### 4.2 深处的颜色是褪色

> **深处的颜色不是蓝色，是被时间漂白的颜色。**

「无蓝色滤镜」禁令之后，深度需要一个正面的色彩语言：**色龄差**。深度界面以下的材质像晒了二十年的海报——红绒褪成粉白、工装蓝褪成灰、亮漆失去高光；同一面墙、同一块桌布跨过界面出现颜色年龄的断层。它同时踩中千禧怀旧（褪色本来就是怀旧的颜色）与干燥深海（沉积年代感），并给美术一条可量化的验收线：**跨界面色相不变、饱和度与对比度按深度衰减**。实现是一张遮罩 LUT 的事。

## 5. 恐怖逻辑呈现

### 5.1 服从度量

> **这游戏吓人的方式，是让你发现自己已经开始守它的规矩。**

恐怖的验收单位从「玩家叫没叫」改为「玩家改没改行为」：系统静默统计玩家的自我约束——绕开背影的次数、让行选位的讲究、出声前的犹豫时长——并让 NPC 说出来：「你走路的样子越来越像本地人了。」玩家汗毛立起来的瞬间，是发现**被同化的进度条原来一直在自己身上走**。P2 门「出现自发回避行为」已经在测这个，本条只是把测量结果喂回叙事——零新系统，一组 NPC 台词的事。

### 5.2 缺席的最后一声

> **最可怕的声音，是你耳朵自己补上的那一声。**

全作声音设计规则：任何重复序列——警报、点名、鞭炮、敲门、拍手——**永远缺最后一响**。人耳会自己补上，补上的那一下不存在于混音里，却真实地在玩家颅内响了：这是成本为零的恐怖，且与民俗设定严丝合缝（「最后一声之后别回头」「最后一声警报响完，潮没有来」——点火事件本身就是全镇最大的一次缺席回响）。写进声音管线验收表即可执行。

## 6. 丢弃清单

按任务要求，太机械、太刻板、一句话讲不清的想法直接处决，尸体示众如下，禁止复活：

| 死掉的想法 | 一句话死因 |
| --- | --- |
| 理智值/San 值系统 | 拿仪表盘替玩家害怕，是恐怖游戏最懒的一集 |
| 借视保留 POV 但加更重的干扰 | 违宪就是违宪，干扰再重也是在借敌人的眼睛 |
| 玩家手绘排线本（手动地图 + 笔记也算记录） | 想法有味道，但「记笔记要付费」惩罚的是认真玩的人——留档，P3 后凭盲测数据翻案 |
| 莫比乌斯全镇提前实装 | F0 原型已证明它贵；一次软翻面（B9）够讲清概念，全镇翻面是内容不是命题 |
| 多主角三视角 | 05 已裁决过一次，本轮维持：单人产能撑不起，且会稀释「无名护甲」的唯一性 |
| 收集记忆碎片解锁真相档案 | 与「读档案有代价」正面相撞，且给了叙事空洞一个填法——空洞填了，作品就死了 |
| 动态难度（吓不到就加码） | 恐怖的节奏是导演活，交给算法等于承认没有导演 |
| 归来者随机徘徊增加不可预测性 | 「沿旧路线回返」是设定的脊椎——随机=否定「它们在履行记忆」这件事本身 |
