# 《返潮》现状评估报告

> 日期：2026-08-25。评估范围：交接包 292 文件（已通读核心设定、H00-R0 四轮评审、实现路径决策）、PR #2/#4 设计宪法（`docs/game-design/00–06`）、PR #3/#5/#6 Demo 谱系（`demo/web` 3D 切片 + 生产规格 07–09）。
> 本文只做三件事：说清精髓在哪、不足在哪、哪些地方自相矛盾。裁决建议随附，执行项进 [03 下一步制作清单](03_下一步制作清单.md)。

## 1. 精髓：这个项目真正值钱的五样东西

### 1.1 「潮来了，但水没有来」——一条物理命题统摄全作

这不是氛围口号，是一条可执行的世界规律：深度（压力、沉积、声学、时间）按真实海面高度穿过干燥空间。它同时是玩法（测深/读深度）、视觉（承压证据链）、主题（被排除者的回返）的公分母——**一句话能卖、一帧画面能证明、一个机制能玩**。市面上没有第二个恐怖游戏握着这样的命题。

### 1.2 归面礼——没有反派的民俗内核

「每一代人只是多留一点、多叫一次、多等一会儿」——仪式在善意中做反，这是用户口述的原创伦理结构，也是本作与死魂曲/寂静岭真正拉开距离的地方：**恐怖的源头不是邪教、不是诅咒，是爱的存档格式错了**。它天然长出玩法（守仪式）、威胁（归来者）、经济（记录即喂养）、结局（送走/留住/切断），一条链没有断点。

### 1.3 「看见即恐怖」形象纪律

一句话测试（不给背景，念「看见什么」给陌生人听，对方该已经不舒服）是全项目最锋利的质检工具。M01 无正面父亲是它的最佳产物：**背影是最可信的劳动者，侧面是一个地质断面**——两种读法装在同一具身上。这条纪律砍掉了交接包里所有靠背景故事抢救的形象，必须终身有效。

### 1.4 测深——代价长在机制心脏上的招牌动词

「每次警报既是你的眼睛，也是它的路标」——读出路线与暴露自己是同一个按钮。这种把代价焊死在能力里的设计（而不是外挂一条体力槽）是一流恐怖机制的骨相。同类还有：失败=被温柔归位而非死亡、让行不推回、记录即喂养。**这套动词的共同点是「世界用因果回应，不用对错回应」**——值得当作全作的机制宪法句。

### 1.5 证据文化与行为合同

「已完成只认可运行、截图、日志」、行为合同数值化（1.5 m/s 恒速、2.4 m 归档半径、≤2 秒侧向证据）、Demo 自动化测试（当前 15 项全过）——这套工程纪律是交接包文档通胀病史的解药，也是多 Agent 协作还能保持不散架的原因。

## 2. 不足：按杀伤力排序

### 2.1 招牌机制至今零实现（最高风险）

测深是玩法宪法的第一支柱、盲测门的核心、P1 机制门的第一关——而它**在任何可运行物里都不存在**。3D Demo（`demo/web`）里没有测深、没有承压证据链、没有深浅声学差；四个宪法动词（测深/读深度/改承压/守仪式）在 Demo 中实装数为 **0/4**。如果「声学显深」在实机里读不出来，整个玩法塌方——这个问题拖得越久，沉没成本越重。

### 2.2 Demo 验证的是质感，不是命题

当前 3D Demo 的成就是真实的：行为合同全项通过、死魂曲级灯光声景、15 项自动化测试。但它验证的是「像不像死魂曲」，而不是「是不是返潮」。拿成片门的标准问它——盲测者能复述「这里是干的，但已经在海底」吗？**不能，因为画面里没有一件东西在承受深度。** Demo 与 07 节拍表（B2 承压带、B3 测深、B7 玻璃对照）之间隔着整个核心命题。

### 2.3 声音是第一叙事层，却仍是最空的一层

宪法说「恐怖预算大头在声音」，交接包 2026-08-01 就指出「声音只有文档」——一年过去，仍然只有程序化占位音。测深双族回声（清晰短促 vs 拖长降调）的听感原型不存在，实录声音库（继电器、餐具、卷帘、CRT 高频）零采集。**声音先行的宪法条款目前是全项目执行率最低的一条。**

### 2.4 文档产能与可玩物产能持续倒挂

交接包 130 篇设定文档对一个灰盒；本轮 PR 谱系又新增约 2000 行设计文档（07/08/09 生产规格共 640 行）对一个 Demo。文档质量确实在提高，但**通胀病史的复发模式一模一样：写规格比做实现便宜，于是规格永远跑在实现前面三个身位**。07 节拍表逐 30 秒规划了 12 拍，实装 0 拍——这份规格如果三个月内不被实装消化，就会变成下一代 Agent 的「交接包」。

### 2.5 叙事传达路径未经任何验证

禁区条款（零解释腔、NPC 不讲课、录像带只放普通婚宴）是正确的——但它建立在一个未验证的假设上：玩家能从纯环境证据里读出叙事。目前没有任何一次盲测检验过这条传达路径。如果验证失败，退路（加多少解释、加在哪）完全没有预案。
