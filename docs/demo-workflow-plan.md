## 1. 不可违背的核心约束（CANON）

以下内容为共同确认基线，任何轮次的交付不得与之冲突：

1. 一句话核心：**潮来了，但水没有来；真正抵达陆地的是水深、压力、沉积、声学和时间留下的后果。**
2. 时代：2001 年前后中国北方沿海小镇；现实底片先成立，再发现深海后果。
3. 不使用可见海水、潮湿水线、蓝色水下滤镜、海洋装饰直接宣布恐怖。
4. 人不突然变成统一怪物；恐怖来自动作/职责被旧伤、压力和位置重新规定。
5. 永久禁止：跳脸、冲刺追击、碰撞推回、随机恐怖过场、把瓷砖腰线变形当唯一异常、伪精确物理数值（30 米/65dB/120Hz 一类）。
6. 石化海洋生物复眼是 M01/实体视觉的**候选**种子，不是全员统一脸；首次正面只能是短暂侧向证据。
7. 异常必须回答三问：原本的日常功能是什么？深度/时间/旧伤把它错误归类成了什么？玩家能否从动作、材料、声音、路线读懂这个错误？

## 2. Gate 顺序（继承自交接包，不变）

```text
1 Canon → 2 空间 → 3 行为 → 4 时代底片 → 5 异常因果 → 6 资产 → 7 运行验收
```

每一轮交付必须包含五件套：**设计合同 / 生成与审计记录 / 可运行证据 / Gate 结论（PASS·CONDITIONAL·NOT RUN·FAIL）/ 下一轮输入**。只有通过项进入下一轮；失败退回对应输入，不允许用加装饰来掩盖失败。

## 4. 里程碑与交付物

### M0 仓库化与证据留存（本 PR 完成）

- 交接包解压入 `archive/`（保留原始目录与中文文件名，作为不可变历史证据）。
- UE 参考源码工作副本落位 `demo/ue/H00_Source/`。
- 交付物：本文档、`docs/tech-route.md`、更新后的 README。
- 通过条件：新读者只看仓库即可理解项目现状，不必翻 zip。

### M1 行为合同可视化——Web 灰盒并行切片（本 PR 完成）

- `demo/web/` 可玩原型：A/B/C/D/E 闭环、浅处/低处双路线、REC/PAUSE 归档、实体 D→B→C门外→E→D 回返、让行不推回、E/B 交界侧向证据、R 全局复位。
- 交付物：可运行页面、俯视地图、节拍截图、机制分镜、`docs/demo-v1-walkthrough.md`。
- 通过条件：不看旧包也能从截图+文档读懂空间、任务与实体行为；行为与 Round 2 合同逐条对应。
- 边界：Web 切片**只验证行为合同**，不验证时代底片、材质、灯光、镜头手感（那些属于 UE 主线的 Gate）。

### M2 UE 可见画面复验（下一步，需要有 UE 5.8 的开发机）

- 在原开发机（或任何装有 UE 5.8 的机器）打开 `demo/ue/H00_Source` 对应工程，复跑 `Entry` 地图。
- 交付物：非黑屏的 720p 运行截图 ≥3 张（A/B 入口、C 归档台、E/B 交界）、启动日志。
- 通过条件：画面可见、无漂浮物、玩家可控；与 Web 切片行为一致。

### M3 人工 60–90 秒手感验收

- 人工完整走一遍节拍：A→B（二选一路线）→C 归档→返程→A；观察实体"始终像在工作而不是追逐"。
- 交付物：一段无剪辑行为录像、让行/机位问题清单。
- 通过条件：Round 2 状态表中六段节拍全部可复现。

### M4 2001 时代底片替换

- 用有制造方式、使用痕迹和时代来源的道具替换占位盒（参照 `archive/02_当前Demo_H00-R0/返潮_W01中式婚宴厅照片化制作规格_v0.1.md` 与生产美术圣经）。
- 通过条件：5 秒静帧读出"具体的 2001 年海边小镇婚宴后场"。

### M5 异常因果落地

- 同一不可见高度在门框/柜脚/墙角/密封条上的干燥受压后果；低处声学状态（变厚、变远，无水声无滤镜）。
- 通过条件：30 秒内读出"没进水，但这里承受过不属于陆地的深度"。

### M6 普通 NPC 与 M01 候选

- 先普通工作人员（站立/拿物/递交/停顿/回头/回返），后 M01 三视图与 10 秒行为。
- 通过条件：交接包"怪物 Gate"四项测试（10 秒移动预测、3 站位重心、路线因果、720p 双层读法）。

### M7 正式资产与贴图

- 只有 M6 通过后才评估 Hunyuan3D（形体候选）与 ComfyUI（可重复贴图）；每个资产带 brief/来源/许可证/gate 记录。

### M8 垂直切片验收

- 60–90 秒可重置 Demo、720p 固定镜头、运行日志、三张审片帧、一段行为录像；按交接包"完成定义"八条逐条验收。

## 5. 增补 / 删除决策与理由（本次修订新增）

### 增补 A1：Web 行为灰盒作为并行验证切片

- **决策**：新增 `demo/web/`（纯 HTML/Canvas，无依赖）作为行为合同的可执行说明书；**官方主线仍是 UE 5.8**。
- **理由**：① 云端与多数评审环境没有 UE 5.8，行为合同（航点、让行、归档、复位）此前只存在于文字和一次无法复跑的历史日志里；② Web 切片让任何人 10 秒内打开验证行为规则，成为跨端回归基线；③ 成本极低（零依赖静态页），不占用资产 Gate 的任何预算。
- **边界**：Web 切片永远不承担美术、镜头、声音质感 Gate；若与 UE 行为不一致，以 Round 2 合同为准修正两端。

### 增补 A2：把"UE 可见画面复验"升格为独立里程碑 M2

- **理由**：交接包中它只是 Round 4 表格里的一行"待复验"，但它实际是 UE 主线当前唯一的硬阻塞（黑屏 = FAIL）。不升格就会被后续资产工作掩埋，重演"用加资产掩盖基础失败"的旧错误。

### 增补 A3：仓库化与证据留存规范

- **理由**：交接包工具矩阵明确写着"Git：当前项目缺版本历史，应优先安装"。本 PR 落实：每个 Gate 的交付物必须进入 git 历史；`archive/` 为只读历史层，新工作只在 `docs/`、`demo/`、`assets/` 进行。

### 删除 D1：Godot 混合 2.5D 路线（归档，不执行）

- **对象**：`archive/04_实现路径与历史路线/返潮_技术路线复判与24小时引擎门_v0.2.md`（结论为"首周 Demo 不再以 UE5 为主，改用 Godot 4 + Blender 混合 2.5D"）。
- **理由**：① 该复判针对的是**旧泥滩/海洋馆周期**的"一周个人 Demo"命题，其场景（海洋馆墙体积液、玻璃压力）已随 2026-08-04 重制决定整体冻结；② 重制后的实现路径决策（`archive/03_实现路径与工作流/01_实现路径决策.md`）已明确"路径 A：H00 独立 Unreal 5.8（当前主线）"，且 Round 4 已在 UE 5.8 上产生编译与状态机证据，切换引擎会作废唯一的运行时证据链；③ 用户在本次任务中再次确认路径 A 为技术主线。
- **处理**：文档保留在 `archive/` 供追溯；其中仍然有效的思想（固定机位构图、低配目标、"引擎不能替创意背锅"）已吸收进 `docs/tech-route.md`。

## 6. 执行纪律

1. 每次生成只问一个问题；每帧只有一个主读点。
2. 不通过时只修一个变量（地图入口/碰撞/灯光/材质/动作/文本），不同时改五项。
3. 不把工具安装当进度：Hunyuan3D/ComfyUI 在 M6 之前不安装。
4. 不把 Agent 的文字审查当作视觉证据；视觉 Gate 只认截图/录像。
5. 诚实标注：任何"历史证据"必须注明验证时间与环境，不得默认它在当前环境仍然成立。
