## 0. 一句话任务

在 `demo/web3d/` 用 **Three.js** 做出 H00-R0《婚宴后场：返席》的 **3D 可玩灰盒 Demo**：60–90 秒可重复回路、M01 返席人（按新形象宪法「看见即恐怖」）、三个关键镜头截图；浏览器可玩、行为可自动测试、截图可 headless 复现。

## 2. 技术栈与目录约定

- **运行时**：Three.js（npm 安装最新稳定版后，把 `node_modules/three/build/three.module.min.js` 拷入 `demo/web3d/vendor/`），原生 ES Modules + import map。**断网可玩**：运行时不允许任何 CDN 依赖。
- **不用打包器、不用框架**：无 vite/webpack/react。本地运行方式与 2D 灰盒一致：`python3 -m http.server 8000` → `http://localhost:8000/demo/web3d/`。
- **npm 只用于**：获取 three、开发期工具（测试用 Node 自带 `node --test`；截图用系统 headless Chromium 或 puppeteer）。`package.json` 放在 `demo/web3d/`，`node_modules/` 不入库。
- 目录：

```
demo/web3d/
  index.html            入口（import map、canvas、HUD 提示条）
  main.js               装配与主循环
  src/constants.js      全部几何与行为常量（Step 2 唯一产出）
  src/world.js          场景灰盒（房间、家具、W00 元素、灯光）
  src/player.js         玩家控制器与碰撞
  src/entity.js         M01 状态机（纯函数，可被测试与主循环共用）
  src/figure.js         M01 占位形象（几何拼装 + 步态）
  src/audio.js          WebAudio 程序化声音
  src/shots.js          URL 参数场景复现与固定机位
  vendor/three.module.min.js
  tests/entity.test.mjs 行为合同自动测试（node --test）
  README.md             操作说明 + 诚实状态表
tools/capture_web3d.py  headless 截图批量脚本（仿 tools/capture_screenshots.py）
assets/screenshots-web3d/   产出截图（≥8 张 1280×720）
```

- **坐标约定**：2D 灰盒的 (x, y)（米，y 向下）映射为 3D 的 (x, z)，高度为 y 轴。所有平面数值原样搬运。

## 3. 最小可玩 Demo 范围

锚定 H00-R0 婚宴后场，与 2D 灰盒同一空间、同一任务、同一节拍，升级为 3D + 新形象语法：

**做**：A—E 五区闭环；持录像带→C 卡座归档→返回 A 的 60–90 秒回路；M01 基础层行为（工作循环/让行/从不转身/声音先于画面）；M01 占位形象（背影可信、侧面主异常，见 Step 6）；W00 散场宴会厅的「看见」时刻（一致朝向的椅群、热气、空白横幅、停在同一小节的伴奏）；低处路线的声学状态；三个关键镜头与截图模式；R 复位；行为日志。

**不做**（提案也不要）：测深/读深度/改承压/守仪式机制、认领系统、记录经济、海洋馆走廊、M02—M04 登场、任何贴图美术、烘焙光照仿真、结局内容、UE 相关任何事、剧情文本。

**恐怖语法红线**（贯穿所有 Step）：玩家可见文本只有操作提示（「按 E 归档」级别），**零解释**——出现「归面/仪式/记忆/海把…/认领」任一词即违宪（[01 §7](../game-design/01_故事背景设定.md#7-禁区)）；无跳脸、无音刺、无追逐、无碰撞推回、无可见水、无蓝色滤镜。

## 4. 分步任务清单

> 顺序执行，每步先看「完成标准」再动手；某步失败就修复该步，不许用下一步的产出掩盖。

### Step 1 工程脚手架

- **输入**：本手册 §2。
- **操作**：建 `demo/web3d/` 目录骨架；vendor 化 three；`index.html` 建 import map、全屏 canvas、底部 HUD 提示条（纯 DOM）；`main.js` 渲染一块地面与天空色，挂 `requestAnimationFrame` 主循环。
- **输出**：上述文件 + `demo/web3d/README.md` 初稿。
- **完成标准**：`python3 -m http.server` 后页面渲染无 console 错误；断网刷新仍可运行。
- **禁止**：CDN 运行时依赖、打包器、TypeScript（保持零构建）。

### Step 2 常量移植（数据先行）

- **输入**：`demo/web/main.js` 的 `WALLS / FURN / TABLES / ROOMS / LOW_ZONE / PRESS_MARKS / CAMS / ROUTE / PLAYER_START / ARCHIVE_POINT / ARCHIVE_RADIUS(2.4) / PLAYER_SPEED(3.6) / ENTITY_SPEED(1.5) / BEATS`。
- **操作**：原样搬进 `src/constants.js`（单位米）；补高度常量：墙高 2.8，门洞高 2.1；家具高度——服务台/保温台/卡座台 0.9、洗涤台 0.85、器材架 1.2、磁带架 1.9、货箱 0.6、卸货台 1.0、圆桌面 0.75；玩家眼高 1.6。
- **输出**：`src/constants.js`；一张顶视 debug 相机截图。
- **完成标准**：顶视截图与 `assets/maps/h00_r0_topdown.png` 逐房间对照，门位、比例、家具位置一致。
- **禁止**：改动任何行为数值；重新发明布局；「顺手优化」房间尺寸。

### Step 3 场景灰盒与 W00 看见时刻

- **输入**：constants；[01 §4 W00](../game-design/01_故事背景设定.md#4-形象库看见即恐怖)；[02 §3.1](../game-design/02_视觉原型设定.md#3-异常态语法)。
- **操作**：墙体/家具用 Box 网格、圆桌用圆柱+桌布裙边，纯色 Lambert/Standard 材质分区（地面用 2D 灰盒各房间色加深一档，墙统一 #8a857c）；灯光 = Hemisphere 底光 + A 厅 3 盏暖钨丝 PointLight + 后场 2 盏冷白。W00 元素全部落位：8—10 把椅子（含 2 把倒地的）**朝向全部指向主桌**；转盘上菜品占位 + 2—3 缕缓慢上升的半透明热气面片；门口红横幅 plane，名字位置留两块干净空白；C 房 CRT 屏（熄屏深灰）。低处区域**不变色不画线**，只放 PRESS_MARKS 的柜脚/门框下部受压痕（深色小面片）。
- **输出**：`src/world.js`。
- **完成标准**：站在 A 厅环视一圈的截图能被复述为「散场中的婚宴厅，没有人」；低处路线肉眼无任何 UI 标识。
- **禁止**：贴图、Bloom/色差后期、蓝色调、可见水。

### Step 4 玩家控制器

- **输入**：constants；2D 灰盒的圆形 vs AABB 碰撞逻辑。
- **操作**：PointerLock 鼠标转向 + WASD（速度 3.6 m/s）；肩后第三人称相机（距 2.4m、高 1.7m，射线检测碰墙拉近）；玩家占位体（素色胶囊）；按键 `E` 交互、`R` 复位、`V` 调试标注层（房间名/航点/低处范围，默认关）、`M` 静音。
- **输出**：`src/player.js`。
- **完成标准**：能无卡顿走完 A→B→C→E→D 闭环，门洞通过顺畅，不穿墙不穿家具。
- **禁止**：跳跃、冲刺、体力条、小地图、任何 HUD 数值。

### Step 5 M01 行为状态机（先测试后接入）

- **输入**：[03 §3.1 基础层](../game-design/03_核心玩法.md#31-m01-返席人无正面的父亲行为合同)；constants 的 ROUTE（15 航点，含 pause 与 evidence 标记）。
- **操作**：`src/entity.js` 写成纯函数 `stepEntity(entityState, playerState, dt) -> entityState`：状态只有 WORK/MOVE/WAIT；匀速 1.5 m/s 恒定；到点按 pause 停留（1.4—3.2s 做工作动作标签）；**让行**：玩家距离 <1.2m 且处于前进方向锥内 → WAIT，>1.5m 恢复；朝向永远等于路径方向（从不面向玩家）；侧向证据：evidence 航点 + 玩家在低处 + 视线可及 + 距离 <6m → 激活 1.6s，每圈一次；日志格式沿用 2D 灰盒（含 RESET_REASON）。
- **输出**：`src/entity.js` + `tests/entity.test.mjs`（`node --test`，≥8 用例：航点推进顺序、速度恒定、停留时长、让行触发、让行解除、归档半径 2.4 判定、侧向证据每圈一次、R 复位全量还原、整圈用时落在 60—120s）。
- **完成标准**：`node --test demo/web3d/tests/` 全绿。
- **禁止**：实体速度受玩家影响、任何追逐/寻路向玩家、把测试写成永真断言。

### Step 6 M01 占位形象（看见即恐怖的灰盒下限）

- **输入**：[01 §4 M01](../game-design/01_故事背景设定.md#4-形象库看见即恐怖)、[02 §3.2](../game-design/02_视觉原型设定.md#3-异常态语法)。
- **操作**：`src/figure.js` 几何拼装，身高 1.78m：躯干/四肢盒体+胶囊，工装蓝灰 #3e4a56、裤深灰 #2f3338；**左肩比右肩低 4cm，右脚步幅短 15%**（步行摆动相位不对称即可）；背面完全正常。正面：额头到胸口一道纵向凹槽（暗褐 #2a211c），槽内嵌 24—40 个半球「复眼」（黑色低粗糙度，靠高光读出湿亮）+ 6—10 个盐晶锥（#d8d2c4）；无嘴、无鼻、无眼眶。平时正面天然背对玩家（行为合同保证）；侧向证据激活的 1.6s 内，它在 E/B 交界转身 70—90° 做「放盘」动作，把断面短暂暴露给低处视角。
- **输出**：`src/figure.js`；两张 720p 检查图（纯背影 / 侧向证据帧）。
- **完成标准**：**轮廓双读**——背影图给未接触项目的人看，答案是「一个工人」；侧面图的描述里出现不适词。无人可盲测时自查：背影不含任何异常件；侧面主异常只有一处（凹槽断面），无第二异常。
- **禁止**：跳脸机位、发光红眼、触手、贴图、给它加音刺。

### Step 7 程序化声音

- **输入**：[03 §2](../game-design/03_核心玩法.md#2-四个核心动词) 的「声音先于画面」原则；2D 灰盒的声学状态设计。
- **操作**：`src/audio.js` 全部 WebAudio 合成，零采样素材：A 厅伴奏 loop（8 秒和弦琶音 + 磁带底噪，**永远停在同一小节重新开始**，声源在 A 厅音箱位，距离衰减）；实体工作声（短促瓷器/敲击合成音，绑定实体位置，视线被墙挡时衰减 6dB 并低通）；低处声学状态：玩家进 LOW_ZONE 时全局低通 ~800Hz + 音量微降（「变厚变远」）；侧向证据**不新增任何声音**。`M` 键静音。
- **输出**：`src/audio.js`。
- **完成标准**：闭眼在 B 走廊行走，凭听感能分辨浅处/低处；实体不可见时能凭工作声判断大致方位。
- **禁止**：水声、突然巨响、倒放人声、儿童笑声、任何「恐怖音效素材」。

### Step 8 任务与节拍装配

- **输入**：BEATS 六节拍文案（沿用 2D 灰盒，可微调措辞但不得加解释）；归档交互合同。
- **操作**：玩家初始持录像带（HUD 一行字说明）；C 卡座 2.4m 内按 `E` 归档：CRT 亮起播 3 秒「普通婚宴画面」占位（纯色块变化即可）后回熄屏；归档后返程；回到 A 只落一行日志，**无结算画面**。R 全局复位对齐 2D 灰盒语义。
- **输出**：装配进 `main.js` 的完整回路。
- **完成标准**：人工走完 60—90 秒回路顺畅；全部 HUD 文案通过解释腔词表检查（见 §6）。
- **禁止**：教学弹窗、成就、评分、结算、「剧情提示」。

### Step 9 截图模式与三个关键镜头

- **输入**：[02 §4 镜头语法](../game-design/02_视觉原型设定.md#4-镜头语法)；2D 灰盒的 URL 参数复现方法论（`applySceneParams`）；CAMS 三机位。
- **操作**：`src/shots.js` 实现 URL 参数确定性复现（玩家位姿/实体航点进度/evidence 激活/冻结/裸画面）；三个固定机位关键镜头：
  1. `shot_w00_hall`——A 厅广角（Cam_A_B 位）：一致朝向的椅群 + 热气 + 空白横幅同时入画（W00 看见时刻）；
  2. `shot_doorframe`——C 门外（Cam_C_Door 位）：门框切开实体肩线，背影可信；
  3. `shot_evidence`——E/B 交界（Cam_E_B 位）：低处视角，侧向证据激活帧，断面与复眼可辨。
  写 `tools/capture_web3d.py`（headless Chromium，参照 `tools/capture_screenshots.py`）批量输出 ≥8 张 1280×720 至 `assets/screenshots-web3d/`（三关键镜头 + 六节拍抽样）。
- **输出**：`src/shots.js`、`tools/capture_web3d.py`、截图集。
- **完成标准**：脚本一条命令可重跑出同样构图；三关键镜头构图要素逐项齐备。
- **禁止**：后期滤镜、画面内叠字幕解释、临时改场景摆拍。
