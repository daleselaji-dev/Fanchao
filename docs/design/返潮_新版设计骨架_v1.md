# 《返潮》新版设计骨架 v1

> 日期：2026-08-25
> 性质：对交接包（2026-08-05）全部设定文档批判性审查后的新版骨架。它回答四件事：核心设定、核心工作流、技术栈、逐步步骤。
> 上位关系：本稿在「潮来了，但水没有来」这条已确认物理规律之上，重铸恐怖的**人心层**；不推翻已通过的 H00-R0 空间与行为 Gate，只重标定其语义与资产层。
> 评审标准来源：用户明确要求——恐怖要能在很短时间内造成张力，一两句话能展开逻辑、还能往里加纵深；对标《死魂曲》（SIREN）「世人的恐怖」（过分享乐的异化、邪教感）与《寂静岭》的深度；淘汰浅、机械、无趣的旧钩子。

## 0. 一页总览

**新版核心（两句话）：**

> **潮来了，水没有来——海把人们记错的亲人送了回来。**
> **小镇不害怕：小镇在办喜事。**

宴席不散，红绸不摘，婚庆录像连夜放；谁回来了，就给谁摆一副碗筷。外乡人来了也一样——镇上会热情地、不容拒绝地，替你也留好一个座位。

- **恐怖母题定名：「返席」。** 回来的东西要入席；活着的人也要被安排入席。当前 Demo《婚宴后场：返席》的标题从场景名升格为全作核心动词。
- **五秒张力测试：** 深夜两点，婚宴厅一半桌子已撤空、一半仍满席热闹；空椅子上摆着满杯的酒，喜字贴在墙面一条干燥的深水压痕上。不需要一个字的说明。
- **可纵深：** 物理层（干燥深度）→ 民俗层（归面礼如何被做反）→ 社会层（喜悦是恐惧被礼数消化后的形状）→ 伦理层（保存＝占有；你补齐真相的动作与他们补齐亲人的动作同构）。

### 1.2 为什么旧恐怖「浅、机械、无趣」——病因诊断

交接包里的设定演进（空位有重量 → 内里翻出 → 深压伤向同化 → 余海残骸生态）有一个共同病灶：**每一版都在升级「物质如何异常」，没有一版回答「人为什么不害怕」。**

物理规则越写越精密（八条宪法、四种证据、生成链八环），恐怖却越来越像一套需要 GDD 才能理解的物性演示。《寂静岭》《死魂曲》的深度从来不在物性，而在**共同体对灾变的态度**：SIREN 里尸人照常巡逻、耕作、大笑，村庄以一种诡异的正常运转——「世人的恐怖」的本质是**灾变被日常化、甚至被喜悦化**。

交接包其实两次摸到了这个东西（「过量的安置」的不合时宜的轻松；「内里翻出」的过分殷勤的喜悦），但两次都把它当成配菜扔掉，回头继续雕刻材料受力。**新版骨架的唯一大动作，就是把这份「喜悦」从配菜提为主菜，并给它一个中国千禧年独有的容器：办喜事。**

## 2. 新版核心设定

### 2.1 两句话与展开

> **潮来了，水没有来——海把人们记错的亲人送了回来。**
> **小镇不害怕：小镇在办喜事。**

逐句的逻辑展开（每句都经得起「为什么」的追问，这就是纵深入口）：

- **为什么送回来的是「记错的」亲人？** —— 因为归面礼送走的从来不是人，是家属对亲人的不完整描述。海只能按描述归还：描述里没有的部分（没见过的正脸、没听过的话），海用自己拥有的古老结构补齐——石化复眼、贝灰、压实沉积。**回来的东西越像，说明家人记得越多；越不像，说明爱得越粗心。** 这本身就是一层伦理恐怖。
- **为什么是喜事？** —— 三层解释，层层加深：
  1. **表层（礼数惯性）：** 沿海规矩，久别归人要接风、要办酒；亲人「回来了」，于礼必须庆。
  2. **中层（恐惧的形状）：** 镇上人心里都清楚回来的不对。但第一个不肯敬酒的人、第一个说「这不是我爸」的人，等于当众宣布自家亲人死了两次。没人敢先停下来。**喜悦不是没有恐惧，喜悦是恐惧在礼数里唯一被允许的形状。** 宴席越热闹，说明镇上越怕。
  3. **深层（宴席即锚）：** 席开着、名字被叫着、位置被留着，回来的东西就安分地坐在席上。散席，它们就要「回家」——回到各自家里的床上、饭桌上、户口本上。全镇联手把喜事无限延长，本质是一场以庆祝为形式的**镇压仪式**。这是「邪教感」的落点：没有黑袍与祭坛，只有红绸、喜字与不许停的电子琴。

### 2.2 五秒／三十秒／九十秒张力合同

沿用交接包的三读法门结构，替换内容：

- **5 秒（一张静帧）：** 深夜的婚宴厅，一半席已撤、一半仍满员热闹；空座上碗筷齐全、酒是满的；喜字贴在墙上一条横贯整面墙的干燥深水压痕上。观看者应能说出：「这里在办喜事，但不该办。」
- **30 秒（一段行走）：** 玩家穿过后场，听见宴厅传来碰杯与笑声——但笑声的节拍完全一致，像同一段笑被多人分演；一名服务员在给空椅子里的「人」布菜，动作恭敬而熟练。
- **90 秒（一次遭遇）：** 玩家被一位喜气洋洋的长辈拉住，喊他一个不属于他的名字，往他手里塞酒杯；全桌鼓掌。玩家挣脱或顺从的选择立刻改变一件事：他在座位表上的名字。

### 2.3 纵深层（按解锁顺序）

1. **物理层（第一小时可感）：** 「潮来了但水没有来」全部沿用——同一高度的桌腿短缩、密封条挤出、耳压与声学突变、沉积层理。新增一条对应关系：**深度界面的高度 ＝ 宴席仍在办的楼层。** 席办到几楼，深度就压到几楼。玩家测深即是在测「喜事蔓延到了哪里」。
2. **民俗层（第一幕末揭开）：** 归面礼的正史与反转史（沿用基础设定第二轮评审稿全文）：允许记得、不许替死者继续生活 → 录像与照片年代「留白＝不够爱」 → 2001 年滩涂最后一次集体送面 → 潮没有来。
3. **社会层（第二幕主体）：** 镇民不是统一邪教。有人真信亲人回来了（最幸福也最危险）；有人明知不对但不敢先停杯；有人想借宴席把某个活人「顶」进缺席者的位置；有老人记得正确的老规矩，只会纠正动作、不解释原理。多立场结构沿用《世界与叙事原型 v0.5》第 10 节。
4. **伦理层（第三幕反转）：** 玩家（返乡录像员）以为自己在「记录真相、补齐证据」；最终发现完整的录像、名册、门牌恰恰是海用来「补全」归来者的原料。**你拍得越全，回来的越像。** 主角的职业本身就是加害机制——这是把立项骨架「补齐真实＝占有」的命题变成了可操作的玩法反噬。
5. **空间层（贯穿）：** 莫比乌斯小镇沿用：连续路线翻面后，所有「离镇」的路都从宴厅另一侧的门回来。结局不是杀死什么，而是决定散不散席、以及散席的代价由谁承担（沿用立项骨架第四幕「不完整地离开」）。

### 2.4 主威胁重铸：待客者（M01「无正面父亲」沿用形体，重写职责）

- **形体沿用已确认方向：** 背影是可信的 2001 年沿海父亲——旧蓝工作服、左肩被渔网压低、右脚拖半步；正面自额至腹是一整片石化海洋复眼甲壳，无嘴、不咆哮。视觉 Gate 记录全部有效。
- **职责由「履职者」重铸为「待客者」：** 它不巡逻、不追杀。它在**布席**——沿旧后勤路线收盘、摆筷、领位。发现玩家时它停下、侧身、抬手做一个「请」的手势，然后开始为玩家摆座。它的靠近方式沿用「只倒退接近」的已确认设定（家人只记得背影，所以它永远以背影面对你）。
- **失败状态不是死亡，是「被入席」：** 玩家被按进座位，镜头落在自己面前的座位卡上——写着别人的名字。重开时从后场醒来，某个 NPC 开始用那个名字称呼你（可洗掉，有代价）。
- **为什么这比追逐怪更可怕、也更好做：** 不需要复杂追逐 AI（它走旧路线、目标是「座位」而不是「玩家坐标」）；恐怖峰值来自玩家理解它的目的的那一刻——它不想伤害你，它想**安顿**你。这正是「过量安置」的实体化。
- **后续怪物谱系入口（不进第一切片）：** 「数人的母亲」（席间反复清点人数，数到你）、「抬面者」（合力把新归面抬进宴厅的四人组）、被旧伤重塑的镇民（沿用深压伤向同化的生成规则）。

### 2.5 玩家与核心动词（重标定）

主角沿用立项骨架的**返乡录像员**（有进入公共场所、接触录像设备、询问家庭的现实理由，有随时离开的车票）。四个动词沿用并重标定语义：

| 动词 | 原语义 | 重标定后 |
| --- | --- | --- |
| 读深度 | 从材料与声学判断深浅 | 不变，新增社会读法：深度界面＝宴席蔓延高度 |
| 干潜 | 短暂探入深层声场换取信息 | 不变，深层能听见宴席的「另一半」——先人席的碰杯声 |
| 改承压 | 操作设施改变结构受力与路线 | 不变，新增宴席物件（转盘、推车、卷帘、扩声台） |
| 记路线 | 用地标与声音记住莫比乌斯路线 | 不变，新增「称呼锚点」：你在哪些地方被喊过什么名字，决定翻面后哪些门为你开 |
| **新增：辞席** | — | 拒绝一次敬酒、撕掉一张座位卡、纠正一次称呼。每次辞席立刻改变空间与身份关系，也立刻得罪一桌人——这是把「有代价的切断」做成高频小选择 |

### 2.6 叙事空洞（保留不动）

沿用《世界与叙事原型 v0.5》第 8 节全部空洞：失踪者最后经历、归来物是否含本人意志、海／媒介／愿望谁是主动者，一律不给终极确认。新增一条：**宴席是否真的镇住了什么，还是镇民只是需要相信它镇住了什么——不回答。**

## 3. 核心工作流

工作流骨架沿用《Demo 重制总计划》的 Gate 链与《潮汐制作工作流》的四轨检查，裁决冲突如下。

### 3.1 制作顺序总线（沿用并生效）

> **体验合同 → 俯视地图 → 灰盒行为 → 正常时代底片 → 异常因果 → 正式模型／贴图**

禁止「先生成一张很酷的怪物图，再反向发明地图和玩法」。所有资产按 CANON / CANDIDATE / ARCHIVE 分层管理。

### 3.2 每轮内循环：四轨检查（沿用潮汐工作流，替换北极星句）

- **生活轨：** 人物先有具体事务与可爱节奏，危机中继续做这件事。
- **证据轨：** 每轮只证明一个不可能，其余元素只支持它。
- **误判轨：** 玩家第一次必须有合理但错误的解释（喜宴通宵很正常／老人认错人很正常）。
- **代价轨：** 有效行动立刻改变称呼、座位、路线或证据。

北极星句替换为：玩家结束一段后能说出——**「我为了不被安排进那个座位，亲手让谁的席散了。」**

### 3.3 评审最小问题（沿用核心框架八问，新增两问）

原八问全部沿用（真实生活？中国千禧？系统原本为谁服务？哪个对应关系反了？画面可自证？可观察可干预？干预失去什么？是否偷偷填满空洞？）。新增：

9. **不看文字，测试者能否说出「这里在办喜事，但不该办」？**
10. **这轮的恐怖是否需要玩家先读设定才成立？是则退回。**

### 3.4 分工矩阵（沿用交接包决策）

- **Codex／项目总控：** 维护 CANON、拆 Gate、写工程、验收，任何生成结果不自动升格。
- **网页 ChatGPT：** 视觉总监与审稿（构图、提示词、A/B 评审），不直接改工程。
- **Gemini／Antigravity CLI：** Blender 脚本、灰盒、GLB、manifest 等执行代理。
- **本人（用户）：** 唯一的 canon 裁决者；Gate 通过与否以其判断为准。

每个资产目录保持 `brief.md / source.json / prompt_*.md / candidate / gate.json / review.md / license` 结构。

## 4. 依托的技术栈（含冲突裁决）

### 4.1 裁决：引擎主线为 Unreal Engine 5.8

交接包内存在三条互相冲突的技术路线：① UE 5.8 独立工程（`FanchaoH00UE`，当前主线）；② Godot 4 + Blender 混合 2.5D（技术路线复判 v0.2，2026-07 决策）；③ 复用 Three.js 酒店原型做 24 小时切片（立项骨架 §9.3）。

**裁决：① UE 5.8 为唯一主线。** 理由：

1. 时间顺序上它是最新决策（2026-08-04 重制决定之后的《实现路径决策》明确路径 A 为当前主线）；
2. H00-R0 已在该工程通过 Round 1–4（空间、节拍、灰盒、状态机）四道 Gate，弃用等于抛弃已验证证据；
3. 「PS3 级 720p 固定机位」的画面目标在 UE 内完全可控，不需要 Lumen/Nanite 全开，UE5 的伸缩设置足以向下兼容；
4. Godot 混合 2.5D 与 Three.js 路线保留为 ARCHIVE：前者的「预渲染远景＋实时近景」分层思想在 UE 内同样可用（关键异变可预渲染成序列帧接入），后者的交互骨架经验已被 H00 状态机吸收。

## 5. 逐步要做的步骤

原则：每步只验证一件事，失败退回本步输入，不加装饰救场。H00-R0 已通过的 Gate 不重跑。

| # | 步骤 | 产出 | 通过门 |
| --- | --- | --- | --- |
| 1 | **UE 可见画面复验**（阻塞项） | 修复后 Entry 地图的 720p 截图与一段走查录像 | 玩家可控、灯光可见、无黑屏；日志与画面互证 |
| 2 | **H00-R0 语义重标定**（纸面，半天） | 修订版 90 秒 beat sheet＋声音因果表：A 厅从「收场」改「不肯散场」，实体从「履职」改「待客」，结尾不可逆变化改为「玩家名字出现在座位卡上」 | 空间闭环 A–E 与状态机零改动；新 beat 只动资产层与表演层 |
| 3 | **视觉基准帧组**（生图，按 Prompt 文档执行） | W01 宴厅「不肯散场」目标帧、B 走廊深度证据帧、M01 待客者三视图等（优先级见姊妹文档） | 5 秒读出「办喜事但不该办」；不看文字复述核心 |
| 4 | **待客者行为门**（灰盒占位体） | 走／停／「请」三组动作＋倒退接近＋摆座目标逻辑 | 测试者能从姿态判断「它想让我坐哪」，而非「它要抓我」 |

| 6 | **宴席声场门** | 同拍笑声、碰杯节奏、电子琴缺件、空座布菜声；深层「先人席」声场 | 关掉画面只听声音，能判断宴席方向与深度 |

## 6. H00-R0 兼容性说明

已通过的四道 Gate（空间方案、节拍与行为合同、Blender 灰盒、Unreal 状态机）**全部有效**。重标定只改三处，全部位于资产与表演层：

1. **A 宴会厅状态：** 「婚宴收场中」→「婚宴不肯散场」。半撤半满、空座满杯、喜字压痕同帧。
2. **实体语义：** M01 沿 D→B→C→E→D 的旧路线动作从「放盘、擦手、转身」改为「收盘、摆筷、领位」，增加一个「请」的手势；路线与状态机不变。
3. **结尾不可逆变化：** 原「实体回到旧位置」保留，叠加一层：玩家归档录像带后返回 B 走廊时，服务台名单上多了一个名字——他自己的。

录像带归档任务、浅／深双路线、禁止项（不攻击、不冲刺、不跳脸、无可见水线）全部不变。
