# 《返潮》故事与形象设定

> 状态：现行宪法。本文是对旧版（180 行说明书体）的重写：砍掉三层世界结构、七条返还规则、仪式五段程序与逐年代仪式演变史——那些把恐怖「解释清楚」的东西不再是主叙事。
> 世界观因果压缩为文末**一页制作备忘**，只供制作组内部自洽用。
> 写作纪律（对本文档所有后续修订者生效）：**先写看见什么，再极短地写它怎么动。玩家看到形象就该害怕，不需要读懂任何历史。**

---

## 1. 一句话世界

2001 年，中国北方一座海边小镇。潮来了，水没有来。被海送回来的人开始回家。

## 2. 舞台

刚装修好几年、仍在体面营业的千禧年小镇：婚宴酒店排着座、海洋馆即将开幕、滩涂上立着海防警报塔。全程**绝对干燥**——真实的水只存在于鱼缸、水杯和海里。正常态必须先赢：玩家先认出一个值得怀念的小镇，再撞见下面这些东西。

## 3. 主角

**韩汛**（P01），外乡来的海防警报/广播线务员，22—26 岁，唯一应聘者。职责覆盖全镇声路：警报塔、街道喇叭、婚宴厅扩声、海洋馆广播——这份工作是他进入所有关键空间的现实通行证。他不懂本地禁忌，本能是「测试线路=发声确认」，而这正是本地人最忌讳的事。他不能战斗，只能测深、读空间、改承压、学会不做什么（玩法见 [03](03_核心玩法.md)）。

## 4. 形象库：看见即恐怖

> 2026-08-24 三审：本节旧版的 M01 返席人 / M02 迎宾的人 / M03 洗涤间的搁浅者 / M04 敬酒的女人经用户否决**全部废弃**（命名与意象封存，禁止变体回归，裁决见 [05 §8](05_设定审定_保留与删除.md#8-三次审定2026-08-24废弃-m01m04-形象库)）。现行怪物宪法为 **[07 恐怖核心与怪物设计](07_恐怖核心与怪物设计.md)**，编号自 M05 起。

现役名录（四栏形象页与恐怖核心三铁律见 07）：

- **M05 双背**——收台工，绕到正面看见的还是一个后背（Demo 与垂直切片主怪，身体规则破坏）；
- **M06 梁下**——太高的上菜员，被吊顶压弯着工作（P2，空间压迫）；
- **M07 空趟**——先声后人的一趟上菜（P2/P3，声音先于画面）；
- **M08 对班**——复放玩家上一次动作的那个班次（P3，错误熟悉感）；
- **W00 散场的宴会厅**——空间形象，继续有效，Demo 直接使用（阈限空间）。

总纪律不变：形象必须通过「一句话测试」——不给任何背景，把「看见什么」念给陌生人听，对方应当已经不舒服。做不到就回炉，禁止靠补背景故事抢救。新增形象走 [07 §6 新怪准入三问](07_恐怖核心与怪物设计.md#6-新怪准入三问取代长框架)。

## 5. 叙事节拍：玩家看见 → 身体反应

节拍单位不是「玩家理解了什么」，而是「玩家看见了什么、身体先做了什么」。以 H00 婚宴后场为例：

| 玩家看见 | 预期身体反应 |
| --- | --- |
| 散场宴会厅：热菜、坐皱、无人（W00） | 放轻脚步，不自觉压低呼吸 |
| 走廊尽头一个背影在收桌，动作可信 | 松一口气——「还有人在干活」 |
| 跟了半条走廊，他一次也没有回头；折返时他不转身，倒着走回来 | 停下，起疑，想抢到他前面看一眼正面 |
| 迎面走来的还是一个后背：同样的驼肩、领口、发旋 | 后退半步，之后拒绝再绕到任何背影的正面 |
| 他停在你的必经路上，完全静止地等你让开 | 主动贴墙让路——玩家开始服从它的秩序 |

规则：每个场景只允许一个主形象承担「看见」时刻；声音永远先于画面抵达；看见之后**不结算、不解释、不奖励**。

## 6. 剧情骨架（每行一幕，不再展开）

- 一·**潮窗**：抵达、三张工单的日常、滩涂集体送面点火、末班车无人下车。
- 二·**测深**：学会用警报读出干燥空间的深度；婚宴后场与海洋馆走廊互为翻面。
- 三·**认领**：镇上的活人开始被当成「应该回来的人」对待；主角自己的细节逐项吻合某个失踪者。
- 四·**再送**：在翻面的城镇重建一条真正向外的路，把回来的东西再送走一次。

三个结局，都有代价，没有正确答案：**送走**（静默全部声路，带人离开，不回头）／**留住**（保留认领，小镇在翻面中保持完整）／**切断**（毁掉公共声路，每户独自面对）。

## 7. 禁区

1. **禁止解释腔**：任何玩家可见文本（对白、磁带、录像、UI、加载页、道具描述）不得出现因果说明——不解释仪式史、不解释怪物成因、不出现「记忆缺口 / 海补全 / 仪式做反」等制作组内部词汇。
2. 不用 NPC、收集品或教程给玩家上世界观课；NPC 只做事、只忌讳，不讲解。
3. 不以「一场失败仪式释放怪物」总结全镇；不设单一事故谜底、隐藏名单、正确人数。
4. 不用「主角其实早死了」作总反转；不让任何角色掌握全套真相。
5. 不把传统写成邪教，也不写成无瑕智慧；不把现代等同罪恶。
6. 形象服从「一句话测试」，禁止靠背景故事抢救不吓人的形象；禁止把海洋结构当随机贴纸（贝壳鱼鳞贴满伤口）。
7. 海是否有意识、归来者体内是否有本人、返潮到底是什么——**全作不回答**，制作组也不在任何文档里给出标准答案。

## 附录：世界观制作备忘（全部因果只此一页，禁止扩写）

> 用途：让场景、资产、行为设计在内部自洽。**本页任何内容不得以任何形式进入玩家可见文本。**

- 海难者无尸可葬时，家属捏一个临时人形「归面」送归海。仪式的本意是：能确认的塑造，不能确认的留空——允许记得，但不让记忆替死者继续生活。
- 几十年里没有反派，只有每一代人「多留一点、多叫一次、多等一会儿」：照片、录音、门牌被一件件加回归面。方向反了——从送走亲人，变成给愿望一具不会离开的身体。
- 2001 年初夏，积压两年的送面在同一个潮窗集体举行，接入了现代警报链。最后一声警报响完，潮没有来；几百具归面像同时落入深处一样被压矮，然后一起转向陆地。
- 自那之后：人记得的部分决定归来者的轮廓与动作；人没提供的部分不会留空——身体以错误的方式把缺口补成「完整」（没被记住正面的人两面都是背，没被记住身高的人被楼层压弯，先被想起声音的人声音先到）。归来者回到别人记忆中的位置，继续做记忆里的事。呼名与回头等于认领；记录（照片/录音/录像）是喂养。
- 空间侧：返潮先改材料受力与声音方向，再改身体。干燥房间先出现承压证据与延迟回声（玩法转译见 [03](03_核心玩法.md)、[04](04_核心机制.md)）。
- 主角侧：他按下了点火事件的最后一声警报；他的年龄、口音、步幅正逐项吻合码头失踪者——离开小镇之前，他得先把「自己是谁」从别人的记忆里取回来。
