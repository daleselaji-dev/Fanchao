# 《返潮》故事与形象设定

> 状态：现行宪法。本文是对旧版（180 行说明书体）的重写：砍掉三层世界结构、七条返还规则、仪式五段程序与逐年代仪式演变史——那些把恐怖「解释清楚」的东西不再是主叙事。
> 世界观因果压缩为文末**一页制作备忘**，只供制作组内部自洽用。
> 写作纪律（对本文档所有后续修订者生效）：**先写看见什么，再极短地写它怎么动。玩家看到形象就该害怕，不需要读懂任何历史。**

---

## 1. 一句话世界

2001 年，中国北方一座海边小镇。潮来了，水没有来。被海送回来的人开始回家。

## 2. 舞台

刚装修好几年、仍在体面营业的千禧年小镇：婚宴酒店排着座、海洋馆即将开幕、滩涂上立着海防警报塔。全程**绝对干燥**——真实的水只存在于鱼缸、水杯和海里。正常态必须先赢：玩家先认出一个值得怀念的小镇，再撞见下面这些东西。

## 3. 主角

**韩汛**（P01），外乡来的海防警报/广播线务员，22—26 岁，唯一应聘者。职责覆盖全镇声路：警报塔、街道喇叭、婚宴厅扩声、海洋馆广播——这份工作是他进入所有关键空间的现实通行证。他不懂本地禁忌，本能是「测试线路=发声确认」，而这正是本地人最忌讳的事。他不能战斗，只能测深、读空间、改承压、学会不做什么（玩法见 [03](03_核心玩法.md)）。

## 4. 形象库：看见即恐怖

每个形象四栏：**看见什么 / 它在场上怎么动 / 为什么一眼可怕 / 禁用的解释腔**。
总纪律：形象必须通过「一句话测试」——不给任何背景，把「看见什么」念给陌生人听，对方应当已经不舒服。做不到就回炉，禁止靠补背景故事抢救。

### M01 返席人（无正面的父亲）——P1 垂直切片唯一威胁

- **看见什么**：散场中的婚宴后场，一个穿旧蓝工装的男人背对你收拾桌子，动作熟练，节奏安稳，左肩比右肩低，右脚拖半步。绕到侧面才看见：他没有正面——从额头到胸口是一道纵向裂开的旧伤，伤口里嵌满**石化的古代生物复眼和盐晶**，像被敲开的礁石断面，干燥，一颗颗复眼在无水处缓慢对焦。
- **怎么动**：只做工作——收桌、洗涤、把东西归位，匀速，永不追人；你挡在他的旧路线上，他停下，等你让开。全场他**从不转身**。
- **为什么一眼可怕**：背影是最可信的普通劳动者，侧面是一个地质断面——两种读法装在同一具身体上（恐怖谷 × 局部异化）。他工作得越认真，越可怕。
- **禁用的解释腔**：不得解释这道伤从哪来、复眼为什么长在那里、他是谁记错的谁。「记忆缺口」「海补全」等词永远不得出现在玩家可见文本里。

### M02 迎宾的人（照片脸）——P2 登场

- **看见什么**：婚宴厅门口的红绸拱门下站着迎宾员，西装、绶带，向每个经过的人微微鞠躬。他的脸第一眼完全正常，第二眼哪里都不对：像一张翻拍过多次的婚礼合影被放大后重新捏出来的脸——五官位置都对，分辨率不够。笑容保持得太久，颧骨的皮肤已经像干涸的滩泥一样细细皲裂。
- **怎么动**：站定，鞠躬，问候语永远是同一句的前半句。他始终面向门口，欢迎从来不会来的宾客。
- **为什么一眼可怕**：恐怖谷 × 怀旧恐怖——他是婚礼录像里最熟悉的角色，但他是从录像里、不是从活人里长出来的。
- **禁用的解释腔**：不得解释他是照片变的还是人变的，不得给他名字和家庭。

### M03 洗涤间的搁浅者——P2/P3 登场

- **看见什么**：洗涤间水池下方的空隙里卡着一个人，四肢折叠的方向不对——肘和膝都朝里收，肩胛从工作服后背顶出错误的角度，像退潮后被水流反复摆放又搁浅的东西。他仍在工作：一只从架子间隙里伸出来的手，把洗好的盘子一只只递出来，摞得整整齐齐。
- **怎么动**：不离开那个空隙。你取走盘子，他继续递；你不取，那只手停在半空，一直等。
- **为什么一眼可怕**：肢体恐怖——人体被塞进不可能的容积，却保持着最尽责的劳动；错位不流血、不呻吟，比任何暴力都糟。
- **禁用的解释腔**：不得解释他怎么进去的、为什么不出来、他是谁家的谁。

### M04 敬酒的女人——P3 登场

- **看见什么**：宴会厅角落，一个穿红礼服的女人保持着敬酒的姿势，杯子举在半空。举杯的那条手臂从肘部以下不再是手臂，而是一段**干燥的潮间带岩面**——藤壶、石灰质管虫、牡蛎壳层层覆盖，全是干的；藤壶的壳盖仍在极缓慢地开合，像在没有水的地方呼吸。杯子被岩面包进去半只，酒还在。
- **怎么动**：几乎不动。每隔很久，把杯子举高一寸，等待有人碰杯。
- **为什么一眼可怕**：海洋侵入身体——身体的一部分已经是海的领土，而这片海是干的；一个礼节动作被无限延长。
- **禁用的解释腔**：不得解释这条手臂发生了什么、她在等谁、酒为什么没洒。

### W00 散场的宴会厅（空间形象）——H00 的基调，Demo 直接使用

- **看见什么**：婚宴散到一半的宴会厅：转盘上的菜还冒着热气，红绒椅套上有人形的坐皱，伴奏带停在间奏，一个人都没有。所有椅子——包括推开的、倒下的——朝向完全一致，全部指向主桌，像退潮在滩涂上留下的搁浅物。门口横幅上，新人名字的位置是两块干净的空白。
- **怎么动**：它不动。你离开再回来，热气还在，伴奏还停在同一小节。
- **为什么一眼可怕**：阈限空间 × 怀旧恐怖——最热闹的公共空间保留着「刚刚还有人」的全部证据，唯独没有人；时间不肯流逝，比闹鬼更糟。
- **禁用的解释腔**：不得用广播、字条或 NPC 解释人去了哪。

> 制作状态：M01 与 W00 属于垂直切片；M02—M04 形象已锁、登场后置（准入与排期见 [05](05_设定审定_保留与删除.md)、[00](00_项目总览与规划.md)）。新增形象必须走 05 的准入测试，且至少覆盖一种尚未用满的恐怖源（局部异化 / 肢体恐怖 / 海洋侵入身体 / 怀旧恐怖 / 阈限空间 / 恐怖谷）。

## 5. 叙事节拍：玩家看见 → 身体反应

节拍单位不是「玩家理解了什么」，而是「玩家看见了什么、身体先做了什么」。以 H00 婚宴后场为例：

| 玩家看见 | 预期身体反应 |
| --- | --- |
| 散场宴会厅：热菜、坐皱、无人（W00） | 放轻脚步，不自觉压低呼吸 |
| 走廊尽头一个背影在收桌，动作可信 | 松一口气——「还有人在干活」 |
| 门框切开他的肩线：左肩太低，节奏太稳 | 停下，开始绕着看 |
| 侧面 ≤2 秒：断面、复眼、盐晶 | 后退半步，之后拒绝再走近任何背影 |
| 他停在你的必经路上，等你让开 | 主动贴墙让路——玩家开始服从它的秩序 |

规则：每个场景只允许一个主形象承担「看见」时刻；声音永远先于画面抵达；看见之后**不结算、不解释、不奖励**。

## 6. 剧情骨架（每行一幕，不再展开）

- 一·**潮窗**：抵达、三张工单的日常、滩涂集体送面点火、末班车无人下车。
- 二·**测深**：学会用警报读出干燥空间的深度；婚宴后场与海洋馆走廊互为翻面。
- 三·**认领**：镇上的活人开始被当成「应该回来的人」对待；主角自己的细节逐项吻合某个失踪者。
- 四·**再送**：在翻面的城镇重建一条真正向外的路，把回来的东西再送走一次。

三个结局，都有代价，没有正确答案：**送走**（静默全部声路，带人离开，不回头）／**留住**（保留认领，小镇在翻面中保持完整）／**切断**（毁掉公共声路，每户独自面对）。

## 7. 禁区

1. **禁止解释腔**：任何玩家可见文本（对白、磁带、录像、UI、加载页、道具描述）不得出现因果说明——不解释仪式史、不解释怪物成因、不出现「记忆缺口 / 海补全 / 仪式做反」等制作组内部词汇。
2. 不用 NPC、收集品或教程给玩家上世界观课；NPC 只做事、只忌讳，不讲解。
3. 不以「一场失败仪式释放怪物」总结全镇；不设单一事故谜底、隐藏名单、正确人数。
4. 不用「主角其实早死了」作总反转；不让任何角色掌握全套真相。
5. 不把传统写成邪教，也不写成无瑕智慧；不把现代等同罪恶。
6. 形象服从「一句话测试」，禁止靠背景故事抢救不吓人的形象；禁止把海洋结构当随机贴纸（贝壳鱼鳞贴满伤口）。
7. 海是否有意识、归来者体内是否有本人、返潮到底是什么——**全作不回答**，制作组也不在任何文档里给出标准答案。

## 附录：世界观制作备忘（全部因果只此一页，禁止扩写）

> 用途：让场景、资产、行为设计在内部自洽。**本页任何内容不得以任何形式进入玩家可见文本。**

- 海难者无尸可葬时，家属捏一个临时人形「归面」送归海。仪式的本意是：能确认的塑造，不能确认的留空——允许记得，但不让记忆替死者继续生活。
- 几十年里没有反派，只有每一代人「多留一点、多叫一次、多等一会儿」：照片、录音、门牌被一件件加回归面。方向反了——从送走亲人，变成给愿望一具不会离开的身体。
- 2001 年初夏，积压两年的送面在同一个潮窗集体举行，接入了现代警报链。最后一声警报响完，潮没有来；几百具归面像同时落入深处一样被压矮，然后一起转向陆地。
- 自那之后：人记得的部分决定归来者的轮廓与动作；人没提供的部分由海床材料补齐（石化复眼、盐晶、贝灰、压实沉积）。归来者回到别人记忆中的位置，继续做记忆里的事。呼名与回头等于认领；记录（照片/录音/录像）是喂养。
- 空间侧：返潮先改材料受力与声音方向，再改身体。干燥房间先出现承压证据与延迟回声（玩法转译见 [03](03_核心玩法.md)、[04](04_核心机制.md)）。
- 主角侧：他按下了点火事件的最后一声警报；他的年龄、口音、步幅正逐项吻合码头失踪者——离开小镇之前，他得先把「自己是谁」从别人的记忆里取回来。
