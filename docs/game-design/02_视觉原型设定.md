# 《返潮》视觉原型设定

> 状态：现行宪法。本文档锁定美术方向，整合交接包中「核心框架与视觉宪法」「中国千禧年怀旧恐怖美术锁定」「视觉风格圣经」「生产美术圣经」等十余篇文档中互相重复、互相冲突的条目，收敛为一份可验收的规范。
> 交接包所有 AI 生成目标帧一律视为**未通过**候选，只有走完 §6 原型制作门的图像才获得设定权。

---

## 1. 视觉主句

**这是一座能被 2001 年地方电视、婚礼录像和普通相机如实记录的中国海边小镇；摄影没有失效，失效的是干燥材料所承担的深度。**

两条推论：

1. **正常态必须先赢**。玩家先认出一个真实营业中的沿海小镇——刚装修好几年、仍被认真使用的体面——然后才发现深海后果。正常态不够真实、不值得怀念，返潮就没有损失感；
2. **异常是证据，不是宣布**。深度通过墙体、门框、柜脚、桌腿、密封条、管线、地面、声音和人体姿态的**长期后果**被推断出来，不通过滤镜、水面或怪物脸宣布。

## 2. 正常态锁定：2001 年的体面

### 2.1 千禧识别物（美术必须优先制作的资产池）

- **婚宴酒店**：深红亮漆前台、仿大理石台面、金色不锈钢包边、红绒椅套、白桌布、转盘、塑料花、镜墙、金色线脚、「囍」字、暖钨丝灯、伴奏带音响；
- **公共与办公**：总台多线路电话、房号铜牌、2002 年挂历、宾至如归牌匾、手写押金单、穿孔打印纸、灰黑 CRT、保温瓶、搪瓷杯、烟灰缸、计算器、钥匙皮牌；
- **海洋馆**：褪色青绿、乳白玻璃、彩绘导视、新旧工业构件、儿童讲解广播、水泵与过滤设备声；
- **街镇与劳动**：水泥灰、锈铁、粉刷绿、广告红、荧光灯白、旧蓝工作服、围裙、胶鞋、宴会推车、渔网、泡沫箱、三轮车、公用电话亭；
- **线务员职业物**（英雄资产）：警报控制箱、继电器、线务工具包、蜡光线路图、检修工单、鳄鱼夹表笔。

### 2.2 色彩宪法

主色板：**水泥灰、褪色红、旧工作服蓝、警示黄、贝灰、黑绿色霉层**。

- 红色只属于真实礼俗与商业装饰（婚宴、招牌、警示），不作恐怖信号滥用；
- **禁止蓝色水下滤镜、全屏冷色调统治**。明亮婚宴厅、白天海洋馆和日光街镇都必须能承受最严重的返潮；
- 千禧感来自拍摄、设备、材料、衣着和人的用途，**不靠 VHS 噪点滤镜覆盖**。

### 2.3 海雾

海雾用于尺度、距离和声音方向，**不用来遮盖粗糙模型**。参考寂静岭的教训：Team Silent 的雾不是单纯的绘制距离补丁，而是一套响应位置与移动、与声音系统整合的「氛围优先」资产——本作的雾同样要作为一等资产制作：分层密度、可寻址声源穿雾、湿轮胎与雨棚滴水等近景声证据。

## 3. 异常态语法

### 3.1 六条视觉执行规则

1. **绝对干燥**——返潮区不出现漫入的水、漂浮颗粒、水面折射、气泡。真实的水只存在于鱼缸、水杯和海里，与返潮形成对照；
2. **深度有连续证据**——同一受力高度需要在连续材质和多个功能对象上留下证据（胶条挤出、桌腿短缩、墙体微弯、纤维压实），不能只在墙上贴一条异常带；
3. **服役历史，不是一次破坏**——一个位置像在相应深度工作了数十年：油漆、木纤维、橡胶、织物、纸张各自有不同的长期后果。材料保留本质：混凝土被压白、钢材沿旧折线变形，**不能所有东西都海洋化或软化**；
4. **霉变是时间证据，不是生态**——表面保持干燥触感，有机材料却像经历了多年密闭潮暗：霉斑、粉化、纤维脆化。霉不长成触手、器官或独立生态；
5. **压力通过结构传递**——墙、梁、门框、卷帘、柜体和人体姿态必须展示力从哪里来、经过哪里、在哪里释放；
6. **一帧一异常**——任何画面只突出一个主异常：承压、长期霉变、沉积错位、声源距离或重力翻面。其余感官负责支持，不争夺注意力。

### 3.2 人物与威胁

- 先做可信的中国普通人：脸型、发型、工服、婚宴服、围裙、鞋、站姿和劳动动作。SIREN 的方法在此直接适用——**用真实演员/真人照片投射贴图获得「照片可信度」**，本作以自采集照片与扫描材质替代，这比堆面数便宜且更接近死魂曲的质感来源；
- 威胁形态从**姿态被固定、关节承压、衣料受力和动作目的错位**中产生，先是普通人的工作姿态和生活残留，再从记忆缺口长出海的结构；
- **石化复眼**是 M01 的核心视觉种子（用户已确认方向），使用约束：首次正面只能是短暂、侧向、由动作和受力关系支持的证据，不跳脸；它不是全项目统一脸型；
- 脸部恐怖依靠认错人、目光落点、表情迟滞和称呼反应，不依靠持续怪脸。

### 3.3 视觉禁止清单

触手、外星甲壳、巨型器官、鱼头、尸兔、统一锈肉、全城器官化「生物机械」；蓝滤镜与全屏水下效果；随机海洋装饰（贝壳/鱼鳞贴满伤口）；跳脸与自动恐怖过场；无功能的符号堆叠；一切「看起来酷但答不出原本日常功能是什么」的图像。

**每个异常必须回答四问**：原本的日常功能是什么？深度、时间或旧伤把它错误归类成了什么？玩家从动作、材料、声音和路线能否看懂这种错误？删掉它叙事有没有损失？

## 4. 镜头语法

- 默认**肩后或略高的中近距离镜头**，优先保留人体与建筑的受力关系；
- 关键空间允许**固定/受限机位**混用（狭窄后场、玻璃对照位、翻面证明位）：固定构图保证「墙体远端鼓起、门框被挤压、玻璃反光弯曲」等证据同时入画，冲击力不依赖玩家偶然站对位置——这是从死魂曲固定演出镜头与老式生存恐怖预渲染构图中转译的纪律，不是省性能的借口；
- 声音先于画面：异常入画前，其声学证据必须已经可听；
- 镜头不制造操作困难：切镜遵守人物位置与方向连续性；
- 每章至少一个「美术圣经机位」：同一机位的正常态/返潮态对照，不看文字也能读出唯一不可能（借鉴《寂静岭 2》纪录片中「第一个厕所成为其他场景的 graphics bible」的做法——先做一处满分，再让全作向它看齐）。

## 5. PS3 级画质的可量化定义

「PS3 级」不是怀旧借口，是**导演能力的下限承诺**。对个人+AI 管线这是高目标：它要求构图、材质、灯光的控制力，而不是面数。量化如下（性能预算详表见 [06 技术文档](06_技术栈与制作工作流.md)；Demo 逐资产的执行口径、LOD 链、照片投射流程与恐怖谷规范见 [08 资产精度规范](08_Demo资产精度与恐怖谷规范.md)）：

| 维度 | 目标 | 说明 |
| --- | --- | --- |
| 分辨率/帧率 | 1080p / 30fps 稳定（720p 兜底） | 所有视觉验收在 720p 下复核轮廓可读性 |
| 光照 | 烘焙为主 + 少量受控动态光 | 不依赖 Lumen/Nanite；应急灯、CRT、雾中扩音器灯等动态光每场景 ≤4 盏 |
| 材质 | 可信法线与粗糙度，照片扫描优先 | 近景材质 1K—2K，英雄资产 2K；禁止 4K 贴图堆砌 |
| 模型密度 | 英雄资产近景可看，量产资产模块化 | 玩家会近看和操作的物件（控制箱、推车餐具、门框卷帘、人物脸手）集中投入；远景与重复桌椅靠模块与材质变化 |
| 人物 | 照片投射贴图低模 + 干净骨骼动画 | 面部恐怖靠迟滞与目光，不靠高模微表情 |
| 后期 | 克制：轻微颗粒、色域收敛 | 禁止 VHS 滤镜、色差滥用、动态模糊遮丑 |

**验收基准片**：SIREN（PS2，2003）的仪式与人物质感、《寂静岭 2》的空间灰度、优秀 PS3 后期作品（如《死魂曲：新翻译》）的实机截图。本作任何实机画面与它们并排时不应因「素材感」出戏。

## 6. 原型制作门

**在任何正式资产生产之前**，必须产出并通过五张视觉基准图（实机引擎截图或同管线渲染，禁止用概念画或 AI 生成图代替）：

| # | 基准图 | 通过标准 |
| --- | --- | --- |
| 1 | 婚宴厅正常态（营业中，有人气） | 不看标题能认出中国 2001 沿海小城婚宴；值得怀念，不像鬼屋 |
| 2 | 同机位返潮态 | 保持营业秩序的「无人」；一帧一异常；与图 1 逐像素对照可读出唯一不可能 |
| 3 | M01 首次侧面出现（婚宴后场走廊） | 先被识别为一个具体的人（背影），再被识别为怪物（侧面复眼）；720p 下轮廓双读成立 |
| 4 | 海洋馆玻璃对照位 | 缸内真实海水正常，缸外干燥走廊承担深压；玻璃两侧的「陆地证据」同时入画 |
| 5 | 滩涂点火远景（雾、警报塔、归面群） | 尺度、雾层与声源灯光方向可读；烟柱折向陆地的单一异常成立 |

通过流程：每图先出灰盒构图 → 材质灯光迭代 → 720p 复核 → 外部盲测（一句话复述画面里「哪里不对」）。五图未全部通过前，**禁止任何量产资产、禁止委托或生成新的怪物图**。

AI 图像工具的位置：允许用于**参考与情绪板**，产出物一律进入 `CANDIDATE`，不得直接转为资产或反向修改设定——交接包的病史（生成图反向绑架设定）不得复发。
