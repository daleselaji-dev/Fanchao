# 《返潮》恐怖核心与怪物设计（三审重写）

> 状态：现行宪法。本文取代 [01 §4](01_故事背景设定.md#4-形象库看见即恐怖) 旧形象库——M01 返席人 / M02 迎宾的人 / M03 洗涤间的搁浅者 / M04 敬酒的女人经用户否决**全部废弃**，命名与核心意象封存，禁止变体回归（裁决记录见 [05 §8](05_设定审定_保留与删除.md#8-三次审定2026-08-24废弃-m01m04-形象库)）。
> 写作纪律：每条设计先回答「**在 Three.js 灰盒里怎么演**」。演不出来，或演出来不可怕的，不写进本文。

## 1. 恐怖核心：三条铁律

1. **灰盒即成立**。恐怖只准由四样东西构成：轮廓、动作、空间、声音——这四样在无贴图的灰盒里就有。凡是要靠材质细节（伤口、纹理、脸）或背景说明才可怕的形象，不收。
2. **第一眼永远正常**。每个怪物的第一读法都是「一个还在干活的人」。第二读法必须由玩家自己的走位换来（跟近、绕面、走低处），不许用脚本塞给玩家。
3. **身体先于理解**。验收标准不是玩家「懂了什么」，而是玩家的身体做了什么：后退、贴墙、放轻脚步、加速通过、从此不敢绕到任何背影的正面。

## 2. 四个杠杆（每只怪物主用一个，不许堆叠）

| 杠杆 | 一句话 | 灰盒里怎么演 |
| --- | --- | --- |
| 身体规则破坏 | 人体默认规则少一条 | 几何与朝向：对称、不转身、静止得过分 |
| 空间压迫 | 房间对身体是错的 | 尺度与姿态：人被建筑压弯，天花板因他变矮 |
| 声音先于画面 | 耳朵先撞见 | 定位音频：声音沿真实路径先于实体抵达 |
| 错误熟悉感 | 最熟的动作重复到错 | 录制与复放：动作对、节奏对、人错了 |

## 3. 怪物库

> 编号自 M05 起；M01—M04 编号永久封存，不复用。每只一页，四栏之外不许加「设定背景」栏。

### M05 双背 —— Demo 与垂直切片主怪（H00 婚宴后场）

- **看见什么**：远处，一个穿旧蓝工装的收台工背对你擦桌子，动作熟练，节奏安稳。你跟着他走过半条走廊，他一次也没有回头。你从另一条路绕到他前面，等他走过来——迎面走来的仍然是一个后背：同样的驼肩、同样的领口、同样的发旋。**这个人没有可以面对你的那一面。**
- **怎么动**：只做工作。沿旧后勤路线匀速循环（1.5 m/s，恒定），到点收桌、放盘、洗涤。你挡在他的路线上，他停下等你让开——等的时候完全静止，连步态的余摆都没有，静止得不像活人。需要折返的路段（洗涤台、C 门外）他**不转身**，用同样的步态倒着走回去。
- **玩家怎么与之发生关系**：让行（他等你，你会主动贴墙）；跟随（永远只看到背，越跟越想看正面）；绕面（游戏从不阻止你绕到他前面——这一眼是玩家自己要来的，之后玩家会自己惩罚自己的好奇心）。
- **为什么在三维灰盒里一眼可怕**：驼肩、肩胛、发旋是纯轮廓信息，无贴图就能读；正反两面镜像同一个背影，任何距离一眼成立。「绕到正面看清楚」是玩家在一切游戏里的默认权利，这里被解剖学没收——比任何一张脸都糟。他从不转身不是行为限制，是身体事实。
- **声音**：瓷器、擦拭、脚步永远先于画面（隔墙低通衰减）；脚步每一步是极近的两声（前后各落一次）。
- **禁用项**：正面不得出现任何脸部残迹（眼、嘴、伤口、凹槽）；不得解释他是谁、为什么有两个背；不得对玩家有任何主动行为；不得在他身上加发光、音刺或跳脸机位。

### M06 梁下 —— A 宴会厅（P2 登场）

- **看见什么**：宴会厅深处站着一个上菜员，托盘端得很平。他太高了——直起腰这层楼装不下他，所以他从肩胛处向前折弯，后颈贴着吊顶，脸朝着地面。他就保持这个姿势工作，托盘始终水平。
- **怎么动**：几乎不走。每隔很久沿桌间挪到下一张桌，挪动时保持折弯，后颈沿吊顶滑行。任何门他都进不去，也从不试。
- **玩家怎么与之发生关系**：他站在必经路线上方的阴影里；没有任何机制阻拦，但玩家会自己绕开他的正下方——没人愿意从那张朝下的脸底下过。
- **为什么在三维灰盒里一眼可怕**：高度与折角是纯几何。看见他的一瞬间，整个房间的天花板变矮了——空间压迫由一具人体承担，玩家替他弯腰。
- **声音**：托盘上杯子的极轻碰撞，从头顶方向来。
- **禁用项**：不解释他为什么这么高；不做「抬头对视」演出；脸部不做任何细节。

### M07 空趟 —— B 服务走廊（P2/P3 登场）

- **看见什么**：一趟完整的上菜从你身边过——脚步、推车轱辘、盘沿相碰，从走廊那头来、贴着你过去、进了门——走廊里始终一个人都没有。几分钟后，同样的声音再来一遍，这一次有人：一个推备餐车的员工，踩着刚才那些声音走过的每一步。
- **怎么动**：固定班次，先声后人；声与人走完全相同的路径、节奏与停顿。
- **玩家怎么与之发生关系**：第一遍玩家会给空气让路；第二遍玩家明白自己刚才让对了——并从此对每一段脚步声让路。
- **为什么在三维灰盒里一眼可怕**：第二遍使第一遍**事后成立**，恐怖发生在玩家自己的记性里；实现只需定位音频 + 复放实体，灰盒零成本。
- **声音**：本体即声音设计；全程无突发响度。
- **禁用项**：不解释这趟班是谁的；两遍之间不得插任何提示或 UI。

### M08 对班 —— C 录像·广播室（P3 登场）

- **看见什么**：你回到 C 房，卡座前已经有人在做你刚才做过的事——同样的站位、同样的停顿、同一只手先抬。他做完你上一次的全部动作，然后走你上次走的那条路离开。
- **怎么动**：完全复放玩家自己上一次在此空间的移动与交互轨迹（录制—复放），不新增任何原创动作。
- **玩家怎么与之发生关系**：玩家的过去成了场上的一个班次；玩家开始故意改变自己的习惯路线——用行动回答「我是不是也被排进班表了」。
- **为什么在三维灰盒里一眼可怕**：灰盒里所有人都是占位体，「那是我」不需要长得像——位置、节奏、习惯就是身份。
- **声音**：与玩家自己触发的音效完全一致，不多一声。
- **禁用项**：不给它任何面部；不用 UI 指认「这是你」；不解释。

### W00 散场的宴会厅（空间形象，继续有效，Demo 直接使用）

- **看见什么**：婚宴散到一半的宴会厅：转盘上的菜还冒着热气，红绒椅套上有人形坐皱，伴奏带停在间奏，一个人都没有。所有椅子——包括推开的、倒下的——朝向完全一致，全部指向主桌。门口横幅上，新人名字的位置是两块干净的空白。
- **怎么动**：它不动。你离开再回来，热气还在，伴奏还停在同一小节。
- **为什么一眼可怕**：最热闹的公共空间保留着「刚刚还有人」的全部证据，唯独没有人；时间不肯流逝。
- **禁用项**：不得用广播、字条或 NPC 解释人去了哪。

## 4. 背景的场景直读原则

背景设定只保留三件能从场景里直接读出的事，其余一概不写：

1. **一场婚宴散了，散得不对**——热菜、坐皱、空白横幅；
2. **班次还在继续**——有东西仍按老班表干活，干得很认真；
3. **这里没有别人。**

玩家的思考只通过行动表现：走哪条路、跟不跟、敢不敢绕面、要不要让路。任何玩家可见文本只有操作提示（「按 E 归档」级别），零因果说明。

## 5. 废案封存

M01 返席人 / M02 迎宾的人 / M03 洗涤间的搁浅者 / M04 敬酒的女人：形象、命名、核心意象（纵裂面复眼盐晶、婚礼合影分辨率的脸、池下错位肢体递盘、肘下潮间带岩面）整体废弃，编号封存不复用，任何变体（换部位、换材质、换场景）视同回归，直接打回。M01 行为合同的**基础层四条**（工作循环 / 让行不推人 / 从不面向玩家 / 声音先于画面）与形象无关，作为工程验证资产转移给 M05（见 [03 §3.1](03_核心玩法.md#31-m05-双背行为合同)）。

## 6. 新怪准入三问（取代长框架）

任何新怪物提案，先用无贴图灰盒（脑内或实做）演一遍，回答：

1. 第一眼正常吗？第二眼可怕吗？
2. 第二眼是玩家自己走出来的吗？
3. 它的声音比画面先到吗？

答不全三个「是」，不立项。补背景故事不能改判。
