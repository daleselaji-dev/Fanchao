# 《返潮》核心机制：调研与转译

> 状态：现行宪法。本文档回答：从《死魂曲/SIREN》《零/Fatal Frame》《寂静岭》《遗传厄运》中**可迁移的是什么设计原则**，以及它们如何转译为《返潮》自己的民俗逻辑。
> 纪律：只迁移方法，不迁移符号。任何「换皮借用」（相机打鬼、雾镇美式街道、家庭邪教）在 [05 审定文档](05_设定审定_保留与删除.md) 中均已列为禁区。
> 调研来源：外山圭一郎访谈（FFT 译本、Siren Maniacs、电ファミ）、《SIREN》Making Of 纪录片文字稿、《寂静岭 2》制作纪录片与设计文档、Fatal Frame 系列机制资料（Zero Wiki / Fatal Frame Wiki / IGN 攻略）、Hereditary 導演 Ari Aster 访谈（Den of Geek / THR / Yahoo）。

---

## 1. 《死魂曲/SIREN》：把玩家放进绝对弱势，再给一件昂贵的感知工具

### 1.1 调研事实

- **视界劫持的真实出身是声呐**。外山圭一郎自述：机制原型来自潜艇游戏——在看不见的水下听敌人的声音、分析、定位；团队把「听」换成了「看」。**初版设计里，劫持尸人视野会有暴露自己位置的风险**，因难度原因在平衡阶段被删掉；
- 直接灵感是一次艺术展上的「知觉交换装置」：两人戴上摄像头+监视器护目镜，互相看见对方的视野——主题是「感觉的成长与扩张」；
- 尸人（Shibito）不可被杀死，只能被打倒进入休眠；他们是**困在生前生活循环里的人**（继续耕作、巡逻、值班），像钟表一样规律，潜行玩法的核心是读出他们的循环并利用缝隙；
- 立项只有三四页纸，关键词是「日本的黑暗面」；团队先写**反类型禁令清单**（不做收集消耗品、巨大 Boss、瞬间恢复、传统锁钥拼图），再实地调查废弃村落、用真实演员照片做纹理、手工制作档案道具；
- 多角色时间线靠一张维护多年的 Excel 表保证「谁在何时何地做什么」；第一个关卡（学校）先验证一个核心恐惧：「躲在厕所里，通过敌人的主观视野看着它探查后离开」；
- 教训同样明确：过高难度与试错伤害了传播。

### 1.2 转译到《返潮》

| SIREN 原则 | 本作转译 | 差异（为什么不是换皮） |
| --- | --- | --- |
| 感知工具=声呐的感官扩张 | **警报测深**：用公共警报的回声读出干燥空间的深度界面 | SIREN 把听换成看（借敌人的眼），本作留在听本身，且玩家用的是**自己职业的公共设备**，不借任何超自然视角 |
| 初版被删的「劫持暴露自己」 | **捡回来作为机制心脏**：每次测深同时把自己暴露给沿声回返的归来者 | SIREN 删它是因为劫持高频使用；测深低频、主动、可规划，代价撑得住 |
| 尸人=困在生活循环里的人 | 归来者=**被记忆固定在家庭位置上的人**；「仍在履职的人」沿旧后勤路线回返 | 循环的来源不同：尸人是感染后的残留，归来者是**别人的记忆要求他们如此**——恐怖指向活人 |
| 反类型禁令先行 | 本作禁令清单见 [03 玩法 §7](03_核心玩法.md#7-不做清单玩法层) 与 [02 视觉 §3.3](02_视觉原型设定.md#33-视觉禁止清单) | 方法直接继承 |
| 实地调查+真人照片纹理 | 千禧沿海实景/器物照片采集进入资产管线（见 [06 技术文档](06_技术栈与制作工作流.md)） | 方法直接继承 |
| Excel 时间表管多角色 | 单主角，但**镇民日程表**同样必要：每个 NPC 在危机各阶段的位置与动作先于对白写定 | 规模缩小，纪律保留 |
| 难度教训 | 追逐短促路线化、失败叙事化不读档、守仪式提供确定性规则 | 主动规避 SIREN 的传播损伤 |

## 2. 《零/Fatal Frame》：注视的代价结构与民俗的机制化

### 2.1 调研事实

- 射影机的伤害模型是一套**风险换伤害**的时间经济：怨灵在取景框捕获圈内停留越久、蓄力越满，伤害越高；**Shutter Chance**（捕获圈发光，通常在鬼攻击前后瞬间）伤害加成并击退；**Fatal Frame** 是更严苛的窗口（常只有约一秒，藏在攻击动作里），最高伤害、大幅击退、唯一可连拍成 combo——**打得最痛的瞬间就是离死最近的瞬间**；
- 胶卷经济：Type-07 无限但弱，高级胶卷稀缺、装填时间各异。玩家在「省胶卷冒险等窗口」与「花资源换安全」之间持续决策；
- 射影机同时是探索工具：显示隐藏灵体、解谜、提示去向——**一件工具承担战斗/探索/叙事三职**；
- 民俗不是皮：绳之仪式、社人柱等祭仪直接生成敌人行为、地图结构（村落按仪式功能布局）与道具体系。

### 2.2 转译到《返潮》

**明确不做**：相机打鬼（举起设备削减鬼血条）。本作没有可削减的威胁，「用镜头攻击」与归面礼的伦理（记录即占有）正面冲突——在本作的世界里，**举起相机拍归来者恰恰是喂养它**。

迁移的是三条结构原则：

1. **「注视的代价结构」→ 测深判读窗口**。零的洞见是：信息/伤害最大化的瞬间=风险最大化的瞬间。本作转译：测深回声最清晰、信息最完整的位置，恰是声学上最暴露的位置；归来者逼近时其声学感知锁定玩家，此刻的「静止聆听」能读出它的路线（最有价值的信息），但多听一秒它就近一步。零用一秒的 Fatal Frame 窗口制造心跳，本作用「再听半秒还是现在就走」制造同款心跳，无需武器；
2. **胶卷经济 → 记录经济**（展开见 §5）；
3. **一件工具三职**。线务工具包（表笔、录音磁带、手持扩音器）同时承担：测深/导航（玩法）、修复声路（进度）、记录证据（叙事+资源）。不添加第二套工具体系。

## 3. 《寂静岭》：氛围优先的资源分配与心理地理

### 3.1 调研事实

- 雾的真相：不是单纯掩盖绘制距离的补丁。Team Silent 为《寂静岭 2》自建引擎时**把优化目标从多边形数量改为氛围密度**——动态体积粒子雾（700 粒子池、风场、与几何碰撞、被玩家推开）、与位置音频整合。技术分配本身就是恐怖设计；
- 外山（初代导演）的理念：冒险游戏近似「别人的梦」——碎片拼合、似曾相识的怀旧街道、普通人主角、日常物的轻微变形。团队用「梦里是否成立」给不条理表达划边界，而不是无限允许怪事；
- 《寂静岭 2》纪录片方法论：先拍现实参考；第一个建成的厕所成为其他场景的 graphics bible；里世界的地图**不扭曲几何，而是解锁原本锁住的门**，打开同一建筑里此前不存在的区域；长距离行走与大尺度是刻意制造的孤立感，不是填充；为脚步声做了大量变化以避免重复。

### 3.2 转译到《返潮》

| 寂静岭原则 | 本作转译 |
| --- | --- |
| 氛围优先的技术分配 | 引擎预算优先级写死：**声音系统 > 雾与光 > 材质 > 面数**（见 [06 技术文档](06_技术栈与制作工作流.md)）。恐怖预算大头在声音 |
| 雾=感知的敌人，与声音一体 | 海雾削弱视觉距离的同时**放大声学导航价值**——高频被吃掉、低频船笛与扩声从看不见的位置抵达，测深在雾中从「有用」变成「必需」 |
| 「梦里是否成立」边界 | 本作等价物：**「深度、时间或旧伤把它错误归类成了什么？」四问**（[02 视觉 §3.3](02_视觉原型设定.md#33-视觉禁止清单)）。答不出的怪事不进生产 |
| 里世界=解锁的门而非扭曲几何 | **莫比乌斯软翻面**：同一空间几何不变，变的是路线连通性、称呼与深度归属。走同一条路回来，门的归属和你的身份变了——比几何扭曲便宜一个量级，且更贴合主题（技术裁决见 [05 审定 §3.3](05_设定审定_保留与删除.md#33-莫比乌斯小镇改造后置)） |
| 心理地理 | 有节制地使用：空间反映的是**全镇的集体愿望**（愿望空间事件如「饭已经做好了」），不是主角个人创伤的投影——这是与寂静岭 2 拉开距离的关键决定 |

## 4. 《遗传厄运》：从祭品视角看一场早已布置好的仪式

### 4.1 调研事实

- Ari Aster 的自我定义：「一场持续多年的附身仪式，从**祭品的视角**讲述」。观众与家庭一起处于无知中，但影片本身「知道故事去哪」——每件事都在咔哒就位，一切不可避免；
- 微缩屋是核心隐喻：人物是被外力摆布的玩偶，「他们试图夺回的任何控制都是徒劳」。开场镜头从微缩屋房间无缝进入真实房间——**观看者与被布置者的界线被取消**；
- 预兆的事后可读性：鸽子断头、教室里关于「无自由意志的悲剧人物」的讨论、外婆葬礼上微笑的陌生人、光柱上的符号——第一遍是噪音，第二遍全是宣告；
- 恐怖的大部分发生在**日光与家庭日常**里；仪式逻辑不必向观众解释通顺（宗教仪式本就不需要现实逻辑），只需自洽且early-planted。

### 4.2 转译到《返潮》

1. **玩家就是祭品视角**。返潮不是主角来解决的案件，而是一场他从抵达那天就身处其中的、更大的「认领」——他被招聘、他按下最后一声警报、他的口音与步幅逐项吻合失踪者。通关后玩家应能回看第一小时并发现：**每张工单都是布置**。为此建立「预兆埋设表」：每章预先写定哪些第一遍是噪音、第二遍是宣告的细节（对应 SIREN 的 Excel 时间表纪律）；
2. **不可避免性 ≠ 无能动性（agency）**。遗传厄运里家庭毫无还手之力——电影可以，游戏不行。本作的分寸：返潮的发生不可避免（玩家阻止不了点火事件），但**如何结束由玩家累积决定**（三结局）。诅咒锁死过去，不锁死未来；
3. **微缩屋 → 归面**。同构的恐怖物：按记忆捏出的人形、被摆进家庭位置、替真人承受愿望。归面在场景中的摆放语法（谁家里留了小脸、朝向哪里）成为环境叙事的主语；镜头语法中的俯视「被布置感」机位（[02 视觉 §7](02_视觉原型设定.md#7-参考作品用法限定)）用在认领进度的关键节点；
4. **家庭诅咒的去邪教化**。遗传厄运有一个女巫会在幕后执行计划；本作明确无阴谋方——做反仪式的是**每一代人温柔的小改动**。恐怖从「有人害我们」升级为「我们自己就是机制」。

## 5. 记录经济：记录即喂养

四作调研的交汇点，本作最重要的原创系统。取零的胶卷经济骨架、SIREN 的档案系统、遗传厄运的「保存即占有」主题，融成一个资源循环：

### 5.1 规则

- **记录载体有限**：磁带、胶卷、录像带是消耗品（零的胶卷经济）。用它们可以：录下测深回声供事后比对（延长测深价值）、保存 NPC 证词、拍摄异常证据（解锁部分路线与结局材料）；
- **每件记录都是喂养**：录有称呼、地址、人脸的载体会被声路与媒介拾取。携带的记录越多，认领系统对玩家和相关 NPC 的锁定越快；存放在录像·广播室归档架（H00-R0 已验证的归档交互）可以隔离，但归档的证据无法随身使用；
- **销毁有代价**：消磁/曝光一件记录永久移除其喂养效果，同时永久失去证据——某些结局材料因此不可逆地关闭；
- **三难决策常态化**：随身带（可用但喂养）/ 归档（安全但用不上）/ 销毁（干净但永失）。这就是「彻底补全真相 vs 彻底恢复亲人 vs 允许空洞存在」的主题在每十分钟玩法里的微缩版。

### 5.2 验收标准

- 陌生玩家在 Alpha 一小时内至少主动做出一次归档与一次销毁；
- 通关不需要集齐任何记录；「全收集」路径明确通向伦理最危险的结局分支；
- 记录数量少而重（全篇 ≤40 件有名记录），禁止百份日志式填充。

## 6. 补充参考（每项只取一条可执行结论）

| 作品 | 取走的一条 |
| --- | --- |
| Pathologic | 镇民有自己的日程与利益，危机按天推进不等玩家——本作危机阶段（结露→逆流→认领→翻面）按章节推进，NPC 状态随阶段独立恶化 |
| Darkwood | 视锥外的恐怖靠声音与预兆运作即可成立——归来者在画面外的存在感全部交给声学 |

| Kunitsu-Gami | 仪式可以是玩法动词而非过场——守仪式四条对策全部做成可操作输入 |
| 中国沿海民俗（潮魂/叫魂、无尸衣冠葬、迁坟禁忌、渔民不说「翻」） | 归面礼的每条禁忌都有真实民俗原型支撑其「可信的严厉」；语言禁忌（避讳字）进入对白写作规范 |

## 7. 机制裁剪总原则

1. 四动词+记录经济+认领状态机，**全作系统到此为止**。新系统提案必须先通过 [05 审定文档](05_设定审定_保留与删除.md#新设定准入八问) 的八问；
2. 每个机制必须同时在玩法层（有决策）、叙事层（有含义）、声音层（有可听证据）成立，缺一层退回；
3. 机制验证顺序永远先于美术投入：P1 第一个 Gate 就是灰盒测深可玩验证（见 [00 总览 P1](00_项目总览与规划.md#p1-垂直切片vertical-slice)）。
