# 《返潮》核心玩法

> 状态：现行宪法。回答一个问题：**玩家每分钟在做什么，为什么害怕，为什么继续。**
> 机制的调研依据与设计原理见 [04 核心机制](04_核心机制.md)；本文只写玩家可感知的层面。

---

## 1. 体验支柱（三条，冲突时按序取舍）

1. **用声音看见深度**——玩家的核心能力是把不可见的深度界面「测」出来。这个能力每次使用都有代价；
2. **威胁不可消灭，只可理解**——归来者不能被杀死，只能被预测、误导和送走。玩家变强的方式是更懂规则，不是更能打；
3. **知道得越多，占有得越深**——记录、呼名、确认这些「玩家本能」在世界规则里是喂养。最优策略常常是克制。

一句话循环：**接到日常职责 → 测深读出空间真实状态 → 规划路线并改变承压 → 在归来者的感知规则下穿过 → 决定记录什么、不叫什么名字 → 留下一处不可逆的关系变化。**

## 2. 四个核心动词

少而硬：全作玩法由四个动词构成，每个都做到可教学、可精通、有代价。任何新系统提案先回答「它属于哪个动词」。

### 2.1 测深（主动，本作招牌）

玩家在固定警报控制箱（后期可携带手持扩音器，功率更小）发出短促测试警报。声音穿过干燥空间时，尘埃、布料、门框和薄金属沿不可见深度平面受压，回声携带信息：

- **清晰、短促的回声** = 浅处，路线接近现实平面；
- **拖长、降调并伴随结构内缩的回声** = 深处，空间正在承受错误压力；
- 回声的方向差 = 深度界面的走向，可据此规划绕行。

代价（不可移除，是机制的心脏）：**每次警报也是归来者的声源。** 测深让玩家读懂空间的同时，把控制箱位置和自己暴露给沿声倒退接近的东西。玩家永远在「读出路线」和「引来威胁」之间做选择。

硬约束：这不是声呐小地图、不是灵视扫描、不借用敌人视野。玩家始终留在第三人称视角，用声音和物质反应理解空间。**不出现任何 HUD 深度数值。**

### 2.2 读深度（被动，免费但慢）

不发声的观察：同一高度重复出现的胶条挤出、桌腿短缩、墙体微弯、耳压变化、脚步声衰减、蹲低时听到的墙体传声。读深度免费、无暴露，但速度慢、精度低、需要玩家真的学会看。

设计承诺：所有深度证据服从 [02 视觉文档 §3](02_视觉原型设定.md#3-异常态语法) 的连续性规则，**用功夫读环境的玩家可以少按一半警报**。测深与读深度构成「花安全换时间，还是花时间换安全」的持续决策。

### 2.3 改承压（空间操作）

玩家操作真实设施——卷帘、推车、门闩、设备支架、通风口、闸阀——使压力沿不同结构释放。效果：

- 改变可走路线（被压变形的门重新可开，或反之）；
- 改变声源传播（关闭卷帘切断一条回声路径，误导归来者）；
- 改变威胁行为（归来者沿旧后勤路线回返，路线的承压状态决定它从哪扇门出现）。

硬约束：改承压**不改变返潮的绝对深度**，只改变力走哪条路。错误操作不弹「解谜失败」，而是产生新的追逐路线——世界永远用因果回应，不用对错回应。

### 2.4 守仪式（约束动词，本作独有的「反操作」）

从民俗对策中转译的玩家纪律，是玩法与主题咬合最深的一层：

- **不回头**——归来者在玩家背后靠近时，回头确认=认领的一半。正确操作是压低视线、用镜面/玻璃反光侧看、倒退离开。游戏用声音把「想回头」的冲动做成压力测试；
- **不呼名**——对话轮与广播操作中出现称呼选项时，说出名字有短期收益（NPC 合作、信息），长期喂养认领；
- **不踩拖痕**——滩涂与走廊上前人送面留下的拖痕是「别人的归路」，踩入会把玩家的路线并进别人的回返路线（空间软翻面的触发器之一）；
- **背潮认亲**——终局与关键节点的操作姿态：面向陆地、背对海说话。摇杆朝向在这些时刻有叙事意义。

守仪式没有 HUD 提示，靠 NPC 示范、环境证据和一次代价可控的失败教学。它把「玩家能做什么/不能做什么」从系统限制变成文化知识。

### 2.5 明确不存在的动词

战斗（无武器、无血条威胁）；跳跃/攀爬体系；背包管理与合成；技能树；体力条。主角能小跑、蹲低、贴墙、推拉重物，仅此而已。

## 3. 威胁如何逼近

### 3.1 M05 双背：行为合同

> 2026-08-24 三审：本节原为 M01 行为合同。M01 形象与命名已废案（见 [05 §8](05_设定审定_保留与删除.md#8-三次审定2026-08-24废弃-m01m04-形象库)），行为合同的工程内核与形象无关，整体转移给 **M05 双背**（形象宪法见 [07 §3](07_恐怖核心与怪物设计.md#3-怪物库)）。

玩家可学习、可预测、不可消灭。行为分两层：

**基础层（空间与数值已在 `demo/web/` 灰盒逐条验证，3D 实现见 `demo/web3d/`，任何实现必须首先复现）**：

1. **只做工作**——沿旧后勤路线（D 卸货口→B 服务走廊→C 门外→E 洗涤间→D）匀速循环（1.5 m/s，恒定，不因玩家改变），在工作点停留做普通动作；
2. **让行不推回**——玩家挡在路线上时它原地等待，不推挤、不加速、不绕圈逼近；等待时**完全静止**，连步态余摆都没有；
3. **朝向只由路线决定**——它从不面向玩家，因为它没有可面向的那一面（正面是第二个背）；折返路段它不转身，用同样步态倒着走回去；
4. **声音先于画面**——不可见时只有工作声（隔墙低通衰减）；视线被墙遮挡则不渲染。

**扩展层（垂直切片目标行为，须先在 Demo 执行栈灰盒验证后才进 UE）**：

5. **沿声倒退接近**——声源（警报、呼名、餐具碰撞、录像机走带声）改变它的目标点，它以背影朝向声源方向移动；改承压可以封闭或打开路线的门，玩家能用路线知识把它引向空处；
6. **绕面无兑现**——游戏从不阻止玩家绕到它前面，也永不给「正脸」兑现：绕面得到的是第二个后背。这是全作对跳脸的制度性替代——恐怖由玩家自己的走位换来，不由脚本发放；
7. **接触即认领开始**——被它贴近的失败不是血条清零，而是一段不可跳过的「归位」演出：它替玩家整理衣领、按到座位上（见 §6 失败设计）；
8. **可送不可杀**——任何攻击无效。中期玩家学会用测深把它引回滩涂方向「暂时送走」；彻底解决只在结局层发生。

### 3.2 逼近的节奏设计

- 威胁的存在先用**声音的错位**宣布（脚步声从错误材质传来、扩音器里出现不属于当前广播的呼吸），画面证据永远晚半拍；
- 每次遭遇有安全阅读期：玩家先看到「一个普通人的背影在做熟悉的事」，恐怖来自识别（那是谁的动作）而非惊吓；
- 追逐是短促的、路线化的（60—90 秒内解决），失败惩罚是叙事性的。**禁止无限追逐关和背板即死**。

## 6. 胜利、失败与揭秘

### 6.1 失败设计：被归位，而不是死亡

被 M05 贴近、认领进度满、或在关键仪式节点违反对策，触发「归位」：一段短演出后，玩家在**某个家庭位置**上醒来——坐在婚宴空位上、躺在别人家的床上、站在旧工位前——身上多了一件不属于自己的物品（工牌、椅套、称呼）。

- 机制代价：认领进度+1（全局蓄积，影响结局可达性与 NPC 称呼）；时间流逝；
- **不读档惩罚、不丢资源**。世界记住失败并继续——这比重来更冷。玩家想「洗掉」被认领的细节，必须主动完成小型送面（花时间与仪式材料）。

### 6.2 胜利与进度

进度单位是**关系与路线的不可逆变化**，不是钥匙和门：每章结束时玩家改变了一条声路的归属、一个 NPC 的称呼状态、一段空间的翻面朝向。章节目标始终是具体的职责（修通某段广播、护送某人过滩、静默某个声源），宏观目标（三结局）由累积的认领/送走状态决定，见 [01 故事文档 §6](01_故事背景设定.md#6-剧情骨架每行一幕不再展开)。

### 6.3 揭秘的发生方式

- 世界因果靠**空间与行为**揭示（同机位对照、NPC 的动作退化、广播链的称呼漂移），不靠长文档；
- 媒介记录（磁带、录像、照片）提供局部证据，同时每一件都是喂养素材——**读档案有代价**，这是本作对「收集品叙事」的改造（原理见 [04 机制文档 §5](04_核心机制.md#5-记录经济记录即喂养)）；
- 玩家不需要集齐任何东西就能通关；集得越全，越接近「彻底补全」结局路径的伦理危险。

## 7. 不做清单（玩法层）

- 战斗系统、可击杀敌人、Boss 战；
- 背包/资源管理、合成、商店、经济数值；
- RPG 成长（等级、属性、技能树）；
- 收集图鉴与成就驱动的探索；
- 小地图、任务标记、发光轮廓、扫描视觉；
- 无限追逐关、背板即死、跳脸 QTE；
- 多角色操作（P3 前）；开放世界式自由漫游（章节制、路线化）。
