## 本目录的裁决权规则

1. 任何新提案（怪物、场景、机制、画面）进入制作前，必须先通过 [05 审定文档](05_设定审定_保留与删除.md) 末尾的「新设定准入八问」。
2. 交接包中标记为「已否决 / ARCHIVE」的方向（湿拓、异形方法、酒店发育器官、灭世生态、尸兔、二号桌等）**不得以任何换皮形式重新进入生产**；重新提出需在本目录留下书面翻案理由。
3. 一张再好看的概念图不自动获得设定权。图像只有通过 [02 视觉文档](02_视觉原型设定.md) 的原型制作门才进入资产管线。
4. 本目录文档修订使用 git 历史追溯，不再另开「v0.x 评审稿」平行文件——那正是交接包烂掉的方式。

## 交接包如何阅读

原始 zip 在仓库根目录。zip 内使用 Windows 反斜杠路径，直接 `extractall` 会得到平铺文件，请用以下方式解压：

```python
import zipfile
from pathlib import Path

zpath = Path("返潮_项目设定与Demo交接包_2026-08-05.zip")
out = Path("handover")
with zipfile.ZipFile(zpath) as z:
    for info in z.infolist():
        name = info.filename.replace("\\", "/")
        if name.endswith("/"):
            continue
        target = out / name
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_bytes(z.read(info))
```

`handover/` 已加入 `.gitignore`，解压产物不入库。交接包内部结构与可信度说明见其 `00_整理索引/`；对其内容的逐项裁决见本目录 [05 审定文档](05_设定审定_保留与删除.md)。
