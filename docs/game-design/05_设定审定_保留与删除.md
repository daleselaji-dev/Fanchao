# 《返潮》设定审定：保留与删除

> 状态：现行宪法。本文档对交接包（292 文件）中每一项有设定权主张的内容作出裁决：
> **保留**（直接进入现行宪法）/ **改造**（内核保留、形态重写）/ **删除**（归档，禁止换皮回归）/ **降级**（存为附录候选，排队等待翻案）。
> 每条给理由。翻案必须在本目录留下书面理由并通过文末[新设定准入八问](#新设定准入八问)。

---

## 0. 三基线冲突的总裁决

交接包并存三份互相竞争的「当前核心」，主角、场景、核心动词各不相同：

| 基线 | 内容 | 用户态度（原始沟通记录） |
| --- | --- | --- |
| 1. 立项骨架（2026-08-04 评审稿） | 返乡录像员、四动词（读深度/干潜/改承压/记路线）、婚宴厅→海洋馆 Demo、物理宪法八条 | 「这一稿不太行」；「北极星」类产品话术被明确否定；局部（物理宪法、海洋馆反证、四幕）未被否定 |
| 2. 基础设定第二轮稿（2026-08-04） | 归面礼、滩涂点火、无正面父亲、警报测深、外乡警报值守员 | **用户逐句口述过因果并明确下令执行**；民俗内核全部来自用户本人 |
| 3. H00-R0《婚宴后场：返席》 | 婚宴后场 60—90 秒行为切片：归档录像带、实体沿旧后勤路线回返 | 重制决定成立，四个 Gate（空间/节拍/灰盒/状态机）已通过 |

**裁决**：

1. **世界因果层采用基线 2**。理由：它是用户的原创民俗内核，是本作区别于死魂曲/寂静岭的根；来源可信度最高（用户口述）；且民俗因果（归面礼→召回）能统摄另两条基线的素材，反之不能。
2. **物理层三线共享的「潮来了但水没有来，水深来了」保留为最高物理宪法**。理由：用户多次确认；它同时是玩法（测深）、视觉（承压证据）、主题（被排除者的回返）的公分母。
3. **主角统一为外乡警报/广播线务员**。理由：基线 1 录像员与基线 2 值守员的职业能力在「线务员」处天然合并——警报塔（测深）、婚宴厅扩声（H00 空间）、海洋馆广播（反证场景）、录像·广播室（归档交互）全部被一份职业职责覆盖，不需要剧情特批。外乡身份保留：不懂禁忌是玩法教学与叙事视角需要的缺口。
4. **H00-R0 保留为行为验证资产**，垂直切片在其空间骨架上扩建，不推倒。理由：它是唯一有日志证据的可运行物；其「归档录像带」交互被记录经济直接继承。
5. 三基线中一切与上述裁决冲突的条目，以下面各节逐项处理。

### 3.3 莫比乌斯小镇：改造后置

**裁决：公理层保留为宪法，全镇实装后置到 P3，垂直切片与 Alpha 只允许「软翻面」。**

理由，逐条：

1. **技术证据**：`f0_mobius_walk` 原型证明连续翻面在技术上可表达（124 秒连续路线、`route_parity` 翻转成立），也证明它贵——30fps 独立宿主复核与外部盲测未通过。在 PS3 级写实资产密度下做全镇连续翻面，是当前产能无法承诺的；
2. **设计证据**：寂静岭 2 的里世界不扭曲几何、只解锁门（见 [04 机制 §3](04_核心机制.md#3-寂静岭氛围优先的资源分配与心理地理)）——恐怖不需要几何魔术。本作的等价物「软翻面」（同一空间，路线连通性、称呼与深度归属改变）便宜一个量级且更贴主题；
3. **主题证据**：莫比乌斯的价值在「离开最终回到旧位置」的必然感，不在拓扑奇观。玩家记住的是「我走同一条路回来，家却换了含义」，不是「地面翻了个面」。

保留的公理（写入宪法，各阶段都必须遵守）：路线连续、无黑场传送、无发光门；翻转不可指认发生在哪一步；中央空洞不能进入只能围绕。

实装节奏：P1 一次翻面证明（后场→海洋馆走廊→反向回到宴会厅）；P2 一次软翻面（回到同一地点但称呼已变）；P3 R1 环湾海堤首次真翻面（一圈翻面、两圈复原，复用 F0 公理层）。

## 4. 玩法系统

| # | 系统 | 裁决 | 理由 |
| --- | --- | --- | --- |
| 4.1 | 警报测深 | **保留（核心）** | 用户口述机制；本作招牌。风险：至今只存在于纸面——P1 第一 Gate 必须是它的灰盒可玩验证 |
| 4.2 | 读深度 | **保留** | 与测深构成「花时间还是花安全」的持续决策；也是视觉宪法（证据链）的玩法回收 |
| 4.3 | 干潜 | **改造合并** | 「把身体探入深层换信息」作为独立系统与测深职能重复、且需要一套额外的身体状态数值。其体验内核（蹲低、探头、承压听墙）合并进读深度的姿态层。独立的「潜水条」式系统删除 |
| 4.4 | 改承压 | **保留** | 空间操作动词；「不改绝对深度、只改力的路径」的限制使它不会退化成万能开关 |
| 4.5 | 记路线 | **降级为设计原则** | 「用地标、坡度、声音记住小镇」是关卡设计义务，不是需要系统支撑的玩家动词。不做地图系统即自然成立 |
| 4.6 | 守仪式（不回头/不呼名/不踩拖痕/背潮认亲） | **保留（新增为第四动词）** | 交接包中散落在民俗描述里、从未被机制化——本轮审定的主要增补。它是玩法与主题咬合最深的一层 |
| 4.7 | RPG 系统（角色数值、成长、装备） | **删除** | 稀释民俗恐怖；主角的成长是知识与纪律，不是数值。交接包「角色_RPG与核心交互原型」整体归档 |
| 4.8 | 战斗/可击杀敌人 | **删除** | 归来者可送不可杀是主题底线；任何武器系统直接违宪 |
| 4.9 | 收集图鉴 | **改造** | 收集本能改造为记录经济（[04 §5](04_核心机制.md#5-记录经济记录即喂养)）：收集有代价、全收集通向伦理危险，收集行为本身被主题化 |
| 4.10 | 「二号桌」式单点谜题、找钥匙解谜 | **删除** | SIREN 反类型禁令直接适用；解谜由改承压的因果操作承担 |

## 新设定准入八问

任何新提案（怪物、场景、机制、画面、系统）进入制作前，提案人必须书面回答，任何一问不合格即退回：

1. **日常功能**：它原本的现实社会功能是什么？（没有正常态的东西不准有异常态）
2. **一眼测试**（2026-08-24 修订，原「异常因果」问废止）：一句话说清「看见什么」；不给任何背景，陌生人第一眼是否已经不适？需要解释才可怕的提案直接退回
3. **机制归属**：它属于四动词与记录经济中的哪一个？若都不属于，为什么值得开第五个系统？
4. **声音先行**：它的声学证据是什么？（答不出即退回——声音是第一叙事层）
5. **主轴纪律**：它服务「民俗恐怖 × 干燥深海」主轴，还是在引入新的恐怖类型？
6. **必要性**：删掉它，全作有什么具体损失？（「很酷」不是损失）
7. **预算**：它在 PS3 级预算与单人+AI 产能内可实现吗？最贵的部分是什么？
8. **距离**：它与死魂曲/零/寂静岭/遗传厄运的对应元素距离够远吗？是转译还是换皮？

已删除条目（§2.4、§2.5、§2.9、§3.2、§4.7、§4.8、§5.4、§5.6 等）的翻案除八问外，还须额外书面说明「当初删除理由为何不再成立」。
