# 《返潮》威胁谱系与怪物设计

> 状态：**现行生产规格**。服从 [docs/game-design/](README.md) 宪法；与交接包冲突时以宪法 + 本规格为准。
> 上游：[01 §5 威胁谱系](01_故事背景设定.md#5-威胁谱系)、[03 §3 威胁如何逼近](03_核心玩法.md#3-威胁如何逼近)、[05 §5 威胁裁决](05_设定审定_保留与删除.md#5-威胁与怪物)。
> 纪律：所有威胁沿**归面生成链**产生（活人描述 → 归面 → 海补空白 → 归来者回家 → 关系要求活人归位），不存在链外怪物；已否决方向（触手、外星甲壳、尸兔、酒店器官、灭世生态、巨物等）不以任何换皮回归；**Demo 实装威胁只有 M01**。

---

## 1. 设计公理（先于任何具体怪物）

1. **反「血厚/弱点」公理**：本作威胁没有血条、没有弱点、没有击杀。威胁的「强度」是它对空间、声路和关系的**占有度**；玩家的「对策」永远是三件事的组合——**读懂它的规则、守住仪式、改变路线**。任何写成「打法攻略」口吻的威胁设计直接退回；
2. **感知底座统一**：归来者共享「仍在履职的人」感知规则（[05 §5.3](05_设定审定_保留与删除.md#5-威胁与怪物)）——听**结构振动与工作顺序**，无万能视觉、无嗅觉雷达、无剧情透视。差异只在「听什么、走哪里」；
3. **差异化强制**：每个威胁必须有**一种独特读法**（玩家靠什么预判它）与**一种独特应对**（别的威胁用不上的对策）。两个威胁若可以互换应对方式，砍掉一个；
4. **四卡制**：每个威胁必答四卡——**记忆缺口是什么 / 海补了什么 / 玩家如何在不战斗的情况下读懂并应对 / 它与 Demo 的关系**（实装 / 只露证据 / 剪影 / 不登场）；
5. **形态即缺口**：每一处海洋结构必须对应一个具体的记忆空白与一种感知方式（[01 §9](01_故事背景设定.md#9-剧情设计禁区)）。石化复眼**只属于 M01**，不是谱系统一脸型；海补材料只从返还规则 2 的材料池取（贝灰、矿化壳板、滤食腕、石化复眼、盐晶、压实沉积物、黑绿色霉层）。

## 2. M01 无正面父亲（英雄威胁，全量行为合同）

### 2.1 四卡

| 卡 | 内容 |
| --- | --- |
| 记忆缺口 | F01 一家只记得父亲离开码头时的**背影**：旧蓝工装、左肩被渔网压低、右脚拖半步。没有正面照片，没人记得他最后转身时的脸 |
| 海补了什么 | 从额头到腹部的一整片**石化复眼甲壳**填满正面空白。没有嘴，不咆哮；复眼只在警报与呼名后从所有玻璃反光里同时睁开 |
| 不战斗的读懂与应对 | 读：声音减法（车轮声消失=状态切换）、拖痕（路线证据）、反光（唯一安全正面观察）。应对：餐具声误导、改承压改其回返路线、蹲低走浅/深声学差、不回头、不呼名 |
| 与 Demo 的关系 | **唯一实装威胁**（B3–B9 全程，见 [07 §3](07_Demo垂直切片_玩法与叙事框架.md#3-节拍表8-12-分钟逐-30-90-秒)） |

### 2.2 双层状态机（H00-R0 合同 × 宪法合同的正式缝合）

**履职态（默认）**——继承 H00-R0 已验证的全部行为合同：

- 沿旧后勤路线 D→B→C门外→E→D 航点循环（父亲生前给酒店后厨送货、收场帮工的路线）；
- 工作点停留做普通动作（起点值 1.4–3.2 秒）；**匀速恒定（起点值 1.5m/s），速度永不因玩家改变**；
- **让行不推回**：玩家占道时它原地等待——但它不给玩家让路，它只是不推你。等待超过一定时长，它开始整理离玩家最近的桌面（压力不靠攻击性制造）；
- 它在 A 厅的工作是**返席**：把收场中的婚宴一桌桌摆回开席状态——它不是在收场，是在把「结束」摆回「还没结束」。

**循声态（被声源触发）**——宪法行为合同的实装：

- 触发源：警报（测深）、呼名、餐具碰撞、录像机走带声。触发有**一拍迟滞**：它先把手里的动作做完（放下碗、扶正椅子）才动身——工作优先于反应，这半秒的「像在回忆该不该去」正是恐怖谷的姿态来源；
- **以背影朝向声源、倒退移动**逼近声源位置。仍然匀速，不冲刺、不转身；
- 状态宣布是**声音减法**：放下推车，车轮声消失，只剩右脚拖步声；
- 声源冷却 60–90 秒后回到履职态最近航点。**禁止无限追逐与背板即死**。

### 2.3 可玩细节（本轮深挖，全部服务四动词）

1. **倒退的空间语言**：它接近你时，你看到的是「一个背对你走远的人却在变大」——运动方向与身体朝向的矛盾是 720p 轮廓级的可读异常（[08 §5.2](08_Demo资产精度与恐怖谷规范.md#52-m01-威胁门四测试执行细则)）。副作用是它的正面永远朝向你**看不到的方向**——它把「脸」留给你身后的空间，这让「不回头」有了物理意义：回头的那一眼看到的正是它的正面；
2. **拖痕系统**：右脚拖半步在地面留下干燥拖痕。拖痕是三合一道具：**路线证据**（读深度：拖痕走向=它的回返路线）、**禁忌触发器**（踩入=玩家路线并入其回返路线，守仪式「不踩拖痕」的机制化）、**时间证据**（拖痕的新旧=它多久前经过）；
3. **返席可利用**：玩家亲手把某桌摆回开席状态，它会跳过该桌航点——你可以用「替它完成工作」缩短它在宴会厅的滞留、清空一段路线。代价不是数值：你每摆一桌，宴会厅就离「他回来了」的场面更近一步，B10 的留位证据随之增多。**帮它收场就是帮它回家**——四动词之外零新系统，纯环境状态；
4. **反光管理**：反光是它的感知宣布（睁眼），也是玩家的导航工具（B8 反光导航）。玩家可以转动可动镜面/用桌布罩住 CRT 来改变「睁眼」覆盖面——但打碎玻璃是**声源**，且永久失去一面导航镜。因果回应，不设对错；
5. **听觉材质表**：它听结构振动。地毯上的脚步它几乎听不见，水泥与瓷砖上听得远；**你能听见它的地方它也能听见你**——蹲低贴墙偷听（读深度的姿态层）同时是双向暴露。玩家的最优通道（低处、桌下）恰好在深声学区，「安全的路更深」是常态压力；
6. **认领演出（失败）**：拂平衣领 → 按入 3 号桌空位 → 搭上椅套。它对你做的是「让家庭完整」的动作，全程没有一个伤害帧——被温柔地归位比被杀死更冷（[03 §6.1](03_核心玩法.md#61-失败设计被归位而不是死亡)）；
7. **暂时送走**（P2 起，Demo 不实装）：中期玩家学会用测深把它引回滩涂方向。Demo 内玩家对它只有「绕开、误导、改道」三法。

### 2.4 Demo 节拍绑定

B3 循声态首触发（只闻其声）→ B4 履职态返席（安全阅读期）→ B5 二选一穿越（循声态可被玩家主动触发）→ B6 改承压改道其回返路线 → B8 反光睁眼+不回头 → B9 镜墙反光内持续返席（零遭遇成本的存在感）。

## 3. 后续威胁（三个，P3 前不得制作正式资产）

编号制度化：M02 数人的母亲、M03 抬面者（两者为宪法已点名保留后置项，本节回答八问作为进入生产规格的手续）；M04 未面者（本轮唯一全新威胁，占用「允许 1 个全新链上威胁」的额度）。

### 3.1 M02 数人的母亲

| 卡 | 内容 |
| --- | --- |
| 记忆缺口 | F02（旧村多子女家庭）的母亲失踪后，孩子们记得的只有「她总在门口背光处数孩子回没回来」——一个逆光剪影、一套点数的节奏、一副藏在袖口里的手。**没人记得她的脸**（她永远背对屋里的灯），没人记得她的手（袖口太长） |
| 海补了什么 | 脸的空白被补成一片**盐晶结壳**——逆光下像结霜的玻璃，看不清，却让每个看的人「以为看清了」：盐晶的漫反射让观看者把自己期待的脸投上去。**认错人发生在观看者一侧，海没有给她做脸**。袖口里的手被补成一串**矿化壳板指节**，点数时发出贝壳相叩的轻响 |
| 不战斗的读懂与应对 | 读：点数节奏（她的声学签名——壳板轻叩 + 逐个念称呼），数到缺席者会**停顿、重数**——重数窗口是玩家的移动窗口。应对：她只数「在家庭位置上的人」——椅子、床、工位、被登记的座位。**站到无名位置**（门槛、楼梯中段、服务通道）就不可数；更深一层，从名单、座位表、登记册上抹掉自己的名字可以永久免数——但销毁记录的代价照付（记录经济） |
| 与 Demo 的关系 | **只露证据，不登场**：B1/B10 座位表上有红笔逐个打勾的「点到痕」——婚宴排座本身就是一次数人。无声音、无剪影 |

行为特征（与模板的距离）：她**不追、不抓、不巡逻、从不进屋**——她站在门口等孩子进来。威胁是「被点到」：被她数入的人获得一个家庭位置并开始被这个位置要求（认领 +1，NPC 状态机漂移）。她是全谱系里唯一「站着不动也在推进危机」的威胁——压力来自你迟早要经过一扇门。

### 3.2 M03 抬面者

| 卡 | 内容 |
| --- | --- |
| 记忆缺口 | 一次送面路上，抬归面的四个人自己失踪了。镇里人记得的不是四张脸，而是「四个人抬一具归面走过滩涂」的**队形与步频**——记忆把四个人记成了一个动作。他们各自是谁，没人说得全 |
| 海补了什么 | 四人之间的抬杠被补成一根**压实沉积的矿化长杠**，肩与杠长成一体——四人被固定成一组，永远保持抬扛间距与步频。杠中央压着一段看不清的压实沉积——**他们抬着的东西永远看不清**（叙事空洞，不填） |
| 不战斗的读懂与应对 | 读：**四双脚一个节奏**的合一步频（独特声学签名，隔两堵墙可辨）+ 旧送面潮路的路线证据（沉积带、涵洞走向、平行拖痕四行）。应对：他们**只走旧潮路、永不改道、对一切声音无反应**——像列车一样绝对可预测，对策就是读线、让开、等它过。用门挡潮路无效：杠头抵门原地不退，承压证据在门框上一轮轮积累直至门框失效——**你不能用改承压挡住仪式**（改承压玩法的反面教材，也是它的教学功能） |
| 与 Demo 的关系 | **一次远景剪影，不可交互**：B6 卷帘半开的 40cm 缝外、雾中滩涂方向，四条腿抬一根长杠匀速经过，≤3 秒，无音乐提示 |

行为特征（与模板的距离）：与 M01 恰成对照——M01 循**声**（可被玩家操纵），M03 循**路**（对玩家彻底无感知）。它不是敌人，是一班定时定线的仪式列车；被卷进队形之间的失败是「被抬走」：玩家被抬着走一段潮路，在滩涂方向醒来（归位演出的 M03 变体）。谱系里它承担「世界不是围绕你运转」的功能。

### 3.3 M04 未面者（全新，占用唯一新增额度）

| 卡 | 内容 |
| --- | --- |
| 记忆缺口 | F01 家的老二——1999 年冬与父亲同船失踪。他离家早，家人对他记得**最少**：没有正面近照，口音记不准，身高「大概到门框那道漆痕」。他的归面**一直没做完**——能确认的太少，留空塑面留出的几乎是整个人 |
| 海补了什么 | 缺口太大，海按返还规则只能等待描述。点火事件后，F01 发现外乡线务员「像我们家老二」，开始**用韩汛的细节重新描述老二**——年龄、口音、拖半步的走路习惯，一项项进入家庭的讲述、相簿与录音。于是那具未完成的归面（贝灰 + 旧衣 + 空白面的材料人形）开始**逐项长出玩家被记录的特征**：步态先来（最容易被观察），然后是口音（若有录音被拾取）、常走的路线。它永远比玩家「落后几天」——它是玩家被记录版本的回放 |
| 不战斗的读懂与应对 | 读：它从不接近玩家——它出现在**玩家不在的地方替玩家生活**：宿舍、修过的警报箱旁、常走的路线上；NPC 会说「刚才看见你在滩涂」而你没去过。独特读法是**行踪对不上**。应对是记录经济的主战场：归档/销毁与自己有关的记录（**饿它**）、改变习惯路线（喂给它过时的路线）、守仪式——永不应答「老二」这个称呼；P3 关键节点的唯一「正面对抗」是背潮认亲式自证：面向陆地，说出关于自己的、不能代表一生的普通小事，用仪式语法把姓名从别人的描述里取回来 |
| 与 Demo 的关系 | **只露证据，不登场**：① B1/B10 座位表被红纸盖住的名字（家人既想留位又不敢呼名的那个座位——B10 的空位餐具同时是 M01 返席行为的谜底与 M04 的第一证据，一件道具两条线索）；② C 归档架上一格贴着「老二」标签的空格（家人送来「等他回来看」的预留格） |

行为特征（与模板的距离）：替身题材在恐怖传统里存在，但 M04 的每一层都来自本作自己的规则——它不是镜像恶魔，是**一具没做完的归面在用别人对你的描述自我完成**；它从不攻击、从不追逐，失败形式是**身份漂移**（镇民对你的称呼逐渐让位给它），全谱系唯一没有归位演出的威胁。它把主角线（4.2「他开始被认领」）从状态数值变成一个可遭遇的身体。

**禁区自查（写入宪法级承诺）**：M04 **不是**「主角其实是老二」或「主角早已死去」的暗示——韩汛与老二无血缘、无秘密关联，相似是统计性的（年龄段、外县口音、劳动步态），[01 §9](01_故事背景设定.md#9-剧情设计禁区) 的总反转禁区必须守住；老二本人的真实面目属于叙事空洞，任何档案不得给出。

## 4. 差异化应对矩阵（谱系总表）

| | 感知 | 路线逻辑 | 独特读法 | 独特应对 | 失败形式 |
| --- | --- | --- | --- | --- | --- |
| M01 无正面父亲 | 结构振动听觉 | 旧后勤路线 + 循声改向 | 声音减法、拖痕、反光睁眼 | 声误导 / 改承压改道 / 不回头 | 被按入座位（归位） |
| M02 数人的母亲 | 名单与家庭位置 | 门到门，从不进屋 | 点数节奏、重数停顿 | 站到无名位置 / 从记录除名 | 被数入名单（认领） |
| M03 抬面者 | 无（对玩家零感知） | 旧送面潮路，永不改道 | 四合一步频、潮路证据 | 读线让开、等它过 | 被抬走一段潮路 |
| M04 未面者 | 记录与习惯（经由家人的描述） | 玩家的历史路线 | 行踪对不上（「刚才看见你」） | 记录节食 / 不应答 / 背潮自证 | 身份漂移（无演出） |

矩阵验收：任意两行的「独特读法 + 独特应对」不可互换；四个失败形式互不重复；无任何一行需要武器、血条或数值成长。

## 5. 新设定准入八问（逐威胁作答）

按 [05 审定文档](05_设定审定_保留与删除.md#新设定准入八问) 要求，M02/M03 为宪法已点名的后置项、M04 为全新项，三者八问全部书面作答如下。

### M02 数人的母亲

1. **日常功能**：多子女家庭的母亲每晚在门口数孩子回没回来——真实的看护行为；
2. **异常因果**：记忆只保存了「数」这个动作，海把她固定成永远数不齐的点名者。玩家从点数声、门口剪影、座位表点到痕看懂；
3. **机制归属**：守仪式（家庭位置的离开与占用）+ 记录经济（名单除名）。零新系统；
4. **声音先行**：壳板指节相叩 + 逐个念称呼的点数节奏；数到缺席者的停顿重数是可玩窗口；
5. **主轴纪律**：民俗（点名/叫魂的看护变奏）× 干燥深海（盐晶、壳板），无新恐怖类型；
6. **必要性**：她是「被记住=被固定」主题的母亲侧——删掉她，认领系统只剩威胁没有源头的爱；
7. **预算**：一个角色资产 + 门口固定演出位；无追逐 AI（她不动），是全谱系最便宜的威胁；
8. **距离**：与 SIREN 尸人（循环劳作）的距离在于她无攻击行为、威胁是社会性的（被点到）；与寂静岭护士等巡逻怪无任何机制重叠。

### M03 抬面者

1. **日常功能**：送面礼中抬归面过滩的执事——真实的仪式分工；
2. **异常因果**：记忆把四个人压缩成一个动作，海把动作固定成永不停歇的抬行。玩家从四合一步频、平行拖痕、潮路沉积带看懂；
3. **机制归属**：读深度（潮路证据）+ 守仪式（不踩拖痕、让路）。零新系统；
4. **声音先行**：四双脚一个节奏的步频，隔墙可辨——先听见，后看见；
5. **主轴纪律**：民俗（仪式执事）× 干燥深海（矿化杠、沉积负重），无新类型；
6. **必要性**：全谱系唯一对玩家零感知的威胁，承担「危机不等玩家、世界不围绕你」的 Pathologic 式功能；删掉它，威胁谱系全部变成「冲着玩家来的」；
7. **预算**：一组四人共享骨骼的组合资产 + 固定路线，无 AI 决策；贵在组合动画的步频同步（最贵项）；
8. **距离**：「仪式列车」结构在恐怖游戏里罕见；与 SIREN 尸人巡逻的区别是不可惊动、不可利用视线；与任何 Boss/精英怪结构无关。

### M04 未面者

1. **日常功能**：一具按礼俗未做完的归面——留空塑面的伦理本体；
2. **异常因果**：家人用外乡人的细节续写失踪者的描述，海按描述逐项补全。玩家从「行踪对不上」的 NPC 证词、自己房间的使用痕迹、归档架预留格看懂；
3. **机制归属**：记录经济（核心：记录节食）+ 守仪式（不应答、背潮自证）。零新系统——它就是认领状态机的实体化；
4. **声音先行**：它的声学证据是**玩家自己的声音**从错误的地方传来（自己修过的警报箱重放自己的测试音、广播里出现自己的口音）；
5. **主轴纪律**：民俗（归面、认领）× 干燥深海（贝灰材料人形），无新类型；主角线与威胁谱系在它身上合流；
6. **必要性**：删掉它，「主角被认领」只是菜单里的一个数值；有了它，玩家对每一次记录的犹豫都有一个具体的身体在等着收走；
7. **预算**：形态分阶段（材料人形 → 逐项长出特征），复用 P01 的骨骼与动作库（它本来就在学玩家）——最贵的部分是分阶段贴图组，其余是复用；
8. **距离**：与「主角早死了」总反转（已删除项）**无关**且明文禁止暗示；与恐怖传统的 doppelganger 的区别是它无恶意、无攻击、由记录喂养、可被仪式自证反制——对应元素距离足够远，是转译不是换皮。

## 6. Demo 纪律重申（防动物园条款）

垂直切片内：M01 实装全行为；M02 只有座位表点到痕；M03 只有一次 ≤3 秒剪影；M04 只有红纸座位与归档架空格两处静态证据。**四者在 Demo 里共用的画面时间 ≤3 秒（M03 剪影）**，其余全部是可错过的环境细节。任何「让 Demo 更热闹」的威胁增量提案，直接引用 [05 §5.6](05_设定审定_保留与删除.md#5-威胁与怪物)（恐怖类型堆叠，制度性禁止）驳回。

## 7. 威胁设计禁止清单

- 血条、弱点、可击杀结构、Boss 战、精英/小怪层级；
- 索敌仇恨值、视锥探测、警觉条 UI；
- 链外怪物（无归面来源的任何存在）；
- 已否决项换皮：触手、外星甲壳、尸兔、酒店器官、湿拓、灭世生态、巨物；
- 跳脸、音刺惊吓、随机恐怖过场；
- 用「更多怪物」补氛围——氛围预算属于声音与空间（[06 §3](06_技术栈与制作工作流.md#3-声音管线第一叙事层)）。
