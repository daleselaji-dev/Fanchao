# 《返潮》Demo 垂直切片：玩法与叙事框架

> 状态：**现行生产规格**（P1 垂直切片）。本文档服从 [docs/game-design/](README.md) 宪法；与交接包及任何历史分支材料冲突时，以宪法 + 本规格为准。
> 本文回答三个问题：Demo 的一句话是什么；8–12 分钟里每 30–90 秒玩家在做什么；视觉风格如何落到每一拍。

## 1. Demo 的一句话（锁死，盲测验收标准）

### 1.1 三句拆解

- **叙事来源（一句）**：2001 年，海边小镇把送走无尸亲人的「归面礼」一代代温柔地做反成了召回。
- **恐怖来源（一句）**：回来的不是亲人，是**别人记错的他**——记忆的空白由海床补全，而你每呼名、每记录一次，他就更真一点。
- **玩家可复述单句（对外盲测用）**：

> **「小镇把送走死者的仪式做反了，海把被记错的亲人送回了家——房间是干的，但已经在海底。」**

### 1.2 收束说明

这一句不开新世界观，全部成分来自宪法既有裁决：仪式做反（[01 §3.2](01_故事背景设定.md#32-仪式如何被做反)）、被记错的亲人（返还规则 1/2，[01 §3.4](01_故事背景设定.md#34-返还规则世界规则各部门必须执行)）、干燥深海（最高物理宪法）。因果不变，只把「归面礼→召回」与「潮来了，水没有来」压进一口气里。

### 1.3 验收

成片门盲测（无解释文字的完整录像）后提问「这里发生了什么」，外部测试者的复述必须命中两个短语的语义：**「这里是干的，但已经在海底」**与**「它是被记错的人」**。命中一个为 CONDITIONAL，零命中为 FAIL 退回。

## 2. 空间与行为地基

### 2.1 空间（不新增，全部为宪法已批空间）

婚宴后场闭环 **A 宴会厅 / B 服务走廊 / C 录像·广播室 / D 卸货口 / E 洗涤间** + 一段**海洋馆服务走廊**（翻面证明段）。拓扑沿 H00-R0 Round 3 灰盒，不推倒。

关键点位：

| 点位 | 功能 | 归属动词 |
| --- | --- | --- |
| C 卡座/归档架 | 换带、归档（H00-R0 原交互，半径 2.4m） | 记录经济 |
| B/C 交界配线龛（扩声机柜） | 主测深点 | 测深 |
| D 卸货口外墙警报分箱 | 次测深点（本 Demo 只作证据，不强制使用） | 测深 |
| D 卷帘 + 门框传力点 | 改承压主操作 | 改承压 |
| 海洋馆玻璃对照位 | 缸内真水 vs 缸外干压 | 读深度 |
| A 圣经机位 | 同机位三态对照（见 §5.2） | —— |

### 2.2 M01 的双层行为（H00-R0 合同与宪法合同的缝合）

H00-R0 验证的是「像在工作而不是追逐」；宪法 [03 §3.1](03_核心玩法.md#31-m01-无正面父亲行为合同) 规定「沿声倒退接近」。两者不冲突，是同一威胁的两个状态：

| 状态 | 内容 | 来源 |
| --- | --- | --- |
| **履职态**（默认） | 沿旧后勤路线 D→B→C门外→E→D 航点循环；工作点停留做普通动作；匀速恒定，速度永不因玩家改变；玩家占道时原地等待，不推挤、不绕圈逼近 | H00-R0 行为合同（已验证） |
| **循声态**（被声源触发） | 警报、呼名、餐具碰撞、走带声触发；放下手中工作，**以背影朝向声源、倒退移动**逼近声源位置；仍然匀速，不冲刺；60–90 秒内声源冷却则回到履职态最近航点 | 宪法行为合同 |

状态切换的宣布方式是**声音减法**：循声态的它不再推车，车轮声消失，只剩拖步声——玩家闭着眼也能知道它变了。完整行为合同（含反光睁眼、拖痕、认领演出）见 [09 §2](09_威胁谱系与怪物设计.md#2-m01-无正面父亲英雄威胁全量行为合同)。

### 2.3 威胁纪律

Demo 实装威胁**只有 M01**。M02（数人的母亲）只露证据，M03（抬面者）只有一次不可交互的远景剪影，M04（未面者）只露证据——三者均不进入可交互空间，逐项界定见 [09 §3](09_威胁谱系与怪物设计.md#3-后续威胁三个p3-前不得制作正式资产)。禁止在本 Demo 中新增任何第四种存在感。

### B0 换带归档（0:00–0:45）

- **玩家动词**：移动；C 卡座换磁带并按 REC/PAUSE 归档（H00-R0 原交互）。
- **空间**：C 录像·广播室。
- **声音先于画面**：走带声、卡座继电器咔嗒；墙后宴会伴奏与人声——现实底层先成立。
- **M01**：不存在，无任何威胁暗示。
- **失败/归位**：无失败。
- **教学点**：移动、交互、交互半径的身体感。
- **一帧一异常**：**无异常**。正常态必须先赢（[02 §1](02_视觉原型设定.md#1-视觉主句)）。

### B1 送场回路（0:45–1:45）

- **玩家动词**：应阿澄（N01）之托把一车餐具从 A 推到 E 洗涤间——推拉重物的动作教学，为改承压做身体铺垫。
- **空间**：C→B→A（收场中的婚宴，有人气）→E。
- **声音先于画面**：瓷器碰撞、椅腿拖地、伴奏——这些正常声在 B4 会被 M01 逐一「复述」，此拍是听觉基准。
- **M01**：不存在。
- **失败/归位**：无。
- **教学点**：A–E 闭环认知；阿澄用正常称呼（「小韩师傅」）建立称呼基准。
- **埋设**：座位表一角有个被红纸盖住的名字（不解释）；镜墙正常反光；**阿澄经过 B 走廊时下意识跨过地面一道旧拖痕**——NPC 示范「不踩拖痕」，无台词。
- **一帧一异常**：无异常。

### B2 断电与两秒伴奏（1:45–2:30）

- **玩家动词**：读深度（首次，被动观察）。
- **空间**：A→B。
- **事件**：全场断电，应急灯亮起（动态光预算 1 号位）。**伴奏带在断电后多放了两秒才停**（巧思 4，见 §5.3）。
- **声音先于画面**：断电闷响之后，建筑结构一次整体「沉降吱嘎」先于一切视觉变化；低处的伴奏残响变厚、变远。
- **视觉证据（读深度教学素材）**：同一高度出现连续承压带——胶条挤出、桌腿短缩、门框密封条像牙膏外挤（[02 §3.1](02_视觉原型设定.md#31-六条视觉执行规则) 规则 2）。C 房间 CRT 靠应急电仍亮着：**录像里 3 号桌已经恢复成开席摆法，而现实里它还是收场半桌**（巧思 1 前半，此刻玩家多半不会注意——预兆的事后可读性）。
- **M01**：未见；D 方向传来一声卷帘金属受压。
- **失败/归位**：无。
- **教学点**：异常是证据不是宣布；低处 = 深。
- **一帧一异常**：承压带（唯一主异常）。

### B3 第一次测深（2:30–3:30）

- **玩家动词**：测深（首次）。玩家以线务员职业本能接入 B/C 配线龛扩声机柜，发出短促测试警报。
- **空间**：B/C 交界。
- **听感教学**：朝 A 方向回声**清晰短促**（浅）；朝 D 方向回声**拖长、降调、伴结构内缩**（深）。方向差 = 深度界面走向。无 HUD、无数值。
- **代价教学（机制的心脏）**：警报余音未散，D 方向响起匀速的餐具车轮声，由远及近，**节奏完全不变**——有东西循声而动，而且不着急。
- **M01**：循声态首次触发，全程不可见。
- **失败/归位**：无（首拍测深有保护距离，M01 到达配线龛需时长于玩家自然离开的时间）。
- **教学点**：测深读深浅与走向；**测深即暴露**。
- **一帧一异常**：无新视觉异常——这是纯声学拍，画面刻意不变。

### B4 背影返席·安全阅读期（3:30–4:30）

- **玩家动词**：读深度（找安全高度：低处伴奏变厚、耳压——桌下高度在「深处」）；从 B 门缝/服务窗固定机位观察。
- **空间**：B 门缝→A 边缘。
- **M01**：履职态进入 A，开始**返席巡桌**——把收场中的婚宴一桌桌摆回开席状态：翻正倒扣的碗、扶正椅子、把撤下的椅套重新搭好。它做的第一桌就是 3 号桌——**与 B2 录像里已完成的画面逐渐重合**（巧思 1 后半）。
- **声音先于画面**：进入 A 前先有瓷器与椅腿声；它的脚步声从错误材质传来——**地毯上走出水泥的回声**。
- **安全阅读期**：≥20 秒无威胁观察窗口。恐怖来自识别，不是惊吓：旧蓝工装、左肩被渔网压低、右脚拖半步——B1 里见过收场工人的正常姿态，现在读出「这个人在把结束的事做回去」。
- **失败/归位**：无（玩家不进 A 中央即无风险）。
- **教学点**：先认出人，再认出怪物；巡桌 = 它的循环，循环可读可利用。
- **一帧一异常**：声源材质错位（主异常在听觉；画面主读点是背影与桌面摆法的时间倒错，二者不同帧出现）。

### B5 穿厅二选一（4:30–6:00）

- **目标**：从 A 东侧到 D 卸货口。必经 A 中央，或绕 B 浅处服务线。
- **方法一（快而险）**：敲击远处餐桌转盘制造餐具声——M01 切循声态，放下推车（车轮声消失，只剩拖步声），倒退走向声源；玩家蹲低从桌下低处穿过。低处 = 深处：伴奏变厚、耳压；**玩家自己的脚步声也变了**——它听结构振动，你能听到它的地方它也能听到你。
- **方法二（慢而稳）**：绕 B 浅线。代价：时间，且经过 C 门外航点时若 M01 在位，须按让行合同等待或绕行（它不给你让路，它只是不推你）。
- **拖痕规则**：M01 拖半步的右脚在地面留下干燥的拖痕。**踩入拖痕 = 把自己的路线并进它的回返路线**——它的下一个履职态航点会变成玩家当前位置（软性代价，不判死）。B1 阿澄已无台词示范过跨越。
- **声音先于画面**：循声态切换由声音减法宣布（§2.2）。
- **失败/归位**：被贴近→**归位演出**：它替玩家拂平衣领，把玩家按进 3 号桌一个空位，肩上搭一条椅套。认领 +1（全局蓄积），玩家从 E 洗涤间醒来，身上那条椅套还在。M01 回到履职态。**不读档、不丢资源、不重放节拍**——世界记住失败并继续。
- **教学点**：沿声倒退接近；两种通过方法（成片门要求两法都成立）；失败不是死亡。
- **一帧一异常**：倒退移动的背影——运动方向与身体朝向的矛盾，720p 轮廓必须可读（[08 §5](08_Demo资产精度与恐怖谷规范.md#5-720p-轮廓双读验收) 验收项）。

### B6 改承压开卸货口（6:00–7:00）

- **玩家动词**：改承压。
- **空间**：D 卸货口。卷帘被深压压死：门框下段压短、导轨弯折、漆面压白（英雄资产近景，[08 §4](08_Demo资产精度与恐怖谷规范.md#4-英雄资产清单demo-必须达标)）。
- **操作**：把宴会推车顶进门框传力点，让力改走推车钢架，再摇卷帘至半开约 40cm。
- **错误操作的因果回应**：先摇卷帘不垫推车——不弹失败提示，导轨应力换路径，E 洗涤间方向一扇旧门「砰」地弹开，**M01 的回返路线改道 E→B**：下一次它会从玩家背后方向出现。世界用因果回应，不用对错回应。
- **声音先于画面**：动手前，门框木纤维持续的「咯」声先行宣布承压。
- **M03 剪影（唯一一次，不可交互）**：卷帘半开的 40cm 缝外，雾中滩涂方向，**四条腿抬着一根长杠的剪影**匀速经过，≤3 秒，无音乐提示（[09 §3.2](09_威胁谱系与怪物设计.md#32-m03-抬面者)）。
- **失败/归位**：无硬失败，只有路线后果。
- **教学点**：改承压不改绝对深度，只改力走哪条路。
- **一帧一异常**：门框承压变形（主异常）；剪影属于下一帧，不与之争夺注意力。

### B7 玻璃对照位（7:00–8:00）

- **玩家动词**：读深度（对照）。
- **空间**：海洋馆服务走廊。固定机位：**缸内海水一切正常**——气泡上升、鱼群、水泵声清亮；**缸外走廊干燥承深压**——密封条外挤、贝灰粉化带、脚步声闷厚、耳压。同一块玻璃，两侧都在陆地，承压的是没有水的一侧（巧思 2）。
- **声音先于画面**：进走廊先听见两种声学并置——水声清亮与足音闷厚同帧共存。
- **M01**：不在场。这是刻意的喘息拍，也是全 Demo 信息密度最高的一帧。
- **失败/归位**：无。
- **教学点**：「返潮不是水」的一帧证明——全作反证场景的预告。
- **一帧一异常**：玻璃两侧的矛盾（唯一主异常，禁止叠加其他异常）。

### B8 反光睁眼·不回头（8:00–9:15）

- **触发**：走廊嵌墙喇叭泄出一段旧录音——一个女人的声音在呼一个名字（F01 家认亲录音沿声路泄漏，不是玩家发出的）。随即**全部缸面反光同一帧睁眼**（巧思 3）：M01 感知锁定态的全场宣布，无 UI。
- **M01**：循声态，已进入走廊，在玩家与来路之间。背后是拖步声。
- **规则**：**回头看 = 认领的一半**，直接触发归位。正确操作：压低视线，用缸面反光侧看导航，倒退或侧移离开走廊——反光是唯一安全观察其正面的方式。
- **声音的压力设计**：背后声音的距离感忽近忽远（结构传声的欺骗）；呼名声逐渐换成更接近玩家名字的音。游戏用声音把「想回头确认」做成压力测试，不用跳脸。
- **记录决策（记录经济的 Demo 一课）**：泄音源头是接线盒里卡着的一盘磁带，线务员有职业理由打开它。三选一：带走（可用证据，但随身携带期间 M01 循声态触发变频繁）/ 留在原处（安全，失去证据）/ 事后送 C 归档架隔离（安全且保存，但要再穿一次后场）。无提示，纯环境。
- **失败/归位**：回头→归位演出（被带回 A，按进座位），认领 +1，从 E 醒来。
- **教学点**：不回头；反光导航；记录三难。
- **一帧一异常**：反光中的复眼正面与现实中的背影同帧（唯一一次允许两个读点，因为它们是同一异常的两半）。

### B9 翻面回厅·换称呼（9:15–10:15）

- **空间**：走廊尽头的门推开——直接回到 A 宴会厅**另一侧**。无黑场、无传送、几何连续，但连通性不可能：这是莫比乌斯软翻面的一次证明（[05 §3.3](05_设定审定_保留与删除.md#33-莫比乌斯小镇改造后置) 批准的 P1 额度）。
- **翻面证据**：婚宴横幅文字左右反（主读点）；桌次镜像；镜墙换边。
- **阿澄**：中景背影 + 画外音，用另一个称呼叫玩家：「哥，你去哪了？」对话轮出现称呼选项——**纠正他**（说出自己的名字：短期收益，阿澄恢复常态并指近路；但说出名字 = 呼名，认领状态 +1）/ **沉默**（守仪式，绕远路）。没有正确答案，只有代价。
- **声音先于画面**：推门前，门后传来 B1 那首伴奏、但从头放起——时间在门后被摆回去了。
- **M01**：现实厅内没有它；**镜墙反光里它仍在返席**（持续存在感，零遭遇成本）。
- **失败/归位**：无硬失败；称呼选择写入认领状态，影响结束帧阿澄的最后一句称呼。
- **教学点**：不呼名（包括自己的名字）；软翻面 = 走同一条路回来，家换了含义。
- **一帧一异常**：横幅反字（唯一主读点；桌次镜像与镜墙换边作为支持证据不做特写）。

### B10 座位表与空位餐具（10:15–11:15）

- **空间**：A' 通往正门的路线经过座位表与主桌。
- **证据**：座位表上的红纸**换了位置**——现在盖住紧邻主桌的一个座位（巧思 5）；那个座位上，撤走的餐具被重新摆成正式的一副——**有人在为「他」留位**。玩家在 B4 看过 M01 的返席，现在明白它在为谁摆桌。
- **玩家动词**：读深度收尾（正门门框有全 Demo 最深的承压证据——出口比来路更深）；若 B8 带了磁带，此处 C 归档架顺路可归档。
- **声音先于画面**：远处滩涂方向，警报余音开始隐约、规律地重复——不是玩家发出的。
- **M01**：镜墙反光内持续返席。
- **失败/归位**：无。
- **教学点**：无新教学，收束已学——这一拍必须让玩家自己把「返席—红纸—空位餐具」连成因果，无任何台词。
- **一帧一异常**：红纸位移 + 空位餐具（同一异常「留位」的两个物证，同帧同读点）。

### B11 结束帧（11:15–12:00）

- **空间**：A' 正门推开：门外不是街道——**干燥泥面、雾、离岸桩剪影**，警报余音在雾里规律重复。玩家迈出一步，脚下是压实沉积。
- **镜头**：A 圣经机位第三帧（同机位序列：B1 正常态 → B10 返潮态 → B11 门外，见 §5.2）。定格数秒，淡出。无结算、无文字。
- **M01**：只有声学存在（警报余音的方向）。
- **教学点**：无。此拍只服务盲测复述（§1.3）。
- **一帧一异常**：门外是滩涂（空间归属的错误——正门原本通向镇街）。

### 节拍纪律核对

- 恐怖类型唯一：全部 12 拍只有「民俗恐怖 × 干燥深海」一条主轴；阈限（收场婚宴的无人化）与肢体（M01 姿态）只作为主轴表现手段出现（[05 §5.6](05_设定审定_保留与删除.md#5-威胁与怪物)）。
- 四动词覆盖：测深 B3 / 读深度 B2·B4·B7·B10 / 改承压 B6（B1 铺垫）/ 守仪式 B5（拖痕）·B8（不回头）·B9（不呼名）。「背潮认亲」不进 Demo，留给终局（[03 §2.4](03_核心玩法.md#24-守仪式约束动词本作独有的反操作)）。
- 记录经济只给一课（B8 磁带三选一 + B0 归档基准），不做完整经济。
- R 键全局复位降级为**开发调试功能**；玩家侧的「重来」只有归位系统。

### 5.3 五个巧思（每个一句话解释功能）
