# 《返潮》Demo 资产精度与恐怖谷规范

> 状态：**现行生产规格**（P1 垂直切片）。服从 [docs/game-design/](README.md) 宪法；与交接包冲突时以宪法 + 本规格为准。
> 本文回答：什么叫「达到 SIREN / 优秀 PS3 后期 / Switch 级」；每件资产做到多细、怎么验收；恐怖谷从哪里来、明确不从哪里来。
> 上游口径：[02 §5 PS3 级画质的可量化定义](02_视觉原型设定.md#5-ps3-级画质的可量化定义)、[06 §6 性能与资产预算](06_技术栈与制作工作流.md#6-性能与资产预算ps3-级的工程口径)。本文只细化，不推翻。
> 提醒：本文是给下一步制作用的规格。**文档写完不等于美术完成**；「已完成」只认可运行、截图/录像、日志三种证据。

## 1. 精度基准：三个参照系合成一个口径

| 参照系 | 取什么 | 量化含义 |
| --- | --- | --- |
| **SIREN**（PS2，2003） | 照片可信度的来源：低模 + 真人照片投射贴图；恐怖谷的原产地——脸是真的，动起来却不对 | 人物贴图必须来自真实照片；表情系统是贴图切换而非骨骼微表情 |
| **优秀 PS3 后期**（《死魂曲：新翻译》2008 等） | 构图、材质、灯光的导演力下限；烘焙 GI 的空间灰度 | 任何实机画面与其截图并排不因「素材感」出戏（[02 §5](02_视觉原型设定.md#5-ps3-级画质的可量化定义) 验收基准片） |
| **Switch 级** | 同一预算纪律在现代硬件上的执行口径：中低模 + 高质量贴图 + 烘焙光照，1080p/30 稳定、720p 兜底 | [06 §6](06_技术栈与制作工作流.md#6-性能与资产预算ps3-级的工程口径) 的全部预算数字即此口径 |

核心命题重申：**精度是导演能力，不是面数**。三个参照系的共同点是把预算花在「哪一帧被看见、被看见什么」上。本文所有数值都是制作预算与验收参数，不是叙事设定（伪精确物理数值的禁令不适用于生产口径，适用于剧情文本）。

## 2. 面数与 LOD

### 2.1 预算（继承 06，细化 LOD 链）

| 资产层级 | LOD0（近景/交互距离） | LOD1（≈8m 起） | LOD2（≈20m 起） | 剪影代理（雾中远景） |
| --- | --- | --- | --- | --- |
| 英雄资产 | ≤5 万三角形 | 50% | 25% | 不需要（英雄资产不进雾距） |
| 量产资产（桌椅/管线/货架） | ≤8 千三角形 | 50% | 25% | 面片/合并网格 |
| 角色（NPC/P01） | ≤4 万三角形 | 50% | 25% | 深色低模（≤2 千） |
| M01 / P01 | ≤6 万三角形（上浮 50% 额度） | 50% | 25% | M01 剪影代理是**独立资产**（见 §5.2） |

- 单场景（含同屏全部 LOD0）≤150 万三角形，A 宴会厅闭环为基准场景；
- LOD 切换距离在固定/受限机位下逐机位校准——机位清单（[07 §5.2](07_Demo垂直切片_玩法与叙事框架.md#52-机位清单固定受限机位构图证据的保险)）内可见的资产禁止在画面内发生可察觉的 LOD 跳变。

### 2.2 轮廓优先建模

顺序强制：**剪影 → 比例 → 大面 → 细节**。每件资产在灰模阶段先过一次 720p 灰度轮廓检查（§5），轮廓读不出功能与受力关系的资产不准进入细化。细节面数申请制：LOD0 超预算需要书面理由（哪一帧、哪个机位需要它），否则一律用法线与粗糙度承担。

## 3. 贴图与材质

### 3.1 分辨率与密度

| 用途 | 分辨率 | 贴图密度（起点值） |
| --- | --- | --- |
| 英雄资产 / 角色 | 2K（M01 允许身体+甲壳各一张 2K） | ≥512 px/m（玩家会贴到 0.5m 内看的面） |
| 量产资产 | 1K | ≥256 px/m |
| 远景 / 结构面 | 512 | ≥128 px/m |

通道：BaseColor / Normal / Roughness（AO 烘焙进光照图）。**禁止 4K 贴图**；禁止金属度滥用（本作金属只有不锈钢包边、锈铁、继电器触点等少数真金属）。法线来源必须是照片/扫描或结构性建模烘焙，**禁止雕刻噪声冒充细节**。

### 3.2 五大主材质规格

每种主材质做一份「正常态 + 承压态」母材质，场景实例化调参。承压态遵守 [02 §3.1](02_视觉原型设定.md#31-六条视觉执行规则)：材料保留本质，服役历史而非一次破坏。

| 材质 | 采集来源（第一资产来源=实拍/扫描） | 正常态要点 | 承压态变化（可做的） | 禁止 |
| --- | --- | --- | --- | --- |
| 水泥 | 旧楼梯间、后场地面实拍 | 灰度层次、拖把痕、修补色差 | 压白带（受力高度连续）、细裂网、粉化 | 溶洞化、湿渍 |
| 红绒（椅套/台面呢） | 婚宴椅套实物扫描 | 绒毛方向性高光、坐痕 | 纤维压实到反光变哑、压痕如烫过 | 霉变成图案、变黑成血色 |
| 旧蓝工服 | 真实工装做旧后平铺扫描 | 洗褪色阶、领口油光、补丁 | 受力点（左肩）永久褶皱、盐霜析出（白色粉环） | 破洞卖惨、海藻附着 |
| 贝灰（粉化带/归面材料） | 贝壳灰浆、石灰墙皮实拍 | 微孔、抹痕 | 层状剥落、压实成板、与漆面的分界线 | 长成珊瑚礁装饰 |
| 黑绿色霉层 | 密闭仓库霉斑实拍（灰度重调色） | —— | 沿受力高度的分布、干燥触感（哑光、粉状边缘） | 湿亮高光、长成触手/器官、独立生态 |

### 3.3 材质纪律

- 同一受力高度的承压证据必须跨材质连续（胶条、木框、漆面、织物同高作证）；
- 每个场景一张「材质高度表」：标注深度界面经过的高度区间，所有承压态实例按表调参——这是把「深度是证据」落到管线的方式；
- 霉层与贝灰的覆盖率有预算：单帧内 ≤15% 画面面积，超过即在「宣布」而非「作证」。

## 5. 720p 轮廓双读验收

### 5.1 双读定义

任何关键资产/关键帧缩到 720p 并灰度化后：**第一读**——它是什么、原本的日常功能是什么（一个具体的人/一件具体的设备）；**第二读**——哪里不对（受力、时间、方向的错误）。两读都成立才通过；只剩第二读=「怪物感先行」，退回。

### 5.2 M01 威胁门四测试（执行细则）

| 测试 | 做法 | 通过标准 |
| --- | --- | --- |
| 预测回返 | 给测试者看 10 秒履职态移动，遮屏，问「它接下来去哪」 | 能按旧后勤路线说出下一站 |
| 三视人物重心 | 正/侧/背三视静帧 | 三视都读出「左肩低、右脚拖」的劳动者重心，不读出「怪物站姿」 |
| 路线因果 | 演示一次改承压后的路线改道 | 测试者能复述「因为门变了所以它从那边来」 |
| 720p 轮廓双读 | 背影帧与侧面帧各一张，720p 灰度 | 背影帧只读出人；侧面帧读出「正面不对」但说不全是什么 |

### 5.3 环境资产轮廓验收

承压门框（H3）在 720p 灰度下仍必须读出变形方向与力的走向；玻璃对照位（B7）在 720p 下缸内外两种状态仍可分辨。验收帧存档入库（`docs/notes/` 盲测记录）。

## 6. 禁止用面数冒充质感

1. 任何资产未过 720p 轮廓读法，处理方式是**重做设计（轮廓/比例/姿态）**，不是细分加面；
2. 使用痕迹（磨损、油光、坐痕、磕碰）优先用粗糙度与 BaseColor 承担，其次法线，最后才是几何；
3. 禁止为「显得精致」添加与 2001 年小镇不符的装饰细节——时代正确性优先于细节密度；
4. 预算超支的处理顺序（继承 06）：先砍面数与贴图分辨率，再砍动态光，**永远不砍声音**。

## 7. 照片投射人物流程（SIREN 方法，本作执行版）

### 7.1 采集规范

- 真人模特（含授权书面记录），2001 年造型：旧蓝工装做旧、当年发型、劳动者的手；
- 机位：正/背/左右侧/左右 45°/俯 30°，各拍中性表情一组；另拍两种「特定表情」（见 7.2）；
- 光照：阴天平光或柔光箱，**禁止戏剧光**——光影由引擎烘焙负责，照片只提供反照率；
- 同批采集手部（持工具、扶车、指尖特写）与后颈、耳廓——恐怖谷的主战场是这些「平时没人看」的部位。

### 7.2 制作与表情系统

```
照片采集 → 低模（轮廓优先，§2.2） → UV → 照片投射烘焙
  → 手修接缝（发际、耳后、领口） → 粗糙度手绘（T 区油光、唇部） 
  → 表情=贴图集切换（SIREN 式：中性 / 注视 / 一个不该出现的表情）
  → 目光=独立眼球小骨骼或 UV 偏移（只控制落点，不做眼皮微表情）
```

铁律：**禁止 AI 磨皮、美化、修脸**——照片的毛孔、色斑、疲惫是可信度的来源，抹掉它们就抹掉了 SIREN 质感的根。表情不做面部骨骼绑定与微表情动画；表情切换发生在玩家视线离开的帧或反光/远景中（切换本身不被直视，符合「姿态迟滞」的恐怖谷来源）。

### 7.3 M01 的双材质缝合（本资产最贵的部分）

- **背面**：真人照片投射，照片级可信——「父亲的背影」必须真到家人会认错的程度；旧蓝工装的左肩渔网压痕烘进法线；
- **正面**：从额头到腹部的石化复眼甲壳——材质来源是**实拍合成**（贝灰浆、珊瑚化石切面、压实沉积岩、水泥剥面的扫描拼合），不做生物光泽、不发光、干燥哑面；
- **缝合线**（领口、肩线、下颌线）是设计重点：缺口边界必须**清晰**——家人记得的部分与海补的部分之间没有渐变融合。缝合线像贝灰浆抹进衣领的收边，是「补全」的施工痕迹，本身就是叙事；
- 复眼「睁开」是贴图/反射事件（§9.2），不是几何形变。

## 8. 恐怖谷规范：错觉从哪里来

本作的恐怖谷**不来自怪脸**，来自五个便宜的错位。每一条都有验收问句。

| # | 来源 | 执行 | 验收问句（盲测） |
| --- | --- | --- | --- |
| 1 | **认错人** | 威胁与普通人共享服装库、身材库与动作库；M01 的第一读永远是「收场工人」；阿澄被家人当哥哥对待 | 「你第一次看到它时以为是谁？」——答案必须是一个正常身份 |
| 2 | **目光落点** | NPC 目光比对话对象偏移少许或停留过久；翻面后阿澄的目光落在玩家身后半米；M01 无目光，反光睁眼是全 Demo 唯一「被注视」事件 | 「他在看你吗？」——期待答案是「说不清」 |
| 3 | **表情/反应迟滞** | 对呼叫与事件的反应慢一拍（起点值 0.4–0.8 秒，盲测调参）；动作序列正确但衔接处有停顿——像在回忆怎么做这个动作 | 「他哪里不对劲？」——期待「反应慢半拍/像卡了一下」 |
| 4 | **衣料受力与姿态** | 永久褶皱烘进法线（渔网压肩）；重心偏移（左肩低、右脚拖）进 idle 与走路循环；布料在错误受力点起皱，不做布料模拟 | 720p 三视重心测试（§5.2） |
| 5 | **记忆缺口的海床补全** | 缺口边界清晰锐利（§7.3）；补全材料全部来自海床材料池（贝灰/矿化壳板/压实沉积/盐晶），每处形态对应一个具体记忆缺口，禁止随机海洋装饰 | 「它缺的是什么？是谁忘了？」——能猜到「没人记得他的正面」即成立 |

**明确不做**：高模微表情、面部动捕、Metahuman 级皮肤、跳脸构图、持续怪脸特写、音刺配合的惊吓剪辑。恐怖谷效果不足时的补救路径是**回到姿态、目光与迟滞调参**，永远不是加面数、加贴图、加怪物元素。

## 9. 灯光预算（Demo 各场景执行表）

### 9.1 烘焙为主，动态光每场景 ≤4 盏

| 场景 | 烘焙层 | 动态光名额（≤4） |
| --- | --- | --- |
| A 宴会厅（正常态） | 暖钨丝主光全烘焙 | 0 |
| A 宴会厅（断电后） | 低亮度天光补 | ① 应急灯（其中 1 盏带缓慢闪烁）②CRT 透过 C 门的溢光 |
| B/E 后场 | 荧光灯管烘焙 | ① 应急灯 |
| C 录像·广播室 | 弱环境烘焙 | ①CRT（主光源）② 卡座指示灯（近景点缀） |
| D 卸货口 | 门缝天光烘焙 | ① 手持工作灯（可选，玩家不携带光源则删） |
| 海洋馆走廊 | 走廊荧光烘焙（半熄） | ① 缸内照明（含焦散贴图动画）② 应急灯 |

不依赖 Lumen / Nanite / 硬件光追（[06 §1.2](06_技术栈与制作工作流.md#12-论证)）。

### 9.2 反光睁眼的实现口径

「全场反光同帧睁眼」用**材质与反射对象替换**实现（平面反射专用低模 / 反射贴图切换），不占动态光名额、不依赖实时全局反射。缸面、镜墙、CRT 熄屏各做一个反射替换位，由导演状态机统一触发——这是把 [03 §3.1](03_核心玩法.md#31-m01-无正面父亲行为合同) 条款 3 落进管线的方式。
