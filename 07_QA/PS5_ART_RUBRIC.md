## 逐项细则与证据

### 1. 开场 5 秒冲击（9 / PASS）

**标准**：打开游戏 5 秒内，玩家应看到「发行级动态标题」而非静态文字——多层动态元素、可读的世界观暗示、美术完成度不输独立发行标题屏。

**实测**：标题屏共 8 层动态元素——绸纹对角流动底纹、CRT 扫描线缓降、底部水面微光带（返潮暗示）、3 粒浮烬上飘、SVG 红绳曲线 + 穗结摆动、「囍」字脉动、金属渐变标题字、噪点颗粒层。5 秒内全部进入动画状态。

**证据**：`game/media/shots/01_title.jpg`、`game/media/art_title.png`

**扣分**：无 loading 进度演出（进入即玩，故不扣重）；-1 分因标题静置 30 秒后无 attract mode。

### 2. 牵红可读性（9 / PASS）

**标准**：玩家应在无 UI 箭头情况下，凭世界内信息读懂「哪里可摘 / 哪里可挂 / 侍应走哪条绳」。

**实测**（`game/test/r4_verify.mjs` 自动化断言，全绿）：
- 对准绳端：准星变「摘」态 + 目标绳结呼吸放大 1.35–1.49 倍 + 键帽提示「E 摘下红绳（拦门绳）」；
- 持绳时：可挂礼钩呼吸发光，准星变「挂」态；
- 滞回吸附：锁定后视线偏 19.5° 目标不丢（断言 `sticky.afterDeviation` 保持锁定）；
- 黑暗节拍中绳网自发光（emissiveIntensity>2 断言），侍应动线 100% 可追踪。

**证据**：`game/media/art_grab_aim.png`（绳结放大+键帽提示）、`game/media/art_threat_edge.png`（屏缘威胁红纱）、`game/media/shots/05_cord_held.jpg`、`game/media/shots/06a_shock_corridor_blackout.jpg`（全黑中的自发光绳网）

### 3. 材质/光影/后期（8.5 / PASS）

**标准**：材质有法线/粗糙度层次，光影有电影意图（不是均匀照亮），后期是完整电影管线。

**实测**：
- 材质：水磨石/瓷砖/海水 1024 分辨率 + 独立粗糙度贴图；桌布涤纶褶皱法线、金箔箔皱、丝绒各向异性暗纹、湿痕反光斑；
- 光影：区域电影曝光（宴会厅 1.32 过亮日常 vs 员工连廊 0.95 过暗通道）、体积光锥×吊灯/射灯/灯泡、贴地流动雾×6、海洋馆双层滚动焦散；
- 后期：ACES filmic + 双尺度泛光 + 胶片 halation 红晕 + 锐化 + 双层颗粒（静颗粒+走纹）+ 呼吸暗角 + 软边 letterbox + 冲击色差 + 静默低压失血层。

**证据**：`game/media/shots/03_hall_maintable_announce.jpg`（红金过曝喜宴）、`game/media/shots/08_lobby_after_ignition.jpg`（点火后大堂）、`game/media/shots/10_aquarium_corridor.jpg`（焦散玻璃廊）

**扣分**：-1.5 分诚实边界——程序化纹理在 1 米内特写时颗粒感弱于扫描资产（见 RELEASE_NOTES 诚实表）。

### 4. 实体细节（8.5 / PASS）

**标准**：四主要实体在 3 米距离可读出「哪里不对」，特写不穿帮。

**实测**：
- 司仪：金缘翻领/口袋巾/袖扣/胸花；下颌胡茬点阵、太阳穴汗珠沟、供灯烤红的耳缘；广播时口部钙化颗粒蠕动（声不由口出）、周期性正式鞠躬、身体缓慢追踪玩家朝向；
- 侍应：白手套/黑领结/跳号胸牌（04、07、13——不连号）；闭目睑线加粗 3 米可读、礼貌到不自然的浅笑双涡、左眼下干涸水线、颈侧盐渍白霜；警戒时托盘瓷器细颤（配 porcelainRattle 音）、追逐时前扑而托盘恒水平；
- 回眸客：长发水流感摆动、双重曝光错位呼吸、暗色底影保证亮背景可读、被直视时消隐（软化曲线）、断绳残端细颤；
- 新娘：凤冠珠旒近距细颤、盖头随玩家接近缓转、腕上红绳、绣金囍盖头双道金线+垂穗。

**证据**：`game/media/art_mc.png`（舞台特写：眼/口部钙化/金缘翻领/胸花）、`game/media/art_waiter.png`（正面特写：闭目浅笑/白手套/领结）、`game/media/art_waiter_scene.png`（前景侍应+背景聚光司仪）、`game/media/art_bride.png`（凤冠珠旒/盖头）、`game/media/art_gazer.png`

**本轮修洞**：Round 6 发现并修复了一个隐藏美术 bug——全部人形的五官贴图自装配起朝向身后
（球体贴图中心在 +X，`rotation.y=π/2` 误将其转到 -Z），后脑发包也错盖左脸。
修复后司仪的眼睛、侍应的闭目浅笑首次真正面向镜头（上列特写即修复后实拍）。

**扣分**：-1.5 分诚实边界——无骨骼动画系统，表演靠程序化顶点/组变换，近距离肢体过渡有机械感。

### 5. 震惊节拍（9 / PASS）

**标准**：三个以上打断预期的高光遭遇，全部无穿帮、有声画配合。

**实测**（冒烟测试逐拍断言）：
1. 走廊灭灯横穿（拍 2）：灯管由远及近熄灭、全黑中红绳网自发光、侍应贴身滑过——断言 `_shock1` + emissive>2；
2. 暗影撞玻璃（拍 4）：boom 巨响 + 裂纹 + 应急绿光——断言 `_shock2`；
3. 灯泡爆裂（拍 4.5）：bulbPop + 回眸客前移一步——断言 `_shock3`；
4. 终局收网（拍 5）：正门轰闭、彩带坠落、满厅红光、letterbox 收窄。

**证据**：`game/media/shots/06a_shock_corridor_blackout.jpg`、`10a_shock_glass_slam.jpg`、`12a_shock_bulb_burst.jpg`、`13_finale_throat_hall.jpg`

### 6. 交互无坏档（10 / PASS）

**标准**：核心链路（摘/挂/寄挂/改道/闸门二择/剪缆/双结局）自动化全绿，无 JS 错误。

**实测**：`game/test/run.mjs` 六拍全流程 20+ 断言全绿、`pageerror` 计数 0；`r4_verify.mjs` 真实键路径（keydown E）摘→挂→滞回→威胁指示全绿；`call_verify.mjs` 点名寄挂（激活→腕绳亮→寄挂→段数递减）全绿；`r5_verify.mjs` 音频 API 全调用无异常。四脚本可复跑。

**证据**：`game/media/qa_smoke_summary.txt`（断言输出存档）

### 7. 音频气氛（8.5 / PASS）

**标准**：低频不安、延迟声画、静默前兆、近身立体声威胁，耳机向混音。

**实测**（`game/test/r5_verify.mjs` 验证节点图与自动化参数）：
- 低频不安：41Hz 双正弦 0.55Hz 差拍层，随议程 0.16→0.85 加深，收声期不收（静默是压着的）；
- 延迟声画：广播/电铃从「远厅」迟到抵达（闷化+偏侧+左右交替），延迟随同步律 1.7s→0.08s 收拢；
- 静默前兆：收声瞬间 7kHz 极弱耳鸣浮出——安静得耳朵自己响；
- 近身威胁：立体声威胁层（高频微光+低频脉动）+ 4.5m 内 0.32Hz 呼吸声像层 + 载客绳鸣邻近层；
- 耳机混音：母线 DynamicsCompressor 粘合 + 房间底噪左右失谐展宽 + 空间自适应混响（瓷砖短亮/大堂厚软/海洋馆长暗）。

**扣分**：-1.5 分诚实边界——全程序化合成，无采样级人声/器乐质感。

### 8. 林奇气质（9 / PASS）

**标准**：梦核不安、日常喜事下的错误熟悉感、过曝红金、空寂走廊、延迟声画、不解释的注视。逐条对照：

| 气质要素 | 落地 |
| --- | --- |
| 过亮的日常 | 宴会厅曝光 1.32 过曝红金 vs 服务区 0.95 过暗（区域电影曝光） |
| 延迟声画 | 广播先于司仪手势（同步律滞后）；远厅回声迟到；CRT 先播一步 |
| 不解释的注视 | 回眸客永远面向你；浮客每 18–30 秒随机一位瞬间换朝向（无动画） |
| 错误熟悉感 | 侍应笑得太标准（双涡浅笑）；胸牌不连号；停摆挂钟 23:58；永不开门的电梯到站铃 |
| 静默压迫 | 广播前全楼收声 + 耳鸣浮出 + 画面失血（uDread） |
| 空寂空间 | 员工连廊低吟、隔墙笑声戛然掐断、暗处水滴 |

**证据**：`game/media/shots/12_connector_gazer.jpg`（注视）、`09_call_active.jpg`（点名压迫）

### 9. 双结局演出（9 / PASS）

**标准**：剪缆→出门（好结局）与被引座到底（坏结局）两条路径演出完整、可稳定触发。

**实测**：冒烟测试断言剪缆成功（`__cut` 状态机）、好结局车灯白入+制作名单、坏结局桌牌 3D 翻转（伴娘→上宾）。两路径截图齐全。

**证据**：`game/media/shots/15_after_cut.jpg`、`16_exit_doors.jpg`、`17_good_end.jpg`

### 10. Release 可启动（10 / PASS）

**标准**：win64 exe 解压双击可玩；web 包双击 index.html 可玩。

**实测**：`game/test/verify_pkg.mjs` 用 Linux Electron 壳（与 win64 包同 app 内容、同 Chromium 内核）自动化启动 → 进拍 1 → 截图确认渲染出画面；web 包为单文件 bundle 零网络请求，`file://` 直开验证通过。

**证据**：`game/media/qa_pkg_electron_boot.png`

## 复跑方式

```bash
cd game
npx esbuild src/main.js --bundle --outfile=dist/bundle.js --minify
node test/run.mjs         # 六拍全流程冒烟（20+ 断言）
node test/r4_verify.mjs   # 交互手感（真实键路径）
node test/call_verify.mjs # 点名寄挂机制
node test/r5_verify.mjs   # 音频节点图与参数自动化
node test/verify_pkg.mjs /tmp/pkg/app  # 发布壳启动验证（先按 RELEASE_NOTES 打包）
```
