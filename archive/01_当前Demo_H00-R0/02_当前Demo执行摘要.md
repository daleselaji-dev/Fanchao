# 当前 Demo 执行摘要：H00-R0《婚宴后场：返席》

## 体验合同

玩家是婚宴后场的临时录像/服务工作人员，手里拿着一盒刚交回来的婚宴录像带。唯一任务是把录像带插回 C 房间卡座并按下 `REC/PAUSE` 完成归档。

## 空间闭环

`A 婚宴厅 → B 后场服务走廊 → C 录像/广播室 → E 洗涤/器材间 → B → A`，实体从 `D 卸货口` 出发并沿 `D → B → C 门外 → E → D` 回返。

玩家可在 B 选择较开阔的服务台路线或较短的低处器材线。低处不使用可见线条，区别来自家具占位、门槛、柜脚、受压痕迹和声音状态。

## 60--90 秒行为节拍

- 00--12：从 A 进入 B，先读懂正常婚宴收场和后场工作。
- 12--28：在 B 发现同一高度的低处材料后果，并听到实体沿旧路线工作。
- 28--43：在 C 插带并按 `REC/PAUSE`，看到普通婚宴录像，不解释怪物。
- 43--60：玩家选择返程路线；路线是信息与风险交换，不是正确/错误分支。
- 60--76：实体继续执行放盘、擦手、转身等普通工作；侧正面短暂显示石化海洋复眼前侧证据。
- 76--90：玩家回到 A，实体仍沿旧路线离开，留下未解释的工作声。

## 禁止项

实体不攻击、不冲刺、不因玩家靠近而跳脸；不使用碰撞推回、可见水线、蓝色滤镜、随机恐怖过场或把瓷砖腰线变形作为单一异常。
