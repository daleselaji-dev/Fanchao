# 制作工作流

## Gate 顺序

1. Canon：用户确认的世界、时代、恐怖句子、禁止项。
2. 空间：俯视地图、功能、连续路线和固定机位。
3. 行为：普通人动作、玩家交互、实体航点、让行和重置。
4. 时代底片：2001 年道具、材料、声音、光线和使用痕迹。
5. 异常因果：同一深度、旧伤或时间在多种材料和动作上成立。
6. 资产：形体候选、材质候选、贴图、动画和 UE 接入。
7. 运行验收：60--90 秒可玩、输入真实、证据可复核、失败可重置。

## 每轮交付物

- 设计合同：明确这轮只验证什么。
- 生成/审计记录：记录模型、提示词、审查结论和失败理由。
- 可运行证据：截图、日志、视频或独立工程启动记录。
- Gate 结论：PASS、CONDITIONAL、NOT RUN 或 FAIL。
- 下一轮输入：只允许通过项进入下一轮。
