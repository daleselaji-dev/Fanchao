# 《返潮》项目设定与 Demo 交接包

整理日期：2026-08-05

这份包把目前项目中已经讨论过的世界设定、美术原则、Demo 方案、实现路线和原始沟通材料集中保存。它分成两层：

1. `00_整理索引` 到 `05_实现参考`：便于继续工作的阅读版与可执行参考。
2. `99_原始文档档案`：从项目目录复制的原始 Markdown、评审记录、提示词记录和候选方向，保留原文件名与版本。

## 状态标签

- `共同确认 / 当前基线`：来自用户在沟通中明确认可、否定或要求保留的方向，并与当前工作流相容。
- `当前切片`：H00-R0《婚宴后场：返席》正在执行的 Demo 设计。
- `候选 / 待验证`：有价值的设想或视觉种子，但不能当作最终 canon 或正式资产。
- `历史 / 冻结`：曾经的路线、失败原型或旧工程，保留用于追溯，不继续叠加生产。
- `实现状态`：代码、引擎和测试现状；不等于世界设定已经成立。

## 阅读顺序

先看 `01_共同确认的核心设定.md`，再看 `02_当前Demo_H00-R0.md` 和 `03_美术规则与资产生产.md`。需要继续开发时阅读 `04_可能的实现路径与工作流.md`，最后按 `05_实现参考/文件清单.md` 回到实际项目文件。

## 重要边界

这不是把所有 Agent 草稿升级为 canon。包内明确保留了分歧、失败和未通过项；其中 H00 Unreal 运行时代码曾完成编译和状态机验证，但最后一次视觉 QA 在空地图启动画面上发现黑屏，修复后的可见画面尚待复验。
