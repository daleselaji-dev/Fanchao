# 网页 ChatGPT：M01 甲壳复眼贴图审计任务

请审计所附的两张灰模 QA 图（正面、背面）以及 `m01_father_compound_eye_proxy_spec.md`。这不是让你重新设计角色或生成泛恐怖概念图；任务是为既有候选灰模提出可实施的 PBR 贴图和材质方向。

## Canon 约束

- 《返潮》的恐怖来自“潮来了，水没有来”：绝对干燥、不可抵达深度、持续服务史、结构压力、声音早于视觉。
- 父亲的背面必须先是 2000/2001 年小镇基层服务人员；正面才显示分层甲壳结构与多点观察面。
- 甲壳不是昆虫、寄生物、触手、怪物皮肤或祭祀物件；它是与警报、深度、观察/回避有关的旧工业/建筑式结构。
- 禁止沙子泄漏、悬锤钥匙、胸前容器、血浆、VHS 滤镜、泛 90 年代动作海报感。

## 请输出

1. 先给出通过 / 不通过的审计结论，并指出灰模最可能滑向“昆虫怪物”或“人偶”的 3 个风险。
2. 对每个材质槽给出 PBR 方向：`WORK_JACKET`、`TROUSERS`、`SHOES`、`HAIR_BACK`、`EYE_CARAPACE`、`EYE_FACETS`、`EYE_INTERIOR`、`ENV_DRY_CONCRETE`。包括颜色逻辑、粗糙度变化、磨损位置和明确禁止项。
3. 给出一张 2048×2048 可平铺/可烘焙纹理的“材质参考板”生成 prompt；它应是材质板而非角色海报，不包含文字、人物正脸或镜头叙事。
4. 给出 5 条最终验收规则。若任一条失败，保持 CANDIDATE，不提升为 Canon。

输出中文，结构化、可直接交给 3D 美术执行。
