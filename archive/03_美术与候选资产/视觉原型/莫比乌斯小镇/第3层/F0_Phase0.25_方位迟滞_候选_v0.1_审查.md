# F0 Phase 0.25 方位迟滞：审查 v0.1

> 结论：有条件通过。它是 Phase 0.25 的当前唯一有效候选，可以作为下一阶段编辑源，但不是像素级锁定的最终生产资产。

## 通过项

- 第一眼仍是 Phase 0 的同一机位、同一街道与同一时刻；
- 广播塔、冷库烟囱、蓝色穹顶仍保持原有左—中—右顺序，没有提前完成翻面；
- 广播塔向右、烟囱向左的迟滞已经可通过 A/B 对照辨认；
- 前景道路、黄线、棚面、公交站杆、修理棚和人物密度大体保持稳定；
- 海天线保持水平，玩家不能把变化解释为相机倾斜。

## 条件与风险

- 广播塔的位移略强于目标，下一阶段不得继续沿同一方向等量移动；
- 蓝色穹顶的位移偏弱，Phase 0.5 需要通过海岸遮挡关系补足，而不是放大或重画穹顶；
- 生成式编辑并非逐像素仿射变换，屋顶、云层、人物与细小纹理可能有次要漂移；
- 进入引擎构建时必须用同一基础场景、地标 Transform 和锁定相机复现，不能以两张生成图之间的纹理差作为异常内容。

## 对下一阶段的硬约束

Phase 0.5 只允许增加“同一海面同时封住画面两端”的空间证据。相机、前景、人物、三个地标身份与当前地标顺序继续锁死。
