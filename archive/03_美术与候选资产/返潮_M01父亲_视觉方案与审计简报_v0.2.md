# 《返潮》M01 父亲：视觉方案与审计简报 v0.2

状态：**REVISE / 未获建模授权**  
来源：v0.1 方案 + Antigravity CLI / Gemini 3.1 Pro High 独立审计。  
本稿仅定义下一轮灰模，不生成贴图，不接入 UE，不提升 Canon。

## 1. 本轮被否决的内容

- 六边形复眼阵列：会被读成蜂巢/虫卵。
- 甲壳薄片逐个翻开：会被读成机械传感器盖板。
- 从眉弓到上腹的完全连续凹面：容易成为“被挖空的尸体”。
- “每孔看见不同深度/不同记忆”：无法由灰模与镜头验证，删除。

## 2. 一句话角色形象（修订）

**一个穿褪色蓝工装、背影仍像父亲的码头工人；他正面原本属于脸与胸的体积，被深海强行压成一块干涸的石化剖面，剖面里的不规则暗井只会在反射中同时对准你。**

第一眼必须是：**熟悉的塌肩工装削面人**。

## 3. 造型硬约束

### 背面：完整的人

- 2001 年沿海基层工人；蓝灰短工装、深工裤、旧黑鞋、短发。
- 左肩低、右脚拖半步是唯一私人线索。
- 背部、肩胛与衣褶完整自然。无挂件、钥匙、仪器、符号化道具。

### 侧面：被压扁的正面，而非掏空躯干

- 头、胸、上腹仍留一条可辨的人体剪影与内在受力支承；不允许成为整片无厚度的洞。
- 正面体积被压向身体中轴，形成不规则、沉重、干硬的剖断面；工装前襟沿这条断面绷紧、脆裂。
- 断面是海床压实层侵入人体缺口的结果：干泥、贝灰、盐霜和矿化层；无血、无湿、无黏液。

### 正面：石化观察井，而非复眼球

- 正面是一块向内沉的干涸石化剖面，参考海床沉积泥岩的天然溶蚀孔、古沉船石裂隙与压实层；**不使用六边形、网格、规则阵列、镜头圈或眼球球体。**
- 暗井为 7–9 个不等大小的自然孔洞，只有局部轮廓具甲壳分节感；不对应人脸的双眼位置，不排成对称面具。
- 孔内是无光干沉淀；正常正面永远处于暗部，禁止主光直射，也没有任何开合机构。

## 4. 唯一异常动作：反射聚焦

父亲沿警报回声**倒退引航**，始终把熟悉背影留给玩家。

当玩家为了确认路线，把视线穿过警报箱玻璃、抛光金属或一块尚未受压的水面反射时，暗井深处才出现极弱、干燥的矿物点反光；这些点以固定的相位差收束到玩家相机位置。它不是攻击动画、不是开眼、不是扫描：玩家主动使用反射确认路线，才意识到海的补全物早已在对准自己。

第一声警报：环境受压，反射中只出现一个错误点位。  
第二声警报：多个点位以固定相位锁向玩家，父亲改走另一条回声路线。  
第三声警报（不属于首日 Demo）：玩家明白反射既是测深工具也是暴露工具。

## 5. 三镜头灰模 Gate（先于贴图/GLB）

| 镜头 | 画面任务 | 通过条件 |
| --- | --- | --- |
| 1. 背面步态，0–2 秒 | 建立具体的人 | 去贴图、去雾后，盲测者 1.5 秒内说出“疲惫的中年码头/基层工人”，不能预判为怪物。 |
| 2. 侧面剪影，第 3 秒 | 建立正面被压没 | 盲测者说出“正面被深重东西压平/削掉”，不能说“面具、掏空尸体或虫头”。 |
| 3. 转角反射 | 建立被观察的惩罚 | 反射里读到不规则暗井的强制聚焦，但外轮廓不被读成昆虫复眼、科幻镜头组或残破人脸。 |

三镜头任一失败：退回本稿，不进入建模、贴图或 UE。
