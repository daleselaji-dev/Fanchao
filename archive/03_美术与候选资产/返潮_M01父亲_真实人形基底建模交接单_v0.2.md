# 返潮 M01「父亲」真实人形基底交接单 v0.2

状态：当前没有候选通过 Gate。所有临时方块人、UE Mannequin、CesiumMan 和外挂复眼板都不得进入 Demo。

## 目标

先让三视图读成 2001 年中国沿海普通工人/父亲，再在人体前轮廓内部压入“海洋生物石化复眼”的干燥负体积。背面必须先读普通工人：褪色蓝灰工装、左肩下沉、右脚落后半拖。正面不得出现正常脸、面具、胸甲、孕腹、伤口或寄生虫。

## 几何 Gate

1. Gate 01 背面：普通工人身份清楚；工装是连续人体外形的一部分，不是漂浮壳片。
2. Gate 02 侧面：前侧结构完全向人体内凹，不得越过原人体前轮廓；禁止外凸盾牌、薄片、圆盘和厚边。
3. Gate 03 正面：从眉弓、喉部、胸骨到上腹形成同一连续石化底床；7–9 个不规则浅晶面由底床直接刮削，禁止圆眼、孔洞、环、蜂窝、镜片和机甲面板。
4. 三个 Gate 必须在无材质 Clay 灰盒下通过，之后才允许 UV、PBR、贴图与 Unreal 导入。

## 交付格式

- `.blend` 原始文件 + `.glb` 静态网格交付；允许保留工作层，但导出层必须只有一个连续的父亲主体网格。
- 单位为厘米；站立高度 170–185 cm；原点在双脚中间地面；面朝 Unreal 的 `-Y`；无旋转、无负缩放。
- 网格可以是静态网格，因为当前 Demo 只需要演员平移/转身；若交付骨骼，仍必须额外导出同一姿态的静态 Gate 网格。
- 不做贴图依赖。Unreal 会从 `/Game/Mudflat/Art/M01_Father_Validated/M01_Father_Body` 加载通过 Gate 的主体。
