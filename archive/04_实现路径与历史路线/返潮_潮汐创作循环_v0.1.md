# 《返潮》潮汐创作循环 v0.1

> 目标：停止用线性文档流程“逐项完成设计”，改为持续制造、碰撞、淘汰和验证有生命的场景。每轮只留下一个能被人复述的瞬间，弱方案立即退潮。

## 1. 工作流不是管线，而是一口会呼吸的井

传统流程容易把创作切成世界观、角色、美术、玩法、技术五个部门，最后得到每项都正确、放在一起却没有生命的作品。

《返潮》改用一个循环。每轮从真实生活开始，在同一场景里同时逼出人物、异常、声音、行动和代价：

```text
涨潮：积累生活与欲望
→ 返流：让一个正常关系反向
→ 见证：让两个人或两种媒介看见不同事实
→ 翻面：把矛盾变成身体、声音和路线
→ 失去：让玩家的有效行动伤害某种善意
→ 退潮：删掉解释、装饰和弱版本
→ 留痕：只保存一个人物、一个不可能、一个选择后果
→ 下一轮
```

这七个动作不是项目阶段。一轮可以在半天到两天内跑完；任何地点、人物、怪物或主线想法都必须进入同一个循环接受淘汰。

## 2. 四张椅子

每个场景同时由四个位置审视。创作者可以在十分钟内轮流换座，不需要组建部门。

### 居民的椅子

他今天原本要做什么？异常出现后，他为什么仍觉得这是一件可以处理的生活问题？若他只会害怕、解释或发任务，场景没有共同体生命。

### 外来者的椅子

他凭什么认为自己更客观？哪个瞬间让他的职业常识仍然正确，却不再足以解释现实？若外来者只是摄像机，场景没有认知冲突。

### 摄像机的椅子

不用字幕，观众先看见什么正常关系，又在哪一秒准确发现哪里不可能？若需要读完设定才能看懂，场景没有视觉证据。

### 海的椅子

不把海当反派，而问：哪一个人类系统正在拒绝结束、拒绝空白或拒绝变化？它沿什么材料、声音或关系获得方向？若答案只是“长出海洋器官”，场景不属于《返潮》。

## 3. 一轮创作只用六张牌

每轮随机或有意选取一张生活牌，再补齐其余五张：

1. **生活牌**：登记、搬家、敬酒、换班、转诊、候车、修泵、打印、回电。
2. **人物牌**：一个可爱／可笑的节奏，一个私人愿望，一个错误的正常。
3. **反向牌**：退房变续住、送走变认领、记录变生产、地址变召回、服务变占据。
4. **见证牌**：真人与 CRT、两名角色、广播与现场、旧家与新家、玻璃两侧。
5. **身体牌**：受力、停顿、呼吸、视线、声音延迟、路线改变；只选一种主要证据。
6. **代价牌**：保住人却失去名字、打开路却确认关系、切断声音却失去导航、留下证据却固定身份。

六张牌必须落在同一个场景里。任何一张只能靠旁白说明，就换牌，不扩写解释。

## 4. 场景竞技场：四生一死

同一组牌必须快速产生四个彼此不同的场景种子，而不是爱上第一个点子。每个种子只写七行：

- 谁在做什么生活事务；
- 谁让人喜欢、好笑或不舒服；
- 哪个对应关系反了；
- 谁看见另一版本；
- 玩家第一次能做什么；
- 有效行动会失去什么；
- 结尾留下哪个声音或动作。

四个种子互相决斗，只看五项：

1. 陌生人能否复述一个人物；
2. 能否用一句话指出不可能；
3. 玩家行为是否改变人物或路线；
4. 去掉海雾、怪物和参考作品名后，是否仍是《返潮》；
5. 制作一个 30—90 秒原型是否能回答真正问题。

只让一个种子进入原型。其余三个不“以后再用”，只保留一句失败原因，避免死点子在后续文档中反复返潮。

## 5. 原型不是演示答案，而是制造反证

胜出的场景只做三层：

- **人层**：20—30 秒正常对话或动作，让测试者记住一个人；
- **裂层**：5—15 秒不可能关系，通过连续动作与声音自行证明；
- **选择层**：一次输入改变路线、身份或证据，并立即留下可见代价。

第一版允许临时演员、静态照片、占位配音、简单碰撞和剪辑欺骗。禁止先做正式怪物、完整关卡、全套 UI 和长篇文案。

测试不问“好不好看”，只让陌生测试者口述：

> 你记住了谁？哪里不可能？你做了什么？因此失去了什么？

四问有一问答不出，就找到对应层修订；不以增加细节作为默认补救。

## 6. 强度不是不断加码，而是四次改义

一场强戏至少让同一事物改变四次含义：

1. **生活用途**：它本来帮助人完成正常生活；
2. **古怪习惯**：人物对它的使用让人觉得亲切或好笑；
3. **生存规律**：玩家发现它能预测或改变危险；
4. **伦理代价**：玩家使用它时，才发现它同时在固定一个人。

例如电话不是先变成鬼电话。它先是前台工作工具，再表现员工过分认真的礼貌，随后成为判断房间位置的生存工具，最后让一次转接把某个人正式分配进错误家庭。

## 7. 活力保护规则

- 每三分钟高压前，至少有一个人物愿望或生活动作得到空间。
- 每个重要场景至少允许一种干燥幽默、尴尬或温柔，不写成段子。
- 危机后仍保留做饭、值班、搬运、护理、争论、交易和错误救助。
- NPC 必须主动改变世界：拿走物件、封路、播音、认领、救人或误伤，而非等待玩家触发。
- 同一异常至少存在两个真诚但不兼容的解释，不设唯一“正确居民”。
- 梦逻辑必须留下碰撞、声场、路线、身份或资源后果。
- 怪物出现前，场景已经能让人不安；怪物离开后，人物关系仍在继续。

## 8. 退潮纪律

以下情况立即砍掉，不继续润色：

- 最好看的部分可以无损搬到另一部恐怖游戏；
- 人物全部拿掉后，场景仍几乎不变；
- 只有创作者知道“这象征什么”；
- 玩家只是观看，没有误判、学习与改变；
- 解决方式只影响机关，不影响人、路线、证据或身份；
- 参考味道来自红水、红幕、倒放、雾、爵士、低清或怪腔怪调；
- 失败后第一反应是增加怪物、污渍、残骸和解释。

## 9. 项目记忆只保存三样东西

每轮结束只写：

- **存活片段**：一个可复述的场景与当前原型位置；
- **死亡原因**：三个被淘汰方案各一句，不保存完整设定；
- **下一口气**：下一轮唯一要验证的表演、动作、声音或选择问题。

长设定仍归原有世界文档；创作循环不再产生新的百科、怪物表和检查清单。

## 10. 第一轮入口

从 H00-A 开始，因为它已经证明普通人物、千禧酒店工作密度与现实材质。第一轮不验证酒店是否必须成为正式开场，只验证：

> **当一个本地前台员工把不可能当作仍需礼貌处理的住宿问题时，人物温度、共同体经验和空间恐怖能否同时成立？**

本轮存活场景见 `返潮_H00活体场景_续住名单_v0.1.md`。
