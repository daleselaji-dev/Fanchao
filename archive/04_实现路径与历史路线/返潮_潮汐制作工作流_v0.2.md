# 《返潮》潮汐制作工作流 v0.2

> **状态：停止作为当前阶段的上位工作流。** 本稿把“误判—操作—代价”提前成了统一生成器，导致设计反复回到门、钥匙、登记和错误分配等局部机关。当前阶段改由 `返潮_莫比乌斯小镇_构建总线_v0.1.md` 控制；本稿只保留为可玩段落阶段的历史参考，不能再决定美术、空间与世界设定。

> 这不是项目管理表，而是一套会把“有味道但没游戏性”的点子逼到可玩、可复述、可删除的制作循环。
> 当前应用对象：`prototypes/h00_siren_ps3/`，目标是把《返潮》推向《死魂曲》的 cult 压力与 PS3 时代的可信材质，而不是做一层怀旧滤镜。

## 0. 北极星：每一轮都要留下一个玩家会带走的画面

玩家结束一段后，应该能用一句话说出：

> “我刚才为了让一个正常系统继续工作，亲手把一个人/一条关系/一条路线分配到了错误的位置。”

如果玩家只能复述“这里很潮”“有个怪物”“画面很像某部作品”，本轮不通过。cult 感不来自符号堆叠，而来自一个小镇系统认真履职到荒谬的程度。

## 1. 四条制作轨道

所有场景、角色、异常和资产都同时经过四条轨道。轨道不是部门，可以由一个人连续切换。

### 生活轨

- 先写人物当下要完成的具体事务：值班、收礼、搬运、维修、等车、接听、核对。
- 给人物一个会让人喜欢、发笑或心软的节奏；不要先给“受害者”标签。
- 让人物在危机中继续做这件事务。越认真，越恐怖。

### 证据轨

- 只选择一个主要失效的判断：距离、声源、时间顺序、归属、身体连续性或出口。
- 先摆出正常基准，再让一个物件成为第一处不可能。
- 后续视觉、声音、NPC 姿态和路线只证明同一个矛盾，不同时发明第二套谜语。

### 误判轨

- 玩家第一次必须有一个合理但错误的解释，例如串线、延迟、设备故障、婚宴恶作剧。
- 玩家通过观察和移动学到局部规律，而不是读提示得到答案。
- 规律必须有边界：它能救玩家一次，但不能成为万能解。

### 代价轨

- 玩家有效行动立即改变至少一项：人物称呼、登记身份、空间路线、可见证据或一段声音。
- 代价不是结算画面里的“选择结果”，而是同一场景里马上能看见、听见或走到的后果。
- 任何解决方式只影响机关、不影响人或路线，都视为未完成。

## 2. 一轮制作：六步，半天到两天

### 1）涨潮：把地方写活

用六张牌开局，不写世界百科：

1. 生活牌：登记 / 婚宴 / 换班 / 送行 / 借电话 / 修门。
2. 人物牌：愿望、习惯、可爱或可笑之处。
3. 反向牌：结束变续住、送走变认领、记录变生产、地址变召回。
4. 见证牌：真人 / CRT、现场 / 广播、镜前 / 镜后、两名居民。
5. 身体牌：停顿、侧听、呼吸、受力、动作迟滞、视线偏移。
6. 代价牌：保住路线却失去称呼、保住名字却失去证据、切断声音却失去导航。

### 2）四生一死：同一组牌做四个种子

每个种子只写七行：谁在做什么、为什么让人记住、哪个关系反了、谁看到另一版本、玩家第一次做什么、行动失去什么、结尾留下什么声音或动作。

只留一个。其余三个写死因，不保留完整设定，避免死点子在后续文档里反复返潮。

### 3）灰盒：先证明因果，不做气氛

只做 30–90 秒可走片段：

- 一个现实人物或人物替身；
- 一个正常物件；
- 一个可观察的异常变化；
- 一次真实输入；
- 一条会被改变的路线或关系。

禁止先做正式怪物、长对白、完整 UI、海雾滤镜和解释性档案。

### 4）表演：让异常经过身体

给人物只做三组动作：正常工作、察觉异常、继续履职但身体已经不对。

威胁也只做三态：巡查、侧听、面对玩家。姿态先于速度，停顿先于追逐；玩家必须能从身体方向判断“它现在相信什么”。

### 5）翻面：把玩家的正确操作变成伦理问题

玩家操作不能只打开门。它要让某个系统重新分配对象：总机接错人、钥匙认错房、镜子保留错位、广播叫回已离开者。

翻面后不解释真相，只让场景继续生活：员工照常接下一通电话，亲属照常递喜糖，宴会照常少一拍。

### 6）退潮：删掉所有不能被复述的东西

测试者离开后只问四句：

1. 你记住了谁？
2. 哪个关系不可能？
3. 你做了什么改变它？
4. 因此失去了什么？

有一问答不出，就只修对应的一层，不增加装饰和解释。

## 3. PS3 质感门：可信不是高清，而是受控的证据密度

### 必须成立

- 普通材质先可信：湿木、黄铜、贴膜、CRT 玻璃、旧漆、塑料、婚宴桌布必须有使用痕迹。
- 关键异常有前后基准；不能靠一张静态图让玩家猜原来是什么。
- 低模角色的姿态、衣物重心和停顿要能读懂；细节不足时优先修轮廓和动作。
- 机位、雾、噪点和色偏只服务于空间证据，不用统一滤镜替代光照和材质。
- 过门只保留会话状态，卸载旧区；黑场换区是分区流送，不是菜单分支。

### 一律退回

- “看起来像 PS3”只靠低分辨率、色带、胶片噪点或 VHS 叠层。
- 怪物特写先于人物欲望和异常规律。
- 远景有漂亮氛围，但玩家无法知道自己为什么能走到下一处。
- 任何只在特定截图角度成立、自由移动就失效的恐怖证据。

## 4. 当前主线的工作卡：H00「续住名单」

### 本轮只验证一件事

当一个本地前台员工把不可能当作仍需礼貌处理的住宿问题时，人物温度、共同体经验和空间恐怖能否同时成立？

### 已成立

- 婚宴厅作为第一主猎场，真实移动到扩声台后触发公共断裂。
- 前台红电话、按住 `Q` 借视、214 跨重力钥匙、物理插孔和总机改道已经走通。
- H00 / W01 / 返程墙门后分区流送，连续路线状态已通过测试。

### 本轮不再扩张

- 不增加新地点、新怪物、新分支或完整 RPG。
- 不再用占位低模承担“玩家应该记住谁”的任务。

### 本轮交付

1. 玩家与婚宴来客各有走、停、侧听三组可读姿态。
2. 214 钥匙在借视时显示两套重力，在玩家身体回归后可被亲手拉出。
3. 威胁行为由姿态和听觉先提示，追逐只作为错误判断后的结果。
4. 一条 20 秒无字幕回放，让陌生测试者说出“谁在看谁、钥匙为什么不能直接拿”。

## 5. 每轮的唯一记录

每轮结束只更新三段：

- **存活片段**：一句可复述场景 + 原型路径 + 截图或视频证据。
- **死亡原因**：三个淘汰种子各一句。
- **下一口气**：下一轮唯一要验证的动作、声音、表演或选择。

长设定、材质规格和技术说明仍放回各自文档；本工作流不再制造新的百科。

## 6. 通过标准

一轮只有在以下条件同时成立时才算活着：

- 真实输入能改变玩家位置与结果；
- 视觉、声音、身体和路线共同证明同一个不可能；
- 玩家第一次误判是合理的；
- 玩家学到的规律能帮助一次但有边界；
- 有效行动留下立即可见的关系或路线代价；
- 陌生测试者能复述人物、不可能、行动和损失；
- 运行时无控制台错误，且至少有一台目标机器能稳定完成整段。

否则回到对应轨道，不靠加怪物、加雾、加解释补救。
