# 《返潮》原型设计总纲与制作顺序 v0.1

> 文档性质：项目控制台。它不直接规定怪物长什么样，而是规定在进入怪物设计和 Demo 制作前，哪些基础原型必须完成、哪些决定已经成立、哪些旧方向不得继续回流。
>
> 当前阶段：暂停怪物设计与怪物视觉生成，先完成整体原型。

## 一、正确的制作顺序

《返潮》接下来的顺序调整为：

1. 世界与历史原型；
2. 核心命题、叙事空洞与故事结构原型；
3. 小镇空间和关键场所原型；
4. 外来角色、多角色／RPG 结构与人物关系原型；
5. 核心交互、探索、资源、冲突和选择原型；
6. 不依赖怪物的恐怖体验原型；
7. 声音、媒介与千禧年代感原型；
8. 美术方向探索与视觉风格圣经；
9. 技术路线和一周 Demo 垂直切片；
10. 怪物谱系、具体怪物和怪物视觉原型。

怪物必须是前九项自然推导出的结果，不能再被当作独立的概念艺术练习。

## 二、当前决策边界

### 已确认，后续设计必须尊重

- 故事发生在千禧年前后的中国海边小镇，以真实生活经验增加代入感，而不是只使用复古滤镜。
- 第一接触角色是外来者。地方社会对异常的适应与外来者的不理解共同制造恐怖。
- 主角自身的家庭恐怖不在开场说明，而随进程逐步揭开，并与小镇问题互相照见。
- “返潮”具有多重含义：自然和建筑现象、被压回去之物的返回、习俗在传承中的变形、家属不愿完全忘记逝者，以及旧关系重新占据现在。
- 传统不是邪教机关。它来自长期生活和告别需要，也会在温柔、合理的传承变化中逐渐改变方向。
- 蚀湾存在明确的危机前与危机后。外来者进入时城镇仍能正常生活，失败的送离／返潮相关仪式成为全镇危机的点火事件。
- 点火事件不是全部历史的唯一解释；长期改变的海岸设施、家庭记忆和传统语境决定了为什么一次局部失败能够扩散为全镇返潮。
- 危机后出现具有实体威胁和传播可能的异变者，但传播方式须在玩法与怪物原型阶段验证。
- 千禧蚀湾同时包含旧单位生活与新旅游、娱乐、消费和媒介空间，不能被缩减为一座老旧工业废墟。
- 核心叙事围绕一个不能被真相完全填满的空洞：活人是否有权用自己的记忆固定失踪者，以及完整解释是否本身也是一种占有。
- 恐怖来源可以并存：民俗、家庭、怀旧、海洋、恐怖谷、密集、身体与动作、声音、空间、身份和现实连续性，但它们不是每个设计都必须填写的清单。
- 可以存在 RPG 元素和不同可选角色。每个角色都能经历完整的恐怖体验，但掌握的故事侧面、装备、能力和选择不同。
- 所有文案必须回答它如何在游戏里被玩家看见、听见、触发、承受或利用。
- 参考作品应吸收其恐怖成立的层级和设计强度，不复制表面符号，也不能把所有作品压成同一个公式。

### 暂定，需要通过原型确认

- 角色数量、角色切换方式，以及是开局选择还是章节切换。
- 外来角色的具体职业。测量员只作为候选，不再为了保留测量玩法而强行成立。
- 点火仪式的最终名称、步骤、参与家庭、纪念对象及其准确作用。
- 旧蚀湾、新蚀湾、工业设施和住宅区之间的空间对应关系。
- 返潮危机的物理诱因、社会诱因与超自然因果如何闭合。
- 作品最终使用第一人称、第三人称、固定镜头或混合镜头。
- 真人照片贴图、低模写实、像素、预渲染和高保真 3D 各占多大比重。
- UE5、Three.js、其他引擎或混合管线的最终选择。

### 明确废弃，不再回收

- 人口普查员作为主角及“十八人”谜底。
- 默认使用摄像员身份，只因摄像机方便叙事。
- “合镇面”或一次新近事故解释整座小镇为何长期扭曲。
- 固定潮位阶段、固定返潮顺序和用统一机制解释全部异常。
- 把测量、标高、读数和规则校验做成主要玩法劳动。
- 用三秒、十秒等任意时间指标判断恐怖是否成立。
- 先规定统一怪物生成链，再把每个怪物填入同一格式。
- 把海洋填充、腐烂鱼鳃、盐、铜锈、孔洞等当作所有怪物的默认起点。
- “后脑通向夜海”的 NPC 原型。
- “家属黑白照片直接拼贴在一个人正面”的怪物原型及其两版视觉图。
- 提前给怪物批量起类似图鉴条目的短名称。

### 两份保留稿的地位

- `返潮_背景故事与叙事空洞_v0.4.md`：重要母本，但其中具体仪式、危机因果、测量员和潮路机制仍可重写。
- `返潮_隐喻与恐怖语法_v0.1.md`：历史阶段稿，不再作为怪物生成法规。“唯一生成链”“六条总规则”“审核表”均须重新审视。

## 三、必须完成的九组前置原型

### P1：世界与历史原型

要解决的问题：蚀湾为什么是一个真实生活过几十年的地方，而不是为恐怖桥段搭建的布景？

必须产出：

- 小镇从旧渔村、单位工业化到九十年代停产改制的历史线；
- 居民如何工作、住房、迁移、结婚、送别、保存照片和理解失踪；
- 传统在不同年代发生的具体微小变化；
- 2000 年危机为什么在此时显形，同时避免“一次错误仪式开启一切”；
- 地方内部至少三种互相冲突但都合理的解释。

完成标志：即使暂时删除所有超自然内容，蚀湾仍然像一座能够独立成立的小镇。

### P2：核心命题与叙事结构原型

要解决的问题：玩家经历的事件如何不断改变自己对“归来、记忆、家庭与真相”的理解？

必须产出：

- 创作者掌握的背景真相与永远不能确认的空洞；
- 开场、中段、后段三次故事地平线变化；
- 主角家庭线如何逐步进入，而非开局抢夺地方故事；
- 玩家最终面对的不是善恶按钮，而是互相冲突的不完整善；
- 多角色获得的信息如何互相补充，同时保留无法合并的矛盾。

完成标志：没有怪物设定，故事仍然存在持续推进的认知恐怖。

### P3：小镇与空间原型

要解决的问题：返潮如何发生在路线、建筑和尺度中，而不是靠随机传送与“里世界换皮”？

必须产出：

- 一张可理解的现实小镇基础图；
- 住宅、厂区、泵站、滩涂、旧村、学校／医院／市场等地点的社会功能；
- 三条能在危机中发生连续翻转的关键路线；
- 空间变化与历史、关系或感知之间的原因；
- 玩家如何在不可靠空间中形成暂时判断，又为何无法彻底征服它。

完成标志：选取一条路线即可写出完整的进入、迷失、理解和付出代价的体验。

### P4：角色与 RPG 结构原型

要解决的问题：不同角色为什么值得游玩，而不是换皮重复同一剧情？

必须产出：

- 可选角色的社会位置、私人缺口、初始误解和不可替代的信息来源；
- 每个角色不同的装备、处理问题方式和关系权限；
- 共通的探索、危险和恐怖体验；
- 不同选择如何改变信息、关系、路线与资源，而不是只改变结局字幕；
- 角色间是否见面、错过、留下痕迹或互相改变场景。

完成标志：删去一个角色后，故事或玩法会永久失去一个无法由其他角色补上的维度。

### P5：核心玩法与交互原型

要解决的问题：玩家在恐怖中具体做什么，而且这些动作是否强化主题？

必须产出：

- 探索、观察、隐蔽、冲突、资源、对话、物件和选择的基本循环；
- 装备的实际用途和角色差异；
- NPC 在危机前后如何生活，而不是只等待玩家触发任务；
- 玩家如何误判、学习和改变局面；
- 战斗存在到什么程度，以及暴力能解决什么、不能解决什么。

完成标志：可以用一个地点、一名 NPC 和一种危险写出不依赖说明文字的可玩段落。

### P6：非怪物恐怖原型

要解决的问题：在任何怪物出现前，《返潮》凭什么已经令人不安？

至少覆盖：

- 正常生活中的细小现实断裂；
- 家庭称呼、座位、旧物和习惯如何分配身份；
- 失踪照片、录像、电话、广播和寻呼信息如何变得不可信；
- 空间尺度、声音来源、因果顺序和人物身份如何分别失真；
- 地方居民为何能继续日常生活，外来者为何无法把它归为正常；
- 海洋、潮湿、密集或身体元素在需要时如何出现，而不是自动出现。

完成标志：至少形成三个完全没有怪物出场、却能直接做成游戏段落的恐怖场景。

### P7：声音与媒介原型

要解决的问题：玩家闭上眼睛时，《返潮》是否仍有自己的世界？

必须产出：

- 现实环境的声音底色；
- 不同建筑与材料的声学差异；
- 声源错位、声音年代错位和语言身份错位的方式；
- 录音带、电话、广播、电视、寻呼机等媒介的叙事功能；
- 静默、低频、生活噪声和人物动作声的使用边界；
- 一段不靠突然巨响成立的声音恐怖原型。

完成标志：声音不是画面的附属提示，而能独立改变玩家对人物、地点和时间的判断。

### P8：美术方向与视觉风格圣经

要解决的问题：所有视觉原型为什么一眼属于同一个作品？

在生成任何新的视觉图之前，必须先确定：

- 现实底材：实拍、照片贴图、低模、写实 3D、预渲染、像素或混合形式；
- 摄像机语言：镜头高度、焦段感、视角自由度、构图习惯和是否允许电影式切镜；
- 人物现实感：真人脸如何获得、贴图如何变形、身体比例与动作保留多少笨拙；
- 环境材料：墙面、地砖、塑料、布料、木材、金属和潮湿如何表现；
- 光线：自然光、荧光灯、路灯、电视光和黑暗区域的层级；
- 色彩：现实层的基准色、异常发生时允许改变什么、禁止用统一滤镜代替事件；
- 清晰度：低分辨率、噪点、压缩、扫描、录像拖影等媒介痕迹的来源；
- 超自然表现：哪些效果发生在材质、几何、动画、镜头、曝光或剪辑层；
- UI 与档案：字幕、地图、照片、录像和角色状态如何进入画面；
- 明确避免：通用“恐怖游戏滤镜”、无意义脏污、过度电影海报化和 AI 概念图式对称构图。

完成标志：先用同一套风格规则描述三个非怪物测试画面——白天镇区、夜间住宅、发生轻微异常的室内——确认它们属于同一世界，再允许生成怪物视觉。

### P9：技术路线与一周 Demo 原型

要解决的问题：哪条路线最能在一周内证明作品的独特性，而不是只证明引擎能运行？

必须比较：

- 像素／2D：生产速度、表演限制、实拍污染能力；
- Three.js／WebGL：发布便利、定制渲染、角色和动画成本；
- UE5：真人感、光照、动画、音频和空间能力，以及资产生产与学习成本；
- 其他可行混合方案：实拍素材、预渲染背景、照片贴图低模、局部高精模型。

最终必须产出：

- 明确引擎和资产管线；
- Demo 唯一地点与完整路线；
- 一个核心交互循环；
- 一个非怪物恐怖段落；
- 一个 NPC／关系反转段落；
- 怪物是否进入首周 Demo 的决定；
- 可删减项和绝不能删的招牌体验。

完成标志：所有内容可以在一周内被排进实际制作日程，并且最小版本仍能表达《返潮》的独特性。

## 四、视觉原型生成的前置规定

### 1. 先写视觉圣经，再写单图提示词

每一次视觉生成必须由两个区块组成：

1. **不可随单图漂移的风格母版**：媒介、摄像机、人物、材料、光线、色彩、清晰度与时代质感；
2. **本次场景变量**：地点、人物、动作、事件、异常和画面重点。

单图提示词无权临时发明新的全局画风。

### 2. 先生成世界，不先生成怪物

视觉测试顺序固定为：

1. 无异常的白天小镇；
2. 有人生活的普通住宅；
3. 工业设施或公共空间；
4. 只发生一种轻微异常的现实场景；
5. 人物近景与动作测试；
6. 上述风格稳定后，才进入超自然实体和怪物。

这里规定的是验证顺序，不规定每张图必须出现哪些主题元素。

### 3. 先做遭遇画面，再做图鉴画面

怪物阶段开始后，第一张图必须模拟玩家实际遭遇时的镜头，而不是白底设定图、正反面对照表或海报。遭遇成立后，才补充结构图、动作图和材质图。

### 4. 每张生成图只回答一个主要问题

例如：

- 这个现实底材是否可信？
- 真人照片贴图是否形成恐怖谷而不是廉价拼贴？
- 异常是否发生在空间而不是滤镜？
- 人物运动是否像真实表演被某种力量破坏？

如果一张图同时承担世界观、怪物、玩法、UI、高潮和宣传海报，它通常不会把任何一项做深。

## 五、下一步实际工作

按顺序先完成 P1 与 P2：对两份保留稿进行一次“不增加怪物”的重新整合，明确哪些历史、仪式和危机因果真正成立，并形成新的世界与叙事原型。完成后进入小镇空间图和角色结构。
