# H00-R0《婚宴后场：返席》Round 2 节拍与行为合同

日期：2026-08-04  
状态：Round 2 通过，准备制作无贴图纸盒灰盒  
目标：验证一件普通工作、一个异常关系、一条 NPC 旧工作路线和一次玩家路线判断。

## 1. 本轮锁定

### 玩家身份与普通任务

玩家是婚宴后场的临时录像/服务工作人员，手里拿着一盒刚交回来的婚宴录像带。任务只有一个：

> **把录像带插回 C 房间的卡座，按下 `REC/PAUSE`，完成归档。**

这个动作必须有真实对象、真实按钮、真实声音和可见结果。它不是收集任务，也不是打开剧情菜单。

### 唯一异常关系

同一个不可见高度在多个不同物体和同一条工作路线中留下后果：

- 墙面、门框、铁柜脚和卸货口边缘在相同高度以下发生干燥的短缩、挤压或密封件外挤；
- 玩家进入这个高度对应的低处时，宴会厅伴奏和控制室设备声变厚、变远，声音仍来自可辨认的现实声源；
- 实体沿旧后勤路线返回原工作位置，并在同一低处更容易完成动作。

不加入水声、蓝色滤镜、可见水线、瓷砖腰线变形、海洋装饰、数字化深度提示或伪造的物理数值。

### 实体行为

实体暂称“返席人”，仍是候选设计名：

```text
D 卸货口 → B 后场服务走廊 → C 控制室门前 → E 洗涤/器材间 → D 卸货口
```

它保持一个普通后勤工作人员的步速、肩线、持物和工作重心，不随机追踪玩家，不突然冲刺，不因玩家靠近而表演惊吓。

前 55 秒只读背影、工作服和持盘动作；在 E/B 交界处，玩家第一次可能看到一小段侧正面。石化海洋生物复眼甲壳只作为身体前侧的短暂证据，不在本轮解释名称、来源或完整生态。

## 2. 60–90 秒节拍

镜头采用受控第三人称与三组固定/半固定机位，不使用自由第一人称镜头，也不靠电影过场完成实体动作。

### 00–12 秒：公共现实成立

- 玩家从 A 宴会厅侧门进入 B，手持录像带。
- 画面先看见暖色宴会厅、红椅套、用过的席面、冷色服务门和后场不锈钢台面。
- 伴奏由 A 的真实音箱播放；玩家能判断声音来自宴会厅。
- 镜头 A/B 过渡只承担一个问题：这里正在收场，谁负责把东西归档？
- 实体已在 D，但不让玩家看见。

### 12–28 秒：空间规则第一次可推断

- 玩家在 B 选择两条同一走廊内的路线：
  - `浅处服务线`：沿较开阔的服务台侧通过，视野好但路稍长；
  - `低处器材线`：弯腰从器材凹位旁通过，距离短但进入异常高度对应的低处。
- 低处不显示线条。玩家只能从门框下部、铁柜脚、墙角压实碎屑和声音变化推断。
- 低处状态只改变声场与可见材料后果，不改变颜色，不添加雾。
- 实体从 D 沿旧路线向 B 移动，玩家只听见规律的工作鞋/金属盘声，不立即看见它。

### 28–43 秒：完成普通工作

- 玩家进入 C，把录像带插入卡座并按下 `REC/PAUSE`。
- 卡座机械声、CRT 扫描底噪和远处宴会伴奏各自有可定位声源。
- 录像屏幕只显示几秒普通婚宴画面：席面、灯、人物站位，不显示怪脸、不解释剧情。
- 当玩家处于低处器材线时，屏幕外的宴会伴奏变厚；回到浅处服务线，音色恢复。恢复不是 UI 提示。
- 实体沿 B 走廊经过 C 门外，玩家只看到背影或被门框切开的肩线；实体不转头。

### 43–60 秒：路线判断

- 玩家完成归档后必须返回 A，但可选择原路的浅处服务线，或从 B 的低处器材线近路返回。
- 选择浅处：看不到实体正面，只能听见它在 E 完成洗涤/放置动作；出口较安全但证据较少。
- 选择低处：更快到 E/B 交界，能看见门框与实体的动作处于同一异常高度；证据更强，但路线会被实体占用几秒。
- 这不是“正确/错误”分支，而是信息与风险的交换；两条路都可完成 Demo。

### 60–76 秒：第一次身体错误

- 实体从 E 走回 B，仍然执行普通的“放盘—擦手—转身”工作节奏。
- 若玩家在低处路线，固定机位把实体的侧正面切入画面一到两秒：看得出前侧是干燥石化结构，不能完整辨认其形态。
- 若玩家停在路线交叉点，实体不攻击；它按旧路线继续，玩家必须退到可避让位置或选择另一条线。
- 不使用物理碰撞把玩家弹回、不触发自动恐怖过场、不改变实体速度。

### 76–90 秒：返回公共空间

- 玩家推开 A 服务门回到宴会厅，手拉门把手归位。
- 宴会厅伴奏恢复原来的空间感；B 的低频/厚声被门隔开，但仍可听见一小段工作盘声。
- 门缝中实体继续沿 D 方向走远，仍是背影，不给结局解释。
- R 可随时把玩家、实体、声音和录像带状态重置到 00 秒。

## 4. 失败与重置

- 实体与玩家路线重合时，实体只占据路线，不攻击、不把玩家推飞；玩家退回最近的分叉或等待它完成动作。
- 若玩家在 20 秒内没有完成插带动作，保持世界状态不变，不自动播放恐怖事件；允许 R 重置。
- 若玩家越过 A/B 入口后卡在碰撞体，R 将所有状态恢复到 00 秒，并记录 `RESET_REASON=BLOCKED_ROUTE`。
- 只要路线、声音和材料证据中有一项无法复现，本轮灰盒不进入正式资产生产。

## 5. 三个被 Gemini 草案否决的点

### 伪精确物理数值

删除 30 米、65dB、120Hz、固定毫米/厘米等未经过工程测量和叙事需要的数字。实现时只定义可听的相对混音状态和可见的受力方向，避免把“深海后果”写成伪科学 UI。

### 异常沿瓷砖腰线

删除瓷砖腰线变形。异常高度必须穿过连续墙面、门框和独立家具，使玩家从不同材料的共同后果倒推出规律。

### 碰撞推回与冲刺惩罚

删除“超过某分贝就延长实体停留”“碰撞把玩家推回角落”。这些规则没有世界内因果。取而代之的是实体占据旧工作路线，玩家通过退让、等待或换线完成空间判断。
