## A 方案正式纸面地图

纸面虚线是设计师标记的“异常高度/声学关系”，不进入游戏画面。

```text
                         ┌──────────────────┐
                         │ A 宴会厅侧门      │
                         │ 玩家起点/公共底片 │
                         └────────┬─────────┘
                                  │ 服务门
                  ┌───────────────┴───────────────┐
                  │ B 后场服务走廊                 │
                  │ 正常路线 / 低处路线判断点      │
                  └───────┬────────────────┬──────┘
                          │                │
              ┌───────────┴───────┐  ┌─────┴─────────────┐
              │ C 录像/广播控制室  │  │ D 卸货口/侧门      │
              │ 身份记录与声音证据  │  │ 硬质受压证据       │
              └───────────┬───────┘  └─────┬─────────────┘
                          │                │
                          └──────┬─────────┘
                                 │
                         ┌───────┴────────┐
                         │ E 洗涤/器材间    │
                         │ 回返点/工作痕迹  │
                         └───────┬────────┘
                                 │ 回到 B
                                 └───────────────
```

### 空间连接规则

- 玩家从 A 进入，只能先通过 B；A 是公共现实底片，不能一开始就放怪物。
- B 是唯一的路线判断点：上半部是正常服务路径，下半部只通过门框、柜脚、墙角和声音变化被推断。
- C 是证据房，不是谜题房；录像/广播设备只证明“旧工作仍在继续”，不承担所有剧情解释。
- D 是实体旧工作路线的起点，也是玩家返回时最远处的轮廓读点。
- E 负责把路线闭环，但不能成为无意义的储物房；它必须留下 NPC 的真实工作痕迹。
- B→C→D→E→B 构成工作回路；A→B 是玩家的公共入口与回返出口。

### NPC 旧工作路线

```text
D 卸货口 → B 服务走廊 → C 录像/广播室 → E 洗涤/器材间 → D 卸货口
```

实体只在这条路线完成“回到原位”的行为，不沿玩家位置随机追踪。玩家改变的是是否进入这条路线以及何时与它产生交叉。

### 唯一异常关系

同一个不可见高度同时影响：

1. B 的门框/柜脚/墙角：干燥、沉重、沿受力方向短缩或挤压；
2. C 的声音：玩家进入低处后，宴会厅伴奏与设备声变厚、变远，但没有水声和滤镜；
3. D 的人物路线：实体在这个高度对应的空间中更容易完成旧工作动作。

第一版不再同时加入镜面递归、广播诱敌、多个怪物或可见水线。

## Round 1 Gate 结果

### 已通过

- A 方案有明确公共功能：婚宴收场后的录像、广播、卸货、清洗和登记工作。
- A 方案形成最小闭环，实体旧工作路线与玩家路线可以交叉但不重合。
- 异常可以由材料、声音和路线共同证明，不依靠怪物图或 UI。
- 现有 W01 婚宴厅、H00 CRT/电话/录像相关资产可以作为现实底片；不需要现在安装 3D 生成模型。

### 暂不通过/必须在 Round 2 解决

- C 录像/广播室的具体设备关系还没有定，必须避免“所有线索都塞进 CRT”。
- 玩家普通任务不能只是“把东西送到某房间”，需要一个会改变路线判断的具体动作。
- 实体的首次出现点必须在 D 或 B 的远端可见范围内成立，不能用跳出镜头补恐怖。
- 婚宴厅的镜面递归、镜中宾客等旧方案暂不启用，除非它们直接改变玩家路线；否则只保留为后续候选。
