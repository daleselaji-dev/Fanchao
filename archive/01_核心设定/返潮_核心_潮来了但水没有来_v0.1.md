# 《返潮》核心：潮来了，但水没有来

> 状态：核心候选，等待目标帧确认。它替代“每个地点各有一种怪事”的拼盘式设计。

## 一句话

**潮来了，但水没有来，水深来了。**

蚀湾没有被淹没。潮汐带来的不是海水，而是本应只存在于水下的深度：压力、沉积、无光处的声学、附着和漫长时间，开始按真实的海面高度穿过街道、房屋与人体所在的日常尺度。

## 这句话解决什么

它把“返潮”从一种潮湿风格或局部异象，变成一条可以穿过整个小镇的客观规律。

- 海面是看不见、绝对水平、缓慢移动的；
- 界面以上仍是陆地生活，界面以下没有水，却必须承担与该深度相称的物理后果；
- 同一件物品可以一半还在正常使用，另一半已经拥有几十年深处生活留下的材料历史；
- 最低处不一定在地板。深度将碎屑、声音和时间沉向它在建筑内部实际找到的位置。

这比“房子有海怪”更直接：玩家不需要先理解故事，只要看到一张桌子的桌面仍在吃饭、桌腿却已经在不见水的深处服役，就知道小镇正在发生什么。

## 允许出现的后果

每一处场景只能挑一个做主画面。

| 看到的事 | 它说明什么 |
| --- | --- |
| 墙、桌腿、窗框和管线在某一高度以下沿同一方向短缩、微弯、挤出密封条 | 那部分空间已经有水深，但没有水 |
| 票据、鱼鳞、纤维和铁屑在本不该低的墙面或桌脚处压成干燥层理 | 深处找到了新的最低点 |
| 同一房间跨过某个高度后，远近声和高频忽然变得不合材料逻辑 | 空气正在承担厚重介质的声学 |
| 阀门根部、反复受力的衣料和建筑接缝出现节制的过滤、附着或锚定结构 | 房屋被误用为可供栖居的残骸 |

不允许把这一整张表同时塞入一张图。恐惧来自一个事实被看得太清楚，而不是素材密度。

## 画面怎么写

先写一个能被看见的句子，不给现象、实体或流程起名字。

- 先写地点和正在进行的普通动作：例如“午饭还在出餐”。
- 再写一个不可能的事实：例如“同一高度以下的桌腿、铁皮柜门和整面墙，都像在无水的深处待了几十年”。
- 最后只写一项最先抵达玩家的感官变化：例如“弯腰后，餐具声忽然像隔着很厚的介质”。

不要用一串抽象词代替画面。画不出来、录不出来或无法放进关卡的一句话，一律先不保留。

## 第一张图的取景规则

食堂侧间必须让玩家一眼知道它仍在营业：一盏亮着的日光灯、一只刚放下的搪瓷碗、出餐窗口的暖光足够。画面中不要放怪物、尸体、符号、蓝雾或显眼的人为装饰。

看不见的高度要横穿一面没有腰线、没有瓷砖分色、没有窗台的完整墙面和铁皮柜门。它不能是一条线；玩家只能从同一高度以下同时出现的材料历史倒推出它存在。异常限于承重与密封位置：桌腿短缩并略向受力方向弯曲，柜门边缘变厚、胶条被挤出，墙角和踢脚线有被长期压住的干燥细屑。它们都必须服从真实的受力方向，不能软塌、融化或长成装饰性的海洋物。

这张图的审查问题只有一个：**不看说明，能否读成“这里是干的，但房间下半部已经在海深里待了很久”？** 不能，就淘汰。

## 人与实体

人不负责解释潮汐，也不优先承担恶心的异变。人的价值是保留正常尺度：有人照常递汤、打卡、开水龙头、修设备。

若之后必须出现实体，它的第一动作只能显示同一条规律如何把一段劳动误分类为深处的功能。例如，某个人的工作姿势被固定在一条移动的干燥层理里，或他的周边房间先替他承受深度，再把他从狭处挤出。完整外形、攻击和名称都必须等画面通过以后再讨论。

## 必须淘汰的读法

- “镇里有水下世界”或“门后通往海底”；
- “半个房间泡在水里”或“蓝色特效覆盖画面”；
- “有人被海洋主题感染”；
- “每一处都出现同样的触手、矿物、鱼、霉菌或器官”；
- “压力只是一记把道具压坏的事故”。

如果一个场景不能让人复述为“这里没有水，但这里已经有水深”，它就不属于《返潮》的核心。
