# 《返潮》生产美术圣经 v0.1

> 用途：把《返潮》的视觉方向转换为 Blender—Godot 可执行规格。适用于首周海洋馆垂直切片；不是全项目永久不可修改的技术法规。
>
> 状态：除标为“探索”的项目外，首周均按本版本执行。24 小时墙体技术门结束后允许升级到 v0.2。

## 1. 生产目标

首周画面不追求 UE5 式全实时高保真，而追求四项结果：

1. 普通电脑看到的构图、人物和材料仍然可信；
2. 高配主机把昂贵的环境光影与海雾离线完成；
3. 玩家直接操作的墙、门、玻璃、人物和物件保持实时；
4. 高低画质只改变精细度，不改变异常的因果证据。

首周视觉成功不以纹理数量、面数或特效数量判断，而以“危机前现实是否可信，异常过程是否不靠文字也能读懂”判断。

## 2. 画幅、分辨率与画面输出

### 主画面

- 画幅：16:9；
- 设计基准：1920×1080；
- 中画质内部渲染：1600×900 或等比例缩放；
- 低画质内部渲染：1280×720；
- 最低可用窗口：1280×720；
- 目标帧率：低配 30 FPS，中高配 60 FPS；
- 主游戏画面不加黑边、扫描线、镜头污渍或全局 VHS 滤镜。

### 世界内媒介

- 地方电视、监控、婚礼录像、VCD：4:3；
- 家庭照片与证件照保持各自真实比例；
- 媒介噪点、色偏、拖影和压缩只出现在有来源的画面中；
- UI 不模仿 CRT，避免把年代感等同于滤镜。

### 预渲染背景

- 工作母版：1920×1080 PNG；
- 游戏发布：根据静态细节测试 PNG、WebP 或高质量纹理压缩；
- 每个机位至少输出：基础背景、前景遮挡层、交互区域遮罩；
- 需要人物穿行时增加：接触阴影层或简化 Shadow Catcher；
- 深度图只在确实用于雾或遮挡时输出，不为“以后可能有用”批量增加资源。

接缝技术门修订：正式合成固定为“后景板—实时层—透明前景遮挡板”。单张完整背景板禁止直接承载全部实时对象，因为它无法恢复管道、门框、公告栏与人物之间的深度顺序。复杂穿行区才额外输出遮挡遮罩或简化实时遮挡网格。

## 3. 色彩管理

- Blender 离线制作使用 AgX 观察变换，曝光保持可回退；
- 导出到游戏的背景统一转换为 sRGB；
- Godot 中避免再次套用强烈电影曲线造成双重调色；
- 肤色、搪瓷白、墙面灰和塑料蓝作为跨软件校准样本；
- 危机前后尽量共享白平衡，让改变来自雾、湿度、光源和空间，而不是统一换 LUT；
- 黑位保留材料，不允许以纯黑隐藏未完成空间。

## 4. 摄像机套件

### A. 房间观察机位

- 主要焦段感：35–45mm 等效；
- 高度：1.45–1.70m；
- 机位必须同时容纳正常尺度参照与异常反应对象；
- 允许轻微轨道移动，不允许自由环绕破坏预渲染衔接；
- 一个房间通常 1–3 个机位，不为每个互动点新增镜头。

### B. 肩后探索机位

- 焦段感：45–55mm 等效；
- 只用于走廊、狭窄路线和需要人物受力的段落；
- 摄像机碰撞优先缩短距离，不穿墙；
- 不使用现代动作游戏的大幅相机摆动。

### C. 互动近景

- 焦段感：50–70mm 等效；
- 用于手压墙、贝壳落盆、玻璃固定件和人物吞咽等材料证据；
- 近景由玩家操作触发，结束后返回空间连续的原机位；
- 不用快速推镜和倾斜镜头替事件制造紧张。

### 切镜纪律

- 保持人物运动方向；
- 切镜后玩家角色必须可见或位置可立即判断；
- 同一异常至少在一个非唯一角度仍能成立；
- 不用切镜隐藏无法实现的主要因果，允许用它隐藏非核心资源切换。

## 5. 世界尺度与资产基准

- Blender 与 Godot 统一使用米制；
- 1 Godot unit = 1m；
- 普通角色基准身高：1.70m；
- 门洞基准：0.90m × 2.05m；
- 走廊净宽基准：1.40–1.80m；
- 售票大厅玻璃单跨宽度：1.2–1.8m；
- 所有场景先放置角色、门、椅子和巴士作为尺度参照，再开始装饰；
- 为恐怖效果改变尺度时，必须保留至少一个未变化参照物。

## 6. 场景的四层结构

### 远景预渲染层

承担建筑主体、复杂反射、大尺度雾、远处车辆与大量非互动陈设。它必须允许低配机直接显示，不依赖实时高级渲染。

### 简化空间层

承担地面、碰撞、路径、门洞、遮挡和人物脚下接触。几何保持简单，材质颜色与预渲染背景匹配。

### 实时事件层

承担墙、门框、玻璃、固定件、柜子、盆、纸张、近景雾和玩家可影响物件。首周的 GPU 与制作预算优先给这一层。

### 前景遮挡层

承担柱子、门框、栏杆、广告牌和近景家具，使人物能够进入画面深处。优先使用真实简化网格；只有完全静止且不会穿帮时才使用透明遮挡图。

固定机位下，完全静止的管道、公告栏、门框可由 Blender 输出透明前景板；会在危机中移动的物件使用正常态烘焙表示与实时网格双表示，并在动作开始前切换。透明前景板和后景板必须来自同一摄像机与同一次色彩管理配置。

## 7. 几何与贴图预算

以下为首周默认上限，不是必须用满：

| 资产 | 建议三角面 | 贴图基准 |
|---|---:|---:|
| 普通角色 | 20k–35k | 身体 2K、脸 2K |
| 主要可形变墙／玻璃 | 5k–20k | 2K |
| 门、柜子、售票台 | 1k–8k | 1K–2K |
| 普通中型道具 | 300–3k | 512–1K |
| 小型重复道具 | 50–800 | 256–512 |
| 背景远景几何 | 由离线渲染决定 | 不进入实时包 |

- 首周不使用 4K 游戏贴图；
- 重复道具共享图集；
- 法线贴图只用于明显改变近景受光的细节；
- 不为预渲染背景中不可接近的物件导出完整实时资产；
- 透明材质数量受到严格控制，雾、玻璃、头发不能同时无限叠层。

## 8. 材料样板

### 湿墙

- 正常态先表现真实乳胶漆、砂浆、刷痕和旧修补；
- 危机态改变粗糙度、颜色、微表面起皱和形体；
- 身体联想来自积液转移和慢回弹，不使用肤色或血管贴图；
- 低画质保留形变、湿痕边界和渗水声，可删除微法线。

技术门修订：正式可形变墙使用至少三层结构，而不是一张整墙网格。承重基墙负责碰撞和大尺度内陷；旧修补／墙皮薄壳负责空鼓、抬起和开裂；内部压力层只负责短时迁移。门框、柜子和盆属于第四组独立响应物件。禁止用单个圆形鼓包代表全部内部体积，也禁止用过窄的整墙 Shape Key 制造迁移脊，以免形成折面和黑缝。

### 玻璃／厚亚克力

- 正常态必须看得出平直边界与厚度；
- 高画质使用有限折射和反射；
- 低画质使用 UV 扭曲、参照线变形和框架位移；
- 透明不能让背景尺度消失，外部巴士和停车线必须清楚。

### 瓷砖与搪瓷

- 瓷砖通过缝隙、局部磨损和反光区别于塑料；
- 搪瓷盆必须提供坚硬、薄壁、清楚的声音；
- 不平均添加污渍，清洁区域同样重要。

### 铝合金与不锈钢

- 区分旅游设施的新铝材和旧设施的盐雾侵蚀；
- 反光保持模糊和现实，不做赛博朋克镜面；
- 固定件受压时先通过位移和声音成立，再增加破损。

### 塑料与玻璃钢

- 危机前保留鲜艳、廉价、努力现代的千禧感；
- 表面褪色和划痕服从使用位置；
- 海洋馆蓝不能统一覆盖其他材料。

### 布与皮肤

- 布料优先用预设骨骼或简化动画，不运行全场布料模拟；
- 皮肤保留年龄、毛孔、色差和不对称；
- 人脸不能靠随机污渍、黑眼圈或湿亮自动变恐怖。

## 9. 灯光规格

### 危机前

- 海洋馆公共区明亮、略俗气、具有真实营业状态；
- 日光、荧光灯、灯箱和水槽蓝光可以混合，但必须能追溯光源；
- 人脸允许处于不讨好的顶光，不刻意恐怖化。

### 危机后

- 不统一断电或变红；
- 远景对比和边缘由雾吞没，近景仍保留局部颜色；
- “巨大吸气”发生时先改变声音、水面和雾，再决定灯光是否响应；
- 低画质最多保留一个投射实时阴影的主光，其余烘焙或无阴影。

## 10. 海雾生产规格

海雾分为三层：

1. **远景雾**：Blender 离线渲染，负责取消地平线和建筑远端；
2. **中景雾**：Godot 深度雾加少量交叉雾片，负责分层和移动；
3. **压力前缘**：有厚度的实时网格／粒子边缘，负责进入门口并推动人物与物件。

- 雾片不得在镜头前明显穿插；
- 雾的移动速度与纸张、衣物和声音变化一致；
- 低画质可减少雾片，但不能删除压力前缘及其物理响应；
- 不使用全屏低饱和替代空气透视。

## 11. 照片现实人物管线

### 照片采集／素材要求

- 正面、左右 45 度、左右侧面、后脑与全身；
- 柔和均匀光，关闭美颜、人像虚化和 HDR 风格化；
- 中性表情后再拍少量自然动作，不先表演恐怖；
- 记录真实服装褶皱、鞋、手和年龄特征；
- 素材授权必须允许项目使用。

### 模型与材质

- 面部保留不对称，不把照片磨成对称美容脸；
- 眼球、眼睑、牙齿独立但保持简化；
- 头发首周使用发片或实体块，不使用高成本毛发系统；
- 照片高频细节与低模轮廓之间允许轻微摩擦，但不能像贴纸；
- 普通人首先必须可信，之后才允许破坏动作连续性。

### 动画

- 正常动作以 30 FPS 数据播放，不人为抽帧制造复古；
- 站立循环保持微弱呼吸与重心变化；
- 对话恐怖来自目光、停顿、呼吸与动作目的错位；
- 抽搐、歪头、倒放、贴脸不作为默认异常动作。

## 12. 怪物生产边界

首周不建立通用怪物 Shader 或统一海洋表面库。第一只怪物开始制作前必须提交：

- 危机前普通人的完整状态；
- 一句可在游戏中直接看见的身体矛盾；
- 正面、侧面和移动状态；
- 独有动作与静止方式；
- 感知玩家的方法；
- 所在空间和生活残余；
- 声音如何从身体结构产生；
- 对门、家具、灯光、雾和其他人的影响；
- 低配实现与高配增强分别是什么。

这份清单规定完成度，不规定灵感来源和怪物外形。

## 13. UI 与字体

- UI 首周保持克制，避免现代科幻 HUD；
- 字体使用清晰的简体中文黑体／宋体体系，最终字体须确认商业许可；
- 互动提示放在行为发生处附近，不用巨大中心图标；
- 字幕始终可读，低分辨率下不溢出；
- 世界内地图、票据、病历和宣传页按照 2000 年真实印刷逻辑设计；
- 暂停菜单和设置页不强行做成录像带界面。

## 14. 音频资产规格

- 工程采样率：48kHz；
- 近距离硬质瞬态优先 WAV，环境循环和语音可压缩为 Ogg Vorbis；
- 单声源尽量保持 mono，由 Godot 做空间定位；
- 音乐和明确立体声媒介保留 stereo；
- 每个异常至少包含材料声、空间声与身体反应声；
- 不用通用低频轰鸣覆盖所有恐怖段落。

命名格式：


- 每次技术门只升级受验证的资产版本。

## 16. 高低画质必须共享的证据

无论画质如何，以下内容不能被关闭：

- 墙体按压处凹陷、修补层响应、远端多点压力与排空后的空间深度；
- 门框、柜子或人物对墙内体积的响应；
- 玻璃平直初态与外部直线参照；
- 门打开后雾、物件、人物和玻璃共同响应；
- “巨大吸气”的声音尺度与危机前后差异；
- 角色面部、手与身体的基本可读性。

可以按画质降低：实时阴影、折射、雾片数量、法线细节、背景分辨率、粒子数量和远景动画。

## 17. v0.2 的触发条件

墙体技术门完成后记录：

- 预渲染背景与实时墙体是否衔接；
- Blend Shapes 在 Compatibility renderer 的表现；
- 低配截图中的材料与轮廓；
- 从 Blender 修改到 Windows 新构建所需的实际步骤；
- 假雾是否需要改用不同层法；
- 镜头是否需要更多或更少的自由度。

只有这些实机证据可以触发生产规格变更。
