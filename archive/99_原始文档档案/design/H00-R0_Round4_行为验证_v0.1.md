日期：2026-08-04

## 本轮问题

在不使用正式怪物模型、贴图或音效的前提下，`H00-R0《婚宴后场：返席》` 是否已经有一个可运行的最小行为闭环：玩家从 A 进入后场，在 C 完成录像归档，实体沿旧后勤路线回返，且 `R` 能把全部状态恢复到 00 秒？

## 运行实现

- 独立 Unreal 5.8 工程：`FanchaoH00UE`。
- 运行时从空 `Entry` 地图生成 A 宴会厅、B 服务走廊、C 录像归档室、D 卸货口和 E 洗涤间；不引用旧泥滩工程。
- 玩家：第三人称胶囊/方块占位，`WASD` 移动，`E` 交互，`R` 重置。
- 普通任务：只可在 C 的 `REC / PAUSE` 录像台半径 240 内完成归档。
- 实体：无攻击、无转头惊吓、无随机追逐；固定航点为 D -> B -> C 门外 -> E -> D，抵达工作点会短暂停留。
- 重置：同时恢复玩家起点、录像带状态和实体航点。

## 已修正的基础问题

最初复制的 `Lvl_ThirdPerson` 是 World Partition 关卡，离开原工程的外部 Actor 数据后会在独立 `-game` 启动时触发引擎断言，且它依赖的 Enhanced Input 资产没有被带入。该地图不再作为 H00 的运行底座。当前工程默认使用 UE 自带空 `Entry` 地图，空间完全由 H00 运行时代码生成。
