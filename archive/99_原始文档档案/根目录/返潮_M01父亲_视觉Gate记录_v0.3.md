# 《返潮》M01「父亲」视觉 Gate 记录 v0.3

状态：**REJECT；方向保留，几何管线冻结，禁止贴图与 UE 接入。**

## 本轮保留

- 「海洋生物石化复眼」仍是 M01 的正确视觉方向。
- 2001 年沿海基层工人、褪色蓝灰工装、塌左肩、拖右脚、干燥海床世界仍是硬约束。
- “正面不是脸，而是被深度压入人体的古老海床观察器官”仍是唯一可继续发展的解释。

## 本轮执行

- ChatGPT 网页端生成了第三次结构参考图；结果仍有腐殖/珊瑚覆盖和正常脸部残留，只能作为气氛参考，不能作为模型参考。
- Blender v0.4/v0.5 执行了：连续体素人体核心、前侧负向布尔切削、凹陷底部矿化面、8 个不规则浅晶面。
- Antigravity / Gemini 3.1 Pro High 复核结论：`REJECT`。

## 失败原因

1. 背面仍像圆润无脸人偶，工装生活剪影不可靠。
2. 侧面仍能读成椭圆薄片向外脱离人体，无法证明负体积内嵌。
3. 正面矿化区仍像竖向盾形面板，周围有暗边。
4. 晶面虽已去掉圆孔形状，仍像贴在面板上的独立石片，没有成为同一矿化底床的刮削结构。

## 管线决定

当前 procedural primitive / voxel / 简易 Boolean 灰盒达到表现力上限，**停止继续调参**。下一轮必须切换到真实人形基底或雕刻管线：

1. 先获得可信的人体比例与 2001 年工装剪影；
2. 冻结左肩加载、右脚拖步；
3. 直接在人体前侧雕刻 2–5 cm 的负向压力槽；
4. 在槽底刮削 7–9 个同质、浅层、不规则晶面；
5. 通过背面、正侧面、正面/反射三镜头后，才能进入贴图。

## 下一轮一票否决

- 侧面矿化结构任何一点越过原人体前轮廓；
- 出现外壳厚度、面板包边、胸甲、面具或孕腹读法；
- 晶面变成圆孔、球体、镜头、蜂窝、独立贴片；
- 背面无法先读成普通沿海父亲。
