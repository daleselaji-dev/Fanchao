# 《返潮》首日 Demo 执行工作流 v0.1

目标：在一天内完成 60-90 秒可玩的滩涂切片。每一步必须留下可运行证据，不能用概念图替代运行结果。

## 阶段门

### G0 视觉语法

输入：`返潮_基本视觉语法_v0.1.md`、`视觉原型/返潮_v0.6/`。

通过条件：冷暖色温同时存在；每帧只有一个异常动作；720p 能读出人物轮廓、警报红和异常方向。

状态：通过。

### G1 场景骨架

资产：一块独立非 World Partition 滩涂地图、一座警报塔、两个控制箱、一个 PlayerStart。

通过条件：`Mudflat_Runtime.umap` 可独立 `-game` 启动 20 秒；地图内持久化 `MudflatDirector` 与 `PlayerStart`。

状态：通过。

### G2 近景资产

资产优先级：控制箱 > 塔入口 > 归面实例 > 无正面父亲英雄模型。

每个资产都走：GLB/Blend 输入 -> UE 导入 -> 材质色板 -> 碰撞 -> 720p 截图。

状态：控制箱与电话 GLB 已导入并接入导演；英雄模型待 Hunyuan3D 权重或 Antigravity 输出。

### G3 可玩节拍

1. 0-8 秒：玩家检查第一个控制箱。
2. 8-16 秒：家属带归面离滩。
3. 16-22 秒：最后警报，归面集体转向陆地。
4. 22-28 秒：玩家第一次测深，学会短/长回声。
5. 28-50 秒：无正面父亲起身，沿警报回声倒退接近。
6. 50-70 秒：第二个控制箱改向，玩家逃入塔。

通过条件：两次 `E` 内理解回声深浅；第二次警报能改变怪物路线；`R` 可重置。

### G4 低配验证

运行：1280x720 窗口，关闭编辑器视口，记录启动、节拍、退出和截图。

不通过时只修一个变量：地图入口、碰撞、灯光、材质、动作或文本，不同时改五项。
