# 《返潮》莫比乌斯小镇：F0 技术承载审计 v0.1

> 结论：现有 Unreal 工程不能承接 F0；现有 Three.js 酒店原型可以提供经过测试的运行方式，但不得提供场景、叙事或美术内容。下一步建立独立的 `prototypes/f0_mobius_walk/`，先证明连续行走与全镇表面翻面，再迁移到重建后的 Unreal 工程。

## 1. 当前工程的真实状态

### `FanchaoLastCallUE/`

- 目录总量约 96KB，`Content/` 中没有地图、网格、材质或贴图；
- `DefaultEngine.ini` 指向不存在的 `/Game/Maps/L_LastBus`；
- `GlobalDefaultGameMode` 指向 `FCGameMode`，但源码中没有 `FCGameMode.h/.cpp`；
- 多个现有类直接 `#include "FCGameMode.h"`，所以当前源码不能完成编译；
- `.uproject` 的 `EngineAssociation` 为空，本机也没有检测到 Unreal Editor；
- `FCStationBuilder` 只生成封闭车站方盒，并写死点名册、广播、电话、出口闸门与绿色雾/暗角/颗粒，全部属于已经否定的“群众秩序与局部交互”旧域。

因此它不是“已有 Unreal Demo”，而是一个缺少核心类和内容的代码草架。当前向其中添加美术或拓扑代码无法获得可运行证据。

### `fanchao_last_bus/`

- Godot 项目曾完成可玩章节、敌人感知与自动冒烟测试；
- 但本机没有 Godot，且项目明确围绕点名、空座、电话和借听；
- 不复用场景、目标链、美术或世界生成规则。

### `prototypes/h00_siren_ps3/`

- Three.js 0.185.1 依赖存在；
- `game.mjs`、`prelude.mjs`、`hotel_loop.mjs` 语法检查通过；
- `tests/game_state.test.mjs` 共 11 项全部通过；
- 可借：渲染器初始化、指针锁定、第一人称移动、GLTF 加载、状态纯函数与 Node 测试方式；
- 禁借：酒店模型、婚宴路线、214 钥匙、借视、敌人、门/黑场流送、危机点火、颗粒/扫描线/红色危险覆盖。

## 2. 技术路径决定

建立独立技术样片 `prototypes/f0_mobius_walk/`。它不是酒店原型的新章节，也不是最终游戏；它只负责回答一件事：

> 玩家能否在没有门、黑场、传送与相机作弊的情况下，连续走完一段镇区路线，并在回到 F0 时亲眼看到海陆和地标完成奇偶翻转？

盲测与技术样片并行：盲测决定五张美术图是否读得懂；技术样片决定这种读法能否由真实空间状态产生。任一失败都不能用另一条证据替代。

## 3. 首个可运行片段

时长 90—150 秒，不包含敌人、谜题、收集、借视或剧情说明。

1. 玩家从新市场 F0 出发，下坡进入 0—30m 的固定近景；
2. 沿市场背街、排水支路和港区边缘连续步行；
3. `fold_phase` 只由路线弧长推进，不提供切相按钮；
4. 玩家在途中可回头，观察远景逐渐出现方位迟滞、双海岸和连续卷起；
5. 路线无缝回到 F0，`route_parity` 变为 1；
6. 同一公交镜、铺面、黄线和人物锚点仍在，远景已变为蓝色穹顶—烟囱—广播塔，海位于原内陆侧。

## 4. 三层空间职责

### 近景 0—30m：绝对固定

- 普通网格与静态碰撞；
- 不进入任何弯曲着色器；
- Phase 0 与 Phase 1 的世界坐标、UV、材质实例和碰撞哈希必须相同；
- 负责证明相机没有移动、画面没有镜像。

### 中景 30—180m：连接层

- 道路、挡土墙、屋顶组、电线和排水必须按同一连续函数变换；
- 每个资产保留基础 Transform，再由 `fold_phase` 计算显示 Transform；
- 不允许分阶段换整套场景或用透明度交叉淡入另一张镇景。

### 远景 180—2200m：拓扑证据层

- 三个地标身份唯一；
- 海面、海堤、道路和天际线共享曲率与遮挡状态；
- Phase 1 只交换海陆归属和地标方位，不镜像纹理或相机；
- 远景可使用独立 LOD 与低分辨率材质，但不能退化为一张随相机转动的背景板。

## 5. PS3 末期画面技术门

这里指 2008—2013 年生存恐怖的完成度与克制渲染，不冒充真实 PS3 硬件认证。

- 内部构图基准：1280×720，16:9，水平视场角 55°；
- 帧预算：目标 30fps，95% 帧时间不超过 33.3ms；
- 可见三角形起始上限：60 万；
- 稳态绘制调用起始上限：700；
- 纹理常驻起始上限：350MB；
- 近景主材质 1024—2048，远景图集 256—1024，必须有 mip 与 LOD；
- 一盏主要方向光、烘焙或预计算环境光、有限局部灯；不使用实时 GI；
- 不使用景深、运动模糊、色差、强暗角、扫描线、全屏噪点或恐怖滤镜；
- 保持有限动态范围、可读的中远景层次和真实湿材料，不用统一锈湿覆盖所有分区。

预算是首个浏览器样片的退回线，不是最终资产必须填满的目标。

## 6. 必须自动验证

- `fold_phase` 单调推进，除重新开始外不可倒退；
- `route_parity` 只在完整一周后翻转；
- Phase 0—0.75 地标顺序保持广播塔—烟囱—穹顶；Phase 1 变为穹顶—烟囱—广播塔；
- Phase 0.5 同时存在两段海，近景无积水；
- Phase 0.75 海、海堤、道路、屋顶与电线使用同一曲率；
- Phase 0 与 Phase 1 的近景 Transform 哈希完全一致；
- 任何相位都不能生成重复地标；
- F0 自动截图必须使用同一相机 Transform 和投影矩阵。

## 7. 迁回 Unreal 的条件

仅当浏览器样片同时具备以下证据才重建 Unreal 工程：

1. 90—150 秒连续路线可从 Phase 0 走到 Phase 1；**状态闭合与内部视觉复审已达成候选**：当前代码无 HUD 连续行走 124.513 秒到达 270m，V1—V4 均出现对应世界证据，终点 `fold_phase=1`、`route_parity=1`；外部盲读未做，仍不放行迁移；
2. 锁机位五阶段自动截图与当前美术序列具有相同空间读法；
3. 近景不变、远景连续变形的自动测试通过；
4. 720p 浏览器样片达到 30fps 技术门。当前 V3 物理岸线版本为 `29 calls / 16,276 triangles`，更新加渲染工作时间 `p95=1.4ms`；但同一内嵌浏览器的 `scene_off` 空场原始 RAF 已为 `p95=33.7ms`，无法作为合格的 30fps 判定宿主。**内容负载预审通过，端到端帧率仍待独立前台 Chrome/GPU 复核，不能宣布本门通过**；
5. F0 无标题盲测通过。

Unreal 重建时只迁移状态数据、变形函数、路线弧长和资产职责，不迁移 Three.js 场景代码，也不修补旧 `FCStationBuilder`。

完整路线的首次失败证据见 `返潮_莫比乌斯小镇_F0连续路线体验审查_v0.1.md`；当前候选复审见 `返潮_莫比乌斯小镇_F0连续路线体验复审_v0.2.md`。67.5m、135m、202.5m 已各自出现真实空间命题，当前剩余门是外部盲读与独立宿主的整圈 30fps 复核；不再通过删除海岸、镇面或沿路实体追逐内嵌浏览器的空场调度噪声。
