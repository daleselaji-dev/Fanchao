# 《返潮》莫比乌斯小镇：F0 五阶段盲测协议 v0.1

> 目的：验证五张图是否无需设定说明就能表达“同一地点经过连续翻面抵达另一面”。本协议不是审美投票，也不询问“够不够诡异”。

## 1. 测试材料

依时间顺序展示以下五张无标题、无阶段编号图像：

1. `视觉原型/莫比乌斯小镇/第3层/F0_Phase0_新市场正常视野_候选_v0.1.png`
2. `视觉原型/莫比乌斯小镇/第3层/F0_Phase0.25_方位迟滞_候选_v0.1.png`
3. `视觉原型/莫比乌斯小镇/第3层/F0_Phase0.5_双海岸_候选_v0.1.png`
4. `视觉原型/莫比乌斯小镇/第3层/F0_Phase0.75_城镇表面卷起_候选_v0.1.png`
5. `视觉原型/莫比乌斯小镇/第3层/F0_Phase1_同一地点另一面_候选_v0.1.png`

测试者至少 6 人，必须没有阅读过空间公理、提示词和审查报告。每张首曝 4 秒，之后允许自由回看全序列一次。

## 2. 不诱导提问

逐人记录原话：

1. 你认为相机有没有移动？为什么？
2. 第 1 张与第 5 张是什么关系？
3. 你注意到哪些东西改变了位置或归属？
4. 第 4 张发生了什么？
5. 这组图更像镜像、换了一座镇、地形变化，还是同一地点翻到了另一面？请自由描述，不提供选项。

## 3. 通过阈值

- 至少 5/6 人认为相机和近处地点没有改变；
- 至少 4/6 人主动说出海从右侧变到左侧；
- 至少 4/6 人主动识别两个外侧地标交换位置或方向；
- 至少 4/6 人将第 4 张描述为整片城镇或海岸弯曲，而不是一条新公路或普通陡坡；
- 至少 4/6 人用“翻面、反面、绕回、空间倒置、同一地方另一侧”等等价语言描述第 1 张与第 5 张；
- 不超过 1/6 人认为它只是整图镜像；
- 不超过 1/6 人认为五张图来自不同城镇。

任一阈值未达成，F0 不通过。

## 4. 失败结论对应修正

| 测试者误读 | 只允许修正 |
| --- | --- |
| 相机转动了 | 加强前景与道路消失点锁定，削弱地标位移幅度 |
| 换了一座镇 | 增加跨阶段不变的中景屋顶组、路口、电线和挡土墙锚点 |
| 普通山城或公路 | 让海面、海堤和多条街道共同弯曲，禁止单一路面承担卷起 |
| 整图镜像 | 强化文字、人物左右手、车辆方向和不对称前景证据 |
| 海水淹城 | 把水体退回远景，保持所有前景地面与建筑基础干燥 |
| 奇幻世界变形 | 降低曲率和灯光戏剧性，保留普通天气与材料 |

不得通过增加说明文字、箭头、旁白或剧情解释修补盲测失败。

## 5. 记录格式

每名测试者记录：编号、五个问题原话、七项阈值的命中情况、第一处察觉异常的阶段、最确信的空间证据。只汇总结果，不对测试者解释正确答案。

盲测通过后，第 3 层才能从“候选完成”改为“v0.1 通过”，并开放第 4 层物质与气象构建。
