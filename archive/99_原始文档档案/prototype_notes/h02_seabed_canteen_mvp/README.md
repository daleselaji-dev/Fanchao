# H02《晚班食堂海床》动态构图验证

> 状态：淘汰。仅保留为早期技术实验，不能作为当前食堂场景的视觉或玩法来源。

> 淘汰原因：整体海床、九名职工和同步动作把恐惧落在集体秩序与显眼的场景效果上。当前食堂只测试一件事：仍在使用的干燥房间里，有一个看不见的水平高度使下半部留下长期深压的材料历史。

这是早期动作和空间关系验证，不是发布级美术，也不是当前目标帧。

运行：

```bash
python3 -m http.server 4175 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4175/prototypes/h02_seabed_canteen_mvp/?automation=1`。

历史审查标准（不再采用）：

- 群众和食堂用途先于异常成立；
- 海床只能是同一高度的硬截断，不能读成水、沙坑、泥浆或舞台；
- 十秒内，打饭窗口、饭票和所有手部的微小同步位移必须让“秩序仍在继续”成立；
- 低模、无贴图的人物不属于最终美术，目标帧通过后全部替换。
