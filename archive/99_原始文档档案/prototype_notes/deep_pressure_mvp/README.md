# 《返潮》无水深海压力 MVP

> 状态：淘汰。仅保留为早期技术实验，不能作为当前美术、关卡或实体设计的依据。

> 淘汰原因：它把压力做成一整套同时发生的动态特效，并以钙化管孔和玻璃鼓起承担主要画面。当前方向只保留“无水空间拥有长期深处材料历史”这一点，第一张图必须在干燥、日常、单一的材料后果里成立。

独立的 45 秒实时镜头实验。它曾尝试验证干燥室内承受深海压力的可读性；其动态玻璃、拖曳和钙化做法已不再采用。

不包含任务、门锁、战斗、怪物图鉴、结局或世界观解释。

## 运行

从仓库根目录启动静态服务：

```bash
python3 -m http.server 4175 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4175/prototypes/deep_pressure_mvp/`。点击进入后场景循环；自动审查可打开 `?automation=1`，直接从高压段开始。

## 历史审查标准（不再采用）

- 玻璃在受压前必须是可辨认的平直基准；
- 没有可见水源时，固定件、纸张、工牌和玻璃必须指向同一个压力方向；纸张只能擦滑，不能漂浮；
- 熟悉的日用品必须保留可辨认的原形；钙化只能从盆沿、铁皮接缝、风扇网罩等真实锚点长出；
- 截图不能依赖文字说明读懂“干燥空间正承受深海压力”。

## 历史禁用清单

- 水滴、浪花、气泡、积水、湿滑高光；
- 触手、眼睛、粘液、肉块、发光鱼类式器官；
- 荧光蓝绿、生物荧光、巨型海怪剪影；
- 失重飞舞和“闹鬼房间”式的无方向运动。
