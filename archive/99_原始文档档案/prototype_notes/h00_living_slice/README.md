# 已否决实验：H00《续住名单》图像叠加切片

> 2026-07-18：该实现被否决。原因是它依赖静态图、字幕和分支按钮，体验接近文字冒险，不能承担《死魂曲》式实时空间压力。当前正式方向是相邻目录 `h00_siren_ps3/` 的第三人称实时 3D 原型。本目录只保留为失败证据，不继续制作。

这是一个约 35–45 秒的本地可交互气质原型。它验证的不是完整玩法，而是三个核心判断：

1. 恐怖发生前，宾馆必须先像一个有人情、婚宴和夜班琐事的真实地方；
2. 林素琴在电话响起前先回答“续住”，因果只错半步；
3. 接听后，钥匙格背后长出 214 房，玩家必须在“把自己写进名单”和“把陈炳兰从婚宴中抹掉”之间转接。

## 运行

macOS 可双击 `RUN_H00.command`，或在项目根目录执行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:4173/prototypes/h00_living_slice/
```

建议使用桌面 Chrome，戴耳机并全屏。点击“接班”开始；红电话响起后点击电话或按 `E`；最后选择 214 或 216。

## 测试

```bash
node --test prototypes/h00_living_slice/tests/living_state.test.mjs
node --check prototypes/h00_living_slice/app.mjs
```

行为测试约束回答/提问顺序、裂缝触发条件和两条身份代价。浏览器实机截图保存在项目根目录的 `output/playwright/`。

## 当前边界

- 这是“动态证据”，不是完整引擎关卡；人物动作来自镜头、转场与声场，而非骨骼动画。
- 中文对白已离线渲染为项目内音频，不依赖浏览器随机选择系统声线；字幕仍完整保留。
- 场景沿用本项目 H00 目标帧与音频，不依赖联网资源。
