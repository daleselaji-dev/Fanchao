# 《返潮》视觉原型 v0.4（色彩校准与质量校准）

v0.4 先做一张校准图，再批量生成。目标不是“更脏”或“更灰”，而是让观者在一眼内读出：这是一个 2001 年中国海镇的真实空间，空间里出现了一个错误的方向或错误的人。

## 视觉系统

主色按面积控制：冷水泥雾灰 60%，氧化青绿 20%，旧工作服蓝 10%，贝灰骨白 7%，警报红 3%。警报红只能出现在警报灯、反光或一件关键遗物上；不能把整张图染红。归面使用偏暖的贝灰骨白，与背景冷灰分离。黑绿色霉层只作为细线和接缝，不铺满画面。

## 质量门槛

- 一张图只讲一个异常动作，不堆多个怪物或灾害效果；
- 主体数量、朝向和视线关系必须可数、可复述；
- 关键轮廓在 720p 缩小后仍清楚；
- 背景负责时代和地理，前景负责恐怖动作；
- 不接受“脏、乱、灰”本身作为恐怖，必须有错误方向、错误人形或错误承重。

## 生成顺序

1. 先生成 `01_校准图_滩涂送面.png`，确认色彩和异常动作；
2. 通过后再生成无正面父亲、警报测深、材质色光三张；
3. 每次只提交一个 prompt，生成后检查构图、色彩和恐怖读点，再决定下一张。

生成端固定为 John Davis 的 ChatGPT Chat 网页会话，不使用 Work 或项目工作区。
