# 《返潮》视觉原型 v0.2（脏版研究图）

本目录保存第一轮网页生图结果，作为被否决的材质研究，不作为最终视觉方向。问题是泥、破败和杂物占满画面，恐怖动作不够清楚。

最终方向转到 `返潮_v0.3`：干净现实场景、明确留白、单一违反常识的动作、清晰轮廓。

原始图仍共同遵守以下基础美术规则：

- 2001 年中国海边小镇的可信现实感；
- 水泥灰、褪色警示红、旧工作服蓝、贝灰、黑绿色霉层；
- 干燥材质承受深海压力，先出现受压、沉积、延迟回声，再出现身体变化；
- 不使用蓝色水下滤镜、黏液覆盖、通用海怪装饰、外星或感染者视觉语言。

## 生成入口

在用户 Chrome 的 ChatGPT 页面可被 OpenCLI 接管后，运行项目根目录中的：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\generate_retide_review_images.ps1
```

脚本会逐张生成、校验文件存在，并将 ChatGPT 返回的链接和本地路径写入 `generation_log.json`。
