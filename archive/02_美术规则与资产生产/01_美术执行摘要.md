# 美术执行摘要

## 正常底片

先做 2001 年沿海小镇的真实社会空间：婚宴厅、服务台、录像设备、CRT、工作服、餐具、旧门、金属柜、冷库/洗涤设备、广播和公共登记。每个道具要有功能、年代和使用痕迹。

## 异常层

异常不是“海洋主题装饰”，而是同一深度和时间作用下的材料历史：长期受压、沉积、附着、密封疲劳、声学过滤和人体动作被旧伤重新规定。每个镜头先读日常，再读异常。

## 角色与实体

M01/实体首先是一个仍在履行职责的普通人，其姿态、重心、服装和工具先能读出工作；石化海洋复眼只在合适的侧正面短时成为证据。正式资产需要先过形体 Gate、空间 Gate、行为 Gate 和视觉审查，不能由一张生成图直接进 UE。

## 生成与审计角色

- Gemini/Antigravity：候选空间、模型和美术方向，负责提出方案与审查。
- 网页 Chat 端：视觉逻辑、高级审计、资产建议和提示词复核。
- Codex/项目总控：维护 canon、拆分 Gate、写入工程、监督结果、拒绝不合规则的输出。
- Blender：可复现灰盒、相机、比例和形体验证。
- Unreal：可操作运行时、交互、航点、声音和最终接入验证。

任何 Agent 输出都要回到同一条证据链：异常物理规则 → 玩家动作 → 可见/可听反馈 → 剧情变化 → 可复核记录。
