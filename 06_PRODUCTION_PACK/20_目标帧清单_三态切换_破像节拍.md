## 2. 三态切换规范（全空间通用执行标准）

### 2.1 切换时序（议程宣布固定序列内的视觉分解）

```
T0      全楼收声开始（逐源离场，3–5s）
T0+3~5  广播词起
T0+词毕 应力声起（该空间的蠕变/剥落采样）
   │    灯光过渡 1.5s（配置表切换，禁突黑除暗拍条款）
   │    差异子网格 swap（按 2.2 无 pop 律择机）
   │    喜事层形态推档（挺括→下垂→覆膜/半埋）
T0+15s  色彩曲线推档（建筑层 −15% 饱和，喜事层 +5% 饱和 −5% 明度，`21` §4）
```

### 2.2 无 pop 律（从 `14` §3.1 落到判定伪码）

```
可切换 = 玩家背向该子网格 (dot(视线,方向)<0)
       ∥ 视线被遮挡 (raycast 命中遮挡体)
       ∥ 玩家不在本空间
兜底   = 灯光暗拍 250ms（每空间每晚一次；用掉后该空间剩余切换必须走前两条）
```

## 3. CRT 破像前后节拍表（秒级，演出与程序共用）

### 3.1 破像动作时序

```
-∞~0   玩家已看过本空间预现（前提；没看过预现的破像无效果差异，但系统仍受理）
0.0    交互锚点物（砸花瓶/搬椅/关灯……各空间锚点见 `14` §2.1-B）
0.0    破坏声=大噪声（必超点名阈——用安全换时间铁律）
+0.4   本空间所有 CRT 同步"啪"一声断信号 → 黑屏材质
+1.5   全楼收声（点名序列启动）
+3.0   司仪点名广播（报本区域）
+6.0   更正议程广播起（同句低速率冷读版）
+6.0   宴会厅浮客全体转向玩家方向一拍（4s）
+8.0   最近侍应改道（直线赴最后发声点=锚点物位置——玩家此刻应已离开）
状态    本空间跳过下一档推进（foretold=false 持续一个议程周期）
```

### 3.2 破像后的世界感（孤岛条款）

全楼继续推档，唯被护空间停一档——玩家从走廊回望：别处都暗了一档，只有这间还亮着上一档的灯。**奖励与恐惧同源**：护住的空间成了全楼最显眼的"没办完"。

### 3.3 预现兑现节拍（破像的反面，同样锁秒）

```
0.0   syncGap→0：CRT 声画与现实完全同步
0.0   画面异常清晰 1–2s（分辨率/噪点全清——全 Demo 唯一的高清画面）
+2.0  失去信号 → 永久雪花
+2.0  显像管内湿摩擦余声（3s 渐弱）
+2.5  现实事件声接管，该空间执行兑现 swap（无 pop 律照常）
```

- 设计保证：每次兑现与录像有一处差异（更近/更慢/已转向玩家——三选一，按空间指定，写入关卡表）。
