## 0. 一句话

**返潮之夜，海从湾里退走了——水进酒店变成了"深度"，湾底裸露出来。玩家在婚宴进行到一半时，从海洋馆排水闸走上这片不该被人看见的海床，沿一排今晚刚点亮的红灯笼走回酒店后门。**

细思极恐层：不是海退了，是**海把水收走去布置酒店了**；灯笼道是全镇给"接亲的"铺的路，玩家走的是接亲的道，方向反着。

## 1. 空间边界（防开放世界的硬约束）

- 可行走区域：一条 90m 长、8–14m 宽的**灯笼道走廊**（露天，但它就是一条走廊），从海洋馆排水闸口到酒店 B1 后门。两侧越界 6m 内泥面渐软（减速 70%+噪声翻倍），12m 处雾墙折返（同 S01 规则）。
- 单夜单次：只在第四幕后半通行一次，之后 B1 后门闭锁，不可重返。
- 全程约 3.5–4.5 分钟，无战斗、无追逐、无 QTE。

```
[海洋馆·排水闸] ──▶ 旧码头残桩区 ──▶ 采料坑阵列 ──▶ 泥中CRT ──▶ [酒店B1后门]
     (雾中左侧：搁浅渡轮轮廓)   (右侧海向：雾顶水平线、远处接亲灯)
```

## 2. 环境总规格

### 2.1 泥面（干燥律的极端执行）

- **龟裂干泥** `[轮廓+痕迹]`：退潮不该让泥当夜干透——这里的泥裂得像干了几十年的湖床（沉积时间的外景版）。裂片六边形 30–80cm，踩上有陶片般的脆响（噪声中危面）。
- 唯一的湿：**采料坑里的水**（负形湿泽，残骸语汇内唯一允许的湿形式）。除坑外全场无一处积水、无一只海洋生物、无一根海草（禁止清单执行：没有搁浅的鱼——**海把它的东西全部带走了**，这比留下尸体更不对）。

### 2.2 天空与雾（巨物恐怖的零成本实现）

- 无月无星。海向的雾有一条**笔直的水平上缘**，高约 25m，缘线以上是更深的黑 `[氛围→轮廓级重要度]`——从海底仰望水面的构图。实现：雾体渐变贴天空盒 + 一条硬边界；成本≈0，效果=全 Demo 最大的一张"哪里不对"（目标帧 F13）。
- 岸向（酒店方向）：酒店四层的窗全亮着，暖黄，隔雾成毛玻璃色块；宴会厅方向透出红。**回头看酒店必须是温暖的**——玩家正走回去的地方才是祭坛，这层反讽不许用冷色破坏。

### 2.3 声场（无海之声，详表见 `22` §5）

- 没有海浪声——潮平线消失后的静。三种声音：泥层深处 40–70s 一次的沉降闷响（远低频，来自海的方向=耐压方向）；镇方向滚来的鞭炮回声（遮蔽窗，8–12s）；酒店方向隔墙的喜歌 A 版残响（越走越清晰=进度反馈）。
- 玩家自己的声音在露天格外裸露：脆裂泥面的踩碎声传得很远——遮蔽窗玩法在此达到峰值（等鞭炮，走一段）。

## 3. 分段资产规格

### 3.1 旧码头残桩区（0–30m）

| 资产 | 规格 | 标签 |
|------|------|------|
| 残桩阵 | 木桩 ×20，截面在同一高度被磨平（旧潮位线——现在高悬在干泥上方 2m，标出"水曾经在哪"） | `[轮廓]` |
| 搁浅渡轮"蚀湾渡" | 40m 外雾中侧影，倾斜 15°，只做剪影级模型；船身一排舷窗，其中一扇亮着（不解释，不可达） | `[氛围]` |
| 缆桩+断缆 | 缆绳断口整齐如切 | `[痕迹]` |
| 灯笼杆列·起始段 | 竹竿 ×8，间距 6m，各挑一盏新红灯笼，烛火稳定**无风也不晃**；杆脚培土是新的——今晚刚栽 | `[轮廓]` |

- 检视物①：杆脚红纸（压在培土下）：「接亲的道 勿踩两侧」——是给"接亲的"铺的路，也是给玩家的行走教学，一物两读。

### 3.2 采料坑阵列（30–60m，材料闭环的现场）

- 岩架（海相石灰岩）上 7 个矩形采料坑，编号凿痕 B1–B7 尚可辨认，**坑的尺寸与大堂七块外板一一对应**（数据对齐 `19` §2.2 表）。坑深 0.8–1.5m，坑内积水，水面覆薄矿物膜。
- 演出（唯一脚本事件 E-T1）：玩家手电扫过坑列时，**最远的 B7 坑水面在无风的夜里起了一圈同心波纹**——一次，不重复。（B7 正是大堂最后脱离的那块板的坑——它刚被"取走"。）
- 检视物②：坑缘的钢钎与断裂的麻绳，1998 年施工遗留；旁边一块施工标牌倒在泥里："取料区——蚀湾建司"。玩家若先看过海洋馆展板（`16` §2.1），此处零文本完成闭环。

### 3.3 泥中 CRT（60–75m，本空间的"必看屏"T09）

- 一台被倾倒的 21" CRT 电视，半埋泥中，屏幕朝上，**亮着**（全场无电——它不该亮，但 CRT 比现实先承受返潮，宪法轴一的极端案例）。
- 屏幕内容：本机位的涨潮画面——同一构图，但镜头已在水下：灯笼光在水中折射成摇晃的红斑，画面上缘有水面（从下面看的那种）。**滩涂的"下一稳定形态"就是回到水下。**
- 玩法：这是预现"时间差异"型的唯一样本（录像与现实差的不是物件，是整个介质）；看完后玩家自然加快脚步——无任何倒计时，纯心理时钟。
- 破像不可用（滩涂无锚点物——**这里没有你能护住的东西**，例外本身是设计陈述）。

### 3.4 接亲灯（75–90m，脚本事件 E-T2）

- 右侧海向 30–40m 外的雾中，一排 9 个红光点自远处向酒店方向匀速移动——另一条灯笼道上有人在走，看不清人，只有灯。
- 规则：玩家手电指向它们 → 全部光点**同时停住**；移开 → 3s 后继续。不接近、不追击、不发声。（实现：光点 + 脚本，无模型、无 AI。）
- 与玩家路线在酒店后门前 20m 处呈剪刀差但永不相交——他们走的是另一条道，去的是同一场喜事。
- 到达后门时，回头：光点已全部熄灭或已到——不给答案。

## 4. 异常执行卡（滩涂）

- 主异常：**空间耐压（露天房间化）**——雾顶水平上缘=天花，雾墙=四壁，滩涂是一间露天的压力舱 `[氛围级成本/轮廓级重要度]`。
- 支持证据：龟裂干泥（沉积外景版）、采料坑负形+湿泽、残桩潮位线。
- 检视物：杆脚红纸、施工标牌（各一行文本以内）。
- 光源：灯笼道（唯一暖光列）、玩家手电、T09 屏光、酒店窗光（远景）。**灯笼是本段的"实用光源"与导航线，一物三用（光/路/喜事层延伸）。**

## 5. 禁止项（区域级，写死）

- 不做涨潮追逐、水墙、海啸演出；离开时也不回灌（玩家走后这片地怎样，不解释）；
- 不做任何海洋生物（活的死的都不做）；不做触手/漂浮残骸阵；
- 接亲灯永不给人形轮廓、永不发声；渡轮永不可达、舷窗灯永不解释；
- 不做支线探索区、不做收集品；滩涂只走一次，路只有一条。

## 6. 灰盒验收（G2 追加项）

- 直线灰盒 + 灯笼点位 + 两个脚本事件占位（坑波纹=一个动画面片；接亲灯=移动光点组）即可完整验证节奏；
- 验收问题：测试者走完后能否说出"海去哪了"的自己的答案（任何答案都行，有答案=空间叙事成立）；
- 时长实测 3.5–4.5 分钟窗口外则调整灯笼间距（加密=加快，稀疏=放慢），不改事件。
