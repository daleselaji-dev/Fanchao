## 3. 静默规则执行细目（收声离场次序表）

议程宣布前 3–5s 的"退潮式收声"逐源次序（不是淡出，是逐个离场）：

```
-5.0s 人声群止（话说一半也止）
-4.2s 音响喜歌止（不淡出，像被拔线）
-3.5s 碗筷/器物止
-2.8s 行李车/餐车/机电止
-2.0s 荧光灯电流止（灯不灭，只是不响了——最后一层"正常"被抽走）
-1.0s 全楼只剩玩家自己的呼吸与鞋
 0.0s 广播词起
```

- 完成态静默：兑现空间层一永不恢复（`09` 规则 2）；
- 静默不罚：静默期玩家行动不加噪声值（`09` 规则 3 重申——静默是信息，不是陷阱）。

## 4. 点名链声音序列（秒级）

```
0.0  玩家噪声≥65
0.0  最近喇叭馈电嗡（若 55–64 已预警过则跳过）
+0.8 全楼喇叭齐报："X楼的这位来宾，请入席"
+3.0 其余区域喇叭止，仅玩家区域喇叭轻声循环该句（音量 -12dB）
+3.0 该区荧光灯 +10%
+4.0 最近侍应改道（匀速脚步声渐近——恒定节拍，永不加速，恐怖谷的听觉版）
终止 玩家离区 30s 无新噪声 / 假声源刷新发声点 / 被引座
```

## 6. 混音纪律

- 响度天花板：全 Demo 最响事件=敬酒点火的"吸气"，-6 LUFS 瞬时；任何惊吓性瞬态不得超过它（无重锤铁律的量化）；
- 低频纪律：层三低频 ≤80Hz 部分只从"耐压方向"来（声像固定），玩家可以用耳朵指方向——做不到就删；
- 耳机优先混音，音箱兼容检查；盲测验收（`11` G6）：不看画面能定位侍应方位与议程档位。
