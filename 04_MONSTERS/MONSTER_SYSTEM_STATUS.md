# 怪物体系状态

## 上位规则
原始文档明确：不要先做完整怪物谱系。威胁必须从**危机前身份 → 感知方式 → 动作矛盾 → 环境反应 → 玩家误判 → 可利用规律 → 代价**产生。

因此后期形成的 F01–F07 应重新分级：

### Production Canon
**F01 井身者 / Internal Depth** — 当前唯一 Hero 生产目标。

### Candidate Families / 机制候选族
- F02 相位者：表情/视线/头方向属于不同时间点；
- F03 测深像：通过建筑结构回声测量玩家；
- F04 错层客：身体区段处于不同深度/时间层；
- F05 神像者：过度完整、过度对称的“活图像”；
- F06 无水游体：身体相信房间里有水；
- F07 密集结构宿主：人体局部出现过度密集的自身结构。

它们不是“七类怪必须全部出现”。下一步若制作，必须重新绑定具体中国千禧生活身份和社会功能。

## 当前 Demo 怪物层建议

- F03 只作为“系统压力/感知对抗”的候选，不必立刻做高模；
