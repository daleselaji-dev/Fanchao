# 《返潮》H00-R0《婚宴后场：返席》—— 浏览器实时 3D 最终 Demo

> 潮来了，但水没有来；真正抵达陆地的是水深、压力、沉积、声学和时间留下的后果。

这是可直接在桌面浏览器里游玩的第一人称实时 3D 垂直切片，画面与手感对标 PS3《死魂曲：血之诅咒》的实机质感：低照度实用光源、720p 内部分辨率、胶片颗粒、轻色差、PS3 色阶。行为合同（归档、让行、侧向证据、复位、禁水声）与灰盒 v1 完全一致，并由同一个 `sim` 模块驱动、被自动化测试覆盖。

灰盒 v1 原样保留在 `demo/web-graybox/`，仅作行为合同的历史参照。

## 运行

```bash
# 仓库根目录
python3 -m http.server 8000
# 浏览器打开
#   http://localhost:8000/demo/web/
```

无构建步骤、无外网依赖：Three.js 0.180.0 已 vendor 在 `lib/`，全部贴图、几何、声音均为运行时程序化生成（Canvas + WebAudio 合成，零素材文件）。目标环境：桌面 Chrome / Edge / Firefox。

## 怎么玩（60–90 秒主路径）

你是 2001 年中国北方沿海小镇一场婚宴的后场临时录像员。散场了。唯一任务：把手里这盘录像带插回 C 房间卡座，按 REC/PAUSE 归档，回宴会厅。

| 键 | 作用 |
| --- | --- |
| 鼠标 | 转向（点击画面锁定指针） |
| WASD | 移动 |
| E | 在 C 卡座 2.4m 内插带归档 |
| Q（按住） | 借视：短暂接入返席人所在处的机位视角（重信号干扰——它是信息工具，也是不安来源） |
| R | 全局复位到 00 秒 |
| V | 设计标注层（旧路线 / 低处范围 / 机位） |
| M | 声音开关 |

路线：A 婚宴厅 → 南侧服务门 → B 后场走廊（浅处服务线 / 低处器材线二选一）→ C 录像室归档 → 返程再选一次 → 回 A。与此同时「返席人」沿 D→B→C门外→E→D 的旧后勤路线做普通工作：放盘、洗涤、擦手、整理箱位。

- 它不追你、不吓你、不撞你；你占它的道，它原地等你。
- 走低处：伴奏变厚变远、日光灯声被墙滤掉——信息与风险的交换。
- 蹲守低处巷、在 E/B 交界侧向看它：每圈至多一次、不超过 2 秒的侧向证据——它的前侧不再是脸。
- 建议佩戴耳机。这里的声音先于画面，且没有一滴水声。

## 自动化测试

```bash
npm install            # 只装 playwright-core（e2e 用）
npm test               # Node 状态机单元测试（纯逻辑，无浏览器）
node demo/web/tests/e2e.mjs [截图输出目录]
                       # Playwright + 系统 Chrome 实机通关：
                       # 归档 / 让行不推挤 / 证据每圈一次 / 低处声学 / 禁水声单 / 复位
```

e2e 需要本机有 Chrome（默认 `/usr/local/bin/google-chrome`，可用 `CHROME_PATH` 覆盖）；无 GPU 环境会走 SwiftShader 软渲染，较慢但可完整通关。`tests/shot.mjs` 可单独摆位截图。

## 模块

| 文件 | 职责 |
| --- | --- |
| `js/contract.js` | 单一事实源：房间/家具碰撞、实体路线、低处范围、节拍与数值合同（全部对齐 UE 版：3.6m/s、240UU 交互半径…） |
| `js/sim.js` | 纯逻辑状态机（Node 可跑）：移动碰撞、归档、让行、证据窗口、复位、事件流 |
| `js/materials.js` | 程序化贴图与材质：红桌布、竖褶椅套、做旧瓷砖、水磨石、复眼壳、CRT 动态画面…… |
| `js/world.js` | A/B/C/D/E 全场几何与 2001 婚宴后场道具，按材质合批 + 烘焙式阴影 |
| `js/player.js` | 第一人称：加速度包络步态、头部起伏、呼吸、落步事件、手持录像带 |
| `js/entity.js` | 返席人：程序化人形、工作/移动/等待/欠身/证据侧目动画 |
| `js/audio.js` | WebAudio 全程序化空间音频：伴奏、日光灯、CRT 高频、脚步、杯碟；低处滤波；**声源注册表全程禁水声词条** |
| `js/post.js` | 半浮点 HDR 渲染目标 → 全屏合成：颗粒、色差、暗角、S 曲线、借视信号干扰 |

## 设计红线（代码层面强制）

无可见水、无水声、无蓝色滤镜、无跳脸、无追击、无碰撞推回、无 RPG 数值 HUD。实体速度永不因玩家改变。侧向证据需要玩家主动走低处才兑现，每圈至多一次、≤2 秒。
