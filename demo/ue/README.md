# H00 UE 5.8 独立工程（官方主线）

`H00_Source/` 为 `FanchaoH00UE` 工程的 C++ 源码、配置与 Blender 灰盒脚本工作副本（原件在 `archive/05_实现参考/H00_Source/`，二者当前一致；后续修改只在本目录进行）。

- 空间不依赖资产：`H00DemoDirector` 在空 `Entry` 地图上运行时生成 A/B/C/D/E、归档台与实体航点。
- 输入：`WASD` 移动、`E` 交互、`R` 复位（经典 Axis/Action 绑定，见 `DefaultInput.ini`）。
- 行为回归：命令行开关 `-H00BehaviorTest` 用与玩家一致的距离门槛验证归档与复位。
