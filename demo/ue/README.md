# H00 UE 5.8 独立工程（官方主线）

`H00_Source/` 为 `FanchaoH00UE` 工程的 C++ 源码、配置与 Blender 灰盒脚本工作副本（原件在交接包 zip 内 `05_实现参考/H00_Source/`，二者当前一致；后续修改只在本目录进行）。

> 定位（2026-08-24 双栈裁决）：UE 5.8 是**正式产品栈**，本目录是其起点；UE 任务只指派给装有 UE 5.8 的本地开发机，云端 Agent 不领 UE 任务。Demo 执行栈见 `demo/web3d/`（Three.js，按 `docs/agent-playbook/` 制作）。裁决全文见 `docs/game-design/06_技术栈与制作工作流.md` §1。

- 空间不依赖资产：`H00DemoDirector` 在空 `Entry` 地图上运行时生成 A/B/C/D/E、归档台与实体航点。
- 输入：`WASD` 移动、`E` 交互、`R` 复位（经典 Axis/Action 绑定，见 `DefaultInput.ini`）。
- 行为回归：命令行开关 `-H00BehaviorTest` 用与玩家一致的距离门槛验证归档与复位。
