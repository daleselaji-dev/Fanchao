# 从原始文档恢复到当前项目的上位主题

## 1. “第二次失去”
返潮发生在产业、住房、地址、单位与共同记忆即将一起失去物质凭证的时候。家庭保存失踪者，不只是舍不得人，也害怕连“他曾经存在过的地方”都被拆掉。

## 2. 告别伦理（恢复原则，不锁死五步仪式）
原始传统最有价值的不是神秘步骤，而是四个伦理动作：
- 给无尸者暂时形体；
- 只使用亲自确认的部分；
- 有意留下不知道的部分；
- 在无法验证结果时离开。

后期不应重新把具体“五段送面礼”封死为唯一 Canon；保留的是“承认未知”的伦理。

## 3. 叙事空洞
创作者也不回答：失踪者最后经历了什么、返还物是否有本人意志、海/土地/媒介/家庭谁主动、所有记录一致是否等于真相。空洞不是续作谜底，而是伦理中心。

## 4. 被取消的内湾
不同年代地图对小镇中央旧水面给出不同解释。玩家围绕它行动，却不能进入一个“终极中心”。它把世界空间结构和叙事空洞统一起来。

## 5. 非怪物恐怖优先恢复库
高优先恢复：
- 婚宴录像比现实先完成普通动作；
- 一件家具同时进入旧家和新家；
- 海洋馆玻璃两侧都处在“陆地外侧”；
- 雾中公共广播不断改变同一个人的姓名/亲属/旧地址/新地址；
- 断网网吧继续一段危机前普通对话；
- 门诊无法用单一规则判断“危险者”。

它们比继续填怪物图鉴更能恢复《返潮》的独特性。
