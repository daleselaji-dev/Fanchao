# 宪法补丁 V2.1 —— 主机制条款

> 对 `05_DESIGN_V2/01_项目宪法_V2.md` 的增补与修正。冲突处以本补丁为准，其余条款不变。
> 依据：用户反馈（2026-08）——CRT 预现只是机制之一，不是玩法内核；拒绝窥视式主操作；主机制须视觉可读、操作可摸。

---

## 修正一：新增第 2.5 节「主机制轴」

三条恐怖轴（预现/残骸/喜事）之上，增设**唯一主机制**：

> **牵红（红绳席位系统）**：红绳=侍应动线=空间机关=玩家席位缆。玩家唯一核心动词是「摘/挂」。
> 定义与细则见 `06_GAMEPLAY_CORE/01_玩法内核_牵红.md`，该文件与本宪法同级。

三轴的玩法职能相应定位：

- 喜事轴 → 时钟（议程收网）；
- 残骸轴 → 质感与空间事件（玻璃承压、耐压收拢）；
- 预现轴 → **辅助信息层**（CRT 播下一档绳网与空间形态），不再承担主循环动词。

## 修正二：七问之「游戏机制」答案更新

原：「看录像侦察 → 对照现实找差异 → 议程压力下规划路线 → 声振管理 → 破像」。
改为：**「一眼读网 → 摘绳挂绳改写动线与机关 → 趁隙穿行 → 点名时寄挂保命 → CRT 预读下一档网 → 终局剪缆」**。

## 修正三：破像系统降级

`05_DESIGN_V2/04` §5 的破像配额管理（3+1 次）废止。破像收缩为终局唯一一次**剪缆**（剪断腕绳），承担原「大破像」的全部叙事职能（把自己的名字从席位牌上划掉）。CRT 的其余规则（预现、同步律、雪花、屏幕清单、映射规则）继续有效。

## 修正四：观看动词的地位

「走近屏幕自动聚焦」保留；但设计上不得出现任何**必须**通过观看屏幕才能获得的通关信息。屏幕给的是提前量，不是钥匙。

## 修正五：实体行为与绳网绑定

- 侍应巡逻路径的唯一真源是绳网拓扑（不再维护独立巡逻表）；
- 司仪点名的执行载体从「最后发声点」改为「玩家腕绳」；
- 浮客、回眸客、新娘与绳网的关系按 `06_GAMEPLAY_CORE/01` §3.3 执行。

## 修正六：禁止清单增补

- 禁止为主循环加入任何「举起物品进入观察模式」的操作；
- 禁止把导航信息藏进纯听觉通道（声音只做氛围、代价与预警的冗余通道）；
- 禁止给红绳增加第三个操作动词（如剪断普通绳、编织、张力调节）——摘/挂之外的任何绳操作立项前必须过八问并修宪。

## 生效声明

本补丁随分支 `cursor/gameplay-core-demo-76d0` 生效。`05_DESIGN_V2/10_Demo垂直切片规格.md` 的五幕表在本轮 Demo 中按 `06_GAMEPLAY_CORE/01` §6 的六拍压缩表执行；25–35 分钟完整垂直切片规格保留为下一 Gate 的目标。
