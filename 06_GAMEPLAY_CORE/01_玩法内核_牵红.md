# 玩法内核提案（已锁定）——「牵红」红绳席位系统

> 状态：**生效**。本文件是《返潮》的主机制宪章，与 `05_DESIGN_V2/01_项目宪法_V2.md` 同级。
> 本轮用户反馈已吸收：CRT 预现降级为辅助信息层；主循环不允许是「举机窥视」；
> 主机制必须视觉可读、操作可摸、贯穿全游戏、与喜事/伴娘/海残骸/CRT 咬合。
> 主机制只锁**一条**，附两条辅机制。不堆半成品。

---

## 0. 一句话

**婚宴上拦门、挂囍、系彩用的红绳，返潮之夜成了海的系泊缆——侍应只沿红绳走，门被红绳拦住，玩家手腕上也拴着一根通向那把空椅子的红绳。玩家全程只做一件事：把红绳从一个礼钩上摘下来，挂到另一个礼钩上去。**

正式名：**牵红**（动词即机制名——牵红线的「牵」）。

---

## 1. 主机制定义

### 1.1 世界规则（三条，全部一眼可见）

1. **红绳即动线。** 全楼的红绳张成一张网，两端挂在金色**礼钩**上。侍应（传菜员）不走地面路线，只沿红绳匀速滑行，像索道。看见绳，就看见了威胁的全部巡逻路径——不需要任何 UI、雷达或窥视。
2. **红绳即机关。** 拦门绳（蚀湾婚俗「拦门」的红绳）拴死的门开不了；吊起闸板/餐梯/枝形灯的红绳松开就落下。改挂一根绳＝改写空间。
3. **红绳即席位。** 玩家手腕拴着一根红绳（开场「借福」缠发的具象化），永远从手腕垂到身后、拖过整段走过的路，另一端在宴会厅那把空椅上。司仪点名时这根绳**绷直发亮**，最近的侍应会转上这根绳直线滑向玩家。

### 1.2 玩家动词（就一对）

| 键 | 动作 | 效果 |
|----|------|------|
| E（对绳头） | **摘** | 把红绳一端从礼钩上取下，拿在手里走 |
| E（对礼钩） | **挂** | 把手里的绳头挂上新礼钩，绳网即刻重排 |

派生用法（同一对动词，不加新键）：

- **改道**：把侍应正在走的绳挂到别处 → 巡逻路径当场改写（侍应滑到断点会停住，面向缺口站几秒，再沿新绳走——恐怖感免费）。
- **解拦门**：摘下拦门绳挂到旁边的空钩 → 门开。
- **落闸/放灯**：摘下吊着重物的绳 → 重物落下，砸出巨响（噪声代价）或砸出新路。
- **寄挂**（保命）：点名时，跑到任意礼钩对**自己手腕的绳**按 E → 把点名「寄」在钩上，侍应扑空。但每寄一次，腕绳变短变暗一截——**资源就写在自己手腕上**，不需要数字 UI。终局腕绳只剩最后一截，必须剪断。

### 1.3 为什么直观（对四条硬性要求逐条自证）

| 要求 | 自证 |
|------|------|
| 一眼能看懂 | 暗景里的大红绳是全画面最醒目的东西；绳=路径、亮=点名、短=资源，全部物理写在世界里，零抽象 UI |
| 操作简单 | 一个键、一对动作（摘/挂），WASD+鼠标+E 即全部操作 |
| 与背景咬合 | 拦门绳/挂囍绳/缠发红绳是真实中式婚俗物；「牵红线」本身就是婚姻词汇；系泊缆是海船词汇——喜事轴与残骸轴在同一根绳上会合 |
| 有创造力 | 敌人动线、空间机关、玩家资源、失败倒计时四个系统共用一个可见实体；改一根绳全网连锁重排，解法空间是拓扑的，不是开关式的 |

### 1.4 明确不是什么（防回潮）

- 不是窥视：全程没有「举起设备看世界」的模式切换；
- 不是听声走位：声音只做氛围与代价反馈，不承载导航信息；
- 不是礼仪/错误认领：玩家永远不被要求「做对某个礼节」，绳怎么挂没有「正确答案」，只有后果。

## 2. CRT 降级为哪一层辅助

CRT 保留 `05_DESIGN_V2/04` 的全部世界观规则（预现、同步律、雪花），玩法职能收缩为一层：

> **CRT = 下一档绳网的预告图。** 屏幕显示本空间在「当前议程+1」的形态——包括那时红绳会怎么张、侍应会在哪条绳上、哪扇门会被拦。走近自动聚焦，无按键、无模式切换、无次数限制；看不看都能通关，看了能提前布局。

- 破像系统保留但降级为**演出与终局**：终局大破像=剪断腕绳（见 §4.5），中途不再做破像配额管理。
- 「观看时背对房间」的阈限代价保留（屏幕摆位刻意背对最大入口）。

## 3. 核心循环

### 3.1 三十秒循环

```
进入空间 → 一眼读网（红绳张在哪、侍应在哪条绳上、门被哪根拦住）
→ （可选）瞥一眼 CRT：下一档网型预告
→ 摘一根绳 → 拿着走两步 → 挂上新钩 → 网重排（侍应改道/门开/闸落）
→ 趁空隙穿过 → 若司仪点名：腕绳绷亮 → 冲向最近礼钩寄挂
```

### 3.2 整局循环（议程时钟不变，继承 05_DESIGN_V2）

六项议程（迎宾→入席→上菜→敬酒→上头→送入洞房）仍是全局时钟。每次广播后全楼**收网一档**：红绳重新布线、变密、整体向宴会厅收拢——玩家肉眼看着这张网一晚上慢慢收紧成一个以宴会厅为中心的漩涡。CRT 永远比现实早一档播出网型。

失败仍是**被引座**：侍应沿绳滑到玩家面前，挽住手臂护送回宴会厅空椅（全程微笑礼貌）。议程走完时还坐在席上＝坏结局（桌牌翻成「上宾」）。

### 3.3 与怪物/空间如何互动

| 实体/空间 | 与红绳的关系 |
|-----------|--------------|
| 侍应 | 只沿绳滑行；点名后转上玩家腕绳；绳断则站在断点（静止威胁） |
| 司仪 | 点名的发起者；他的麦克风线是全楼绳网的总根（物理上没入舞台地板） |
| 浮客 | 每人腕上都有一根短红绳垂到地面接进网里——全场只有玩家的绳还长着 |
| 回眸客 | 上一场许潮的伴娘，腕上有一截**剪断过的旧绳头**；她的注视方向指向终局剪缆位 |
| 新娘 | 盖头之下不揭示；她与玩家的绳在主桌下方汇成同一个结（终局可见，不解释） |
| 拦门/闸板/餐梯/吊灯 | 全部由绳吊拴，摘挂即机关 |
| 海洋馆玻璃 | 玻璃承压段：绳网吊着检修闸，落闸的巨响会震裂玻璃——牵红与振动敏感规则咬合 |

## 4. 相对《死魂曲》的对照

| | 《死魂曲》 | 《返潮》 |
|---|---|---|
| 信息获取 | 视觉劫持：借敌人的眼睛看世界（需要切模式、门槛高） | **红绳网**：敌人动线直接物理画在空间里，不切模式、零门槛 |
| 张力来源 | 「我看见它看见我」的错位恐惧 | 「我改了一根绳，整张网都记得」的因果恐惧 + 议程收网的倒计时 |
| 战斗替代 | 弱战斗+躲藏 | 无战斗；拓扑改道 + 寄挂保命 + 引座失败演出 |
| 玩家资源 | 弹药/体力 | **自己手腕上那根越寄越短的红绳**（资源=命运，物理可见） |

我们用「把敌人的视野外化成世界几何」替代「借敌人的视野」——同等信息张力，操作成本降到一个键。

## 5. 辅机制（各一句话，不展开成系统）

1. **噪声值**（继承 05_DESIGN_V2）：跑步/落闸/拨绳过猛产生噪声，噪声超阈触发司仪点名——牵红的代价面。
2. **静默规则**（继承 09_音频方向）：每次广播前 3–5 秒全楼收声，静默即警报——牵红的节奏面。

## 6. Demo 落地范围（本轮交付的浓缩高密度切片，8–12 分钟）

空间环线：**宴会厅 → 服务走廊 → 大堂 → 海洋馆玻璃廊（连廊渗入段）→ 宴会厅（终局）**。
六拍议程压缩执行，每拍教或考一个牵红用法：

| 拍 | 议程 | 空间 | 牵红内容 |
|----|------|------|----------|
| 1 | 迎宾/入席 | 宴会厅（正常态·满员） | 教学：摘/挂、解拦门绳离席 |
| 2 | 上菜 | 服务走廊 | 侍应索道巡逻；改道通过；T02 屏预读下一档网 |
| 3 | 敬酒＝返潮点火 | 大堂 | 全楼收声→状态切换；首次点名→寄挂教学；解拦门进连廊 |
| 4 | 上头 | 海洋馆玻璃廊 | 玻璃承压；绳吊检修闸；改道+落闸抉择（响=裂） |
| 5 | 送入洞房 | 宴会厅（喉道化） | 浮客全体面向主桌；限时穿网抵达上宾空席 |
| 6 | 终局 | 主桌 | **剪缆**：按回眸客注视方向找到骨梳剪断腕绳→司仪失声→走出大门→海雾车灯→散场 |

被引座＝押回空椅坐下，站起（长按 E）再走，损失时间；第 5 拍限时内被引座且议程走完＝坏结局。
