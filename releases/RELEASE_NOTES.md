> 2001 · 蚀湾 · 南方大酒店。一场全镇出席的婚宴。
> 红绳是侍应的全部动线，也是你的席位缆。电视永远比现实先播一步。喜事不许退席。

## 一、下载即玩

### 方式 A：Windows 可执行包（推荐）

1. 下载 `FANCHAO-XiYan-Demo-win64.zip`（约 92 MB）。
2. 解压到任意目录。
3. 双击 `FANCHAO-win32-x64/FANCHAO.exe`。
4. 默认全屏启动；`F11` 切换全屏/窗口，`Alt+F4` 退出。

> 说明：包体为 Electron 便携壳（Chromium 108），无需安装、无需联网、不写注册表。
> Windows SmartScreen 可能提示"未知发布者"——因为未做代码签名，点「仍要运行」即可。

### 方式 B：Web 包（全平台，双击即玩）

1. 下载 `FANCHAO-XiYan-Demo-web.zip`（约 0.2 MB）。
2. 解压后**直接双击 `index.html`**——游戏完全自包含（单文件 bundle、程序化纹理与音频），
   无任何网络请求，Chrome / Edge / Firefox 均可直接以 `file://` 打开。
3. 若个别浏览器限制本地文件（极少见），用附带脚本起本地服务器：
   - Windows：双击 `start_server.bat`
   - macOS / Linux：`bash start_server.sh`
   - 然后访问 `http://localhost:8080`，按 F11 全屏。

## 二、v1.5 相对 v1.0 的升级清单（六轮精修）

> 交付前通过自建 PS5 观感测评（10 项全 PASS）：见 `07_QA/PS5_ART_RUBRIC.md`；
> 实机截图与 60 秒巡演视频证据见 `game/media/`。

### Round 1 · 画质底层

- **材质升级**：水磨石/瓷砖/海水提到 1024 分辨率并配**独立粗糙度贴图**；新增涤纶桌布
  （压折皱法线 + 席位处磨亮）与**锤纹金箔**两种新材质；丝绒各向异性暗纹保留。
- **后期再精修**：新增胶片 **halation 红晕**（高光向红金渗一圈——喜宴的「过亮」有了胶片依据）、
  邻域**锐化**、**双层颗粒**（静颗粒 + 缓慢走纹）、**呼吸暗角**、**软边 letterbox**；
  ACES 参数重标定。
- **区域电影曝光**：宴会厅 1.32（林奇式过亮的日常）vs 员工连廊 0.95（过暗的服务通道），
  跨区域时曝光缓变——从喜事走进后场，是「从一部片走进另一部片」。
- **贴地流动雾**×6：fbm 噪声滚动的薄雾层铺在走廊/大堂/海洋馆地面。
- 修复 SwiftShader 下 canvas 回读的 10 倍加载劣化（`willReadFrequently`）。

### Round 2 · 空间密度

- **宴会厅**：南门雕板金框 + 囍字剪纸、墙裙金线、红绸墙幔金穗、桌面红烛焰苗（烛心呼吸）、
  筷架折扇巾、花篮、麦克风架。
- **服务走廊**：灭火器、打卡架、湿洼反光、管线渍。
- **大堂**：总台账本/红包/算盘、立牌、行李车、柱面绸结、价目牌。
- **海洋馆连廊**：水底沉灯剪影、漂游的红盖头、带锈渍检票柱。
- **员工连廊**：货架杂物、褪色安全横幅、盘管消防带。门外：车影 + 雾灯。
- 红灯笼加发光内芯（透光感）。

### Round 3 · 实体表演

- **司仪**：金缘翻领/口袋巾/袖扣；下颌胡茬、太阳穴汗珠、烤红的耳缘；
  **广播时口部钙化颗粒随声蠕动**（声不由口出）、周期性正式鞠躬、身体缓慢追踪你的朝向
  （追踪速度随「同步律」逐拍加快）。
- **侍应**：白手套/黑领结/**跳号胸牌**（04、07、13）；闭目睑线 3 米可读、
  礼貌到不自然的浅笑双涡、左眼下干涸水线、颈侧盐渍白霜；
  警戒时**托盘瓷器细颤**（新增 porcelainRattle 音）、追逐时前扑**而托盘恒水平**。
- **回眸客**：长发水流感、双重曝光错位呼吸、暗色底影（亮背景可读）、被直视时退进空气里。
- **新娘**：盖头随你接近缓缓转向、近距珠旒细颤、腕上红绳。
- **浮客**：肤色分布；每 18–30 秒随机一位**瞬间**换朝向——没有动画，上一帧他还背对着你。
- 通用人形：翻领/纽扣/袖口白边/耳/鬓角/后梳发型。
- **修复隐藏美术 bug**：全部人形的五官贴图自装配起朝向身后（球体贴图旋转符号错误），
  修复后司仪的眼睛、侍应的闭目浅笑首次真正面向镜头。

### Round 4 · 交互手感

- **滞回吸附**：摘/挂目标一旦锁定，视线偏 20° 内不丢——手感不「滑脱」。
- **目标绳结呼吸放大**：可摘的绳结放大 1.35 倍脉动。
- **抓握呼吸感**：摘绳瞬间 FOV 收窄（拽），挂绳瞬间放宽（放）+ 相机冲击。
- **金环涟漪**：E 成功交互时准星处一圈金环扩散。
- **屏缘威胁指示**：侍应警戒/追逐时，屏幕左右缘按其方位泛起红纱——听觉之外的第二读法。
- 标题屏动态美术：CRT 扫描线、底部水面微光、浮烬、红绳穗结摆动；
  暂停/结算屏电影黑边 + 红线下划。教学文案缩短。

### Round 5 · 音频林奇化（建议佩戴耳机）

- **低频不安层**：41Hz 双正弦以 0.55Hz 差拍缓慢搏动，随议程逐拍加深；
  **收声时刻意不收**——静默是「压着的」，不是「没声音」。
- **静默前兆**：广播前全楼收声的瞬间，7kHz 极弱耳鸣浮出（安静得耳朵开始自己响）。
- **延迟声画**：每段广播/电铃 1–2 秒后从「另一个厅」迟到抵达（更闷、更小、偏一侧）；
  回声延迟随同步律收拢——终局时世界终于对上了拍。
- **空间自适应混响**：瓷砖走廊短亮 / 大堂厚软 / 海洋馆长暗——耳朵先于眼睛知道换了房间。
- **近身呼吸**：侍应 4.5m 内，他的吸气比脚步先到（0.32Hz 呼吸包络，立体声定位）。
- **耳机向母线**：DynamicsCompressor 粘合 + 房间底噪左右失谐展宽。
- 林奇氛围事件：隔墙笑声**戛然掐断**、大堂尽头**永不开门的电梯到站铃**、暗处水滴。

### Round 6 · 测评修洞

- 新建 `07_QA/PS5_ART_RUBRIC.md`：10 项 PS5 观感标准，全部 PASS 后才标交付。
- 三套自动化验证可复跑：六拍全流程冒烟（20+ 断言）、交互手感（真实键路径）、音频节点图。
- 全套实机截图 + 60 秒巡演视频重渲（终版管线）。

## 四、操作

| 按键 | 动作 |
| --- | --- |
| `WASD` | 移动 |
| `鼠标` | 环顾 |
| `Shift` | 快走（**有声**，会积累喧哗） |
| `E` | **牵红**：摘绳 / 挂绳 / 点名时寄挂腕绳 / 终局长按剪缆 |
| `Esc` | 暂停菜单（继续 / 重新开席） |

### 你需要知道的四件事

1. **红绳是侍应的全部动线**。他们只沿绳滑行——摘掉一段绳，那条走廊就安全；挂错一段绳，他们会出现在你要去的地方。
2. **绳也拴着门、闸和你的席位**。拦门绳摘下门就开；闸门吊绳挂到「绞盘钩」安静升起，挂到「卡扣钩」快但巨响。
3. **司仪点名时，腕上的红绳会亮**。冲到任意金色礼钩前按 `E` 把腕绳「寄挂」上去——每寄挂一次，腕绳就短一截。
4. **电视永远比现实先播一步**。CRT 里是这个空间"下一个稳定态"的预览——看见绳网怎么变，你就知道路会怎么变。

## 六、已知限制

- Electron 壳未做代码签名（SmartScreen 会提示）；exe 在 Windows 真机上未做人工回归（云环境无 Windows），
  但完全相同的 app 内容已在 Linux Electron 壳验证启动进拍，且同一 Web bundle 通过 20+ 断言自动化冒烟测试
  （六拍全流程 + 三个震惊节拍 + 双结局路径截图验证，全绿零报错）。
- 集显或低端机建议关闭其他占 GPU 的程序；如遇卡顿可用窗口模式（`F11`）缩小窗口。
- 存档：无（垂直切片一命通关约 10–15 分钟；被引座≠死亡，长按 E 站起来继续）。
- 黑暗节拍中侍应沿绳滑行会撞人（引座）——离发光的红绳远一点是设计内的求生规则。
- 语言：简体中文。

## 七、剧透警告：卡关速查

<summary>展开</summary>

- **东门出不去**：门上有拦门绳——对准绳端按 E 摘下，再挂到旁边任意空钩。
- **被点名**：别跑远，找最近的金色礼钩（发亮），按 E 寄挂。
- **走廊突然全黑**：别贴着红绳站——有东西正沿着绳过来。看得见绳就看得见它的路。
- **海洋馆闸门**：吊绳卡在「卡死位」。摘下来挂「绞盘钩」（高处，安静）；挂「卡扣钩」（近处）也能过，但巨响会引来东西，玻璃也受不了。
- **终局**：上宾席被红绳捆着（主桌东侧）。先摘捆席绳挂到别处，站到席位前**长按 E** 剪断腕绳——侍应会立刻扑过来，剪断前别松手。
