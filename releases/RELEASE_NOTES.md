# 《返潮 / FANCHAO》——「喜宴」垂直切片 v1.0

> 2001 · 蚀湾 · 南方大酒店。一场全镇出席的婚宴。
> 红绳是侍应的全部动线，也是你的席位缆。电视永远比现实先播一步。喜事不许退席。

## 一、下载即玩

### 方式 A：Windows 可执行包（推荐）

1. 下载 `FANCHAO-XiYan-Demo-win64.zip`（约 92 MB）。
2. 解压到任意目录。
3. 双击 `FANCHAO-win32-x64/FANCHAO.exe`。
4. 默认全屏启动；`F11` 切换全屏/窗口，`Alt+F4` 退出。

> 说明：包体为 Electron 便携壳（Chromium 108），无需安装、无需联网、不写注册表。
> Windows SmartScreen 可能提示"未知发布者"——因为未做代码签名，点「仍要运行」即可。

### 方式 B：Web 包（全平台，双击即玩）

1. 下载 `FANCHAO-XiYan-Demo-web.zip`（约 0.2 MB）。
2. 解压后**直接双击 `index.html`**——游戏完全自包含（单文件 bundle、程序化纹理与音频），
   无任何网络请求，Chrome / Edge / Firefox 均可直接以 `file://` 打开。
3. 若个别浏览器限制本地文件（极少见），用附带脚本起本地服务器：
   - Windows：双击 `start_server.bat`
   - macOS / Linux：`bash start_server.sh`
   - 然后访问 `http://localhost:8080`，按 F11 全屏。

## 二、v1.0 相对 v0.9 的升级清单

### 美术 / 渲染

- **电影级后期管线重写**：ACES filmic 调色 + 曝光控制、双尺度泛光（窄亮心 + 宽辉光）、
  胶片颗粒（暗部加重）、暗角、轻色差（冲击时加剧）、动画 letterbox（广播/终局收窄）、震惊闪白。
- **体积氛围层**：吊灯/射灯/灯泡下的体积光锥（与光源闪烁同步）、大厅/大堂/海洋馆漂尘粒子、
  海洋馆动态焦散投影（地面 + 墙面双层滚动）、大堂正门丁达尔光束。
- **五空间细节密度**：大厅红灯笼×6/藻井线脚/褶皱幕布/桌面茶壶蜡烛/花瓣彩屑/遗照相框；
  走廊滴水管/湿滑牌/拖把桶/摞椅/阀门；大堂停摆挂钟(23:58)/钥匙架/铜铃/装饰电梯/凝露玻璃门；
  海洋馆摇摆海带/沉没宴椅/藻痕；连廊胶皮条帘/白霜。
- **门外散场空地**：夜幕背景、双层海雾、径向柔光车灯（好结局迎面亮起）。

### 怪物 / 实体

- 司仪：512 面部纹理（不对称五官、血丝、毛孔、油湿高光）、胸花、鱼籽钙化湿反光。
- 侍应×3：差异化（身高/头倾/托盘内容——沉积皿/摞碗/金属罩）、闭目微笑面部、围裙；
  **预告转头**：追逐前先定住、头部锁向你、刺弦音——威胁可学习。
- 新娘：凤冠（金环 + 摆动珠串）、绣金「囍」盖头、桌下红绳拴向上宾席（终局可见的伏笔）。
- 回眸客：长发剪影、闪烁不定的半透明度、永远面向你。

### 玩法手感

- **交互准星**：摘绳/挂绳/寄挂三态变形 + 键帽式按键提示；剪缆进度环（SVG 环形读条）。
- **摘挂反馈**：挂绳回弹动画（绳松紧过冲）、礼钩挂上时弹跳 + 发光脉冲、相机冲击（挂上挑/摘下压）、
  呼啸/绞盘咔嗒音效；持绳时近处可挂礼钩温和呼吸发光——世界内指路，不用 UI 箭头。
- **教程**：开场 60–90 秒近乎无字——腕绳发光脉冲 + 门绳一次性微光引导，键帽短提示替代长说明。
- **引座演出**：被抓时强制面向侍应 + 收声 + 黑入 + 被按进空椅的低头视角。

### 震惊节拍（六拍之间的高光遭遇）

1. **走廊灭灯横穿**（拍 2）：灯管由远及近逐一熄灭——熄灭的顺序朝着你来；全黑中只有红绳网自发光，
   侍应贴着你沿绳滑过。
2. **暗影撞玻璃**（拍 4）：海洋馆长廊，玻璃后的暗影突然扑向你——巨响、裂纹、应急绿光。
3. **灯泡爆裂**（拍 4.5）：连廊灯泡炸开的一瞬，回眸客往前站了一步。
4. **终局收网强化**（拍 5）：正门轰然关闭、彩带坠落回弹、满厅红光、letterbox 收窄到剪缆。

### 音频

- 近身威胁层：侍应 6m 内渐强的高频微光 + 低频脉冲，**立体声定位**（威胁在左耳就在左边）。
- 绳鸣邻近层：载客的绳在附近嗡鸣。
- 新音色：刺弦 sting、玻璃巨响 boom、绞盘咔嗒、走廊滴水、灯泡爆、呼啸；拨弦支持声像。
- 广播混响尾音、议程静默规则保留并加强。耳机向混音。

### UI 包装

- 标题屏：绸纹动态底、噪点颗粒、金属渐变标题、脉动「囍」、装饰红绳曲线、开席/操作说明菜单、版本号。
- 暂停菜单：继续 / 重新开席 实体按钮面板。
- 结算：好结局车灯白入 + 制作名单滚动；坏结局桌牌 3D 翻转（伴娘→上宾）。

## 四、操作

| 按键 | 动作 |
| --- | --- |
| `WASD` | 移动 |
| `鼠标` | 环顾 |
| `Shift` | 快走（**有声**，会积累喧哗） |
| `E` | **牵红**：摘绳 / 挂绳 / 点名时寄挂腕绳 / 终局长按剪缆 |
| `Esc` | 暂停菜单（继续 / 重新开席） |

### 你需要知道的四件事

1. **红绳是侍应的全部动线**。他们只沿绳滑行——摘掉一段绳，那条走廊就安全；挂错一段绳，他们会出现在你要去的地方。
2. **绳也拴着门、闸和你的席位**。拦门绳摘下门就开；闸门吊绳挂到「绞盘钩」安静升起，挂到「卡扣钩」快但巨响。
3. **司仪点名时，腕上的红绳会亮**。冲到任意金色礼钩前按 `E` 把腕绳「寄挂」上去——每寄挂一次，腕绳就短一截。
4. **电视永远比现实先播一步**。CRT 里是这个空间"下一个稳定态"的预览——看见绳网怎么变，你就知道路会怎么变。

## 六、已知限制

- Electron 壳未做代码签名（SmartScreen 会提示）；exe 在 Windows 真机上未做人工回归（云环境无 Windows），
  但完全相同的 app 内容已在 Linux Electron 壳验证启动进拍，且同一 Web bundle 通过 20+ 断言自动化冒烟测试
  （六拍全流程 + 三个震惊节拍 + 双结局路径截图验证，两轮全绿零报错）。
- 集显或低端机建议关闭其他占 GPU 的程序；如遇卡顿可用窗口模式（`F11`）缩小窗口。
- 存档：无（垂直切片一命通关约 10–15 分钟；被引座≠死亡，长按 E 站起来继续）。
- 黑暗节拍中侍应沿绳滑行会撞人（引座）——离发光的红绳远一点是设计内的求生规则。
- 语言：简体中文。

## 七、剧透警告：卡关速查

- **东门出不去**：门上有拦门绳——对准绳端按 E 摘下，再挂到旁边任意空钩。
- **被点名**：别跑远，找最近的金色礼钩（发亮），按 E 寄挂。
- **走廊突然全黑**：别贴着红绳站——有东西正沿着绳过来。看得见绳就看得见它的路。
- **海洋馆闸门**：吊绳卡在「卡死位」。摘下来挂「绞盘钩」（高处，安静）；挂「卡扣钩」（近处）也能过，但巨响会引来东西，玻璃也受不了。
- **终局**：上宾席被红绳捆着（主桌东侧）。先摘捆席绳挂到别处，站到席位前**长按 E** 剪断腕绳——侍应会立刻扑过来，剪断前别松手。
