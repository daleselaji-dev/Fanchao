# 返潮 / FANCHAO

2001 年，中国北方沿海县镇"蚀湾"。南方大酒店的一场婚宴，是全镇献给海的祭礼；
酒店里所有老 CRT 永远比现实先播一步——你在屏幕里看到的，就是这个空间即将变成的样子。
玩家是伴娘，她会从录像里发现蚀湾婚俗的最后一条：**如果海不满意新娘，就收伴娘。**

## 🎮 可玩 Demo（「喜宴」垂直切片 v1.0）

**下载即玩：[`releases/`](releases/)** —— Windows 便携 exe 包 + 全平台 Web 包（双击 `index.html`）。
运行说明 / 系统要求 / 操作 / v1.0 升级清单 / 已知限制见 [`releases/RELEASE_NOTES.md`](releases/RELEASE_NOTES.md)。

  交互准星/剪缆进度环、发行级标题/暂停/结算 UI、凤冠绣囍新娘

## 从这里开始

**➡️ 当前唯一有效的设计入口：[`05_DESIGN_V2/README.md`](05_DESIGN_V2/README.md)**，玩法内核补充包：[`06_GAMEPLAY_CORE/`](06_GAMEPLAY_CORE/)

三条恐怖轴：

1. **预现** —— CRT 阈限录像先于现实（屏幕显示"当前空间正被返潮推向的下一稳定形态"）
2. **残骸** —— 海残骸生态（干燥的深海时间：深压蠕变 / 附居寄生 / 沉积时间 / 空间耐压）
3. **喜事** —— 不许退席的婚宴（议程时钟：迎宾→入席→上菜→敬酒→上头→送入洞房）

技术栈：Three.js + GLB（True Mesh）Web Demo + Blender DCC 资产管线。
