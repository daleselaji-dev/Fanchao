# 返潮（Fanchao）

2001 年，中国北方一座海边小镇。**潮来了，水没有来。** 被海送回来的人开始回家——干燥的婚宴厅里，一个穿旧蓝工装的男人背对你收拾桌子，动作熟练得让人安心；绕到侧面才看见，他没有正面。

与《死魂曲 / SIREN》同量级的民俗恐怖：单主角、章节制；画质目标不低于优秀 PS3 后期作品。
