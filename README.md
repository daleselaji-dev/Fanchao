# 返潮（Fanchao）

2001 年，中国北方一座海边小镇把送无尸亲人归海的「归面礼」做成了召回。潮来了，水没有来，水深来了。

本作目标是与《死魂曲 / SIREN》同量级的民俗恐怖：单主角、章节制；画质不低于优秀 PS3 后期作品。现行设计入口：
