# 当前 M01 婚宴酒店 Vertical Slice — 接手规格

## 目标体验 10–15 分钟
1. **Normal**：玩家进入可信的千禧婚宴酒店，先建立空间与社会功能。
2. **Leak**：服务走廊出现第一组可测量的 Depth 错误，教学听潮。
3. **Measure**：F03 类“结构测深”机制作为系统压力（不要求当前立刻制作第二 Hero）。
4. **Return**：玩家回到婚宴大厅，空间进入 Prophecy，但仍是同一酒店。
5. **F01 Encounter**：怪物 Local Depth 与玩家读距/空间逃生发生冲突。
6. **Aftermath**：逃脱后留下关系/证据层的余波，而不是只做“过关”。

## 当前必须恢复的原始项目层
Demo 不应只验证 Depth。至少加入一个“非怪物恐怖/社会系统错误”的事件，优先：**婚宴录像比现实先完成动作**。这样 M01 同时验证物理核心和叙事核心。

## 完成定义
- 正常生活底片可信；
- 一个异常规律可学习；
- 一次听潮有真实收益和暴露；
- F01 6m/2m 都成立；
- 玩家一次正确操作带来一个明确代价（证据、路线、关系或安全性）；
- Runtime 实际打开、可见、可操作、可重置。
