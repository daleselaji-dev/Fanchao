返潮 / FANCHAO — M01 Demo Visual Walkthrough

说明：这是当前设计的非交互视觉 walkthrough，用来让下一 Agent 快速理解 Demo 节奏；它不是一个已经通过 Runtime Gate 的可玩 Build。历史 H00 Unreal Source/Graybox 在本目录 HISTORICAL_H00 中。
D00 / D01 — 入口 → 婚宴大厅 Normal

先建立真实 2000/2001 婚宴酒店：红金舞台、圆桌、旧灯、瓷砖和收场后的生活痕迹。没有怪物先行。

D02 — 服务走廊 Leak

第一次明确 Depth 泄漏。玩家学习听潮：得到结构信息，同时暴露自己的位置。

D03 — 后场 / 设备节点

用电话、CRT、录像带、文件柜、推车等千禧后勤物件建立现实功能；这里应恢复一个声音/媒介恐怖事件，例如婚宴录像提前完成现实动作。

D04 — 返回婚宴大厅 Prophecy

不是换地图，而是同一建筑逐渐接受错误 Depth。Normal / Leak / Prophecy 的关系见下图。

D05 — F01 Hero Encounter

6m 首先读成真实酒店员工；2m 才发现双眼与口腔内部存在不可能纵深。核心不是杀怪，而是读懂/打断其感知并利用空间逃离。

D06 — 余波

结尾不只给“逃脱成功”，应留下一个原始项目的伦理代价：证据、关系、路线或安全空间发生改变。
