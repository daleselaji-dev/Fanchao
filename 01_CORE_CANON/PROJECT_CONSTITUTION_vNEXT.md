# 《返潮》Project Constitution vNext

## 1. 双北极星
### 物理
**潮来了，但水没有来；真正抵达陆地的是水深、压力、沉积、声学和时间留下的后果。**

### 叙事
**本应结束的人、关系、地址、制度和称呼，仍继续给人分配位置；保存也可能成为禁止改变的占有。**

任何新设计必须同时能服务至少其中一条，并不得破坏另一条。

## 2. 稳定核心
- 中国 1999–2004 沿海小城，现实生活先成立；
- 小镇曾经历海湾生活、单位工业化、九十年代解体与 2000 年“第二次失去”；
- 返潮不是单一怪物、科学现象或仪式诅咒；
- Dry Depth、Pressure Front、Local Depth Field、听潮是当前可玩物理层；
- 正常系统仍履职，但服务错误的人、年代、地址或关系；
- 玩家能学习局部规律，但不能通过万能系统征服全部异常；
- 最有效的干预必须改变路线、证据、关系、住所或资源；
- 叙事空洞不能被终极档案/老人/怪物填满。

## 3. 视觉宪法
**可信生活 + 正常系统继续履职 + 一个对应关系物理失效 + 动作/材料/声音给证据。**

- 一个事件只证明一个主要不可能；
- 材料保留自身本质；
- 人保留普通身份与衣物；
- 声音与动作先于怪物特写；
- dreamcore 来自社会功能的记忆残留，而不是空房间/VHS 滤镜；
- 空场景必须先让玩家见过它被人使用，才有“空”的重量。

## 4. “死魂曲的骨架，双峰的血肉”只作为方法
- 《死魂曲》：共同体灾变、普通人连续异变、多视角局部经验、真实生存压力；
- 《双峰》：温暖日常、怪人、幽默、秘密、亲切与危险共存；
- 《返潮》自己的灵魂：中国千禧海镇、保存与占有、地址/身份反转、告别中的未知、媒介与公共系统继续分配人。

## 5. 当前技术宪法
- 最终角色、场景、碰撞和 gameplay 主体必须是真 Mesh；
- GLB / Three.js 是当前最终技术目标；
- 3GS / splat / image plane 只可辅助，不可作为主体；
- Runtime 必须实际打开、可见、可操作；
- Hero Sculpt Lock 前不做最终贴图和正式 Rig；
- 正式贴图源使用生图能力，再进行 UV/PBR 适配。

## 6. 设计评审八问
1. 去掉超自然后，地点和人物是否仍像真实生活？
2. 是否具体属于中国千禧海镇？
3. 正常系统原本为谁做什么？
4. 返潮使哪个方向/对应关系反了？
5. 玩家能否从画面/动作/声音自行证明？
6. 玩家能观察、误判、学习和干预什么？
7. 最有效的干预会失去什么？
8. 是否偷偷填满了必须保留的叙事空洞？
