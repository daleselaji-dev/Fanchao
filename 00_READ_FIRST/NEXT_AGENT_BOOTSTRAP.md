## 第一轮唯一 P0
**F01 Hero Sculpt，不扩第二怪、不做最终贴图。**

### Gate A — 普通人
用可靠真实男性 base mesh / DCC / 高质量 Image→3D，先拟合普通 40–50 岁酒店员工。FRONT/SIDE/BACK 通过。

### Gate B — 身份头部
Gold + 头部 3/4：额头、颧骨、鼻梁、耳、下颌、短发必须像同一个具体人。

### Gate C — Internal Depth
只加入双眼井 + 口腔井真几何。边缘仍属于完整人脸，井腔内部有真正空间层级。

### Gate D — 6m
先看成人，再觉得头不对。

### Gate E — 2m
明确读出“里面比外面大”，但不是伤口、面具、贴图黑洞。

### Gate F — Sculpt Lock
只有 A–E 全 PASS，才能进入：生图贴图 → UV/PBR → Rig → Motion → Three.js integration。

## 项目级不要忘记
角色资产只是项目 Gate 6 的子流程。每个新场景/怪物仍要先过：
**Canon → Space → Behavior → Reality → Anomaly → Asset → Runtime。**
