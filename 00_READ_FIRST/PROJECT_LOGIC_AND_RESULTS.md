# 当前项目逻辑与工作结果总览

## 1. 《返潮》现在最完整的核心逻辑

项目有两条同等重要的北极星。

### 物理北极星
> **潮来了，但水没有来；真正抵达陆地的是水深、压力、沉积、声学和时间留下的后果。**

空间保持干燥，却承受了本应只属于深海的“Depth”。因此形成当前游戏层的四个核心系统：
- **Dry Depth**：没有水，但空间拥有深度环境状态；
- **Pressure Front**：相邻空间可以拥有不同 Depth；
- **Local Depth Field**：部分威胁携带移动深度场；
- **Structural Listening / 听潮**：玩家从建筑结构读取信息，同时把自身暴露给会“听结构”的威胁。

### 叙事北极星
> **本应结束的人、关系、地址、制度与称呼，仍在继续为人分配位置；保存一个人，也可能变成禁止他改变和离开。**

原始《返潮》不是“应该忘记死者”的故事，而是讨论：记忆、家庭、档案、地址、照片、录像和礼俗什么时候从保存变成占有。玩家越追求完整答案，越接近镇民追求“一个没有缺口的亲人”。

这两条必须同时成立：**Depth 负责物理与玩法，关系/身份/媒介负责作品的灵魂。**

## 2. 世界背景
- 时间：约 1999–2004，核心气质集中在 2000/2001。
- 地域：真实中国北方/沿海小城；旧版地名为“蚀湾”。
- 历史：海湾生活 → 单位工业化 → 九十年代松动 → 2000 年前后“第二次失去”。
- 第二次失去的对象不只是人，而是厂房、宿舍、旧地址、单位、广播、旧地名和共同生活的物证。
- 小镇不是神秘村，也不是废墟主题公园；危机前必须有人认真工作、办婚宴、搬家、登记、值班和使用公共设施。

## 3. 返潮如何显形
### 物理层
- 干燥空间出现深海压力后果；
- 材料仍保持自己的本质；
- 声音距离/介质关系错误；
- 空间存在不同 Depth 状态；
- 建筑边界成为 Pressure Front。

### 社会层
- 已结束的制度继续安排人；
- 旧地址重新“认领”住户；
- 房间按关系而非建筑归属重连；
- 旧称呼把活人压回过去身份；
- 家庭与公共系统继续替缺席者安排位置。

### 媒介层
- 录像不只记录过去，而会提前完成现实动作；
- 广播把同一个人送回不同关系和地址；
- 电话/录像/网吧聊天让家庭记忆继续生产“新证据”；
- 声音可发生地点错位、时间错位、身份错位。

## 4. 空间逻辑
原始世界地图与当前关卡地图应并存：

### 世界地理（原始）
公路/新市场 → 家属区 → 食堂/澡堂/卫生所 → 厂区/冷库 → 泵站/涵洞 → 旧村/坡地 → 学校/档案/广播 → 滩涂/船道。

城镇围绕一片“被取消的内湾”生活：老地图、新规划、排水图和居民记忆对它有不同解释。玩家能绕着它移动，但不能得到一个终极“中心真相”。

### 当前可制作地点组
- M01 婚宴酒店（第一 Demo / Hub）
- M02 老商场
- M03 招待所/宾馆层
- M04 临海公建
- M05 近海基础设施
- M06 滩涂边缘居住区

## 5. 当前 Demo 逻辑
当前设计优先 M01 婚宴酒店：
入口 → 婚宴大厅 Normal → 服务走廊 Leak → 后场 → Prophecy 大厅返回 → F01 遭遇 → 逃离余波。

核心循环：
异常 → 听潮 → 得到信息并暴露 → 威胁测量/重新获得玩家 → Local Depth 靠近 → 利用门、障碍、空间结构和 Pressure Front 逃生。

原始 H00-R0《婚宴后场：返席》是历史验证：它用“归档录像带 + 实体沿旧后勤路线继续工作”证明了空间、行为合同和非随机追逐的重要性。旧 UE Source/灰盒保留在本包，但不是当前最终 Demo 技术主线。

## 6. 当前怪物结论
### F01「井身者」— 当前唯一 Hero production target
- 40–50 岁中国旧酒店男员工；
- 灰蓝工装、暗红领边、深色裤、旧工作鞋；
- 6m 首先必须像真实的人；
- 2m 才清晰发现双眼与口腔内部拥有不可能的纵深；
- 恐怖是“里面比外面大”，不是伤口/黑洞/腐烂。

### F02–F07
应理解为**怪物机制/视觉语法候选族**，不是必须填满的怪物图鉴：相位脸、测深像、错层客、活神像、无水游体、密集结构宿主等。它们必须从具体社会身份、感知方式、行为、玩家误判和可利用规律中重新验证后才可升格。

## 7. 当前已确认的美术语言
**先真实，再异常。**
- 千禧中国小城现实；
- 普通相机/婚礼录像可以记录的世界；
- PS3 时代高水准日式生存恐怖的运行时可信度；
- practical lighting、真实材料、正常社会功能；
- dreamcore/liminal 来自“功能仍在，但在等错的人/距离错了”，不是滤镜。

禁止 generic 捷径：鱼怪、触手、蓝色水下滤镜、黏液、Gore 主导、黑红邪教、VHS glitch、现代 glossy UE showcase。  
“重雾禁止”应理解为**禁止通用恐怖白雾**；真实沿海海雾仍可作为尺度/声音条件使用。

## 8. 最重要的工作成果
### 世界/设计
- Dry Depth / Pressure Front / Local Depth / 听潮 已形成清晰系统；
- Normal / Leak / Prophecy 三态成立；
- 千禧阈限/梦核定义成熟；
- 世界地图与 M01–M06 关卡组成立；
- 声音/媒介原型库仍值得恢复；
- 原始叙事空洞与“保存 vs 占有”应恢复为上位主题。

### 视觉/资产
- F01 当前 Gold 已通过方向 Gate；
- F01 正/侧/背/头部 3/4 参考链已形成；
- 婚宴大厅、服务走廊、楼梯、Hero Props 有关键参考；
- 多次失败验证了 simple visual hull / 程序化人偶不可作为 Hero 最终路线。

### 技术/流程
- 最终主体必须 True Mesh / GLB / Three.js；
- 3GS/2.5D 可作为重建辅助，不能是最终主体；
- Runtime 文件存在不算通过，必须实际可见、可操作、加载失败可诊断；
- Sculpt Lock 之前不做最终贴图/Rig；
- 正式贴图源以后用生图能力生成，再 UV 对齐/PBR 化；
- F01 角色必须过 6m / 2m 双 Gate。
