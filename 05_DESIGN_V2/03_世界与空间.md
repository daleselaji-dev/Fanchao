# 世界与空间总设计

> 覆盖旧稿的小镇开放空间与莫比乌斯全镇设定（Demo 阶段不做全镇）。
> Demo 世界 = **南方大酒店（四层）+ 员工连廊 + 蚀湾海洋馆西侧公共区**。一栋半建筑，做透。

---

## 0. 总平面

```
             [蚀湾·海]  ……海雾，不可达……
                 │
   ┌─────────────┴─────────────┐
   │        海洋馆 西侧公共区      │
   │  S01停车场入口  S02售票大厅   │
   │  S03员工走廊    S04旧处理间   │
   └───────┬───────────────────┘
           │ 员工连廊（旧冷库结构，二层高差）
   ┌───────┴───────────────────┐
   │        南方大酒店            │
   │ 1F 大堂 / 宴会厅 / 服务走廊  │
   │ 2F 回廊 / 中餐厅 / 保卫科    │
   │ 3F 客房层（107走廊在此）      │
   │ 4F 客房层 / 807新娘套房      │
   └───────────────────────────┘
```

- 酒店与海洋馆共用九十年代末填海工程建材与旧冷库结构——这是残骸生态在两栋建筑同时生效的物质理由，也是连廊存在的理由。
- 玩家动线是一条大回环：套房(4F) → 宴会厅(1F) → 服务走廊 → 大堂 → 连廊 → 海洋馆 → 连廊 → 保卫科(2F) → 套房(4F) → 宴会厅(终局)。没有开放世界，没有回头浪费。

## 1. 南方大酒店整体空间

### 1.1 身份

1998 年开业，蚀湾最体面的建筑。红漆总台、仿大理石地面、金色不锈钢包边、红地毯大楼梯、镜面柱、塑料绿植、大堂吊灯。名字与楼梯间标识以原型图 `worn_chinese_hotel_stairwell_landing.png`（"南方大酒店"）为准。

### 1.2 分层功能与异常分配

| 楼层 | 空间 | 正常态功能 | 主异常（唯一） | 支持证据 |
|------|------|-----------|---------------|----------|
| 1F | 大堂 | 迎宾、签到、行李 | **上宾重组**（古海前肢从建材脱离） | 水磨石失泽、负形空洞、雾腔 |
| 1F | 宴会厅 | 婚宴主场 | **空间耐压**（墙面向内收拢成喉道，见三态设计稿） | 喜事层下垂、桌面沉积 |
| 1F | 服务走廊 | 传菜、备餐 | **沉积时间**（票据/鱼鳞/纤维分层薄板） | 墙面同心波纹、天花缓降 |
| 2F | 回廊 | 俯瞰大堂 | 承接大堂上宾的外板桥面 | 栏杆蠕变 |
| 2F | 保卫科监控室 | 监控墙、录像带架 | **预现集中地**（九宫格监控全部先播） | 磁带沉积、机柜附居 |
| 3F | 客房走廊（含107） | 客房 | **耐压收拢**（一侧墙显露船壳弧面，原型图 door 107） | 门框失矩、地毯湿线 |
| 4F | 807 新娘套房 | 闺蜜仪式 | **镜面/屏幕预现**（梳妆镜与客房电视先播） | 喜服悬浮、脸盆沉积 |
| — | 楼梯间 | 贯穿动线 | 楼层标识与实际层数错位一层（轻量，唯一的空间诡计） | 声学变深 |

规则：**每空间只有一个主异常**，其余证据只做可信度，不抢戏。

### 1.3 酒店事件节拍（议程时钟）

议程由司仪广播宣布，全楼生效。时间为剧情内时刻：

| 议程 | 时刻 | 广播词（示例） | 全楼变化 |
|------|------|---------------|----------|
| 迎宾 | 18:00 | "各位来宾，欢迎光临周府喜宴" | 正常态。大堂满员，玩家自由熟悉空间 |
| 入席 | 18:30 | "请各位来宾入席" | 宾客入宴会厅；走廊清空；CRT 开始出现偏差 |
| 上菜 | 19:10 | "喜宴开席" | 服务走廊侍应动线激活；第一次可见渗漏态 |
| 敬酒 | 20:00 | "有请新人向各位来宾敬酒" | **返潮点火**：全楼收声→吸气→状态切换；玩家从此回不到正常态 |
| 上头 | 22:30 | "吉时已到，请全福人上前" | 套房仪式反转；全福婆激活；玩家必须已拿到关键情报 |
| 送入洞房 | 23:48 | "送——入——洞——房——" | 终局。宴会厅完全喉道化；强制大破像或坏结局 |

- 议程之间的实际游戏时长由玩家推进关键事件触发（软时钟），但**议程顺序与广播词固定**，玩家永远知道下一步是什么——知道却拦不住，是喜事轴的核心体验。

## 2. 大堂宴席（1F 大堂 + 宴会厅）

### 2.1 宴会厅空间

- 以原型图红金大厅系（`空荡的红金婚宴大厅.png`、`婚宴散场后的红色大厅.png`）为空间基准：两层挑高、舞台红幕、金字囍、圆桌×12、主桌居前。
- **主桌细节（喜事轴的第一批可发现证据）**：多摆的一副碗筷；空着的"上宾"席（椅背搭红绸，桌牌写"上宾"二字）；八只酒杯中一只倒扣。
- 三态直接采用 `banquet_hall_states_of_transformation.png` 设计稿：
  - 正常态：满员喜宴，暖光，喜歌；
  - 渗漏态：散场后的残宴，剩菜沉积、椅子堆叠、红布浸湿下垂；
  - 预现态（喉道化）：墙面向内收拢成软腭般的弧面，囍字与 CRT 荧光仍亮——只在屏幕里出现，直到终局议程它成为现实。

### 2.2 大堂空间与"上宾"遭遇

继承旧稿《古海外壳与电视预现原型 v0.1》第 4、5 节已验证的设计，收编如下：

- 危机前玩家已在相同机位见过满员大堂；敬酒（返潮点火）后再进入，大堂无人，只剩行李、鞋印、还在播的设备。
- 遭遇节拍（固定七步）：
  1. 前台 CRT 里，一条巨大分节前肢已从大堂地面弯至三层回廊；
  2. 抬头看现实：只有雾和空栏杆；
  3. 屏幕里过滤叶片从"未来的玩家"身后合拢；
  4. 现实中水磨石沿同一弧线失去光泽，骨料细密爆裂；
  5. 第一块房间尺度外板从地面整体翘起，留下深黑湿润负形；
  6. 其余外板分别从柱体、楼梯侧墙、二层栏板脱离，在空中围绕看不见的软体取得关节位置;
  7. 整条前肢横切玩家熟悉的动线，压弯栏杆、推开雾、吊灯偏转，全程无咆哮。
- 玩法：上宾靠振动感知。红毯上安静、瓷砖与金属栏杆危险；前台电话、行李车、电梯铃是可用的假振动源。目标是**穿过大堂进入连廊**，不是击杀。

## 3. 蚀湾海洋馆（西侧公共区）

继承旧稿《海洋馆局部美术包 G2 v0.1》的空间与两大事件，收编并接入新叙事：

### 3.1 叙事身份

- 婚礼当天下午，婚庆流程包含"新人海洋馆外景拍照"，玩家（伴娘）随行——这是海洋馆正常态的登场理由，也是摄像师录像带的拍摄现场。
- 返潮之夜玩家重返海洋馆的理由：保卫科监控墙显示，摄像师最后出现在海洋馆售票大厅；他手里的母带拍到了"上一场许潮"。

### 3.2 空间清单（首期只做四间）

| 编号 | 空间 | 事件 |
|------|------|------|
| S01 | 停车场入口 | 正常态外景参照；夜间成为"没有远方的广场"（雾中只剩数米内的巴士局部） |
| S02 | 售票大厅 | **玻璃承压事件**：固定件依次弹响→反射先弯→玻璃中央内陷→胶条挤出→门开雾入回弹 |
| S03 | 员工走廊 | **墙体转移事件**：近处按压凹陷、远端沿旧门轮廓隆起、排水后旧门框获得深度 |
| S04 | 旧处理间 | 新馆材料在门口结束，内部保留旧冷库比例与声学；找到摄像师与母带的地方 |

- 两大事件的资产表、关键帧规格、机位（C01–C05）直接沿用 G2 美术包 v0.1，不重写。
- 新增接点：S02 售票台后的小 CRT 是海洋馆区域的"必看屏"；S04 旧处理间墙上有与酒店楼梯间同款的旧冷库编号牌——两栋建筑同源的实物证据。

### 3.3 海洋馆节拍

1. 进入 S01：夜雾，巴士残影，灯箱的光像隔着港池；
2. S02：CRT 预现玻璃内陷 → 现实中固定件开始弹响 → 玩家沿墙通过（不许跑，玻璃对振动敏感）；
3. S03：墙体转移解谜——按压近处凹陷驱动远端旧门轮廓开启，进入 S04；
4. S04：拿到母带；返程时 S02 玻璃已达内陷第三态，原路封死，走排水沟通道回连廊。

## 4. 闺蜜仪式（4F·807 新娘套房）

### 4.1 仪式原型（真实婚俗，做扎实正常态）

**上头**：新娘出嫁前的梳头仪式。全福人（有丈夫有儿女的"好命"妇人）执梳，念吉语："一梳梳到尾，二梳白发齐眉，三梳儿孙满地。"闺蜜在旁递镜、扶发、点红烛（2001 年简化为台灯与蛋糕蜡烛）。

### 4.2 正常态节拍（Demo 开场，约 5 分钟）

1. 玩家（第一人称）在 807 帮新娘周絮整理婚纱；可自由查看房间：梳妆镜、客房电视（播中央台）、喜服、双喜脸盆、窗外海雾；
2. 全福婆到场，上头仪式：玩家被要求**手持镜子**——镜中构图 = 之后所有预现画面的构图基准（教学：本作的"看屏幕"从看镜子开始）；
3. 吉语第三句时，电视雪花一闪，画面变成**同一个房间的俯拍**——只有玩家（镜中）注意到；周絮笑着说"信号总这样"；
4. 全福婆向玩家要一样东西："借你一点福气"——取走玩家的一根头发缠在梳子上（伏笔：影子的登记）；
5. 下楼赴宴，开场结束。

### 4.3 反转态节拍（"上头"议程，22:30，约 6 分钟）

玩家因剧情被迫回到 807（母带需要用客房录像机播放）：

1. 房间保持白天布置，但**镜子先播**：镜中的房间里，上头仪式正在重新进行——梳头方向反了，吉语被替换（"一梳梳到底，二梳沉到底，三梳到了地"），坐在镜前的新娘背影，镜中没有脸；
2. 播放母带（客房电视）：上一场许潮的婚礼录像——同款红金大厅、同款仪式；录像最后，摄像机转向当年的伴娘，她的桌牌被换成了"上宾"；**这是玩家得知"影子顶替"规则的时刻**；
3. 电视失去信号的瞬间，房间灯灭，唯一光源是镜子——镜中的全福婆已转过头（第三只眼睁开，参考 `诡异餐厅走廊中的镜像女侍者.png`）；现实中，梳齿声在玩家**背后**响起；
4. 玩法段：不许回头（回头即被"梳到"），倒退面向镜子退出房间——镜子是唯一能看到全福婆现实位置的"屏"；
5. 出门时广播响起："吉时已到，请全福人上前。"玩家意识到楼下的上头对象即将换人。

### 4.4 "贪图"的处理

旧稿中"闺蜜的贪图"方向保留为**动机底色，不做玩法**：周絮嫁的是玩家高中时喜欢的人；开场对话与房内细节（合影、旧信）轻描一笔即可。它解释玩家为何心绪不宁、为何被全福婆选中"借福"，但游戏不检验玩家的道德，不做选择题。
