# 禁止事项与淘汰说明（防回潮清单）

> 本文件的作用：让下一位 Agent 在想到"好点子"时先来这里查一遍。
> 每条淘汰项都写明**它是什么、为什么淘汰、它的残值去了哪**——避免既回潮、也避免把有效残值一起扔掉。

---

## 1. 明确淘汰的旧设定

### 1.1 礼仪玩法 / 礼节系统

- **是什么**：让玩家执行敬酒顺序、鞠躬角度、称呼选择等社交礼节交互的玩法方向。
- **为什么淘汰**：繁琐不恐怖；把 cult 张力做成了 QTE 答题；表演成本高而画面无冲击。
- **残值去向**：仪式感由议程时钟、场面调度、偏差清单（`06` §3）承担——玩家**目睹**规程，永不**执行**规程。

### 1.2 "错误认领 / 记错人"机制

- **是什么**：NPC 把玩家或他人错认成别人、记忆错位类机制。
- **为什么淘汰**：依赖理解 NPC 的内心状态，无法用画面表现；玩家的实际体验是困惑而不是恐惧。
- **残值去向**："身份被指派"保留为影子规则——但它是**看得见的**：桌牌、同料裙、缠发骨梳、录像里前代伴娘的下场。全部实物证据，零内心戏。

### 1.3 "归面 / 过量安置"背景

- **是什么**：以送面礼、归面仪式、"过量安置逝者"为核心的背景设定群。
- **为什么淘汰**：无法现实落地——需要大量文本解释才能理解，一张图读不出；且民俗构造过于架空，演出抓手弱。
- **残值去向**："小镇拒绝让事情结束"的情绪内核由**喜事必须办完**承载——办喜事是不需要解释的中国民俗画面。仪式类残值收拢为一场婚礼内的真实婚俗（上头、全福人、伴娘），全部有现实原型。

### 1.4 "X鬼"命名体系（误解鬼 / 代价鬼 / 证据鬼）

- **是什么**：按抽象概念给怪物分类命名的体系。
- **为什么淘汰**：名字里没有画面；按概念造怪导向零散怪谈合集；"鬼"字直接把美学拉向廉价灵异。
- **残值去向**：宴席工位命名法（`07` 文档）——名字=工位=功能=画面，司仪/上宾/侍应/全福婆/回眸客/浮客。

### 1.5 "代价 / 误判 / 认错人"核心恐怖

- **是什么**：把恐怖的重心放在玩家决策代价与认知误判上的方向。
- **为什么淘汰**：抽象，验证成本高，Demo 里做不出"第一眼就怕"的画面。
- **残值去向**：三轴全部是第一眼可拍的：屏幕先播（拍得出）、残骸证据（拍得出）、不许退席的喜宴（拍得出）。决策压力仍然存在（破像花在哪、何时冲），但它是资源管理，不是恐怖来源。

### 1.6 抽象哲学论文式文档

- **为什么淘汰**：上一版大量篇幅在论证"保存与占有""叙事空洞"等命题，无法转化为资产与代码任务。
- **残值去向**：本包所有文档强制带落地方式/资产表/触发表/通过条件；宪法立项八问第 1 条即"能否被一张图读懂"。

### 1.7 旧怪物具体方案

- **F01"内里深度"（眼口井穴的酒店职员）**：高模连续两轮未过 Gate，且"体内空间大于体表"不属于四证据语汇。淘汰。构图残值（制服职员+面部唯一异常+先真实后异常）由司仪继承。
- **F02–F07 候选族**：全部作废，不再补做。
- **漩涡空洞脸系列原型图**：视觉强但语汇不符，归档待议，Demo 禁用。
- **"湿拓群像/人在墙里"**：旧稿已否决（滑向浮雕纪念墙），维持否决。
- **M01"石化复眼父亲"**：与婚宴叙事无接口，作废；"干燥矿物质感、负体积凹陷"的材质经验并入上宾外板规格。

### 1.8 旧 Demo 路线

- **H00-R0（Unreal）**：考古封存。UE 管线与最终 Three.js 交付目标不一致，空间验证结论已被新五幕节拍表取代。
- **M01 酒店深度切片（听潮/测深玩法）**：作废。"结构听深"玩法验证成本高、表达抽象；听觉设计残值（声学随深度变化）并入楼梯间混响与三层声场。

## 2. 永久禁止清单（做任何内容前自查）

**叙事与机制：**
- 礼仪/礼节交互、社交选项、道德选择题；
- 错认身份、记忆错位机制；
- "X鬼/X怪/X灵"命名；
- 门后异界、空间翻转传送、无限循环走廊；
- 全知解说 NPC、找到真相文档解释一切的结局；
- 多日时间线、回忆章节、开放小镇。

**视觉：**
- 蓝滤镜/全局恐怖化 LUT；珊瑚藤壶海藻鱼群触手；Gore 与腐尸；黑袍蜡烛五芒星；VHS 数字 glitch；美式废弃感（涂鸦/木板封窗）；给古海生物完整正脸与可理解表情；把酒店整体雕成一只怪物。

**音频：**
- 持续恐怖背景音乐；jump scare 重锤音效；怪兽咆哮/鲸鸣；以静默直接惩罚玩家。

**生产流程：**
- 人形高模前置阻塞任何 Gate（F01 教训写入 `11` 依赖图）；
- 未过灰盒验证就量产资产；
- 在四证据语汇之外发明新异常类型；
- 为"丰富度"添加与三轴无关的支线内容。

## 3. 自查口诀

新点子过三关：

1. **挂轴**：它在预现/残骸/喜事哪条轴上？挂不上，不做。
2. **一图**：能画成一张 6 米可读的目标帧吗？画不出，不做。
3. **查禁**：在本文件清单里吗？在，就换方案。
