# 海残骸生态 —— 干燥的深海时间

> 继承旧稿《余海残骸生态 v0.1》的核心结论（四种证据、反例测试），
> 在其上补齐：三大区域的渗入方案、可读性规范、资产化拆分。
> 旧稿的"归面关系"一节作废（归面设定已淘汰），残骸生态不再需要那层解释——
> 它的解释就是许潮：海来赴宴，顺便认领用它骸骨盖成的房子。

---

## 1. 一句话

**返潮之夜，南方大酒店没有进水，却像已经在海底住了几十年。**

灯亮着、暖气开着、宴席还在继续；但空气里已经没有干燥陆地应有的尺度、材料和声音。

## 2. 四种证据（封闭语汇，禁止扩充）

### 证据一：深压蠕变

- **只出现在**真正承重、密封或长期受力的东西上：楼板、梁柱、门框、玻璃、管道、焊缝、电梯导轨。
- 表现：缓慢、持久、无法自复原的变形——墙面向同一压力方向微弯、楼板失去绝对水平、密封条被长期挤出接缝、金属栏杆呈现被"揉"过的弧度。
- 声音：被厚重介质过滤后的近距离机械声、耳压感、远处低频。
- 禁止：拍成瞬间事故现场；拍成所有东西软趴趴。

### 证据二：附居寄生

- **只长在**深海也会选择的界面：阀门根部、冷凝器翅片、管线弯头、货架孔洞、砖缝、旧修补边缘、制服与皮肤反复摩擦处。
- 形态封闭为四种：半透明过滤囊 / 无口白色钙化细管 / 贴受力面铺开的暗色薄膜 / 缓慢闭合的矿物孔板。
- 每一种必须**占用、过滤、锚定或清理一个真实功能**，不许纯装饰性恶心。
- 禁止：珊瑚、贝壳墙、藤壶地毯、触手、鱼群。

### 证据三：沉积时间

- 本应被清理、流动或使用的东西，在错误位置形成**坚硬、安静、分层**的堆积：宴席票据、鱼鳞、红纸屑、瓜子壳、衣料纤维、发丝、矿物膜。
- 沉积必须有方向、有截面、有重量、有真实汇聚理由（最低点、气流死角、动线交叉）。
- 禁止：脏乱差贴图、霉斑、"恐怖素材包"。

### 证据四：空间耐压

- 空间像长期服役的压力舱：天花在一段走廊里缓慢下降、远端距离压得过近、门框仍是原门框却不再矩形、墙和地面把人推向同一压力方向。
- 必须**连续、可走近、可听见**，且与同一处管线/承重墙/旧修补/附居带互相作证。
- 禁止：翻面、倒转、门后异界、传送。

## 3. 三大区域渗入方案

### 3.1 酒店

| 位置 | 主证据 | 具体铺设 |
|------|--------|----------|
| 宴会厅 | 耐压 | 墙面收拢成喉道弧面（预现→终局兑现）；红幕与囍字随墙面弯曲仍保持悬挂逻辑 |
| 宴席桌面 | 沉积 | 剩菜冷凝成分层"海床剖面"：一桌一个截面，可辨认出虾壳/红纸/蜡油的层序 |
| 服务走廊 | 沉积+附居 | 地面票据鱼鳞薄板（踩上有脆响=噪声值陷阱）；传菜口阀门根部过滤囊 |
| 大堂 | 蠕变+负形 | 水磨石失泽弧线、外板脱离后的湿润负形、栏杆被上宾压出的"揉"弧 |
| 楼梯间 | 耐压（声学） | 每下一层混响变深一档，像下潜；楼层牌错位一层 |
| 107 走廊 | 蠕变 | 一侧墙显露船壳弧面与铆钉列（原型图 door 107），客房门被弧面挤成梯形 |
| 807 套房 | 轻量 | 双喜脸盆底部一枚贝壳沉积（呼应海洋馆 G2 资产"贝壳落盆"），其余保持体面 |

### 3.2 宴席（喜事层被残骸生态处理的方式）

残骸生态**不区分喜事与遗骸**——它把这场不肯结束的婚宴识别为一具迟迟不肯腐败的沉没残骸，并开始按海底的规矩处理它：

- 红布：先浸湿下垂（渗漏态），再被暗色薄膜沿受力面铺覆（预现态）；
- 囍字：金漆下透出钙化白纹——它被当作矿物基底附居；
- 宴席菜：被当作滤食生态的饵料层，侍应仍在一道道上菜——**上菜动线就是投喂动线**；
- 气球与彩带：沉到地面，与票据一起进入沉积层。

### 3.3 海洋馆

- 玻璃承压事件 = 证据一（蠕变）在玻璃上的规范化演出（G2 包已给出四态）；
- 墙体转移事件 = 证据四（耐压）+ 证据二（旧门轮廓即旧修补界面）；
- S04 旧处理间 = 沉积时间的"标本馆"：三十年冷库票据、鱼鳞与保温纤维的完整分层剖面，Demo 内最厚的一块沉积——玩家在这里理解"分层=年数"。

## 4. 可读性规范（行为与视觉）

1. **6 米规则**：每个主证据在 6 米外能读出"哪里不对"，2 米内能读出"它如何工作"（哪个功能被占用/过滤/锚定）。
2. **手电验证**：所有证据经得起玩家手电直照与蹲下细看——不靠黑暗藏拙。
3. **一句话测试**：每个空间的异常能用一句话说清（"这条走廊在海底住了几十年"），说不清的撤掉。
4. **互证律**：附居长在受力面上、沉积堆在蠕变最低点、声音从耐压方向来——三者指向同一物理事实。
5. **干燥律**：地面无积水，画面无水体。湿只允许以冷凝、浸痕、负形湿泽三种形式存在。

## 5. 资产化拆分

| 资产类型 | 命名 | 说明 |
|----------|------|------|
| 蠕变 | `{空间}_Creep_Mesh` | 基础几何的形变变体（morph 或替换网格），配套碰撞更新 |
| 附居 | `Biofoul_{囊/管/膜/孔板}_v{n}` | 四种通用件，实例化铺设，带受力面对齐规则 |

## 6. 已完成的反例测试（防回潮，保留原结论）

- **澡堂隔间里的深海**：失败——被读作"门后有海"。禁止任何"打开门是异界"的表达。
- **干船坞不可见巨物**：未通过核心目标帧——巨物只能作为结构关系的主人（上宾即此结论的正确用法）。
- **单人工人材质异变**（泥沙压实/骨虫/锰结核）：失败——把世界缩成一个人身上的特效。只保留"深海把活物错误分类为残骸功能"这一分类关系（实体设计的基石，见 `07` 文档）。
- **柴油机房压扁薄层**：失败——深压被拍成单次事故。正确做法是让**整个房间**处于四证据共同状态。
