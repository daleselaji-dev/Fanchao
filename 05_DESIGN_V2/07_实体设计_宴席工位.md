# 实体设计 —— 宴席工位命名法

> 覆盖旧怪物体系：F01–F07 编号、"内里深度"F01 Hero、以及一切"X鬼"命名（误解鬼/代价鬼/证据鬼）全部作废。
> 新命名法：**实体的名字就是它在这场喜事里的工位**。桌牌上写什么，它就是什么。
> 设计基石（继承残骸生态已验证结论）：深海把每个还在工作的人**错误分类为残骸生态里的一个功能**。
> 每个实体 = 婚宴工位 × 残骸功能，两个坐标缺一不可。

| 名字 | 工位 | 被误分类的残骸功能 | 规模 | 玩法角色 | 主参考图 |
|------|------|--------------------|------|----------|----------|
| 司仪 | 婚宴主持 | 声呐/召集器官 | 人形 | **Hero 实体**，议程时钟的人格化 | `诡异宴会厅里的惊悚侍者.png` |

| 回眸客 | 观礼宾客 | （未被分类——系统的错误） | 人形 | 非敌对指针/引导 | `诡谲婚宴厅中的回眸女人.png` |

命名规范：两到三字工位名，可挂"的"字短语描述（"站在台上的司仪"），**禁止**任何"鬼/怪/魔/灵"后缀，禁止编号名（F01）出现在玩家可见层。

## 1. 司仪（Hero 实体）

### 1.1 一句话

**口被封死的婚宴主持，声音却仍从全楼每一只喇叭里先一步到来。**

### 1.2 外观（6 米读 / 2 米读）

- 6 米：一个完全标准的 2001 年婚庆司仪——枣红西装、金色领结、手持有线麦克风，站姿挺拔，站在舞台红幕前追光里。轮廓无任何异常，**先真实**。
- 2 米：口部被鱼籽状钙化增生完全封死（参考 `诡异宴会厅里的惊悚侍者.png` 的口部方案）：细密、半透明、按唇形分层生长的矿物卵粒，像被海封存的一声"各位来宾"。喉部随广播词微微起伏——声带仍在工作，声音却不从这里出来。
- 手持麦克风线**向下没入舞台地板**，与酒店广播系统在物理上长为一体——他就是声呐器官的振膜。

### 1.3 行为合同

| 项目 | 内容 |
|------|------|
| 他在维持什么正常生活 | 主持婚宴：报幕、暖场、控制流程。他至今没有失职过一秒 |
| 残骸功能 | 召集：他的广播让全楼实体按议程行动；他的点名让侍应改道 |
| 一眼可见的改变 | 口封而声不止；动作与声音相位错开（先闻其声，数秒后他才做出说这句话的手势） |
| 感知 | 全楼声学。玩家噪声值超阈 → 点名（广播报出玩家所在区域："三楼的这位来宾，请入席"） |
| 玩家对策 | 控制噪声值；用假声源（电话/电梯铃/卡拉OK）转移点名；破像可令一次点名作废 |
| 玩家无法做到 | 伤害他、阻止议程宣布。他不追击、不移动出宴会厅——**他不需要** |

### 1.4 与三轴的关系

- 预现轴：他的声音就是"先于现实"的听觉版——广播词先响，手势后到；同步律对他同样生效，终局他与广播完全同步的一刻即"送入洞房"。
- 残骸轴：口部增生=附居寄生的最高级展示件；麦克风线=与建筑长为一体的锚定。
- 喜事轴：他是议程时钟的人格化。杀不掉时钟，就是杀不掉他。

### 1.5 制作注意

- 高模排期在 G5 末端（全项目最后一个人形高模），此前一律用胶囊体+广播音轨验证——**他的恐怖 80% 在声音设计里**，先把声音做对。
- 广播词全表（六项议程+催请+点名+更正）先行录制临时音轨，G2 即接入。

## 2. 上宾（奇观级实体）

继承旧稿《古海外壳与电视预现原型 v0.1》全部已验证设计，此处收编要点+新叙事绑定：

- **是什么**：一条 20 米级古海滤食前肢，由七到九块房间尺度的矿化外板组成，从大堂的水磨石、柱体、二层栏板中重组脱离；板间无肉，软体缺失——雾被压出连续曲面、吊灯链绕行、投掷物提前偏转。CRT 里偶尔能看到软体的灰黑轮廓，现实中永远只有负空间。
- **新叙事绑定**：主桌那把空着的"上宾"席就是它的席位。它不是闯进婚宴的怪物，它是**被请来的主宾**——大堂是它的入席动线。
- 感知：建筑振动与空气压力（无眼）。红毯减振、瓷砖金属传远、过滤叶片捕捉到振动后突然合拢。
- 玩法：引导振动源穿越大堂（前台电话、行李车、电梯铃）；开火或敲击只改变单块外板姿态，无血条、不可杀。
- 声音：石灰岩内裂、湿陶片摩擦、叶片合拢的密集扫声、排开雾的低频。禁止一切吼叫。
- 终局回收：宴会厅喉道化后，厅顶合拢的过滤叶片属于它——大堂遭遇是"它入席"，终局是"它开席"。

## 3. 侍应（巡回威胁）

### 3.1 外观

- 白衬衫黑马甲的传菜员，托盘端得极稳。颈部与前臂呈**浪蚀浮木**质感——木纹般的流水磨蚀沟槽（参考 `昏暗餐厅走廊里的服务员.png`、`诡异走廊中的沉默身影.png`）；他们经过处，墙面瓷砖上留下扩散的**同心波纹**（材质演出，参考图同款）。
- 三到四名，外观同款不同磨蚀程度——磨蚀越深的个体资历越老。

### 3.2 行为合同

| 项目 | 内容 |
|------|------|
| 正常生活 | 沿服务动线传菜、收盘、清理 |
| 残骸功能 | 输送与清理：把沉积送进宴会厅（投喂），把"离席的来宾"送回座位（引座） |
| 一眼可见的改变 | 步速恒定得非人（传送带式匀速）；托盘上的菜是分层沉积截面 |
| 感知 | 视线锥（短）+ 对司仪点名的绝对响应 |
| 巡逻规则 | 固定动线循环（服务走廊↔宴会厅↔后厨），玩家可通过 T02 屏幕预读下一段动线 |
| 引座规则 | 点名后最近的一名侍应离开动线，直线走向玩家最后发声点；接触玩家 → 引座演出（挽住手臂，护送回宴会厅空椅，全程微笑礼貌）→ 玩家需在议程走完前再次脱身 |
| 玩家对策 | 让路（他们不主动搜索）；躲进动线之外的房间；被追时用假声源刷新"最后发声点" |

### 3.3 制作注意

- 引座演出是本作招牌失败画面，优先级高于侍应高模：G4 用胶囊体+挽臂动画占位验证节奏。
- 波纹墙演出=经过时触发的材质波（shader 参数动画），禁止粒子水花。

## 4. 全福婆（套房专属威胁）

### 4.1 外观

- 枣红缎面袄、盘发插银梳的中年妇人——婚礼上最受尊敬的"好命人"。
- 异常仅一处：**额上第三只眼**（参考 `诡异餐厅走廊中的镜像女侍者.png`）——那不是眼睛，是"开脸"仪式留下的锚定孔板（矿物孔环，缓慢开合）。她用它"看"的不是光，是**福气**（玩家=已借福登记的目标）。
- 镜中与现实形象不同步：镜里她永远比现实早一个动作。

### 4.2 行为合同（807 段落专属规则）

- 只在 22:30"上头"议程激活，只存在于 807 及 4F 走廊。
- **现实中她只出现在玩家背后**；镜子（T06）是唯一能看到她现实位置的视野。
- 玩家回头直视她 → "被梳到"（引座变体：直接押送宴会厅，且扣除一次破像配额）。
- 通过方式：倒退面向镜子移动，用镜中画面导航退出房间与走廊——本作唯一一段"反向潜行"，节奏紧、时长短（≤3 分钟），不重复使用。
- 声音：骨梳过发的沙沙声定位她的现实距离；吉语偏差版低语（"一梳梳到底……"）。

## 5. 回眸客（非敌对指针）

- 半透明、多重曝光质感的年轻女人，礼服款式比 2001 年旧一代（参考 `诡谲婚宴厅中的回眸女人.png`、`诡异红宴厅回眸客.png`）——**她是上一场许潮的伴娘**，被收走的那个影子。
- 全场唯一会"看向玩家"的存在。不可接近（走近即散成雾，下一房间再现）。
- 玩法功能：她在现实中的位置永远与 CRT 录像里不同——**差异连线指向可用路线或锚点物**（对照玩法的活教具）。终局大破像的锚点由她的注视方向提示。
- 叙事功能：玩家的镜像与警告——不需要一句台词。

## 6. 浮客（氛围群体）

- 婚宴宾客，正装，姿态如水中悬浮：脚尖离地半寸、衣摆缓慢漂动、举杯的手在洋流里轻晃（参考 `宴会厅通道中的幽灵身影.png`、`诡影穿行于旧餐厅走廊.png`）。
- 不敌对、不可交互；作为密度、遮挡与软障碍（穿过人群会产生噪声值）。
- 议程推进时全体同步转向宴会厅方向一次——全场只有玩家不知道该看哪，这一拍是喜事轴最便宜也最有效的群体演出。
- 制作：低模+统一悬浮动画+实例化，严格控制在宴会厅与 1F 走廊。

## 7. 不做的实体（防回潮）

- 新娘周絮**不是怪物**：终局盖头之下不给正面揭示（Demo 留白），禁止做任何"新娘怪物化"资产。
- 不做流浪杂兵、不做追逐用速度型怪、不做爬行贴脸 jump scare 用怪。
- 旧 F01"内里深度"（眼口井穴）方案作废：与封闭语汇冲突（它既非附居也非蠕变），且高模已连续两轮未过 Gate。其"制服职员+面部唯一异常"的构图经验由司仪继承。
- `诡异走廊中的空洞面孔.png`（漩涡空洞脸）与 `surreal_void_faced_portrait.png` 系列**暂不入正编**：视觉强但与四证据语汇不符，归档为"待议原型"，禁止在 Demo 中使用。
