## 一句话

**2001 年，蚀湾"南方大酒店"的一场婚宴，是全镇献给海的祭礼；酒店里所有老 CRT 永远比现实先播一步——你在屏幕里看到的，就是这个空间即将变成的样子。玩家是伴娘，她会从录像里发现蚀湾婚俗的最后一条：如果海不满意新娘，就收伴娘。**

## A. 总结四块

### A1. 我们的核心设定

- **时间地点**：2001 年秋，中国北方沿海县镇"蚀湾"。南方大酒店——镇上最体面的新酒店，与相邻的蚀湾海洋馆共用九十年代末填海工程的建材与旧冷库结构。
- **事件**：镇上望族嫁女，全镇出席，在南方大酒店办婚宴。这场"喜事"同时是蚀湾旧俗"许潮"的执行现场：把一位新娘许给返潮之夜回来的海。宾客不是黑袍邪教徒，是穿着最好衣服、真心欢喜的普通镇民——**邪教感来自所有人对这场喜事不容置疑的认真**。
- **玩家**：新娘的闺蜜，受邀做伴娘。按蚀湾旧俗，伴娘是新娘的"影子"——若海不满意新娘，伴娘顶替。玩家在游戏中途才从录像里读懂自己的角色。
- **超自然核心（三条恐怖轴）**：
  1. **预现轴**：老 CRT（监控、婚礼录像、空频道）比现实先播一步，显示"当前空间正被返潮推向的下一稳定形态"。
  2. **残骸轴**：返潮之夜，酒店没有进水，却像已经在海底住了几十年——深压蠕变、附居寄生、沉积时间、空间耐压四种证据（继承自余海残骸生态 v0.1，见 `05_海残骸生态.md`）。
  3. **喜事轴**：婚宴议程（迎宾→入席→上菜→敬酒→上头→送入洞房）是关卡时钟。司仪每宣布一项，全楼向录像里的形态推进一档。喜事不许退席。
- **实体命名法**：全部按宴席工位命名——「司仪」「上宾」「侍应」「全福婆」「回眸客」「浮客」。禁止任何"X鬼"命名。详见 `07_实体设计_宴席工位.md`。

### A2. 核心的工作流

每一层内容先通过"能否被一张图 / 一次灰盒行走读懂"的验证，再进入下一层。顺序固定：

```
目标帧（图像验证）→ 灰盒（空间验证）→ 议程节拍表（时钟验证）
→ CRT 预现管线（核心机制验证）→ 实体行为合同（威胁验证）
→ 资产替换（美术落地）→ 音频与整合（Demo 验收）
```

- 任何设定若不能落到目标帧或灰盒，先降级为候选，不进宪法。
- 人形高模（司仪等）在流程**末端**做，绝不前置阻塞（旧版 F01-only sculpt 阻塞的教训）。
- 每个 Gate 有明确通过条件，写在 `11_生产路线图_Gate.md`，逐 Gate 交付。

### A3. 依托的技术栈

- **运行时**：Three.js + WebGL，浏览器可分发的 Web Demo。资产格式 GLB（True Mesh，真实网格，不用图片贴片冒充空间）。
- **DCC 管线**：Blender 建模/绑定/烘焙 → GLB 导出 → Three.js 场景装配。贴图 1K–2K，PS3 级几何密度（轮廓可读优先于细节数量）。
- **CRT 预现实现**（成本可控的核心技术方案）：每个关键空间准备"当前态 / 预现态"两套状态（共享几何 + 差异子网格 / morph target / 材质变体）；预现态实时渲染到低分辨率 RenderTarget（或预渲染视频纹理），贴到场景内 CRT 屏幕上，叠加隔行/拖影/偏色着色器。**不需要时间回溯系统，只需要状态机 + 第二相机。**
- **全局状态机**：议程时钟（司仪广播）驱动所有空间的状态切换与实体行为阶段。
- **历史说明**：H00-R0 的 Unreal Demo 仅作考古，不再延续。理由：交付目标是可直接分发验证的 Web Demo，Three.js/GLB 管线已在仓库定为最终主体方向，且 CRT 预现方案（RenderTarget + 状态机）在 Three.js 内实现成本最低。

## B. 核心恐怖机制七问（浓缩版）

完整版见 `02_核心恐怖机制七问.md`。

1. **哪里恐怖？** 三处：①你先在屏幕里看到了还没发生的事，然后不得不走进那个画面；②所有人笑着坚持这场喜事必须办完，没有人觉得不对；③干燥、亮着灯、还在营业的酒店，处处证明它已经在深海底住了几十年。
2. **游戏机制？** 看录像侦察 → 对照现实找差异 → 在议程时钟压力下规划路线 → 管理自己发出的声音与振动 → 用"破像"改写一次预现。
3. **视觉机制？** 同一空间共享几何的三态（正常态/渗漏态/预现态）；CRT 低清画面是"未来图纸"；缺失软体的负空间；红金喜事层压在残骸生态层上、可剥落。
4. **美术机制？** 先真实后异常；异常只允许使用四种残骸证据（深压蠕变/附居寄生/沉积时间/空间耐压）；每场景一个主异常，其余证据只做可信度。
5. **音乐机制？** 无持续背景配乐。三层声音：公共声场层 / 广播与 CRT 提前声层 / 残骸低频层。静默规则：司仪宣布议程前 3–5 秒，全楼声源退潮式收声——静默本身是最大警报。
6. **画风？** 2001 年中国县镇写实：红金婚宴 × 水磨石 × 荧光灯 × 海雾。PS3 级可读性（轮廓、材质、实用光源），实拍感构图，禁止蓝滤镜与数字 glitch。
7. **核心玩法？** **"用一台比现实先播一步的电视，在一场不许退席的婚宴里活到散场。"** 侦察（看录像）、对照（找差异）、潜行（声振管理）、抉择（何时花掉一次破像）——全部压在议程时钟之下。
