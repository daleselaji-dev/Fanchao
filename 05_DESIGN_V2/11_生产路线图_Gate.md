# 生产路线图（Gate 式）

> 每个 Gate 有：入口条件、任务清单、通过条件、失败处理。
> 不允许跳 Gate；上一 Gate 未过，下一 Gate 的产出一律视为草稿。
> 下一位 Agent 从 G1 开始执行（G0 由本包交付即完成一半，剩余为通读确认）。

---

## G0 · Canon 签收

- **任务**：通读本包 13 份文档；对照 `12_禁止事项与淘汰说明.md` 确认无回潮项；确认 Three.js/GLB 管线可用（本地能跑一个加载 GLB 的最小场景）。
- **通过**：能用三句话复述三轴；能说出六项议程顺序；最小场景截图。
- **失败处理**：文档冲突处开 issue 记录，以 `01_项目宪法_V2.md` 为准裁决。

## G1 · 目标帧包（10 张关键帧）

- **入口**：G0 过。
- **任务**：产出以下 10 张目标帧（图像生成或手绘均可，构图与内容按本包规格）：

| # | 帧 | 规格来源 |
|---|----|----------|
| 1 | 宴会厅正常态（满员喜宴，同机位基准帧） | `03` §2.1 |
| 2 | 宴会厅渗漏态（散场残宴+红布下垂） | 同上 |
| 3 | 宴会厅预现态（喉道化，仅出现在屏幕内的构图） | 同上 + `banquet_hall_states_of_transformation.png` |
| 4 | 大堂上宾重组（七至九块外板+负形+雾腔，主奇观帧） | `03` §2.2 / 旧稿古海前肢 §11 硬约束 |
| 5 | 前台 T01 预现同框（现实空大堂+屏幕里的前肢） | `04` 文档 |
| 6 | 服务走廊（侍应+波纹墙+沉积地面） | `07` §3 |
| 7 | 807 上头正常态（持镜构图） | `03` §4.2 |
| 8 | 807 镜中反转态（镜里仪式+现实背后） | `03` §4.3 |
| 9 | 海洋馆 S02 玻璃承压（沿用 G2 包 K04 规格） | G2 美术包 |

- **通过**：每张过"遮住异常像纪实照片 / 露出异常 6 米可读"双测试；帧 4 满足旧稿硬约束（遮掉雾和湿气后轮廓仍有冲击力）。
- **失败处理**：单帧最多迭代 3 轮，3 轮不过则回改空间规格而不是继续磨图。

## G2 · 酒店灰盒 + 议程时钟

- **入口**：G1 至少 6/10 过（含帧 1–4）。
- **任务**：Three.js 灰盒——酒店四层+连廊+海洋馆四间的可行走白模（BoxGeometry 级）；议程状态机（六档+破像挂起）；司仪广播临时音轨全表接入；收声序列。
- **通过**：从 807 走到宴会厅再到 S04 全程无卡点；广播能推动全楼状态切换（白模换色即可）；测试者仅凭听觉能答对"现在议程第几档"。
- **失败处理**：动线卡点改空间文档 `03`，不改代码硬绕。

## G3 · CRT 预现管线

- **入口**：G2 过。
- **任务**：第二相机 RenderTarget 管线；CRT shader（隔行/拖影/偏色）；T01+T02 两块屏接入（其一显示"下一档灰盒状态"）；同步律参数；破像锚点物交互；镜面 T06 反射变体。
- **通过**：站在 T02 前能看到走廊的下一档形态；破像后屏幕黑屏且该空间跳过一档推进；30 FPS 不掉。
- **失败处理**：RenderTarget 性能不足时降级为预渲染视频纹理，规则不变。

## G4 · 实体行为灰盒

- **入口**：G3 过。
- **任务**：全部实体以胶囊体+占位音效实现——噪声值系统、司仪点名、侍应巡回/改道/引座演出（挽臂+押送+落座）、上宾振动感知+七块板占位体+假振动源三件套、全福婆倒退导航段、回眸客差异指针、浮客群悬浮+议程转头。
- **通过**：不加任何美术，测试者在灰盒里能完整体验"看屏→对照→挑地面→赌时机→破像"循环并复述三轴；引座演出让测试者形容为"不舒服"而不是"好笑"。
- **失败处理**：引座若好笑，先改节奏（速度/距离/音效）再考虑改设计。

## G5 · 资产替换

- **入口**：G4 过。
- **顺序**（严格执行，场景先行、人形最后）：
  1. 宴会厅三态 → 2. 大堂+上宾外板 → 3. 服务走廊/楼梯间 → 4. 海洋馆 S02/S03（按 G2 包资产表）→ 5. 807 两态+镜 → 6. 侍应 → 7. 全福婆/回眸客/浮客 → 8. 司仪本体。
- **通过**：每步替换后跑一遍对应幕，节奏不劣化（灰盒时好玩的地方替换后必须仍好玩）；材质在禁止清单内零违例。
- **失败处理**：任何资产连续 2 轮不过 6 米/2 米读法，回 G1 重出该目标帧。

## G6 · 音频与整合

- **入口**：G5 主线资产（1–5 项）就位。
- **任务**：三层声场全量替换临时音轨；静默规则接入；喜歌 A/B 版+终局乐句；噪声值反馈链（鞋声/馈电嗡/点名圈定）；五幕串联；检查点。
- **通过**：戴耳机盲测（不看画面）能定位侍应方位与议程档位；终局乐句起播时机准确。

## G7 · Demo 验收

- **入口**：G6 过。
- **任务**：按 `10_Demo垂直切片规格.md` §3 八条通过标准逐条验收；3 名以上未读文档的测试者完整游玩并访谈。
- **通过**：八条全过 + ≥2/3 测试者能复述"电视先播、喜事不许退席、我是替身"。
- **产出**：可分发 URL + 验收报告 + 下一版本（正式版立项）建议。

## 风险与预案

| 风险 | 预案 |
|------|------|
| 上宾外板 rig 超出产能 | 降级：板数 7→5，叶片动画共用曲线；再降级：预现演出化（见依赖图） |
| 人形实体不可信 | 侍应/全福婆先用"背面+远距+逆光"调度隐藏正面（`minimalist_rear_view_studio_portrait.png` 验证过背面即可信）；司仪允许 Demo 内永远处于追光逆光中 |
| RenderTarget 性能 | 预渲染视频纹理降级路径（G3 已内置） |
| 浮客群性能 | 实例化+烘焙顶点动画；数量 24→12 可减半不伤节拍 |
| 中文字体/文本渲染 | 桌牌、楼层牌全部做进贴图，不走运行时字体 |
