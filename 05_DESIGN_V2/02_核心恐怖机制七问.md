# 核心恐怖机制七问（完整版）

> 每一问的回答分两段：**设计答案**（是什么）与**落地方式**（怎么做出来）。
> 不允许出现无法落到资产、代码或节拍表的句子。

---

## 一、哪里恐怖？

### 设计答案

三个恐怖源，按玩家遭遇顺序：

1. **看见注定（预现轴）**
   你在前台监控里看到走廊尽头的门是敞开的、门里有个背对你的侍应——而你抬头看现实里那扇门还关着。你必须走那条走廊。走到一半，你听见门锁转动的声音。
   恐怖点不是 jump scare，是**从"看到"到"走进画面"之间的每一步**。玩家自己用脚把预告片走成正片。

2. **不容拒绝的喜事（喜事轴）**
   返潮已经开始，宴会厅的墙在向内弯，可司仪的广播仍在宣布"下面有请各位来宾举杯"，浮客们仍举着杯，红布下面渗出湿痕，没有一个"人"停下来。玩家是全场唯一觉得不对的人，而全场都觉得玩家不该乱走——侍应会微笑着把你**引座**回去。
   恐怖点是集体的确定性：**不是有人要害你，是所有人都认为这是好事。**

3. **干燥的深海时间（残骸轴）**
   灯亮着、地毯干着、暖气开着，但走廊天花在十米内低了四十公分，阀门根部长着半透明的过滤囊，配电间地面的票据和鱼鳞压成了坚硬的分层薄板。没有水，没有怪物，只有证据：**这里已经在海底住了几十年。**
   恐怖点是可验证的不可能：玩家可以走近、蹲下、用手电照，每一个细节都在说同一句话。

### 落地方式

- 恐怖源 1 → CRT 预现系统（`04` 文档），每个关键空间至少一台"必看屏"。
- 恐怖源 2 → 议程时钟 + 引座失败机制 + 浮客/侍应的群体行为（`06`、`07` 文档）。
- 恐怖源 3 → 四种残骸证据的空间铺设规范（`05` 文档），每空间一个主异常。

## 二、游戏机制是什么样？

### 设计答案

一个循环，四个动词，一个时钟：

```
[看] 找到本区域的 CRT，看这个空间的"下一稳定形态"
 ↓
[对照] 回到现实，找出录像与现实的差异点（差异点=情报：路线、钥匙物、实体位置）
 ↓
[走] 在议程时钟压力下穿越空间；管理声音与振动（跑动、碰倒物品、硬质地面都会被听见）
 ↓
[破像]（有限资源）让现实关键结构与录像不符，作废一次预现，为自己开路
 ↓
司仪宣布下一议程，全楼推进一档，回到 [看]
```

- **失败不杀人**：被司仪点名 → 侍应改道来抓 → 被引座回宴会厅。玩家需要在议程走完前再次脱身；议程走完时仍在座位上，Demo 结束（坏结局）。
- **没有战斗**：不能杀死任何实体，只能利用声源（前台电话、行李车、电梯铃、卡拉OK 点歌机）制造假振动引开它们。

### 落地方式

- 全局状态机：`议程阶段 × 空间状态 × 实体阶段` 三张表驱动，见 `10` 文档节拍表。
- 声音与振动：玩家移动速度 × 地面材质 = 噪声值；超过阈值触发司仪点名。地毯/红布上安静，瓷砖/水磨石/金属楼梯上危险——**地面材质选择就是潜行玩法**。
- 破像：可交互的"锚点物"（录像里完好的花瓶、录像里没有的椅子），交互后当前空间预现作废一个议程周期。Demo 内共 3 次机会 + 终局 1 次强制大破像。

## 三、视觉机制是什么样？

### 设计答案

1. **三态共享几何**：每个关键空间有正常态（婚宴进行）、渗漏态（返潮渗入）、预现态（CRT 里的下一形态）。三态共用同一套建筑几何，只切换差异子网格、材质与光照——玩家必须一眼认出"这还是同一个房间"。
2. **CRT 是唯一的未来窗口**：预现态只在屏幕里出现，低分辨率、隔行、拖影、偏色。当现实逐渐追上屏幕，同步偏差减小；完全重合的一瞬间，画面变得异常清晰，然后失去信号——这是"这个空间完成了"的视觉宣告。
3. **负空间**：最大的实体（上宾）没有可见的身体，只有围绕缺失软体运动的矿化外板，和被排开的海雾、绕行的吊灯链、提前偏转的投掷物。
4. **喜事层剥落**：红金布置作为独立资产层，随议程推进下垂、浸透、被沉积埋住，露出建筑骨架的蠕变。

### 落地方式

- 三态 = GLB 状态变体 + Three.js 场景内切换（灯光配置随态切换）。
- CRT = 第二相机渲染预现态场景到 512×384 RenderTarget，叠加隔行/拖影 shader；固定机位可用预渲染视频纹理省性能。
- 负空间 = 雾卡片受不可见碰撞体推挤变形 + 悬挂物物理绕行，不做全屏体积雾。
- 喜事层 = 独立网格组，三档状态（挺括/下垂浸湿/半埋沉积）。

## 四、美术机制是什么样？

### 设计答案

- **先真实后异常**：每张图先能当 2001 年婚宴纪实照片，再叠唯一主异常。
- **异常语汇封闭**：只许用四种残骸证据（蠕变/附居/沉积/耐压）+ 预现屏幕。不许发明新的异常类型，不许"加点诡异"。
- **每空间一个主异常**：宴会厅=空间耐压（墙向内收成喉道，对应原型图三态设计稿）；大堂=上宾重组（材料脱离+负形）；海洋馆=玻璃承压+墙体转移；服务走廊=沉积与附居；套房=镜面/屏幕预现。
- **证据必须互相作证**：附居长在受力面上，沉积堆在蠕变形成的最低点，声音从耐压方向来。

### 落地方式

- 每空间出"异常分配表"（主异常 + 支持证据 ≤3 项），已写入 `03` 文档。
- 目标帧先行：G1 阶段 10 张关键帧，每张先过"遮住异常还像纪实照片吗 / 露出异常一眼能读吗"双测试。
- 资产命名规范：`{空间}_{层}_{态}`，如 `BQ_Hall_Deco_Sag`（宴会厅_喜事层_下垂态）。

## 五、音乐机制是什么样？

### 设计答案

- **没有持续背景配乐。** 恐怖由声场结构承担，音乐只在三个位置出现：正常态的婚宴喜歌（现场音源：音响、卡拉OK）、预现声（CRT 里提前到来的声音）、终局大破像后的唯一一段谱写乐句。
- **三层声场**：
  1. 公共声场层——宴席人声、碗筷、音响喜歌、行李车、空调（正常态铺满，随议程逐层撤走）；
  2. 广播与预现层——司仪广播、CRT 提前声（录像里栏杆弯曲的声音先于现实数秒到达）；
  3. 残骸低频层——耐压方向的结构呻吟、附居囊的滤水声、沉积层被踩碎的脆响。
- **静默规则**：司仪宣布议程前 3–5 秒，全楼所有声源退潮式收声（不是音量渐隐，是逐个声源"离场"）。玩家学会后，静默本身成为最大的警报。

### 落地方式

- 声音全部空间化（PositionalAudio），挂在真实声源物体上。
- 收声用声源逐个 mute 的序列脚本，接入议程状态机。
- 预现声=同一音效文件在 CRT 声源上提前 N 秒播放，N 随同步度递减——纯播放调度，无特殊技术。

## 六、画风又是什么样？

### 设计答案

- **一句话：2001 年中国县镇婚宴纪实摄影，被深海显影。**
- 色彩：红金（喜事层）× 米黄水磨石与青绿墙裙（建筑层）× 荧光灯青白与钨丝暖黄（光层）× 海雾灰（外部）。预现屏幕是唯一的偏色蓝绿——CRT 荧光本身的颜色，不是滤镜。
- 材质：红绒布、金漆字、塑料花、搪瓷、水磨石、白瓷砖、铝合金门框、绿漆墙裙、涤纶制服。附居生物是唯一的"非本地"材质：半透明囊、白钙化管、暗色薄膜。
- 构图：实拍感——35–50mm 平视机位，允许前景遮挡与不完美构图；重要异常永远给"可走近验证"的纵深，不用特写唬人。
- 精度：PS3 级。轮廓与剪影优先，1K–2K 贴图，实用光源数量控制在每空间 3–5 个。

### 落地方式

- 色板、材质库清单、灯具清单、镜头规范全部写入 `08_美术方向锁定.md`。
- 两批原型图逐张标注"采用哪一层"（`13` 文档）：红金大厅系→宴会厅正常/散场态；侍者异变系→侍应与司仪；三态设计稿→宴会厅状态机；楼梯间/媒体档案室→过场空间。

## 七、游戏的核心玩法到底是什么东西？

### 设计答案

**"用一台比现实先播一步的电视，在一场不许退席的婚宴里活到散场。"**

拆开说，玩家每分钟都在做的事：

1. **找屏幕**——进入新区域先找 CRT，这是本作的"看地图"。
2. **读差异**——录像与现实的不同点是唯一可靠的情报来源：录像里多出的门、少掉的桌子、站错位置的回眸客。
3. **挑地面**——规划一条踩地毯不踩瓷砖的路线，控制噪声值。
4. **赌时机**——议程时钟不等人：现在冲过大堂，还是等下一次收声？
5. **花破像**——三次机会用在哪：躲过司仪点名？还是留给送入洞房？

这五件事全部围绕同一台状态机运转，没有支线系统、没有背包管理、没有对话树、没有礼仪选项。

### 落地方式

- 垂直切片五幕节拍表（`10` 文档）保证每一幕至少让玩家完整跑一次上述循环。
- G2 灰盒阶段的验收就是：不放任何美术资产，仅用方块与广播音轨，测试者能否说出"我在看屏幕、找差异、挑地面、赌时机"。灰盒阶段验证不了循环，后面全部停下重改。
