# Demo 垂直切片规格 —— 《喜宴》

> 覆盖 `03_DEMO/` 全部旧规格（H00-R0 UE 版、M01 深度切片）。
> 目标：25–35 分钟、浏览器可玩的 Three.js 垂直切片，完整跑通三轴与核心循环。

---

## 1. 范围

- **做**：南方大酒店（1F 大堂/宴会厅/服务走廊、2F 回廊/保卫科、3F 107 走廊、4F 807 套房、楼梯间）+ 员工连廊 + 海洋馆 S01–S04。
- **实体**：司仪（声音全程 + 本体仅宴会厅）、上宾（大堂）、侍应×3、全福婆（807 段落）、回眸客、浮客群。
- **系统**：议程状态机、CRT 预现（8 块屏）、噪声值/点名/引座、破像（3+1 次）、三层声场与静默规则。

## 2. 五幕节拍表

### 第一幕 · 上头（正常态，约 5 分钟）

| 节拍 | 内容 | 教学 |
|------|------|------|
| 1 | 807 套房：帮周絮整婚纱，自由查看房间 | 移动/检视 |
| 2 | 全福婆上头仪式，玩家持镜 | 观看构图=预现构图基准 |
| 3 | 电视雪花一闪（房间俯拍） | 预现的第一次暗示 |
| 4 | "借福"取发 | 伏笔（零玩法） |
| 5 | 下楼：楼梯间→大堂（满员）→宴会厅入席 | 记忆正常态空间；声控灯教学 |

### 第二幕 · 开席（渗漏开始，约 7 分钟）

| 节拍 | 内容 |
|------|------|
| 1 | 宴席开始；玩家被支使去服务走廊帮拿喜糖（离席的正当理由） |
| 2 | 服务走廊：T02 屏第一次完整预现（走廊尽头多一扇门）；对照教学 |
| 3 | **敬酒议程=返潮点火**：全楼收声→吸气→状态切换（此演出玩家在走廊经历，回头宴会厅已成渗漏态残宴） |
| 4 | 侍应巡回启动；噪声值/地面材质教学；沉积脆层第一次踩响 |
| 5 | 回眸客首次出现，差异连线指向保卫科方向 |

### 第三幕 · 入席的上宾（大堂遭遇，约 6 分钟）

| 节拍 | 内容 |
|------|------|
| 1 | 2F 保卫科：九宫格预现中枢；破像教学（锚点物：监控室花瓶）；发现摄像师最后位置在海洋馆 |
| 2 | 大堂七步遭遇演出（T01 屏→现实兑现，见 `03` 文档 §2.2） |
| 3 | 振动潜行：红毯路线+假振动源（前台电话/行李车/电梯铃）穿越大堂 |
| 4 | 进入员工连廊（旧冷库声学转场） |

### 第四幕 · 海洋馆（约 8 分钟）

| 节拍 | 内容 |
|------|------|
| 1 | S01 没有远方的广场；S02 玻璃承压预警（T07 屏） |
| 2 | S02 沿墙潜行（玻璃对振动敏感=振动教学的进阶考试） |
| 3 | S03 墙体转移解谜（按压→远端旧门轮廓开启） |
| 4 | S04 旧处理间：找到摄像师（不出场，只留三脚架与取景屏 T08）与母带；沉积标本馆 |
| 5 | 返程：S02 玻璃第三态封路，改走排水沟通道回连廊（空间复用+状态变化） |

### 第五幕 · 上头与散场（终局，约 8 分钟）

| 节拍 | 内容 |
|------|------|
| 1 | 回 807 播母带（T05）：看到上一场许潮、伴娘桌牌变"上宾"——影子规则揭示 |
| 2 | 镜中反向上头；全福婆段落（倒退导航逃出 807 与 4F 走廊，≤3 分钟） |
| 3 | 广播"吉时已到"；下行楼梯间层数错位（3F 按钮到 1F 半——楼在下潜） |
| 4 | 终局宴会厅：喉道化兑现中、厅顶过滤叶片展开、浮客全体面向主桌、盖头新娘就位 |
| 5 | **大破像**：按回眸客注视方向找到锚点（掀翻"上宾"空席 / 砸毁 T03 投影，二选一均可）→ 司仪失声 → 终局乐句 → 玩家走出宴会厅，大门外海雾中一排车灯——散场。切黑，Demo 结束 |

- **坏结局**（任何时刻议程走完时玩家在座位上）：镜头缓推玩家桌牌，牌面从名字翻成"上宾"二字，切黑。

## 3. 通过标准

1. 全流程 25–35 分钟，无卡死、无空转超过 90 秒的段落；
2. 核心循环完整出现 ≥4 次（看屏→对照→潜行→时钟压力）；
3. 三态切换在宴会厅、大堂、S02 三处可被玩家明确目击"同一空间变了"；
4. 预现兑现至少 3 次，且每次兑现与录像存在一处设计差异；
5. 破像至少被玩家主动使用 1 次（若测试者从未使用，教学失败，返工第三幕节拍 1）；
6. 首测玩家不看文档能复述："电视先播、喜事不许退席、我是替身"三件事；
7. 720p / 30 FPS 在中端集显浏览器稳定；
8. 无一处使用禁止清单元素。

## 4. 不做清单（Demo 范围外）

- 全镇开放空间、莫比乌斯小镇、街道行走；
- 战斗系统、体力条、背包、物品合成、地图 UI；
- 对话树、道德选择、多结局分支（只有通关/被引座两种收尾）；
- 新娘正面揭示、许潮完整历史交代、摄像师本人出场；
- 海洋馆主水槽/海底隧道/大量生物；
- 存档系统（Demo 用幕间检查点）；
- 任何礼仪/礼节交互。

## 5. 资产优先级（给排期）

1. 宴会厅三态 + 议程状态机（没有它什么都不成立）；
2. CRT 预现管线 + 破像；
3. 服务走廊/楼梯间/大堂灰盒动线 + 噪声值系统；
4. 上宾外板 rig（七块板 + 三组叶片，低骨骼数）；
5. 侍应（含引座演出）；
6. 海洋馆 S02/S03 两事件（直接按 G2 包资产表执行）；
7. 807 套房两态 + 镜面 T06 + 全福婆；
8. 浮客群、回眸客；
9. 司仪本体高模（最后）。
