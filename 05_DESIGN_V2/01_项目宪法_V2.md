## 1. 世界观定盘

### 1.1 时间与地点

- 2001 年秋，中国北方沿海县镇**蚀湾**。
- 九十年代末，蚀湾试图从旧渔业与停产单位生活转向旅游与消费：填了内湾，用疏浚砂、贝灰、海相石灰岩和旧港区回收钢材，盖起了两座"未来"——**南方大酒店**和**蚀湾海洋馆**。两座建筑共用旧冷库/处理间的部分结构，由一条员工连廊相连。
- 这两座建筑的每一块材料都来自同一片古海床。这是全部超自然现象的物质基础，不需要更多解释。

### 1.2 返潮是什么

**返潮之夜，潮来了，但水没有来。来的是深度。**

- 建筑没有进水，却获得了深海的时间：材料承受了几十年不存在的水压，缝隙里长出了只有深海才会选择的附居生物，地面沉积出海床才有的分层，空间开始服从深度而不服从图纸。
- 返潮不是天灾，是**回应**。蚀湾旧俗"许潮"每隔一代人把一位新娘许给海；2001 年这一场，是填湾之后的第一场，也是最盛大的一场——全镇把它办成了千禧年最体面的婚宴。
- 海赴宴的方式，就是把这座用它的骸骨盖成的酒店，认领回去。

### 1.3 喜事是什么

- 明面：镇上望族嫁女，南方大酒店包场，全镇头面人物出席，婚庆一条龙，摄像师全程录像。
- 里面：这场婚礼严格按"许潮"的老规程办。规程不写在纸上，写在每个环节的细微偏差里：上头的梳子是骨的，敬酒的第八杯泼在地上，宴席永远多摆一副碗筷，主桌的"上宾"席空着——留给海。
- **宾客不是邪教徒。** 他们是真心为新娘高兴的普通人。邪教感的全部来源是：**没有任何人觉得这一切需要解释，也没有任何人允许它中断。**

### 1.4 玩家是谁

- 新娘**周絮**的高中同学、最好的闺蜜，从市里回来做伴娘。外来视角 + 亲密关系，一人兼得。
- 蚀湾旧俗：伴娘是新娘的"影子"，婚礼全程穿与新娘同料子裁的裙子，替新娘挡酒、替新娘答话。老人管这叫"全乎"。
- 规程的最后一条没人告诉她：**若海不满意新娘，收影子。**
- 玩家将在游戏中途，从酒店保卫科监控室的一盘旧婚礼录像带里，亲眼看到上一代"影子"的下场。

## 2. 三条恐怖轴（本作全部恐怖内容必须挂在这三条轴上）

### 轴一：预现（CRT 阈限录像先于现实）

酒店里所有 CRT 设备——前台监控、宴会厅投影、客房电视、保卫科监控墙、婚礼摄像师的取景屏——比现实先播一步。屏幕显示的不是"未来十秒"，而是**当前空间正被返潮推向的下一稳定形态**。

- 玩家用它侦察：哪条走廊会塌、实体下一步在哪、画面里的"自己"站在哪。
- 玩家被它胁迫：看到了就无法假装不知道；很多必经之路的"下一形态"里有等着你的东西。
- 玩家能有限反抗：**破像**（详见 `04_CRT阈限录像系统.md`）——让现实的关键结构与录像不符，可作废一次预现。
- 规则细节全部继承并收编旧稿《古海外壳与电视预现原型 v0.1》中已验证的部分。

### 轴二：残骸（海残骸生态）

异常只允许使用四种证据，这四种证据是深海长期使用一个场所的方式，不是恐怖贴纸：

1. **深压蠕变**——承重与密封材料呈现缓慢、持久、不可自复原的变形。
2. **附居寄生**——过滤囊、钙化细管、暗色薄膜、矿物孔板，只长在深海也会选择的界面。
3. **沉积时间**——票据、鱼鳞、纤维、发丝在错误位置形成坚硬、安静、分层的堆积。
4. **空间耐压**——天花缓慢下降、远端压近、门框失去矩形，连续、可走近、可听见。

规范全文见 `05_海残骸生态.md`。

### 轴三：喜事（不许退席的婚宴）

婚宴议程是关卡时钟：**迎宾 → 入席 → 上菜 → 敬酒 → 上头 → 送入洞房**。

- 司仪的广播宣布每一项议程；宣布之后，全楼向 CRT 里的形态推进一档。
- 玩家可以拖延议程（破像、切断线路、引开侍应），不能取消议程。
- 玩家的失败不是死亡画面，是**被引座**：被侍应带回宴会厅，按进一把空椅子。议程走完时还坐在席上，游戏结束。

## 3. 恐怖生成公式

每一个恐怖内容（场景、实体、事件）立项前必须能填完这张表：

| 字段 | 要求 |
|------|------|
| 它在正常之夜是什么 | 一个 2001 年婚宴上真实存在的人/物/环节 |
| 返潮把它误认成什么 | 残骸生态中的一个功能（承压/过滤/沉积/锚定/清理） |
| 一眼可见的改变 | 重心、轮廓、动作、材料中的哪一项变了，6 米外可读 |
| CRT 里它先变成什么 | 预现态比现实态多出/少掉的那一层 |
| 玩家怎么办 | 玩家用什么动词与它互动（绕开/引开/对照/破像） |

填不完的，不立项。

## 4. 视觉宪法（细则见 `08_美术方向锁定.md`）

- **先真实后异常**：每个空间先作为 2001 年真实营业场所成立，再叠加唯一主异常。
- **喜事层与残骸层分离**：红金婚宴布置（红布、囍字、气球、塑料花）是一层"皮"，蒙在水磨石、瓷砖、水磨石踢脚、荧光灯的建筑"骨"上。返潮过程中喜事层剥落、下垂、被沉积埋住，骨架层显露蠕变。两层在资产上物理分离。
- **PS3 级**的含义：轮廓可读、材质可信、光源实用（荧光灯管、灯箱、CRT 荧光），不是低模借口。
- 禁止：蓝色滤镜、珊瑚藤壶地毯、触手放大、Gore、黑袍蜡烛邪教、数字 glitch。完整清单见 `12_禁止事项与淘汰说明.md`。

## 5. 方法论

- **骨架学 Silent Hill**（空间状态切换、声音先于形象），**血肉学中式县镇**（红金、水磨石、单位制服、公共广播）。
- 电视预现的参照系是"婚礼录像带 + 闭路监控"这一 2001 年真实媒介生态，不是任何西方 analog horror 的像素故障美学。
- Cult 张力的参照系是《仲夏夜惊魂》的"明亮的、集体的、不容拒绝的善意"，但材料全部换成中式喜事：红色、鞭炮、敬酒、闹房、全福人。
