# 音频方向

> 继承《非怪物恐怖：声音与媒介原型 v0.1》的原则（真实底色、无声音惩罚滥用、媒介声学），
> 收编旧稿古海前肢与 G2 海洋馆包的声音清单，统一到三层结构与静默规则之下。

---

## 1. 总纲

- **没有持续背景配乐。** 空间自己发声，音乐只从场景内真实音源（音响、卡拉OK、CRT）发出。
- 一切声音服务于三件事：定位（哪里在变）、预告（预现声先于现实）、压力（议程与静默）。
- 全部声音空间化（PositionalAudio 挂真实声源物体），禁止无源环境音床铺满。

## 2. 三层声场

### 层一：公共声场（正常态铺满，随议程逐层撤走）

宴席人声、碗筷、音响喜歌、婚庆主持暖场、行李车轮、空调、荧光灯电流、后厨、海洋馆水泵与广播。

- **撤场规则**：每项议程推进，撤走一类声源（先人声、再音乐、再器物、最后只剩设备电流）。玩家用耳朵就能知道议程走到哪一档。

### 层二：广播与预现（喜事轴+预现轴的声音）

- 司仪广播：六项议程词 + 催请 + 点名 + 更正议程。全楼喇叭分区播放，喇叭是实体（可被玩家拔线——局部静音，但下一次广播会修复）。
- CRT 提前声：录像里的声音先于现实到达（栏杆弯曲声、叶片合拢声、脚步声）。提前量随同步律收窄，完全同步=事件兑现。
- 母带与录像带：过带噪、抖晃、磁粉脱落声——2001 磁带媒介的真实声学，禁止数字故障音。

### 层三：残骸低频（残骸轴的声音）

- 耐压方向的结构呻吟（远低频，指示压力方向）；
- 附居囊的缓慢滤水声（近距离、细小、湿）；
- 沉积层被踩碎的脆响（玩家自己触发=噪声值反馈）；
- 上宾专属：石灰岩内裂、湿陶片摩擦、过滤叶片密集扫声、排雾低频；
- 禁止：动物吼叫、鲸鸣、昆虫振翅、通用怪兽咆哮、jump scare 音效砸重锤。

## 3. 静默规则

1. **议程收声**：司仪宣布前 3–5 秒，全楼声源按"逐个离场"序列收声（不是统一淡出）。静默=最大警报，玩家习得后仅靠静默即可产生压力。
2. **完成态静默**：空间兑现预现态后，该空间层一声源不再恢复，只剩层三——"这间屋子办完了"。
3. **禁止以静默惩罚**：静默永远是信息，不直接造成伤害；静默期间玩家行动不额外扣噪声值。
4. **全 Demo 唯一谱写乐句**：终局大破像成功、司仪失声的瞬间——一段十几秒的乐句（喜歌旋律的极慢小调变奏，唢呐或双簧管独奏），然后是全 Demo 最长的一段真正安静，玩家走出宴会厅。

## 4. 主题音乐设计

- 主题曲=婚宴喜歌（原创，样式参照 2000 年代喜庆金曲：唢呐+电子琴+合成鼓）。三个版本：
  - A 正常版：开场与迎宾议程，音响播放；
  - B 错误版：渗漏态，同旋律小调化、降速 15%、像隔水播放（低通+失稳抖晃）——喜与丧同构的听觉版；
  - C 终局乐句：见静默规则第 4 条。
- 卡拉OK 点歌机（服务走廊）可被玩家触发作为假声源——播放的是 A 版残段，在返潮后的楼里响起来比任何恐怖音效都瘆人。

## 5. 玩家噪声值反馈

- 地面材质=噪声等级：红毯/红布（安静）< 木地板 < 水磨石/瓷砖 < 金属楼梯/沉积脆层（危险）。
- 玩家鞋声按材质实时切换采样；接近阈值时，最近的喇叭发出轻微馈电嗡声（司仪"注意到了"的预警）——给玩家一次收脚的机会。
- 点名后：全楼喇叭同时报出玩家区域，然后**只留**被点名区域的喇叭继续轻声重复——声音把你圈出来。

## 6. 触发表（接入议程状态机）

| 事件 | 声音序列 |
|------|----------|
| 议程宣布 | 收声(3–5s) → 广播词 → 状态切换应力声（对应空间的蠕变/剥落）→ 层一撤一类 |
| 点名 | 喇叭馈电嗡 → 全楼报区域 → 单区重复 → 侍应改道脚步（匀速，渐近） |
| 破像 | 破坏声（大噪声）→ 屏幕断信号"啪" → 更正议程广播（低速率版） |
| 预现兑现 | CRT 声画异常清晰 1–2s → 失去信号 → 显像管内湿摩擦余声 → 现实事件声接管 |
| 引座 | 侍应"您的位置在这边"（唯一台词）→ 喜歌 B 版渐起 → 落座闷响 |
