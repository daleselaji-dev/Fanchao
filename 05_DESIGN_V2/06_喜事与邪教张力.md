# 喜事与邪教张力 —— 许潮

> 本文规定 cult 恐怖的全部表达手段。
> **红线：没有礼仪玩法。** 玩家永远不会被要求"正确地敬酒""按规矩鞠躬"或在礼节选项里做选择。
> 仪式感全部由场面调度、议程时钟和不可中断性承担，玩家只负责目睹、躲避和逃离。

---

## 1. 许潮是什么

- 蚀湾旧俗：每隔一代人，镇上办一场"许给海"的婚事，保一湾平安。老人不叫它祭祀，叫**办喜事**——这三个字就是全部教义。
- 它没有教堂、没有黑袍、没有咒文。它的载体是每个中国人都认识的东西：红布、囍字、鞭炮、酒席、司仪、全福人、伴娘。**规程藏在正常婚俗的细微偏差里**（见 §3 偏差清单）。
- 1999 年填湾断了海路，蚀湾两年没办成喜事；2001 年这一场是补办，也是最盛大的一场。海这次要亲自赴宴——返潮，就是海来入席。

## 2. 邪教感的四个表达手段（全部可拍、可做、无礼仪玩法）

### 手段一：不容置疑的认真

- 所有宾客真心欢喜。敬酒是真笑，红包是真给，祝词是真诚的。
- 返潮开始后**没有任何人惊慌**：墙在弯、菜在沉积，宾客继续举杯，侍应继续上菜，摄像师继续取景。
- 落地：浮客与侍应的行为状态机在返潮后不改变动作库，只改变材质与速度——"照常"就是最贵的恐怖资产复用。

### 手段二：议程的不可逆

- 六项议程（迎宾→入席→上菜→敬酒→上头→送入洞房）像仪轨一样固定；广播词永远提前让玩家知道下一步——**知道，拦不住**。
- 玩家所有手段（破像、断电、引开）只能拖延一档，广播总会"更正议程"重新宣布。
- 落地：议程状态机只进不退；"更正议程"是同一句广播词的低速率、去混响重录版本，成本=一条音轨。

### 手段三：玩家被包含在仪式里

- 玩家不是旁观者，是仪式的**备件**。开场"借福"取头发、伴娘裙与新娘同料、宴席上玩家有自己的桌牌——中盘看完母带后，这些温情细节全部反转为登记与量体。
- 全场对玩家的态度始终是善意的：侍应抓到玩家不是杀死，是**引座**——"您的位置在这边"。
- 落地：引座失败机制（见 `07` 侍应行为合同）；桌牌、裙料、缠发梳子作为场景可查看物，各配一行文本以内的检视描述。

### 手段四：喜与丧的同构

- 布景细节让玩家逐渐意识到这场喜事按丧事的语法在办：多摆的碗筷、倒扣的第八杯、上宾空席、红布下的白布衬里、喜歌唱到第三段变成哭腔调式（同旋律小调化）。
- 不解释、不点破，全部靠玩家自己发现——发现即恐怖，错过不惩罚。
- 落地：布景差异件清单（G1 目标帧同步锁定），喜歌双版本音轨。

## 3. 偏差清单（正常婚俗 vs 许潮规程）

| 正常婚俗 | 许潮偏差 | 玩家何时可发现 |
|----------|----------|----------------|
| 上头吉语"一梳梳到尾" | "一梳梳到底"（底=海底） | 开场仪式听到的是正常版；22:30 镜中是偏差版 |
| 全福人执木梳 | 骨梳（材质检视可见细密生长纹） | 开场可注视但不点破 |
| 敬酒每桌一杯 | 第八杯泼在地上（敬的不是人） | 敬酒议程演出 |
| 主桌摆新人双席 | 多一副碗筷 + "上宾"空席 | 入席后自由探索 |
| 伴娘裙自选 | 与新娘同料裁制（影子） | 开场文本一句带过；母带后反转 |

| 红布 | 白布衬里 | 渗漏态红布下垂后露出 |

## 4. 议程时钟运行规则（给程序）

- 议程推进由**剧情事件**触发（软时钟），不用真实倒计时；但每项议程内玩家滞留过久时，广播播放"催请"变体（"请各位来宾就座，喜宴马上开始"），提示压力而不惩罚。
- 每项议程宣布时执行固定序列：`全楼收声(3–5s) → 广播词 → 空间状态推进一档 → 实体阶段推进 → CRT 预现内容更新为下一档`。
- 破像挂起：某空间被破像后，该空间跳过本档状态推进，其余空间照常——全楼在变，只有你护住的那间没变，孤岛感是奖励也是恐怖。

## 5. 时间线纪律（用户红线：不许拖长、不许无聊）

- 全部剧情压缩在**一夜之内**（16:00–00:00），Demo 实际游玩 25–35 分钟。
- 六项议程 = 六个节拍，每个节拍必有一个新的空间状态或新实体登场，无空转段落。
- 禁止：多日循环、回忆杀章节、收集全镇背景文本、任何"第二天"。

## 6. 与三轴的关系

- 喜事轴给**时钟与动机**：为什么空间在变（议程推进）、为什么玩家非走不可（影子规则）。
- 预现轴给**信息与恐惧**：席位安排早已写好，屏幕先播给你看。
- 残骸轴给**质感与证据**：海如何赴宴——把酒店当作自己的骸骨认领回去。
- 三轴在终局并轨：司仪宣布"送入洞房"，宴会厅兑现喉道化预现，上宾的过滤叶片从厅顶合拢——洞房就是滤食腔。玩家的大破像（掀翻主桌上宾席 / 砸毁 T03 投影）是唯一的散场方式。
